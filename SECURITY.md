# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request.

Use GitHub's private reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Include what you found, how to reproduce it, and what it exposes.

This covers the website at https://genizahsearch.com, its public API and MCP server, the
desktop application, and this repository (for example a credential or personal data committed
by mistake).

You will get an answer as soon as the report has been looked at. Please give us a reasonable
time to fix the problem before you disclose it.
