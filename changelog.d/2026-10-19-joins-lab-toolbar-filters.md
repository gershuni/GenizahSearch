## [Unreleased] -- Joins Lab: Library and Domain filters in the results toolbar (web, branch `feat/joins-lab-toolbar-filters`)

The website's Joins Lab now shows its Library and Domain filters in the results toolbar, next to Sort, instead of inside the Filter dialog, where they were hard to find (owner, 2026-10-19). Each list shows every value in the results with its count and takes several values. A value kept from an earlier search that none of the new results has stays listed with a count of 0, so it can still be seen and cleared. A choice applies when the list closes, and the clear button undoes it at once. The filter icon is now a "More filters…" button for the rest (material, dimensions, size mismatch, triage, shelfmark), and it shows how many of those are on, e.g. "More filters… (2)". Its Reset leaves Library and Domain as they are. When the filters leave no candidates, the toolbar stays, with "No candidates match these filters.", so they can be undone; before, the grid and its filter button disappeared. The desktop Joins Lab is unchanged. Test: `test_sort_and_filter_by_library_and_domain` in `tests/render_smoke/test_joins_lab_render_smoke.py`.
