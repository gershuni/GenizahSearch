# Accessibility verification scripts and screenshots (2026-04, moved 2026-09-18)

Three Playwright scripts (`verify_a11y.py`, `verify_ltr_layout.py`, `debug_layout_details.py`)
that were run by hand against a live server, and the four screenshots they wrote. Their
self-referential output paths (`verification/<name>.png`) are kept as written; nothing reads them.
They are not pytest tests (`pyproject.toml` collects `test_*.py` only).
