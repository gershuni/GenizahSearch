## 3. זיהוי כפילויות קוד

### 3.1 ייצוא - כפילות משמעותית

**מיקום הקוד:**
- דסקטופ: `genizah_app.py` - מתודות `export_results()`, `_export_as_excel()`, `_export_as_word()`
- אתר: `web/export_service.py` + `web/api.py`

**סוגי כפילות:**
| פונקציה | דסקטופ | אתר |
|---------|--------|-----|
| Excel formatting | `_sanitize_for_excel()` | `sanitize_for_excel()` |
| Word RTL | `_add_docx_highlighted_runs()` | `create_word_export()` |
| Highlighting | שלושה מצבים | שלושה מצבים |
| Filename sanitization | `_sanitize_filename()` | `sanitize_filename()` |

**המלצה:** העברת לוגיקת ייצוא ל-`genizah_core.py` או מודול `export_utils.py` חדש

### 3.2 התאמת Shelfmark

**מיקום:**
- דסקטופ: `genizah_app.py` - `_normalize_shelfmark()`
- אתר: `genizah_core.py` - `normalize_shelfmark()`

**בעיה נוכחית:** הלוגיקה באתר שונה ונותנת תוצאות "רנדומליות" במקום רשימת הצעות

**המלצה:** לסנכרן את הלוגיקה של הדסקטופ לאתר

### 3.3 הדגשת מונחי חיפוש

**מיקום:**
- דסקטופ: `apply_find_highlight()`, `render_asterisks_to_html()`
- אתר: highlighting ב-pages + export

**המלצה:** יצירת מודול `highlighting_utils.py` משותף

### 3.4 טיפול בתמונות

**מיקום:**
- דסקטופ: `ManuscriptViewerWidget`, `ImageLoaderThread`
- אתר: `web/api.py` - endpoints לתמונות

**הבדל:** הדסקטופ טוען תמונות מקומית, האתר עובר דרך proxy
