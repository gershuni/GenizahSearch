# תכנון: חיפוש בסגנון פרויקט השו"ת עבור GenizahSearch

## תאריך: 2026-02-09

---

## 1. סיכום תכונות פרויקט השו"ת

### שלוש רמות חיפוש

| רמה | שם | תיאור |
|------|------|--------|
| 1 | חיפוש בסיסי | מילים צמודות, תו כללני (`*`, `?`), שורש (`%`), ערך (`$`), קידומות (`#`) |
| 2 | חיפוש מתקדם | שורת שאילתה אחת עם תחביר מיוחד למרחקים, חלופות, ומאפיינים |
| 3 | חיפוש טבלאי | טבלה/רשת: כל טור = מרכיב חיפוש + חלופות, עם מרחקים ומאפיינים |

### תכונות עיקריות (מהתיעוד שסופק)

#### א. מרחק בין מילים (Proximity)
- **צמודות**: מילים ברצף (ברירת מחדל)
- **מרחק מספרי**: `נר [4:1] שבת` — המילה השנייה במקום 1-4 אחרי הראשונה
- **מרחק דו-כיווני**: `חכמים [1:2-] תקנו` — גם לפני וגם אחרי
- **מרחק אחיד**: `10: עגונה גוי עדות` — כל המילים בטווח של 10 מילים
- **טווחים**: `משפט:`, `פסקה:`, `מסמך:` — חיפוש בטווח מבני

#### ב. מילים חלופיות (OR)
- סוגריים עגולים עם לוכסן: `(עץ/אילן/נטיעה)`
- שילוב עם מרחק: `(קוצץ/עוקר/משחית) [3:1] (עץ/אילן/נטיעה)`

#### ג. מאפיינים (Modifiers)
| סימן | מאפיין | תיאור |
|-------|---------|--------|
| `*` לפני | קידומות | כל תחיליות אפשריות |
| `*` אחרי | סיומות | כל סיומות אפשריות |
| `#` לפני | קידומות דקדוקיות | אותיות שימוש: ו, ה, ב, כ, ל, מ, ש |
| `!` לפני | כתיב מלא/חסר | מילה בשתי צורות כתיבה |
| `%` | שורש | כל נטיות השורש |
| `$` | ערך | כל צורות הערך המילוני |
| `+` | גרשיים | מצא עם/בלי סימן ראשי תיבות |
| `@` | ריק | אות אופציונלית: `טר(י/@)פה` = טריפה או טרפה |

#### ד. אותיות מאפיינות (Wildcard Pattern)
- `*פ*ט*ר*פ*` — מוצא כל הצורות של "אפוטרופוס"
- `*ו*נ*צ*י*` — מוצא כל הכתיבים של "ונציה"

#### ה. חילופי אותיות בתוך מילה
- `אירו(ס/ש)ין` — מוצא אירוסין וגם אירושין

#### ו. שלילה (NOT)
- מרכיב שלילה: מסנן תוצאות שמכילות מילה מסוימת

#### ז. חיפוש טבלאי — ממשק הרשת
- 3 טורים, כל טור עם 4 שורות (מילה עיקרית + 3 חלופות)
- בין הטורים: שדה מרחק + כיוון ("לפי הסדר")
- לכל מילה: מאפיינים (קידומות דקדוקיות, סיומות, כתיב, שורש, ערך, שלילה)
- אפשרויות טווח: מילים, משפט, פסקה, מסמך

## 2. מצב קיים ב-GenizahSearch

### מצבי חיפוש נוכחיים
1. **מדויק** (`=`) — התאמה מדויקת
2. **וריאנטים** (`?`/`??`/`???`) — החלפות תווים (30/70/150 זוגות)
3. **עמום** (`~`) — fuzzy עם edit distance
4. **רגקס** (`/`) — ביטוי רגולרי
5. **סימן מדף** (`#`) — חיפוש לפי מספר קטלוגי
6. **כותרת** (`$`) — חיפוש לפי כותר

### תכונות מתקדמות קיימות
- **Gap** (0-10): מרחק בין מילים (חד-כיווני)
- **מילות שלילה**: סינון תוצאות לפי מילים לא רצויות
- **Lab Mode**: חיפוש מבוסס fingerprint
- **Deep Scan**: סריקה מורחבת
- **Boundary Crossing**: חיפוש חוצה גבולות פסקה

## 3. מה **כבר קיים** ב-GenizahSearch (מיפוי לפרויקט השו"ת)

| תכונת פרויקט השו"ת | מקבילה ב-GenizahSearch | הערות |
|---------------------|------------------------|-------|
| ביטוי (מילים צמודות) | חיפוש מדויק (gap=0) | ✅ קיים |
| מרחק בין מילים | Gap (0-10) | ✅ קיים, אך חד-כיווני בלבד |
| כתיב מלא/חסר | וריאנטים | ✅ קיים (רחב יותר — כולל גם החלפות דומות) |
| קידומות/סיומות (wildcard) | רגקס | ✅ קיים דרך regex |
| שלילת מרכיב | Exclude Words | ✅ קיים |
| טווח: מסמך | Boundary Crossing | ✅ קיים חלקית |

## 4. מה **חסר** (הפער)

| תכונת פרויקט השו"ת | חסר ב-GenizahSearch | עדיפות |
|---------------------|---------------------|--------|
| **מילים חלופיות (OR)** | אין תחביר `(מילה1/מילה2)` | גבוהה |
| **מרחק דו-כיווני** | Gap הוא חד-כיווני | בינונית |
| **ממשק טבלאי** | אין — רק שורת חיפוש אחת | גבוהה (UI) |
| **קידומות דקדוקיות** | אין — וריאנטים לא מטפלים באותיות שימוש | בינונית |
| **שורש / ערך** | אין מנוע מורפולוגי | נמוכה (דורש מילון) |
| **חילופי אותיות בתוך מילה** | `(ס/ש)` — אין תחביר | בינונית |
| **אותיות מאפיינות** | `*פ*ט*ר*פ*` — אפשרי ברגקס | נמוכה |
| **טווח: משפט/פסקה** | אין הגדרות טווח מבניות | נמוכה |

## 5. המלצה: מה לשלב (MVP)

### עקרון מנחה
הממשק צריך להיות **מוכר למשתמשי פרויקט השו"ת** אך מותאם לקורפוס הגניזה (טקסטים קצרים, מקוטעים, כתיב לא אחיד). לא צריך לשכפל את כל התכונות — רק את הבסיס השימושי.

### Phase 1: חיפוש בסגנון שו"ת — בסיס (MVP)

#### 1. ממשק טבלאי (Tabular Search UI)
- **3 טורים** (מרכיבי חיפוש)
- **כל טור**: שדה עיקרי + 2-3 שורות חלופות (OR)
- **בין הטורים**: שדה מרחק (מספרי, 0-20)
- **צ'קבוקס "לפי הסדר"**: האם סדר המילים חשוב
- **כפתור חיפוש** בתחתית

#### 2. מילים חלופיות (OR Groups)
- ממומש דרך הטורים — כל שורה בטור היא חלופה
- בתחביר שורה: `(מילה1/מילה2/מילה3)` אם המשתמש מעדיף
- תרגום אוטומטי מהטבלה לשאילתה

#### 3. מרחק דו-כיווני
- שדרוג ה-Gap הקיים: אפשרות למרחק שלילי (המילה השנייה יכולה להופיע לפני הראשונה)
- ברירת מחדל: דו-כיווני (כמו בפרויקט השו"ת)

#### 4. וריאנטים כמאפיין (לא כמצב חיפוש)
- במקום לבחור "מצב וריאנטים" לכל החיפוש — צ'קבוקס **לכל מרכיב** בטבלה
- מאפשר חיפוש מעורב: מילה אחת מדויקת + מילה שנייה עם וריאנטים

#### 5. קידומות דקדוקיות (בסיסי)
- צ'קבוקס "קידומות" לכל מרכיב
- מוסיף אוטומטית את אותיות השימוש: ו, ה, ב, כ, ל, מ, ש, וצירופיהן
- מימוש: הרחבה אוטומטית ל-OR group

### Phase 2: שיפורים (עתידי)

- חילופי אותיות בתוך מילה: `אירו(ס/ש)ין`
- טווח מבני: משפט / פסקה / מסמך
- שלילה per-component (לא רק כללית)
- ייצוא/שמירת שאילתות

## 7. מיפוי טכני

### שינויים נדרשים

#### `genizah_core.py` — מנוע החיפוש
1. **`build_tantivy_query()`** — תמיכה ב-OR groups (כבר מבנה OR פנימית לוריאנטים, צריך להרחיב)
2. **`build_regex_pattern()`** — תמיכה במרחק דו-כיווני (A.*B | B.*A)
3. **פונקציה חדשה: `expand_prefixes(word)`** — מחזירה רשימת מילים עם קידומות דקדוקיות
4. **פונקציה חדשה: `parse_tabular_query(columns, distances, options)`** — מתרגם טבלה לשאילתת Tantivy

#### `web/pages/search.py` — ממשק המשתמש
1. **Tab/Panel חדש**: "חיפוש בסגנון שו"ת" — ממשק הטבלה
2. **תרגום טבלה → שאילתה**: לוגיקה שמתרגמת את קלט הטבלה לפורמט שהמנוע מבין
3. **שימוש חוזר**: תוצאות מוצגות באותו אזור תוצאות קיים

#### קבצים חדשים (אפשרי)
- `web/components/tabular_search.py` — קומפוננטת הטבלה (אופציונלי, אפשר גם inline)

## 9. סיכום

### מה מומלץ לשלב (בסיס):
1. **ממשק טבלאי** — 3 טורים עם חלופות ומרחקים
2. **מילים חלופיות** — OR groups
3. **מרחק דו-כיווני** — שדרוג ה-Gap הקיים
4. **וריאנטים per-component** — צ'קבוקס לכל מרכיב
5. **קידומות דקדוקיות** — הרחבה אוטומטית של אותיות שימוש

### מה **לא** לשלב (בשלב זה):
- שורש / ערך (דורש מילון מורפולוגי מלא)
- משפחות מילים (תשתית ייעודית)
- חיפוש שמור / שאילתות קודמות (כבר יש history בדפדפן)
- גרשיים / ראשי תיבות (פחות רלוונטי לגניזה)
