## 1. סיכום תכונות פרויקט השו"ת

### שלוש רמות חיפוש

| רמה | שם | תיאור |
|------|------|--------|
| 1 | חיפוש בסיסי | מילים צמודות, תו כללני (`*`, `?`), שורש (`%`), ערך (`$`), קידומות (`#`) |
| 2 | חיפוש מתקדם | שורת שאילתה אחת עם תחביר מיוחד למרחקים, חלופות, ומאפיינים |
| 3 | חיפוש טבלאי | טבלה/רשת: כל טור = מרכיב חיפוש + חלופות, עם מרחקים ומאפיינים |

### תכונות עיקריות (מהתיעוד שסופק)

#### א. מרחק בין מילים (Proximity)
- **צמודות**: מילים ברצף (ברירת מחדל)
- **מרחק מספרי**: `נר [4:1] שבת` — המילה השנייה במקום 1-4 אחרי הראשונה
- **מרחק דו-כיווני**: `חכמים [1:2-] תקנו` — גם לפני וגם אחרי
- **מרחק אחיד**: `10: עגונה גוי עדות` — כל המילים בטווח של 10 מילים
- **טווחים**: `משפט:`, `פסקה:`, `מסמך:` — חיפוש בטווח מבני

#### ב. מילים חלופיות (OR)
- סוגריים עגולים עם לוכסן: `(עץ/אילן/נטיעה)`
- שילוב עם מרחק: `(קוצץ/עוקר/משחית) [3:1] (עץ/אילן/נטיעה)`

#### ג. מאפיינים (Modifiers)
| סימן | מאפיין | תיאור |
|-------|---------|--------|
| `*` לפני | קידומות | כל תחיליות אפשריות |
| `*` אחרי | סיומות | כל סיומות אפשריות |
| `#` לפני | קידומות דקדוקיות | אותיות שימוש: ו, ה, ב, כ, ל, מ, ש |
| `!` לפני | כתיב מלא/חסר | מילה בשתי צורות כתיבה |
| `%` | שורש | כל נטיות השורש |
| `$` | ערך | כל צורות הערך המילוני |
| `+` | גרשיים | מצא עם/בלי סימן ראשי תיבות |
| `@` | ריק | אות אופציונלית: `טר(י/@)פה` = טריפה או טרפה |

#### ד. אותיות מאפיינות (Wildcard Pattern)
- `*פ*ט*ר*פ*` — מוצא כל הצורות של "אפוטרופוס"
- `*ו*נ*צ*י*` — מוצא כל הכתיבים של "ונציה"

#### ה. חילופי אותיות בתוך מילה
- `אירו(ס/ש)ין` — מוצא אירוסין וגם אירושין

#### ו. שלילה (NOT)
- מרכיב שלילה: מסנן תוצאות שמכילות מילה מסוימת

#### ז. חיפוש טבלאי — ממשק הרשת
- 3 טורים, כל טור עם 4 שורות (מילה עיקרית + 3 חלופות)
- בין הטורים: שדה מרחק + כיוון ("לפי הסדר")
- לכל מילה: מאפיינים (קידומות דקדוקיות, סיומות, כתיב, שורש, ערך, שלילה)
- אפשרויות טווח: מילים, משפט, פסקה, מסמך

## 2. מצב קיים ב-GenizahSearch

### מצבי חיפוש נוכחיים
1. **מדויק** (`=`) — התאמה מדויקת
2. **וריאנטים** (`?`/`??`/`???`) — החלפות תווים (30/70/150 זוגות)
3. **עמום** (`~`) — fuzzy עם edit distance
4. **רגקס** (`/`) — ביטוי רגולרי
5. **סימן מדף** (`#`) — חיפוש לפי מספר קטלוגי
6. **כותרת** (`$`) — חיפוש לפי כותר

### תכונות מתקדמות קיימות
- **Gap** (0-10): מרחק בין מילים (חד-כיווני)
- **מילות שלילה**: סינון תוצאות לפי מילים לא רצויות
- **Lab Mode**: חיפוש מבוסס fingerprint
- **Deep Scan**: סריקה מורחבת
- **Boundary Crossing**: חיפוש חוצה גבולות פסקה

## 5. גישה: צ'קבוקס "מצב פרויקט השו"ת"

### עקרון מנחה
**במקום** קיצורי דרך (prefix shortcuts) כמו `?`, `=`, `~`, `/`, `#`, `$` — **צ'קבוקס יחיד** שמפעיל את תחביר פרויקט השו"ת ישירות בשדה החיפוש הראשי.

### למה זה עדיף:
1. **פשוט** — המשתמש לא צריך לזכור prefixes
2. **מוכר** — משתמשי פרויקט השו"ת יזהו את התחביר מיד
3. **ללא קונפליקטים** — כשהצ'קבוקס פעיל, `*`, `#`, `(/)` מקבלים את משמעות השו"ת
4. **נשאר מקום** — מצבים אחרים (Regex, Shelfmark, Title) זמינים דרך ה-dropdown כשהצ'קבוקס כבוי

### מה קורה כשהצ'קבוקס פעיל:

| תחביר | משמעות | דוגמה | תרגום פנימי |
|--------|--------|-------|-------------|
| `מילה` | חיפוש מדויק | `שלום` | כמו exact |
| `מילה*` | כל מה שמתחיל ב... | `שלום*` | regex: `שלום\S*` |
| `*מילה` | כל מה שנגמר ב... | `*נדר` | regex: `\S*נדר` |
| `*א*ב*ג*` | אותיות מאפיינות | `*פ*ט*ר*פ*` | regex: `\S*פ\S*ט\S*ר\S*פ\S*` |
| `#מילה` | קידומות דקדוקיות | `#שלום` | OR: `(שלום\|ושלום\|השלום\|בשלום\|...)` |
| `(א/ב/ג)` | מילים חלופיות | `(עץ/אילן/נטיעה)` | OR group |
| `מילה(א/ב)מילה` | חילופי אותיות | `אירו(ס/ש)ין` | regex: `אירו[סש]ין` |
| רווח | מילים צמודות | `נר שבת` | כמו gap=0 |

### שילוב עם תכונות קיימות:
- **Gap** — נשאר כמו שהוא (שדה מספרי)
- **וריאנטים** — צ'קבוקס נפרד (סימון/כתיב) **על גבי** שאר החיפוש
- **Exclude Words** — נשאר כמו שהוא
- **Dropdown מצבים** — נשאר, אבל ללא prefix shortcuts. כשצ'קבוקס שו"ת פעיל, ה-dropdown מוסתר/לא רלוונטי

## 7. פירוט טכני — עיבוד שאילתה במצב שו"ת

### שלב 1: פרסור (Parse)

פונקציה חדשה `parse_responsa_query(query_str)` שמפרקת את השאילתה למרכיבים:

```python
# קלט: "#(קוצץ/עוקר/משחית) (עץ/אילן/נטיעה)*"
# פלט:
[
    {
        'type': 'or_group',
        'words': ['קוצץ', 'עוקר', 'משחית'],
        'prefix': True,    # # = קידומות דקדוקיות
        'wildcard': None
    },
    {
        'type': 'or_group',
        'words': ['עץ', 'אילן', 'נטיעה'],
        'prefix': False,
        'wildcard': 'suffix'  # * אחרי = סיומות
    }
]
```

### שלב 2: הרחבה (Expand)

כל מרכיב מורחב ל-terms ו-regex:

#### כוכביות `*`
```python
def expand_wildcard(word, wildcard_type):
    if wildcard_type == 'suffix':     # מילה*
        return rf'{re.escape(word)}\S*'
    elif wildcard_type == 'prefix':   # *מילה
        return rf'\S*{re.escape(word)}'
    elif wildcard_type == 'pattern':  # *א*ב*ג*
        chars = [c for c in word if c != '*']
        return r'\S*' + r'\S*'.join(re.escape(c) for c in chars) + r'\S*'
```

#### סולמיות `#` (קידומות דקדוקיות)
```python
GRAMMATICAL_PREFIXES = [
    '',                          # ללא קידומת
    'ו', 'ה', 'ב', 'כ', 'ל', 'מ', 'ש',  # בודדות
    'וה', 'וב', 'וכ', 'ול', 'ומ', 'וש',  # צירופים נפוצים
    'שה', 'שב', 'שכ', 'של', 'שמ',
    'בש', 'לכ', 'מה',
    'כש', 'כשה', 'לכש',
    'משה', 'ושה', 'ובש',
]

def expand_grammatical_prefixes(word):
    """#מילה → רשימת מילים עם קידומות"""
    return [prefix + word for prefix in GRAMMATICAL_PREFIXES]
```

#### לוכסנים `(/)` (חלופות)
```python
def parse_alternatives(token):
    """(עץ/אילן/נטיעה) → ['עץ', 'אילן', 'נטיעה']"""
    if token.startswith('(') and token.endswith(')'):
        inner = token[1:-1]
        return inner.split('/')
    return [token]

def parse_inline_alternatives(word):
    """אירו(ס/ש)ין → regex: אירו[סש]ין"""
    # מוצא (X/Y) בתוך מילה
    pattern = r'\(([^)]+)\)'
    def replace_alt(m):
        chars = m.group(1).split('/')
        if all(len(c) == 1 for c in chars):
            return f'[{"".join(chars)}]'  # character class
        return f'({"".join(chars)})'  # alternation
    return re.sub(pattern, replace_alt, word)
```

### שלב 3: בניית שאילתה (Build)

המרכיבים המורחבים מועברים ל-`build_tantivy_query()` ו-`build_regex_pattern()` הקיימים, כשכל OR group הופך ל-`(" " OR " " OR " ")` ב-Tantivy.

## 8. מיפוי טכני — שינויים נדרשים

### `genizah_core.py` — מנוע החיפוש
1. **פונקציה חדשה: `parse_responsa_query(query_str)`** — מפרק תחביר שו"ת למרכיבים
2. **פונקציה חדשה: `expand_grammatical_prefixes(word)`** — מרחיב אותיות שימוש
3. **פונקציה חדשה: `expand_wildcard(word)`** — מתרגם `*` ל-regex
4. **פונקציה חדשה: `parse_alternatives(token)`** — מפרק `(א/ב/ג)`
5. **שדרוג: `build_tantivy_query()`** — תמיכה ב-OR groups (כבר מבנה OR פנימית, צריך להרחיב)
6. **שדרוג: `build_regex_pattern()`** — תמיכה ב-wildcards ו-alternations
7. **שדרוג: `execute_search()`** — פרמטר `responsa_mode=False` שמפעיל את הפרסור החדש

### `web/pages/search.py` — ממשק המשתמש
1. **צ'קבוקס "מצב פרויקט השו"ת"** — ליד שדה החיפוש
2. **צ'קבוקס "וריאנטים"** — נפרד, פועל על גבי מצב שו"ת
3. **הסתרת dropdown** — כשמצב שו"ת פעיל, dropdown המצבים מוסתר
4. **עזרה**: tooltip/expansion עם תחביר שו"ת
5. **תצוגה מקדימה**: (אופציונלי) מראה את השאילתה המורחבת

### `web/pages/search.py` — ממשק טבלאי (Phase 2)
1. **Expansion panel** חדש: "חיפוש טבלאי"
2. **3 טורים × 4 שורות** — קלט מובנה
3. **שדות מרחק** בין הטורים
4. **צ'קבוקסים per-component** — וריאנטים, קידומות
5. **תרגום טבלה → שאילתת שו"ת** → הרצה דרך אותו מנוע

- משפחות מילים (תשתית ייעודית)

- גרשיים / ראשי תיבות (פחות רלוונטי לגניזה)

## 11. דוגמאות שימוש

### דוגמה 1: חיפוש מילה עם קידומות דקדוקיות
```
קלט:    #שלום
מורחב:  (שלום|ושלום|השלום|בשלום|כשלום|לשלום|משלום|ששלום|והשלום|...)
```

### דוגמה 2: חלופות עם wildcards
```
קלט:    (קוצץ/עוקר/משחית) (עץ/אילן)*
מורחב:  (קוצץ|עוקר|משחית) (עץ\S*|אילן\S*)
מוצא:   "קוצץ אילנות", "עוקר עצים", "משחית אילני"
```

### דוגמה 3: אותיות מאפיינות
```
קלט:    *פ*ט*ר*פ*
regex:  \S*פ\S*ט\S*ר\S*פ\S*
מוצא:   "אפוטרופוס", "אפטרופס", "אפוטרפוס", "פוטרופא"
```

### דוגמה 4: חילופי אותיות
```
קלט:    אירו(ס/ש)ין
regex:  אירו[סש]ין
מוצא:   "אירוסין", "אירושין"
```

### דוגמה 5: שילוב קידומות + חלופות + gap
```
קלט:    #(קוצץ/עוקר) (עץ/אילן)     gap=3
מורחב:  (קוצץ|וקוצץ|הקוצץ|...|עוקר|ועוקר|...) ... (עץ|אילן)
מוצא:   "הקוצץ את האילן", "ועוקר שלושה עצים"
```

### דוגמה 6: שילוב עם וריאנטים (צ'קבוקס)
```
קלט:    #שלום        + ☑ וריאנטים
שלב 1:  קידומות → (שלום|ושלום|השלום|בשלום|...)
שלב 2:  וריאנטים → (שלום|סלום|שלו|ושלום|וסלום|...)
מוצא:   "שלו", "השלום", "בסלום" (צירוף קידומות + חילופי כתיב)
```
