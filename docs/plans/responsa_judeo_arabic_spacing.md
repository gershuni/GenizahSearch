## 1. ערבית יהודית — אל הידיעה (אל-)

### מה נמצא בקורפוס בפועל

מתוך הטרנסקריפציות (`Transcriptions_part.txt`) — **אל- מופיע כמעט בכל שורה**:

```
אללסאן    (al-lisan = הלשון)
אלהלקום   (al-halqum = הגרון)
אלאסנאן   (al-asnan = השיניים)
אלמרפיין  (al-mirfaʿain = המרפקיים)
אלשפתין   (al-shafatain = השפתיים)
אלחרוף    (al-huruf = האותיות)
אלכלמה    (al-kalima = המילה)
אלשוא     (al-shva = השווא)
אלמכתוב   (al-maktub = הכתוב)
אלואו     (al-waw = הוא"ו)
```

### צירופי מילת יחס + אל-

בערבית יהודית מילות היחס נדבקות ל-אל:

| צירוף | משמעות | דוגמה מהקורפוס |
|--------|--------|---------------|
| **באל** | ב + ה | `באלאסנאן` (בשיניים) |
| **ואל** | ו + ה | `ואלנקטה` (והנקודה) |
| **פאל** / **פי אל** | ב/בתוך + ה | `פי אלמלא` (במילוי) |
| **לאל** | ל + ה | (פחות נפוץ, בד"כ נפרד) |
| **כאל** | כ + ה | (פחות נפוץ) |
| **מן אל** | מ + ה | (בד"כ שתי מילים נפרדות) |
| **עלי אל** | על + ה | `עלי אלף` (על אלף) |

### אותיות שמשיות (حروف شمسية) — הטמעת ה-ל

בערבית, לפני "אותיות שמשיות" ה-ל של אל- נבלעת ומוכפלת:
- אל + שמס → **אשׁשׁמס** (השמש) — ה-ל נעלמת
- אל + דאר → **אדדאר** (הבית)
- אל + נאס → **אננאס** (האנשים)
- אל + תורה → **אתתורה**

**אותיות שמשיות בכתב עברי**: ת, ד, ר, ז, ס, ש, צ, ט, ל, נ

**אבל** — בכתבי יד של הגניזה הכתיב **לא עקבי**. לפעמים כותבים `אלשוא` (עם ל) ולפעמים `אששוא` (בלי ל, עם הכפלה). לכן צריך לחפש **את שתי הצורות**.

### המלצה: הרחבת `#` עבור ערבית יהודית

**גישה א' — הרחבת רשימת הקידומות הקיימת:**

```python
HEBREW_PREFIXES = ['', 'ו', 'ה', 'ב', 'כ', 'ל', 'מ', 'ש',
                   'וה', 'וב', 'וכ', 'ול', 'ומ', 'כש', ...]

JUDEO_ARABIC_PREFIXES = [
    'אל',                         # אל הידיעה
    'ואל', 'באל', 'פאל', 'כאל',  # מילת יחס + אל
    'לל',                         # ל + אל → לל (נפוץ)
]

# כשמצב שו"ת פעיל: # משתמש בשני הסטים
ALL_PREFIXES = HEBREW_PREFIXES + JUDEO_ARABIC_PREFIXES
```

**גישה ב' — סימן נפרד לערבית יהודית (מומלצת):**

| סימן | משמעות | דוגמה |
|-------|--------|-------|
| `#` | קידומות עבריות בלבד | `#שלום` → שלום, ושלום, השלום... |
| `##` | קידומות עבריות **+** ערבית יהודית | `##כלמה` → כלמה, אלכלמה, ואלכלמה, באלכלמה... |

**או לחלופין** — צ'קבוקס "כולל ערבית יהודית" שמשפיע על `#`:

```
☑ מצב שו"ת    ☐ וריאנטים    ☑ ערבית יהודית    Gap: [3]
```

**גישה ב' עדיפה** כי:
1. לא מנפחת שאילתות עבריות (שהן רוב החיפושים)
2. מפורשת — המשתמש יודע שהוא מחפש גם בערבית יהודית
3. מאפשרת שליטה

### מימוש הרחבת אל-:

```python
def expand_judeo_arabic_prefixes(word):
    """##כלמה → כל הצורות עם אל הידיעה וצירופיו"""
    forms = [word]  # המילה עצמה

    # אל הידיעה רגיל
    forms.append('אל' + word)

    # מילות יחס + אל
    for prep in ['ו', 'ב', 'פ', 'כ', 'ל']:
        forms.append(prep + 'אל' + word)

    # הטמעת אותיות שמשיות (אם המילה מתחילה באות שמשית)
    SUN_LETTERS = set('תדרזסשצטלנ')
    if word and word[0] in SUN_LETTERS:
        first = word[0]
        # אל + שמש → אשׁשׁמש (הכפלת האות הראשונה)
        forms.append('א' + first + word)  # אששמש
        # + מילות יחס
        for prep in ['ו', 'ב', 'פ', 'כ', 'ל']:
            forms.append(prep + 'א' + first + word)

    return forms
```

**דוגמה:**
```
##שוא  →  שוא, אלשוא, ואלשוא, באלשוא, אששוא, ואששוא, ...
##כלמה →  כלמה, אלכלמה, ואלכלמה, באלכלמה, פאלכלמה, ...
         (כ אינה אות שמשית — אין הטמעה)
```

## 2. רווחים שגויים — בעיית חלוקת המילים

### מה קורה בפועל

השוואת **אותו קטע** בשתי קריאות שונות (שורות 10 vs 87):

```
קריאה א': ]רת אללסאן ממא ילי אלהלקום דט'ר נגג מחדהא
קריאה ב': תלת אללסאן ממא ילי אלזולקום דטר  נמ  מחדהא
                                    ^^^^^^^^   ^^^^
                                    אלהלקום    דט'ר נגג
                                    אלזולקום   דטר נמ
```

ודוגמה של **רווח שגוי** (שורה 104):
```
קדיגי אליוד    ←  צריך להיות: קד יגי אליוד (שתי מילים)
```

ודוגמה הפוכה — **מילה שנפרדה בטעות** (שורה 46):
```
המצפונפיס    ←  מילים שהתמזגו לאחת
```

### סוגי הבעיה

| סוג | דוגמה | מה קרה |
|-----|-------|--------|
| **מילים שהתחברו** | `קדיגי` במקום `קד יגי` | OCR/קורא לא שם רווח |
| **מילה שנפרדה** | `אל כלמה` במקום `אלכלמה` | OCR/קורא הוסיף רווח |
| **גבול שזז** | `ביתד ין` במקום `בית דין` | הרווח במקום הלא נכון |

### שלוש גישות לפתרון

#### גישה א': רווחים גמישים (Space-Flexible Regex) — **מומלצת ל-MVP**

**רעיון**: צ'קבוקס "רווחים גמישים" שגורם לרווחים בשאילתה להיות **אופציונליים** ב-regex.

```python
# רגיל (gap=0):
sep = r'[^\w\u0590-\u05FF\']+'     # רווח חובה בין מילים

# רווחים גמישים:
sep = r'[^\w\u0590-\u05FF\']*'     # רווח אופציונלי (אפס או יותר)
#                              ^ כוכבית במקום פלוס
```

**מה זה נותן:**
```
שאילתה:   בית דין      + ☑ רווחים גמישים
regex:    בית[^\w]*דין
מוצא:    "בית דין" ✓   "ביתדין" ✓   "ביתד ין" ✓
```

**מימוש — שינוי מינימלי:**
```python
# genizah_core.py — build_regex_pattern()
if flexible_spaces:
    sep = r'[^\w\u0590-\u05FF\']*'   # zero or more
else:
    sep = r'[^\w\u0590-\u05FF\']+'   # one or more (default)
```

**יתרונות**: שינוי של תו אחד (`+` → `*`), עובד עם כל מנגנוני החיפוש הקיימים
**חסרונות**: לא מטפל במילה שנפרדה לשתיים כשהן לא סמוכות

#### גישה ב': חיפוש דו-מסלולי (Dual-Track Search)

**רעיון**: להריץ שני חיפושים במקביל — אחד רגיל ואחד על טקסט **ללא רווחים**.

```python
def search_with_flexible_spacing(query, text):
    # מסלול 1: חיפוש רגיל
    results_normal = regex_search(query, text)

    # מסלול 2: חיפוש ללא רווחים
    stripped_text = text.replace(' ', '').replace('\n', '')
    stripped_query = query.replace(' ', '')
    results_stripped = regex_search(stripped_query, stripped_text)

    # מיזוג תוצאות (עם deduplication)
    return merge(results_normal, results_stripped)
```

**יתרונות**: מוצא כל סוגי בעיות הרווחים — הן מילים שהתחברו והן מילים שנפרדו
**חסרונות**:
- דורש אינדקס Tantivy נוסף (שדה `content_nospaces`) **או** סריקה כפולה
- ה-highlighting מורכב (צריך למפות חזרה מטקסט ללא רווחים לטקסט מקורי)
- כפל זמן חיפוש

#### גישה ג': N-gram Index (ברמת תווים)

**רעיון**: לאנדקס את הטקסט כ-character n-grams (trigrams/4-grams) ב-Tantivy.

```
"בית דין" → trigrams: "בית", "יתד", "תדי", "דין"
            (הרווח לא חלק מה-ngram)
```

**יתרונות**: פותר את בעיית הרווחים באופן מהותי, עובד גם ל-fuzzy
**חסרונות**: אינדקס גדול הרבה יותר, precision נמוכה (הרבה false positives), דורש שינוי בנוי באינדקס

## 3. המלצה משולבת — מה לאמץ

### עבור MVP (Phase 1):

```
☑ מצב שו"ת    ☐ וריאנטים    ☐ ערבית יהודית    ☐ רווחים גמישים    Gap: [3]
```

| תכונה | גישה | היקף | עדיפות |
|--------|------|------|--------|
| **אל הידיעה** | `##` או צ'קבוקס "ערבית יהודית" | ~40 שורות (expand function) | גבוהה |
| **אותיות שמשיות** | הטמעה ב-expand function | ~15 שורות (כלול למעלה) | גבוהה |
| **רווחים גמישים** | צ'קבוקס — `+` → `*` ב-separator | ~5 שורות (!) | גבוהה |
| חיפוש ללא רווחים | שדה Tantivy נוסף | שינוי באינדקס | נמוכה (Phase 2) |
| N-gram index | אינדקס חדש | שינוי מבני | נמוכה (Phase 3) |

### שלושת הצ'קבוקסים יעבדו **יחד**:

```
דוגמה:  ##כלמה     + ☑ וריאנטים + ☑ רווחים גמישים

שלב 1 — ערבית יהודית:
  כלמה, אלכלמה, ואלכלמה, באלכלמה, ...

שלב 2 — וריאנטים (per expanded term):
  כלמה→כלמא, כלמת, ...
  אלכלמה→אלכלמא, אלכלמת, ...

שלב 3 — Tantivy OR group:
  ("כלמה"^5 OR "אלכלמה" OR "כלמא" OR "אלכלמא" OR ...)

שלב 4 — Regex (רווחים גמישים):
  (כלמה|אלכלמה|כלמא|...) + separator: [^\w]*  (אופציונלי)
```

## 4. דוגמאות שימוש מציאותיות

### דוגמה 1: חיפוש מונח דקדוקי בערבית יהודית
```
שאילתה:  ##שוא
מורחב:   שוא | אלשוא | ואלשוא | אששוא | ואששוא | באלשוא
מוצא:    "פצל פי אלכלאם עלי אלשוא" ✓
          "ואלשוא אלסאכן" ✓
```

### דוגמה 2: מילה שאולי נדבקה/נפרדה
```
שאילתה:  בית דין          + ☑ רווחים גמישים
regex:    בית[^\w]*דין
מוצא:    "בית דין" ✓   "ביתדין" ✓   "ביתד ין" ✓
```

### דוגמה 3: שילוב מלא
```
שאילתה:  ##(חרוף/אותיות) ##(כלמה/מלה)     + ☑ וריאנטים + ☑ רווחים גמישים + gap=3
מורחב:   (חרוף|אלחרוף|ואלחרוף|...|אותיות|...) gap≤3 (כלמה|אלכלמה|...|מלה|אלמלה|...)
מוצא:    "אלחרוף קאל אנהא... אלכלמה" ✓
          "מחאל אלארוף א אלחרוף" ✓ (רווח גמיש + וריאנט ארוף/חרוף)
```
