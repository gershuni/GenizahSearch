## תאריך: 2026-02-09

## רקע: למה זה חשוב

קורפוס גניזת קהיר אינו קורפוס עברי טהור. חלק משמעותי מכתבי היד — מכתבים, חיבורים מדעיים, פירושים, שטרות — כתובים ב**ערבית יהודית** (Judeo-Arabic): שפה ערבית בכתב עברי. זו שפת היומיום של יהודי ארצות האסלאם מהמאה ה-9 ועד ה-19.

חיפוש טקסט בקורפוס כזה מחייב הבנה של שתי תופעות:
1. **אל הידיעה** — ה-definite article הערבי שנדבק לתחילת המילה (וצירופיו עם מילות יחס)
2. **רווחים שגויים** — בעיית OCR/קריאה שבה גבולות המילים לא תואמים את המקור

שתי הבעיות הללו **לא קיימות** בפרויקט השו"ת (שמטפל בטקסטים עבריים מודפסים) ולכן הן דורשות התאמה ייחודית ל-GenizahSearch.

## 1. ערבית יהודית — אל הידיעה (אל-)

### מה זה אל הידיעה?

ה-"אל" (ال بالعربية) הוא ה-definite article בערבית — המקביל ל-"ה" הידיעה בעברית. בערבית יהודית הוא נכתב באותיות עבריות: **אל**. הוא נדבק לתחילת השם העצם כמילה אחת.

| עברית | ערבית יהודית | תעתיק | הסבר |
|-------|-------------|--------|------|
| **ה**לשון | **אל**לסאן | al-lisān | "ה" → "אל" |
| **ה**שיניים | **אל**אסנאן | al-asnān | |
| **ה**מילה | **אל**כלמה | al-kalima | |
| **ה**אותיות | **אל**חרוף | al-ḥurūf | |

### מה נמצא בקורפוס בפועל

מתוך הטרנסקריפציות של כתבי יד אמיתיים (`Transcriptions_part.txt`) — **אל- מופיע כמעט בכל שורה** בטקסטים ערביים-יהודיים:

```
אללסאן    (al-lisān    = הלשון)
אלהלקום   (al-ḥalqūm   = הגרון)
אלאסנאן   (al-asnān    = השיניים)
אלמרפיין  (al-mirfaʿain = המרפקיים)
אלשפתין   (al-shafatain = השפתיים)
אלחרוף    (al-ḥurūf    = האותיות)
אלכלמה    (al-kalima   = המילה)
אלשוא     (al-shwā     = השווא)
אלמכתוב   (al-maktūb   = הכתוב)
אלואו     (al-wāw      = הוא"ו)
אלפאתחה   (al-fātḥa    = הפתח [ניקוד])
אלנקטה    (al-nuqṭa    = הנקודה)
אלסאכן    (al-sākin    = השוכן [=נח, ללא תנועה])
אלמואצע   (al-mawāḍiʿ  = המקומות)
```

**שורה טיפוסית מהקורפוס:**
```
פצל פי אלכלאם עלי אלשוא אלשוא ינקסם
(= פרק בעניין הדיבור על השווא. השווא מתחלק...)
```

16 מופעי אל- ב-10 שורות — זהו **התבנית הדומיננטית** בטקסט ערבי-יהודי.

### צירופי מילת יחס + אל-

בערבית יהודית (כמו בערבית ספרותית) מילות היחס הקצרות **נדבקות** ל-אל הידיעה כמילה אחת. זה יוצר צירופים קבועים:

| צירוף | מרכיבים | משמעות | דוגמה מהקורפוס | הקשר |
|--------|---------|--------|---------------|------|
| **באל** | ב + אל | "ב" + "ה" | `באלאסנאן` | "בשיניים" |
| **ואל** | ו + אל | "ו" + "ה" | `ואלנקטה` | "והנקודה" |
| **ואל** | ו + אל | "ו" + "ה" | `ואלנקטתין` | "ושתי הנקודות" |
| **פאל** | פי + אל | "ב/בתוך" + "ה" | `פאלמלא` | "במילוי" |
| **פי אל** | פי + אל (נפרד) | "ב/בתוך" + "ה" | `פי אלמלא` | אותו דבר, כתוב נפרד |
| **לאל** | ל + אל | "ל" + "ה" | (פחות נפוץ בקורפוס) | |
| **כאל** | כ + אל | "כ" + "ה" | (פחות נפוץ בקורפוס) | |
| **מן אל** | מן + אל | "מ" + "ה" | `מן אלוגוה` | "מהבחינות" (שתי מילים) |
| **עלי אל** | עלי + אל | "על" + "ה" | `עלי אלף` | "על [אות] אלף" (שתי מילים) |

**נקודה חשובה**: מילות יחס קצרות (ב, ו, פ, כ, ל) מתחברות ל-אל כמילה אחת. מילות יחס ארוכות (מן, עלי, אלי, פי) בדרך כלל נכתבות **כמילים נפרדות** — אבל לא תמיד עקבי.

### אותיות שמשיות (حروف شمسية) — הטמעת ה-ל

זהו כלל פונולוגי חשוב בערבית. יש 14 עיצורים שנקראים "אותיות שמשיות" (حروف شمسية) — כשהם באים אחרי אל הידיעה, ה-ל **נבלעת** (לא נשמעת) והאות שאחריה **מוכפלת** בהגייה. בכתב הגניזה זה יכול להשתקף בכתיב:

| כתיב מלא (עם ל) | כתיב מוטמע (בלי ל) | תעתיק | משמעות |
|-----------------|-------------------|--------|--------|
| אל + שמס | **אשׁשׁמס** | ash-shams | השמש |
| אל + דאר | **אדדאר** | ad-dār | הבית |
| אל + נאס | **אננאס** | an-nās | האנשים |
| אל + תורה | **אתתורה** | at-tawrā | התורה |
| אל + לסאן | **אללסאן** | al-lisān | הלשון |
| אל + סאכן | **אססאכן** | as-sākin | השוכן (=תנועה נחה) |
| אל + רגש | **ארגש** / **אררגש** | ar-rajsh | הדגש |

**14 האותיות השמשיות בכתב עברי**: **ת, ד, ר, ז, ס, ש, צ, ט, ל, נ, ת׳, ד׳, ט׳, ץ**

שאר האותיות נקראות "אותיות ירחיות" (حروف قمرية) — ה-ל **נשמרת** בהגייה ובכתיב:
- אל + כתאב = **אלכתאב** (al-kitāb = הספר) — ה-ל נשארת
- אל + מלך = **אלמלך** (al-malik = המלך) — ה-ל נשארת
- אל + חרוף = **אלחרוף** (al-ḥurūf = האותיות) — ה-ל נשארת

### הקושי המיוחד בגניזה: כתיב לא עקבי

**אבל** — בכתבי יד של הגניזה הכתיב **לא עקבי**. הסופרים לא תמיד מבחינים בין אותיות שמשיות לירחיות, ולפעמים מערבים בין הצורות:

**דוגמה מהקורפוס** — המילה "הלשון" (al-lisān): ל היא אות שמשית, אז הכתיב ה"נכון" הוא אללסאן (עם ל כפולה). אבל:
```
מופע 1 (שורה 10): אללסאן  ← כתיב מלא (אל + ל כפולה) ✓
מופע 2 (שורה 87): אללסאן  ← אותו דבר
מופע 3 (שורה 75): אללסאן  ← אותו דבר
```
כאן הכתיב עקבי. אבל עבור מילים אחרות:
```
אלשוא (שורה 32) — ש אות שמשית, אבל כתוב אל (עם ל, לא הוטמע)
אלשפתין (שורה 13) — ש אות שמשית, כתוב אל (לא אששפתין)
אלסאכן (שורה 33) — ס אות שמשית, כתוב אל (לא אססאכן)
```

**המסקנה**: בגניזה, רוב הסופרים **שומרים על אל- גם לפני אותיות שמשיות** (כתיב "שמרני"). אבל צריך לחפש **את שתי הצורות** — גם אלשוא וגם אששוא — כי חלק מהסופרים כן מטמיעים.

### כמה טקסט ערבי-יהודי יש בקורפוס?

על בסיס הנתונים מ-`corpus_mapper/parsers/ja_parser.py` (פרסר ייעודי ל-Judeo-Arabic של פרידברג), ומהעובדה שיש 629 זוגות וריאנטים שמערבים את "אל" ב-`unified_variants.py`, ההערכה היא שחלק ניכר מהקורפוס הוא ערבית יהודית. זה כולל:
- חיבורים דקדוקיים (כמו הדוגמאות למעלה)
- פירושים פילוסופיים ותיאולוגיים
- מכתבים מסחריים ופרטיים
- שטרות ומסמכים משפטיים
- חיבורים רפואיים ומדעיים
- פירושי מקרא (כגון של רס"ג)

**משמעות לחיפוש**: משתמש שמחפש מונח בערבית יהודית **חייב** להתמודד עם אל הידיעה, אחרת יפספס חלק גדול מהמופעים.

### המלצה: הרחבת `#` עבור ערבית יהודית

#### שלוש גישות — יתרונות וחסרונות

**גישה א' — הרחבה אוטומטית (תמיד מוסיפים אל-):**

כל שימוש ב-`#` מוסיף אוטומטית גם קידומות ערביות-יהודיות.

```python
# #שלום → שלום, ושלום, השלום, בשלום, ..., אלשלום, ואלשלום, ...
```

| יתרון | חיסרון |
|-------|--------|
| פשוט — סימן אחד | מנפח כל שאילתה (גם עברית טהורה) |
| אין צורך לזכור ## | מוסיף ~12 צורות נוספות שלא רלוונטיות לטקסט עברי |

**גישה ב' — סימן כפול `##` (מומלצת לתחביר):**

| סימן | משמעות | דוגמה |
|-------|--------|-------|
| `#` | קידומות עבריות בלבד | `#שלום` → שלום, ושלום, השלום... |
| `##` | קידומות עבריות **+** ערבית יהודית | `##כלמה` → כלמה, אלכלמה, ואלכלמה... |

| יתרון | חיסרון |
|-------|--------|
| לא מנפח שאילתות עבריות | דורש לזכור שני סימנים |
| המשתמש שולט | |
| שקוף — רואים ב-Preview מה חיפש | |

**גישה ג' — צ'קבוקס "ערבית יהודית" (מומלצת ל-UI):**

```
☑ מצב שו"ת    ☐ וריאנטים    ☑ ערבית יהודית    Gap: [3]
```

כשהצ'קבוקס מסומן, **כל** `#` מתנהג כמו `##`.

| יתרון | חיסרון |
|-------|--------|
| הכי ידידותי — סימן/ביטול בלחיצה | מצב גלובלי — לא per-component |
| מתאים לחוקרים שעובדים עם ערבית יהודית כל הזמן | |
| אפשר לשלב עם תחביר ## למקרים מעורבים | |

**ההמלצה: לשלב ב' + ג'** — צ'קבוקס שמגדיר את ברירת המחדל, + תחביר `##` למקרים ספציפיים. כך:
- חוקר שעובד על טקסט ערבי-יהודי מסמן את הצ'קבוקס → כל `#` מתרחב גם עם אל-
- חוקר שעובד על טקסט עברי עם מילה ערבית אחת → משתמש ב-`##` רק על אותה מילה

### מימוש הרחבת אל- — פירוט

```python
# אותיות שמשיות — ה-ל של אל- נבלעת לפניהן
SUN_LETTERS = set('תדרזסשצטלנ')

# אותיות ירחיות — ה-ל נשמרת
# (כל השאר: א, ב, ג, ה, ו, ח, י, כ, ע, פ, ק, מ)

def expand_judeo_arabic_prefixes(word):
    """
    ##כלמה → כל הצורות עם אל הידיעה וצירופיו.

    מכסה:
    1. אל הידיעה רגיל (אלכלמה)
    2. מילות יחס + אל (ואלכלמה, באלכלמה, ...)
    3. הטמעת אותיות שמשיות (אלשוא → אששוא)
    4. מילות יחס + צורה מוטמעת (ואששוא, באששוא)
    """
    forms = [word]  # המילה עצמה, ללא שום קידומת

    # --- אל הידיעה רגיל ---
    forms.append('אל' + word)

    # --- מילות יחס + אל ---
    # ו (and), ב (in), פ (in/by, קיצור של פי), כ (like), ל (to/for)
    for prep in ['ו', 'ב', 'פ', 'כ', 'ל']:
        forms.append(prep + 'אל' + word)

    # --- ל + אל → לל (צירוף נפוץ: "ל" + "אל" = "לל") ---
    forms.append('לל' + word)

    # --- הטמעת אותיות שמשיות ---
    if word and word[0] in SUN_LETTERS:
        first = word[0]
        # אל + שמש → א + שׁ + שׁמש (הכפלת האות הראשונה)
        assimilated = 'א' + first + word
        forms.append(assimilated)  # אששמש

        # מילות יחס + צורה מוטמעת
        for prep in ['ו', 'ב', 'פ', 'כ', 'ל']:
            forms.append(prep + assimilated)  # ואששמש

    return forms
```

### טבלת הרחבה — דוגמאות מלאות

**מילה עם אות ירחית (כ):**
```

  כלמה        (המילה עצמה)
  אלכלמה      (al-kalima = המילה)
  ואלכלמה     (wa-al-kalima = והמילה)
  באלכלמה     (bi-al-kalima = במילה)
  פאלכלמה     (fi-al-kalima = במילה)
  כאלכלמה     (ka-al-kalima = כמילה)
  לאלכלמה     (li-al-kalima = למילה)
  ללכלמה      (li-al-kalima = למילה, צורה מקוצרת)

```

**מילה עם אות שמשית (ש):**
```

**מילה עם אות שמשית (ל — מקרה מיוחד):**
```
##לסאן  →
  לסאן        (המילה עצמה)
  אללסאן      (al-lisān = הלשון — ל מוכפלת כי היא שמשית וגם ה-ל של אל)
  ואללסאן, באללסאן, ...
  אללסאן      (גם הצורה המוטמעת זהה — כי ל+ל=לל ואל+ל=אלל)
  ← סה"כ 8 צורות (הטמעה = כתיב רגיל, אין הבדל)
```

## 2. רווחים שגויים — בעיית חלוקת המילים

### הבעיה

כתבי יד מהגניזה מתומללים (ידנית או אוטומטית) לטקסט דיגיטלי. התמלול כולל החלטות לגבי **איפה לשים רווח** בין מילים. בעיות נפוצות:

1. **כתב היד עצמו** — סופרים ימי-ביניימיים לא תמיד שמים רווחים ברורים בין מילים
2. **OCR/HTR** — מערכות זיהוי אוטומטי טועות בזיהוי גבולות מילים
3. **קריאה ידנית** — מתמללים שונים מפרשים את אותו כתב יד אחרת
4. **ערבית יהודית** — מילות יחס שנדבקות/נפרדות באופן לא עקבי

### ראיות מהקורפוס — השוואת שתי קריאות של אותו דף

בקובץ `Transcriptions_part.txt` יש **שתי קריאות עצמאיות** של אותו כתב יד. השוואה שלהן חושפת את הבעיה:

**קריאה א' (IE104549337) לעומת קריאה ב' (IE19213988) — אותו דף ממש:**

| שורה | קריאה א' | קריאה ב' | הבדל |
|------|----------|----------|------|
| 1 | `אלהלקום` | `אלזולקום` | אותיות שונות (ה→ז, חסר ול) |
| 1 | `דט'ר נגג` | `דטר נמ` | רווח שונה + אותיות |
| 5 | `]אל מהא תנבדל` | `קאל אנהא תנבדל` | מילה אחת (]אל) → שתיים (קאל אנהא) |
| 10 | `אלמכתוב גפי` | `אלמכתוב בפי` | אות שונה (ג→ב) |

**דוגמאות נוספות לרווחים בעייתיים מהקורפוס:**

```
שורה 104: קדיגי אליוד     ← צריך להיות: "קד יגי" (שתי מילים שהתחברו)
שורה 46:  המצפונפיס        ← מילים שהתמזגו לחלוטין

### סיווג סוגי הבעיה

| סוג | מה קורה | דוגמה אמיתית | שכיחות |
|-----|---------|-------------|--------|
| **מילים שהתחברו** | שתי מילים נכתבו כאחת | `קדיגי` ← `קד יגי` | גבוהה |
| **מילה שנפרדה** | מילה אחת נפרדה לשתיים | `יר שו` ← `גורשו` | גבוהה |
| **גבול שזז** | הרווח נמצא במקום הלא נכון | `ביתד ין` ← `בית דין` | בינונית |
| **אל- נפרד/מחובר** | אל הידיעה נפרד מהמילה | `אל כלמה` ← `אלכלמה` | גבוהה (JA) |
| **שרשרת אותיות** | כמה מילים ללא רווחים | `עזוכזסאוחלו` | נמוכה |

### ההשפעה על חיפוש — למה זה כואב

**מצב נוכחי**: המנוע מפרק שאילתות ב-`.split()` (רווח = גבול מילה). חיפוש `בית דין` מחפש "בית" ואז "דין" כשתי מילים נפרדות. אם בטקסט כתוב `ביתדין` (בלי רווח) — **לא נמצא**.

```
שאילתה:  בית דין    (gap=0)
regex:   בית[^\w]+דין   ← דורש לפחות תו אחד שאינו מילה בין "בית" ל"דין"
טקסט:   "ביתדין"       ← אין רווח → ❌ לא נמצא!
טקסט:   "ביתד ין"      ← רווח במקום הלא נכון → ❌ לא נמצא!
טקסט:   "בית דין"      ← רווח במקום הנכון → ✅ נמצא
```

### שלוש גישות לפתרון

#### גישה א': רווחים גמישים (Space-Flexible Regex) — **מומלצת ל-MVP**

**רעיון**: צ'קבוקס "רווחים גמישים" שהופך רווחים בשאילתה ל**אופציונליים** ב-regex.

**השינוי** — תו אחד בלבד:
```python
# רגיל (gap=0) — מצב נוכחי:
sep = r'[^\w\u0590-\u05FF\']+'     # חובה: תו אחד או יותר שאינו מילה
#                              ^  פלוס = אחד או יותר

# רווחים גמישים — המוצע:
sep = r'[^\w\u0590-\u05FF\']*'     # אופציונלי: אפס או יותר
#                              ^  כוכבית = אפס או יותר
```

**מה זה נותן — כל המקרים:**
```
שאילתה:   בית דין      + ☑ רווחים גמישים
regex:    בית[^\w]*דין

מוצא:
  "בית דין"    ✅  (רווח → [^\w]* מתאים לרווח)
  "ביתדין"     ✅  (ללא רווח → [^\w]* מתאים לאפס תווים)
  "ביתד ין"    ❌  (הרווח במקום אחר — לא מתאים!)
```

**שימו לב**: גישה א' **לא פותרת** את מקרה "גבול שזז" (`ביתד ין`). היא פותרת רק מילים שהתחברו.

**מימוש מדויק יותר** — בנוסף ל-separator, גם **בתוך** כל term מאפשרים רווח אופציונלי:

```python
# גישה משופרת: מוסיפים \s* בין כל אות בשאילתה
def make_space_flexible(term):
    """בית → ב\s*י\s*ת"""
    chars = list(term)
    return r'\s*'.join(re.escape(c) for c in chars)

# ואז:
# "בית דין" → ב\s*י\s*ת\s*ד\s*י\s*ן
# מוצא: "בית דין" ✓  "ביתדין" ✓  "ביתד ין" ✓  "בי תדין" ✓
```

**יתרונות**:
- שינוי מינימלי (אפשר להתחיל רק עם `+`→`*`, ולשדרג בהמשך)
- עובד עם כל מנגנוני החיפוש הקיימים (variants, wildcards, OR groups)
- פותר את רוב המקרים

**חסרונות**:
- גרסת ה-`\s*`-per-char עלולה **ליצור matches ארוכים מדי** (רצף `ב...י...ת` בטקסט ארוך)
- ללא Tantivy awareness — Tantivy מחפש terms מדויקים, לא יודע על רווחים גמישים
- **פתרון ל-Tantivy**: לחפש גם את הצורה המחוברת וגם המפורדת: `"בית" AND "דין"` + `"ביתדין"`

#### גישה ב': חיפוש דו-מסלולי (Dual-Track Search)

**רעיון**: להריץ שני חיפושים במקביל — אחד רגיל ואחד על טקסט **ללא רווחים**.

```python
def search_with_flexible_spacing(query, text):
    # מסלול 1: חיפוש רגיל (כמו היום)
    results_normal = regex_search(query, text)

    # מסלול 2: חיפוש ללא רווחים
    stripped_text = text.replace(' ', '').replace('\n', '')
    stripped_query = query.replace(' ', '')
    results_stripped = regex_search(stripped_query, stripped_text)

    # מיזוג תוצאות (עם deduplication לפי document ID)
    return merge(results_normal, results_stripped)
```

**מה זה פותר מעבר לגישה א'**:
```
שאילתה: אלכלמה
מסלול 1 (רגיל): מוצא "אלכלמה" ✅
מסלול 2 (ללא רווחים): מוצא גם "אל כלמה" ✅ (כי ללא רווחים זה "אלכלמה")
```

**יתרונות**: מוצא **את הכל** — הן מילים שהתחברו, הן מילים שנפרדו, הן גבולות שזזו

**חסרונות**:
- דורש אינדקס Tantivy נוסף (שדה `content_nospaces`) **או** סריקה כפולה ברמת ה-regex — כפל זמן
- ה-highlighting מורכב: מצאנו match ב-stripped text, צריך למפות חזרה לטקסט המקורי כדי להראות למשתמש
- מוסיף false positives: "גמל" יימצא בתוך "דוגמלאומית" (ללא רווחים)

**כדאי לשקול**: שדה Tantivy נוסף `content_nospaces` שמאונדקס בזמן בניית האינדקס. זה מוסיף ~30% לגודל האינדקס אבל פותר את הבעיה ברמת ה-recall.

#### גישה ג': N-gram Index (ברמת תווים)

**רעיון**: לאנדקס את הטקסט כ-character n-grams (trigrams/4-grams) ב-Tantivy. N-grams חוצים גבולות מילים (אחרי הסרת רווחים).

```
"בית דין" → (הסרת רווחים) → "ביתדין"
          → trigrams: "בית", "יתד", "תדי", "דין"
          → 4-grams:  "ביתד", "יתדי", "תדין"
```

חיפוש `בית דין` → trigrams: `"בית" AND "יתד" AND "תדי" AND "דין"` — ימצא בטקסט שמכיל את הרצף ביתדין, לא משנה איפה הרווח.

**יתרונות**: פותר את בעיית הרווחים באופן **מהותי**, space-agnostic, עובד גם ל-fuzzy

**חסרונות**:
- אינדקס גדול משמעותית (פי 3-4 יותר terms)
- precision נמוכה: trigrams קצרים מייצרים הרבה false positives (כל מסמך שמכיל "בית" ו"דין" בנפרד)
- דורש שינוי מבני באינדקס (rebuild)
- מורכבות מימוש גבוהה

**מתאים ל-Phase 3 אם יש ביקוש** — לא ל-MVP.

## 3. שילוב שתי התכונות ביחד — ניתוח אינטראקציות

### ערבית יהודית + רווחים גמישים = בעיה כפולה

שתי הבעיות **מחזקות** אחת את השנייה בערבית יהודית:

1. אל הידיעה יכול להיכתב **מחובר** (`אלכלמה`) או **נפרד** (`אל כלמה`) — בעיית רווחים
2. מילת יחס + אל יכולה להיות **מחוברת** (`באלכלמה`) או **נפרדת** (`ב אל כלמה` / `באל כלמה`) — שילוב שתי הבעיות
3. אות שמשית מוטמעת יכולה להיכתב בצורות שונות: `אלשוא`, `אששוא`, `אל שוא`, `אש שוא`

**דוגמה מהקורפוס** — המילה "אלחרוף" (האותיות):
```
מופע 1: אלחרוף     (מחובר, תקין)
מופע 2: אל חרוף    (נפרד — מתמלל שם רווח)
מופע 3: אלארוף     (שגיאת כתיב: ח→א, או קריאה שגויה)
מופע 4: אלחרופ     (שגיאת כתיב: ף→פ)
```

**בלי התכונות החדשות** — צריך 4 חיפושים נפרדים. **עם התכונות** — חיפוש אחד:
```
##(חרוף/ארוף)  + ☑ וריאנטים + ☑ רווחים גמישים
→ מוצא את כל 4 המופעים
```

### אינטראקציה: וריאנטים + ערבית יהודית

כשוריאנטים פעילים, הם חלים **על כל צורה מורחבת**. זה אומר:
- `##כלמה` + variants → וריאנטים גם ל-"כלמה", גם ל-"אלכלמה", גם ל-"ואלכלמה"
- `כלמה`→`כלמא` (ה→א), אבל גם `אלכלמה`→`אלכלמא`

**פיצוץ קומבינטורי**: 14 צורות (אל + צירופים + אותיות שמשיות) × 30 וריאנטים = 420 terms למילה אחת.

**פתרון**: כפי שצוין ב-`responsa_implementation_response.md` — hard cap של `MAX_EXPANDED_TERMS = 500`. כשחורגים: auto-downgrade variants ל-basic (30 pairs במקום 70/150) + warning למשתמש.

## 4. המלצה משולבת — מה לאמץ

### ממשק: ארבעה צ'קבוקסים

```
☑ מצב שו"ת    ☐ וריאנטים    ☐ ערבית יהודית    ☐ רווחים גמישים    Gap: [3]
```

| צ'קבוקס | מה עושה | מתי שימושי |
|---------|---------|------------|
| **מצב שו"ת** | מפעיל תחביר `*`, `#`, `(/)` | תמיד |
| **וריאנטים** | חילופי אותיות (ד↔ר, ב↔כ, ...) | כתב לא ברור, כתיב לא עקבי |
| **ערבית יהודית** | `#` מרחיב גם עם אל-, `##` תמיד | טקסטים בערבית יהודית |
| **רווחים גמישים** | רווחים אופציונליים | OCR גרוע, רווחים שגויים |

### טבלת מימוש

| תכונה | גישה | היקף | עדיפות | Phase |
|--------|------|------|--------|-------|
| **אל הידיעה** | `expand_judeo_arabic_prefixes()` + צ'קבוקס | ~40 שורות | גבוהה | 1 |
| **אותיות שמשיות** | כלול ב-expand function | ~15 שורות | גבוהה | 1 |
| **רווחים גמישים (בסיסי)** | `+`→`*` ב-separator | ~5 שורות | גבוהה | 1 |
| **רווחים גמישים (מתקדם)** | `\s*` בין אותיות | ~20 שורות | בינונית | 1 |
| **Tantivy: שליחת צורה מחוברת** | `"ביתדין"` בנוסף ל-`"בית" AND "דין"` | ~10 שורות | בינונית | 1 |
| חיפוש דו-מסלולי (stripped) | שדה Tantivy `content_nospaces` | שינוי באינדקס | נמוכה | 2 |
| N-gram index | אינדקס character trigrams | שינוי מבני | נמוכה | 3 |

### Pipeline — איך הכל עובד ביחד

```
קלט:   ##(חרוף/אותיות) ##כלמה    + ☑ וריאנטים + ☑ ער"י + ☑ רווחים גמישים + gap=3

שלב 1 — פרסור שו"ת:
  מרכיב 1: OR group [חרוף, אותיות], prefix=##
  מרכיב 2: [כלמה], prefix=##

שלב 2 — הרחבת ערבית יהודית (##):
  חרוף → חרוף, אלחרוף, ואלחרוף, באלחרוף, ...
  אותיות → אותיות, אלאותיות, ואלאותיות, ...
  כלמה → כלמה, אלכלמה, ואלכלמה, באלכלמה, ...

שלב 3 — הרחבת וריאנטים (per term):
  חרוף → חרוף, חרופ, ארוף, הרוף, ...
  אלחרוף → אלחרוף, אלחרופ, אלארוף, ...
  כלמה → כלמה, כלמא, כלמת, ...
  אלכלמה → אלכלמה, אלכלמא, ...
  (cap: MAX_EXPANDED_TERMS = 500)

שלב 4 — Tantivy query:
  ("חרוף"^5 OR "אלחרוף" OR "ארוף" OR "אותיות" OR "אלאותיות" OR ...)
  AND
  ("כלמה"^5 OR "אלכלמה" OR "כלמא" OR ...)

שלב 5 — Regex (רווחים גמישים):
  (ח\s*ר\s*ו\s*ף|א\s*ל\s*ח\s*ר\s*ו\s*ף|...)
  [gap separator]
  (כ\s*ל\s*מ\s*ה|א\s*ל\s*כ\s*ל\s*מ\s*ה|...)

שלב 6 — Execute:
  Tantivy → ~3K candidates
  Regex → ~25 matches
  Highlight → תוצאות מודגשות
```

## 5. דוגמאות שימוש מציאותיות

כל הדוגמאות מבוססות על טקסט **אמיתי** מ-`Transcriptions_part.txt`.

### דוגמה 1: חיפוש מונח דקדוקי בערבית יהודית
```
שאילתה:  ##שוא
מורחב:   שוא | אלשוא | ואלשוא | באלשוא | פאלשוא | אששוא | ואששוא | באששוא ...

מוצא בקורפוס:
  שורה 32:  "פצל פי אלכלאם עלי אלשוא"        ← אלשוא ✅
  שורה 33:  "קסמין סאכן ומתחרך"               ← (לא מכיל שוא) ❌
  שורה 38:  "אלשוא סאכנא ואנפצל"              ← אלשוא ✅
  שורה 108: "פצר פי אלכלאם עלי אלשוא"         ← אלשוא (קריאה שנייה) ✅
```
**בלי ##**: חיפוש `שוא` מוצא רק מופעים בלי אל-. חיפוש `אלשוא` מפספס `ואלשוא`.

### דוגמה 2: רווחים גמישים — טקסט הגדה
```
שאילתה:  גורשו ממצרים       + ☑ רווחים גמישים
regex:    ג\s*ו\s*ר\s*ש\s*ו\s*מ\s*מ\s*צ\s*ר\s*י\s*ם

מוצא:
  שורה 161: "גורשו ממצרים"     ← רגיל ✅
  שורה 209: "יר שו ממצרים"     ← קריאה שגויה, אבל "שו ממצרים" ✅ (חלקי)
```
**הערה**: במקרה של שורה 209, "יר שו" זו קריאה שגויה של "גורשו". וריאנטים יכולים לעזור עם "גורשו"↔"יורשו" אבל לא עם "יר שו". כאן רק חיפוש ללא רווחים (גישה ב') יעזור.

### דוגמה 3: שילוב מלא — חיפוש מושג דקדוקי
```
שאילתה:  ##(חרוף/אותיות) ##(כלמה/מלה)
אפשרויות: ☑ וריאנטים + ☑ ער"י + ☑ רווחים גמישים + gap=3

מוצא בקורפוס:
  שורה 14:  "אלחרוף ]אל מהא תנבדל"            ← אלחרוף ... (gap)
  שורה 57:  "פצל פי מחאל אלחרוף"               ← אלחרוף ✅
  שורה 71:  "פצל פי מחאל אלחרוף"               ← אלחרוף (קריאה ב') ✅
  שורה 130: "פצל פי מחל אלארוף א אלחרוף אכ"   ← אלארוף (וריאנט: ח→א) ✅
```

### דוגמה 4: אותיות שמשיות — שתי צורות
```
שאילתה:  ##לסאן
מורחב:   לסאן | אללסאן | ואללסאן | באללסאן | ...
          (ל אות שמשית → הטמעה: אל+ל=אלל, שזהה לכתיב הרגיל)

מוצא:
  שורה 10: "אללסאן ממא ילי"     ← אללסאן ✅
  שורה 75: "ואצל אללסאן"        ← אללסאן ✅
  שורה 87: "תלת אללסאן ממא"     ← אללסאן (קריאה ב') ✅
```

### דוגמה 5: ערבית יהודית + קידומות עבריות
```
שאילתה:  ##תורה
מורחב:
  עברי:    תורה, ותורה, התורה, בתורה, לתורה, ...
  ער"י:    אלתורה, ואלתורה, באלתורה, ...
  שמשית:   אתתורה, ואתתורה, ...

מוצא טקסטים עבריים ותרגומים ערביים-יהודיים באותו חיפוש.
```
**זה הכוח של הגישה**: חוקר שעובד על פירוש ערבי-יהודי למקרא מוצא גם את הציטוטים העבריים ("התורה") וגם את הדיון הערבי-יהודי ("אלתורה") — **בחיפוש אחד**.

---

## 6. Edge Cases ומגבלות

### מגבלה 1: רווחים גמישים + שאילתות קצרות
`\s*` בין כל אות הופך שאילתה של 2 אותיות למסוכנת:
```
שאילתה: אל    + ☑ רווחים גמישים
regex:  א\s*ל
מוצא:  כמעט כל שורה בקורפוס (א ו-ל מופיעים בכל מקום)
```
**פתרון**: דרישת מינימום 3 אותיות כשרווחים גמישים פעילים.

### מגבלה 2: אל- שאינו אל הידיעה
המילה "אל" בעברית היא גם מילת שלילה ("אל תעשה") ושם אל ("אלהים"). הרחבת ## תמצא גם מופעים לא-ערביים.
**פתרון**: אין פתרון אוטומטי. זה disambiguation שדורש הקשר. המשתמש יסנן ידנית.

### מגבלה 3: פיצוץ קומבינטורי עם שילוב מלא
```
##מילה + variants + ער"י + רווחים גמישים
= 14 צורות × 30 variants × regex-per-char
= regex ארוך מאוד
```
**פתרון**: MAX_EXPANDED_TERMS = 500 + auto-downgrade. הרווחים הגמישים חלים רק ב-regex (לא מכפילים terms ב-Tantivy).

### מגבלה 4: Tantivy לא מוצא צורות מחוברות
`בית דין` → Tantivy מחפש `"בית" AND "דין"`. אם בטקסט כתוב `ביתדין` (מילה אחת), Tantivy **לא ישלוף** את המסמך.
**פתרון Phase 1**: להוסיף ל-Tantivy query גם את הצורה המחוברת: `("בית" AND "דין") OR "ביתדין"`.
**פתרון Phase 2**: שדה `content_nospaces` באינדקס.
