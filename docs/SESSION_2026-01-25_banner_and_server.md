### 2. Server Management CLI
**Commit:** `3335b0b`

**File:** `server.py`

**Usage:**
```bash
python server.py start     # Start web server (detached, port 8081)
python server.py stop      # Stop the server
python server.py restart   # Stop + start
python server.py status    # Check if running
```

**Features:**
- Tracks PID in `.server.pid` file
- Only kills the specific server process (not other Python instances)
- Uses `taskkill /T` on Windows to kill child processes
- Disables NiceGUI reload for cleaner process management
- Server runs detached (doesn't block terminal)
