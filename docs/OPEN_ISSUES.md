## AI Assistant Maintenance Protocol

**This file holds only what is still open.** Closed items — fixed, resolved, superseded,
and the full Change Log — were split out on 2026-08-12 to
[`docs/archive/OPEN_ISSUES_ARCHIVE.md`](archive/OPEN_ISSUES_ARCHIVE.md). Nothing was
deleted; every line moved verbatim. **Grep the archive, do not read it** — it is ~515 KB.

**Keep it that way.** This file is read at the start of every session, so its size is a
recurring cost. When you mark an item fixed, move the entry to the archive in the same
edit rather than leaving it here with a ✅. If this file passes ~150 KB again, re-split it
(`python scripts/archive_closed_issues.py --apply`; dry run without the flag. NOT `split_open_issues.ps1`, which rebuilds the archive from scratch).

**IMPORTANT:** This document must be kept current. Follow these rules:

### When to Update This Document

1. **After fixing any issue** - Mark it fixed with the date **and move it to the archive**
2. **After discovering new issues** - Add to appropriate section
3. **After completing a work session** - Review and update status
4. **When starting work** - Check current status first
5. **Never cite an entry of this file by line number** (`docs/OPEN_ISSUES.md:<line>`) - rows move
   whenever anything above them is archived, and the citation then points at an unrelated issue.
   Four citations in `.planning/milestones/v9.0.0-MILESTONE-AUDIT.md` broke that way when this file
   was trimmed on 2026-09-20. Quote the entry's headline instead, so a grep finds it wherever it
   sits; `scripts/check_docs.py` fails on a line-numbered citation.

```markdown
# When completing an issue:

```
