Introduction: How it Works

Dicta Genizah Search provides fast and advanced access to the transcription corpus of the "MiDRASH" project. The software is based on a high-speed search engine (Tantivy) and integrates unique algorithms to handle the Hebrew spelling variations typical of Genizah manuscripts.

The software runs locally on your computer but uses an internet connection to fetch metadata and images from the National Library of Israel, Oxford Bodlean Library and Cambridge University Library. It will work without an internet connection, but without images and some extended information. Note: If your connection is not a home network (such as a mobile hotspot), library servers may block your access.

Search Tab

This is the entry point for free text or metadata searches within the corpus.

Search Modes

  • Exact: Matches only the exact word as typed.
  • Variants: Accounts for common letter substitutions in these texts (e.g., Dalet/Resh, He/Het, Vav/Yod).
  • Extended / Maximum: Allows for greater flexibility in letter substitutions (e.g., Qof/Kaf, Tet/Tav), but may return less relevant results ("noise") and take longer to search.
  • Fuzzy: Uses Levenshtein distance to find similar words even with decoding errors.
  • Regex: Advanced search for experienced users. For example, \bא[א-ת]{3}\b finds 4-letter words starting with Aleph.
  • AI Assistant (🤖): Click the AI button to open a chat interface that helps generate regex patterns. Describe what you're looking for in plain language, and the AI will create the appropriate regex. Supports Google Gemini, OpenAI, and Anthropic Claude (configure your API key in the Settings tab).
  • Title: Searches within the catalog titles of compositions. Example: searching "Mishneh Torah" will retrieve all manuscripts identified as Maimonides' Mishneh Torah.
  • Shelfmark: Fast search for shelfmarks (e.g., "T-S 13.15").

Additional Options

  • Gap: Defines how many words can separate search terms. A value of 0 requires an exact sequence.
  • Select All: A checkbox at the top of the table allows you to select all results (or currently displayed results) for focused export.
  • Preview: Double-clicking a row opens the full Manuscript Viewer on that page. Clicking the "👁" button will lead to the same result.
  • Browse Manuscript: Clicking the "📖" icon will open the manuscript in the "Browse Manuscript" tab. A similar browse button is also found in the Manuscript Viewer.
  • Column Filtering: Click on column headers (Shelfmark, Title, Snippet) to filter results by text. Check "Exclude" to hide matching results instead of showing them.

Search Settings (⚙)

Click the gear icon to open advanced search settings:

  • Limit Short Words: Words with ≤ N characters receive only 1 character change in variant modes.
  • Max Changes per Word: Maximum number of character substitutions allowed per word (default: 2).
  • Aggressive Mode: Ignores word length limits for variant generation.
  • Custom Variant Pairs: Define your own letter substitution pairs (e.g., "מ=נו", one per line).

Composition Search

This tool is designed for researchers wishing to find parallels for a complete literary text (such as a Piyyut, medieval commentary, or other rare work) within the Genizah, thereby locating additional textual witnesses, both direct and indirect.

How it Works (The Mechanism)

Unlike a regular search, the engine does not search for the entire text as a single unit. The process works as follows:

  1. The software splits the source text you entered into small segments ("Chunks").
  2. Each chunk is searched separately in the Genizah database.
  3. If a specific chunk is found in a manuscript, it receives a "score".
  4. At the end of the process, the software aggregates the results: if a manuscript contains many found chunks, it receives a high score and appears at the top of the list.

Important Parameters

  • Chunk: The number of words in each search unit. A value too low will return many irrelevant results; a value too high might miss true results.
  • Max Freq: A tool to filter common expressions. If the engine detects that a sequence appears many times in the corpus (like idioms or verses), it will filter it to the Appendix.
  • Filter >: If a specific title (e.g., "Siddur Rav Saadia Gaon") appears more than X times in the results, the software groups these results under a single "Group" in the Appendix to avoid flooding the main list.
  • Sort by shelfmark only: Disables smart grouping and displays a flat, sorted list of all found manuscripts.

Advanced Options

  • Exclude Manuscripts: Allows you to enter a list of known manuscripts to hide from results (they will appear under the "Excluded" category).
  • Filter Text: Allows entering specific texts to mark as "Filtered" in the results. For example, if your text quotes verses, Mishnah, or Gemara, you can enter these texts into the filter so this "noise" is not displayed.
  • Recursive Search: After getting results, this button searches again using the texts of the found manuscripts as a basis for further searching. The search can be fully recursive, or only on results you select after the initial search.

Browse Manuscript

This tab enables convenient continuous reading of a full manuscript, synchronized with source images.

  • Load: Enter a System ID, Shelfmark, or FL ID. The search is flexible and ignores spaces or punctuation (e.g., TS 13 15 finds T-S 13.15). Autocomplete is available for shelfmarks.
  • Navigate Pages: Use the arrows < > to flip between pages within the current manuscript.
  • Navigate Manuscripts: Use the arrows ◀ ▶ at the top left to move to the previous or next manuscript in the database file order.
  • Images: An image viewer is displayed on the side. You can rotate, zoom, and select the image source (NLI or Cambridge/Oxford where supported). Use 🖼️ to show/hide the image panel.
  • View All: Displays all manuscript pages in one long sequence for easy scrolling and for saving as a text file.
  • Find in Text: Type in the search field to highlight matching text in real-time within the current manuscript.
  • Find Parallels: Sends the current page text to the Composition Search tab for finding parallels across the corpus.
  • View on Ktiv: Opens the manuscript in the National Library of Israel's online catalog.

Lab Mode

The "Lab Mode" button activates an experimental and more advanced search engine.

  • Deep Scan: A much deeper and thorough scan. Significantly slower, but recommended for finding rare phrases or ensuring nothing is missed.

Lab Mode Parameters

When Lab Mode is active, a settings panel appears. The available settings depend on the active tab.

Search Tab Parameters

  • Min Match %: Minimum percentage of the query text required to consider a result relevant.
  • Max Results to Process: Maximum number of raw candidates to fetch from the index before detailed scoring. The software first retrieves potential candidates, then searches within them. More candidates result in better accuracy but slower performance.
  • Deep Limit: Maximum number of documents to scan in Deep Scan mode.

Composition Tab Parameters

  • Max Candidates per Chunk: Maximum number of index hits to process per text chunk.
  • Min Chunk Score: Minimum score required for a chunk to be considered a match.
  • Max Final Results: Maximum number of results to display in the tree to prevent freezing (all results are still exported).

Advanced Scoring

Accessible via the "Advanced Scoring..." button:

  • Sequential Order Bonus: Bonus points for finding words in the correct order.
  • Coverage Penalty Power: Penalizes results that do not contain all search terms.
  • Stop-Word Suppression: Lowers the score for very short or common words to reduce noise.
  • Long Word Bonus: Gives higher weight to longer words.
  • Unique Match Base Score: The base score for finding a unique word.
  • Distance Penalty: Penalizes words found far apart from each other.
  • Repeated Word Factor: Reduces score for words appearing more often in the text than in the query.

Settings & About

The Settings tab provides configuration options and information about the application.

Data & Index

  • Download Transcriptions: Opens a link to download the latest transcription data from Zenodo.
  • Build/Rebuild Index: Creates or updates the search index from the Transcriptions.txt file. Required after downloading new transcriptions.

AI Configuration

  • Provider: Select your AI provider (Google Gemini, OpenAI, or Anthropic Claude).
  • Model: The model name to use (defaults are provided for each provider).
  • API Key: Enter your API key for the selected provider.

Application

  • Version: Displays the current application version.
  • Check for Updates: Checks GitHub for new releases. When a new version is available, a notification bar appears at the top of the window.

About

Contains information about the application, credits, data sources, and citation information. Use the "Copy" button to copy the recommended citation.

Exporting Data

At any stage, you can export results for external use:

  • XLSX (Excel): Includes rich formatting and color highlighting of found words within context.
  • CSV: Raw data format, suitable for importing into other databases.
  • TXT: Simple readable text report.
  • DOCX (Word): Microsoft Word document with formatted report.

Note: Export applies to selected results (checkboxes). If nothing is selected, the software exports all available results in the table.

הקדמה: איך זה עובד?

תוכנת Dicta Genizah Search מאפשרת גישה מהירה ומתקדמת לקורפוס התעתוקים של פרויקט "מדרש" (MiDRASH). התוכנה מבוססת על מנוע חיפוש מהיר (Tantivy) ומשלבת אלגוריתמים ייחודיים לטיפול בשונות הכתיב העברית המאפיינת את כתבי היד של הגניזה.

התוכנה פועלת באופן מקומי על המחשב שלכם, אך משתמשת בחיבור אינטרנט כדי למשוך מידע ותמונות מהספרייה הלאומית, מספריית אוקספורד ומספריית האוניברסיטה של קמברידג'. בלי חיבור לאינטרנט היא תעבוד, אך ללא התמונות וללא חלק מהמידע המורחב. שימו לב: אם החיבור שלכם אינו ביתי (כמו נקודה חמה מהטלפון הנייד שלכם) שרתי הספרייה יכולים לחסום אתכם מלקבל מידע.

לשונית חיפוש

זוהי נקודת הכניסה לחיפוש טקסט חופשי או מטא-דאטה בקורפוס.

סוגי חיפוש

  • מדויק: מוצא רק את המילה בדיוק כפי שנכתבה.
  • וריאנטים: מתחשב בחילופי אותיות נפוצים בטקסטים אלו (למשל: ד/ר, ה/ח, ו/י).
  • מורחב / מקסימלי: מאפשרים גמישות רבה יותר בחילופי אותיות (כגון ק/כ, ט/ת), אך עלולים להחזיר תוצאות פחות רלוונטיות ("רעש"), ולקחת יותר זמן חיפוש.
  • עמום: משתמש במרחק לווינשטיין (Levenshtein distance) למציאת מילים דומות גם אם יש שגיאות פענוח.
  • ביטוי רגולרי (Regex): חיפוש מתקדם למשתמשים מנוסים. לדוגמה, \bא[א-ת]{3}\b ימצא מילים בנות 4 אותיות המתחילות ב-א'.
  • עוזר בינה מלאכותית (🤖): לחצו על כפתור ה-AI לפתיחת ממשק צ'אט שעוזר ליצור תבניות רגקס. תארו בשפה חופשית מה אתם מחפשים, והבינה המלאכותית תיצור את הביטוי הרגולרי המתאים. תומך ב-Google Gemini, OpenAI ו-Anthropic Claude (הגדירו את מפתח ה-API בלשונית ההגדרות).
  • כותרת: חיפוש בתוך המידע הקטלוגי של הכותרות. דוגמה: חיפוש "משנה תורה" יביא את כל כתבי היד המזוהים כמשנה תורה לרמב"ם.
  • מספר מדף: חיפוש מהיר של מספר מדף (למשל: "T-S 13.15").

אפשרויות נוספות

  • מרחק: מגדיר כמה מילים יכולות להפריד בין מילות החיפוש. ערך 0 מחייב רצף מדויק.
  • בחר הכל: בראש הטבלה ישנה תיבת סימון המאפשרת לבחור את כל התוצאות (או את התוצאות המוצגות כרגע) לצורך ייצוא ממוקד.
  • תצוגה מקדימה: לחיצה כפולה על שורה תפתח את צפיין כתב היד המלא באותו עמוד. לחיצה על לחצן ה"👁" תוביל לאותה תוצאה.
  • עיון בכתב יד: לחיצה על לחצן ה"📖" תוביל לפתיחת כתב היד בלשונית עיון בכתב יד. לחצן עיון דומה נמצא גם בצפיין כתב היד.
  • סינון עמודות: לחיצה על כותרות העמודות (מספר מדף, כותרת, קטע) מאפשרת לסנן תוצאות לפי טקסט. סמנו "החרג" כדי להסתיר תוצאות תואמות במקום להציג אותן.

הגדרות חיפוש (⚙)

לחצו על סמל גלגל השיניים לפתיחת הגדרות חיפוש מתקדמות:

  • הגבלת מילים קצרות: מילים עם ≤ N תווים יקבלו שינוי תו אחד בלבד במצבי וריאנטים.
  • מקסימום שינויים למילה: מספר החלפות התווים המרבי המותר למילה (ברירת מחדל: 2).
  • מצב אגרסיבי: מתעלם ממגבלות אורך מילה ביצירת וריאנטים.
  • זוגות וריאנטים מותאמים אישית: הגדירו זוגות החלפת אותיות משלכם (למשל: "נו=מ", אחד בכל שורה).

חיפוש חיבורים

כלי זה נועד לחוקרים המעוניינים למצוא מקבילות לטקסט ספרותי שלם (כגון פיוט, פירוש מימי הביניים או חיבור נדיר אחר) בתוך הגניזה, ובכך לאתר עדי נוסח נוספים, ישירים ועקיפים.

איך זה עובד? (המנגנון)

בניגוד לחיפוש רגיל, המנוע לא מחפש את הטקסט כולו כמקשה אחת. התהליך מתבצע כך:

  1. התוכנה מחלקת את טקסט המקור שהזנתם למקטעים קטנים.
  2. כל מקטע נשלח לחיפוש בנפרד במאגר הגניזה.
  3. אם מקטע מסוים נמצא בכתב יד, הוא מקבל "ניקוד".
  4. בסוף התהליך, התוכנה מקשרת מחדש את התוצאות: אם כתב יד מכיל הרבה מקטעים שנמצאו, הוא יקבל ציון גבוה ויופיע בראש הרשימה.

פרמטרים חשובים

  • מקטע: מספר המילים בכל יחידת חיפוש. ערך נמוך יחזיר הרבה תוצאות לא רלוונטיות; ערך גבוה עלול להחמיץ תוצאות אמת.
  • תדירות מקס': כלי לסינון ביטויים נפוצים. אם המנוע מגלה שרצף מילים מסוים מופיע פעמים רבות בקורפוס (כמו מטבעות לשון או פסוקים), הוא יסנן אותו לנספח.
  • סינון >: אם כותרת מסוימת (למשל "סידור רב סעדיה גאון") מופיעה בתוצאות יותר מ-X פעמים, התוכנה תקבץ את כל התוצאות הללו תחת "קבוצה" אחת בנספח, כדי לא להציף את הרשימה הראשית.
  • מיין לפי מספר מדף בלבד: מבטל את הקיבוץ החכם ומציג רשימה שטוחה וממוינת של כל כתבי היד שנמצאו.

אפשרויות מתקדמות

  • החרג כתבי יד: מאפשר להזין רשימה של כתבי יד שאתם כבר מכירים ורוצים להסתיר מהתוצאות (יופיעו תחת קטגוריית "מוחרגים").
  • סנן טקסט: מאפשר להזין טקסטים ספציפיים שברצונכם לסמן כ"מסוננים" בתוצאות. לדוגמה, אם הטקסט שלכם מצטט פסוקים או משנה או גמרא, תוכלו להכניס את הטקסטים האלה לתוך הסינון וכך "רעש" זה לא יוצג.
  • חיפוש רקורסיבי: לאחר קבלת תוצאות, כפתור זה יחפש שוב במאגר, הפעם תוך שימוש בטקסטים של כתבי היד שנמצאו כבסיס לחיפוש נוסף. החיפוש יכול להיות רקורסיבי מלא, או רק בתוצאות שתבחרו לאחר החיפוש הראשוני.

עיון בכתב יד

לשונית זו מאפשרת קריאה רציפה ונוחה של כתב יד שלם, עם סנכרון לתמונות המקור.

  • טעינה: הזינו מספר מערכת, מספר מדף או מזהה FL. החיפוש גמיש ומתעלם מרווחים או סימני פיסוק (למשל TS 13 15 ימצא את T-S 13.15). השלמה אוטומטית זמינה למספרי מדף.
  • דפדוף בעמודים: השתמשו בחיצים < > כדי לדפדף בין העמודים בתוך כתב היד הנוכחי.
  • דפדוף בין כתבי יד: השתמשו בחיצים ▶ ◀ בפינה העליונה כדי לעבור לכתב היד הבא או הקודם במאגר (לפי סדר הקבצים).
  • תמונות: בצד ימין (או שמאל, תלוי בשפה) מוצג צפיין תמונות. ניתן לסובב, להגדיל, ולבחור מקור תמונה (הספרייה הלאומית או ספריית קמברידג'/אוקספורד במקרים נתמכים). השתמשו ב-🖼️ כדי להציג/להסתיר את פאנל התמונות.
  • הכל: כפתור המציג את כל עמודי כתב היד ברצף אחד ארוך לגלילה נוחה ולשמירה כקובץ טקסט.
  • חיפוש בטקסט: הקלידו בשדה החיפוש כדי להדגיש טקסט תואם בזמן אמת בתוך כתב היד הנוכחי.
  • מצא מקבילות: שולח את טקסט העמוד הנוכחי ללשונית חיפוש חיבורים לאיתור מקבילות בכל הקורפוס.
  • צפה בכתיב: פותח את כתב היד בקטלוג המקוון של הספרייה הלאומית.

מצב מעבדה

כפתור "מצב מעבדה" מפעיל מנוע חיפוש ניסיוני ומתקדם יותר.

  • סריקה עמוקה: סריקה מעמיקה ויסודית יותר. איטית משמעותית, אך מומלצת לחיפוש ביטויים נדירים או כשרוצים לוודא שלא החמצתם כלום.

פרמטרים של מצב מעבדה

כאשר מצב מעבדה פעיל, מופיע פאנל הגדרות. ההגדרות הזמינות משתנות בהתאם ללשונית הפעילה.

פרמטרים ללשונית חיפוש

  • אחוז התאמה מינימלי: אחוז הטקסט המזערי מהשאילתא שחייב להופיע כדי שהתוצאה תיחשב רלוונטית.
  • מקסימום תוצאות לעיבוד: מספר המועמדים הגולמיים המרבי שיישלף מהאינדקס לפני שלב הניקוד המפורט. התוכנה שולפת ראשית מועמדים פוטנציאליים, ואז מחפשת בהם. מספר מועמדים רב יותר ימצא תוצאות טובות יותר, אבל יהיה איטי יותר.
  • מגבלת עומק: מספר המסמכים המרבי לסריקה במצב "סריקה עמוקה".

פרמטרים ללשונית חיפוש חיבורים

  • מקסימום מועמדים למקטע: מספר התוצאות המרבי שיעובדו עבור כל מקטע טקסט.
  • ציון מקטע מינימלי: הניקוד המזערי הנדרש כדי שמקטע ייחשב כ"נמצא".
  • מקסימום תוצאות סופיות: מספר התוצאות שיוצגו בעץ כדי למנוע קיפאון של הממשק (כל התוצאות עדיין נשמרות בייצוא).

ניקוד מתקדם

זמין דרך כפתור "ניקוד מתקדם...":

  • בונוס רצף מילים: ניקוד נוסף על מציאת מילים בסדר הנכון.
  • מקדם קנס כיסוי: קנס על תוצאות שאינן מכילות את כל מילות החיפוש.
  • סינון מילות עצירה: מפחית את הניקוד למילים קצרות או נפוצות מאוד כדי להפחית רעש.
  • בונוס מילה ארוכה: נותן משקל רב יותר למילים ארוכות.
  • ניקוד בסיס להתאמה ייחודית: הניקוד הבסיסי למציאת מילה ייחודית.
  • קנס מרחק: מפחית ניקוד למילים שנמצאו רחוק זו מזו.
  • קנס על מילים חוזרות: מפחית ניקוד למילים המופיעות בטקסט יותר פעמים מאשר בשאילתא.

הגדרות ואודות

לשונית ההגדרות מספקת אפשרויות תצורה ומידע על האפליקציה.

נתונים ואינדקס

  • הורדת תעתוקים: פותח קישור להורדת נתוני התעתוק העדכניים מ-Zenodo.
  • בניית/עדכון אינדקס: יוצר או מעדכן את אינדקס החיפוש מקובץ Transcriptions.txt. נדרש לאחר הורדת תעתוקים חדשים.

הגדרת בינה מלאכותית

  • ספק: בחרו את ספק ה-AI שלכם (Google Gemini, OpenAI או Anthropic Claude).
  • מודל: שם המודל לשימוש (ברירות מחדל מסופקות לכל ספק).
  • מפתח API: הזינו את מפתח ה-API של הספק שנבחר.

אפליקציה

  • גרסה: מציג את גרסת האפליקציה הנוכחית.
  • בדיקת עדכונים: בודק אם יש גרסאות חדשות ב-GitHub. כאשר גרסה חדשה זמינה, מופיעה התראה בראש החלון.

אודות

מכיל מידע על האפליקציה, קרדיטים, מקורות נתונים ומידע לציטוט. השתמשו בכפתור "העתק" כדי להעתיק את הציטוט המומלץ.

ייצוא נתונים

בכל שלב ניתן לייצא את התוצאות לשימוש חיצוני:

  • XLSX (אקסל): כולל עיצוב עשיר וסימון בצבע של המילים שנמצאו בתוך הקשר המשפט.
  • CSV: פורמט נתונים גולמי, מתאים לייבוא למסדי נתונים אחרים.
  • TXT: דוח טקסט פשוט וקריא.
  • DOCX (וורד): מסמך מעוצב של מייקרוסופט וורד.

שימו לב: הייצוא מתייחס לתוצאות שנבחרו (באמצעות תיבות הסימון). אם לא נבחר כלום, התוכנה תייצא את כל התוצאות הקיימות בטבלה.
