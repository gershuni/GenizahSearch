# GenizahSearch for Claude

This plugin connects Claude to Dicta Genizah Search, a free research platform for the Cairo Genizah
manuscripts at https://genizahsearch.com. It adds the GenizahSearch connector (a public MCP server,
no account needed) and a skill that teaches Claude the research workflow: search a Hebrew or
Judeo-Arabic phrase or a shelfmark, wait for the search and page through its results, read
manuscript pages before quoting them, find parallels to a passage, read catalogue records and
bibliography, and cite each page with the citation the server provides, which credits whoever made
the text shown.
