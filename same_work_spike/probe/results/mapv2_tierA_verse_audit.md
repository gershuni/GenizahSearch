## Interpretation note (orchestrator, 05:40) — two populations, only one is a defect

The suspect list mixes two fundamentally different cases:

**(a) Audit artifacts — statutory-liturgy editions.** Works whose OWN text IS
statutory liturgy (תפילת עמידה ברכות ראשונות 272/275 flagged, סדר רחמין,
סדר תפילה קראי, הגדה parts) overlap the guard reference BY CONSTRUCTION —
the guard's statutory units contain the same prayers these editions edit.
Under the witness-via-lens semantics these pages ARE witnesses of the unit;
the flag says nothing wrong about them. Next audit cycle: exempt works whose
reference stream itself has >=0.45 coverage by the guard reference (same
own-idiom logic as the deck's cite-formula exemption).

**(b) TRUE census defects — halakhic codes credited via embedded canon.**
The ספר אהבה class Hillel flagged on day one, now quantified: משנה תורה
ספר אהבה (2,883 suspect rows; witnesses 3,124 -> 1,545 without them),
ספר זמנים (1,028), ארבעה טורים או"ח (521), הלכות הרי"ף שבת (424),
הלכות פסוקות (309), שאילתות (216). Pages whose visible content is statutory
prayer or a Bavli passage are credited to the halakhic code that EMBEDS that
text. These rows should carry a suspect flag in census products (the data is
in data/tierA_verse_suspects.json keyed (page_id, work_id)); actual removal
needs per-work review because a genuine Sefer-Ahavah codex page can also be
mostly prayer text — the flank/continuation test on the code's own prose is
the decisive check, which is exactly what the flag queues for review.
