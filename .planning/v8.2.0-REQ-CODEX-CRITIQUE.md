# Codex critique — v8.2.0 Web Joins Lab requirements (pre-lock, 2026-06-17)

Source: `codex exec` against `_tmp/web-joins-lab-req-brief.md`, grounded in the live codebase. All findings incorporated into `.planning/REQUIREMENTS.md` before lock.

## BLOCKERS (all incorporated)

1. **FND-01 adapter must wrap `state.searcher` directly, off the event loop.** The `/api/search` path omits `text_position`/`corpus_scope`, caps normal modes, passes `text_position=None` (`web/search_api.py:1032`). The web adapter should wrap `state.searcher.execute_search` directly, inside an async `run.io_bound`-style shell like `web/pages/search.py:3979`, with timeout / cancel / stale-generation handling. → **FND-01 rewritten.**
2. **PST is internally inconsistent.** `web/safe_storage.py` wraps SERVER-SIDE `app.storage.user`, not browser localStorage (`web/safe_storage.py:47`). NiceGUI `browser` = small encrypted cookie; `client` dies on refresh; `tab` is volatile per-tab (`nicegui/storage.py:84`). Decision: use server-side per-browser-session persistence via `safe_user_*` (survives refresh for anonymous users, keyed by the session cookie) — NOT a literal browser-localStorage claim. → **PST-01/02 rewritten.**
3. **ANC-04 known-joins RLS leak.** `fetch_connected_fragments` has a process-global cache keyed only by doc/PGP (`web/components/joins_panel.py:24`); `get_fragment_joins` may return creator-only proposed joins under RLS (`web/supabase_client.py:1574`) → could leak User A's unconfirmed joins to User B. Require public/confirmed-only rows or user/status-aware cache isolation. → **ANC-04 + ANC-05 (new).**
4. **ACT-02 bulk puzzle handoff missing.** `/puzzle?add=` accepts ONE `sys_id[,fl_id]` (`web/pages/puzzle.py:2218`); puzzle restore is internal `app.storage.tab`. Need a bulk staging payload/API for "anchor + selected candidates". → **ACT-02 rewritten.**

## HIGH (all incorporated)

- **PST conflicts with desktop parity** — desktop persists INPUTS/triage/filter/view ONLY, never candidates/results; restore RE-RUNS search async (`desktop/join_workbench.py:5148`). Adopt the same: persist inputs+triage, re-run on restore (also dodges the SEED-002 / search-history payload-bloat lesson). → **PST-01 rewritten.**
- **BLD-04/05 will silently drop JA/flex/bidirectional** — `compose()` hardcodes them false (`shared/joins_lab.py:741`); desktop patches via `_merge_globals` on both sides (`desktop/join_workbench.py:2473`). → **BLD-04 rewritten.**
- **Cross-side "other side" needs a web contract** — core assumes numeric `page ± 1` (`shared/joins_lab.py:286`); browse supports `volume_ie`, metadata-only pages, nearest-page fallback (`genizah_core.py:9869`). Define p_num vs internal index, multi-IE, unknown totals, sparse pages. → **BLD-02 rewritten.**
- **Parity omits candidate filters/pagination/enrichment** — desktop has material/dimensions/triage/size filters, selection, pagination, enrichment workers (`desktop/join_workbench.py:2294`). → **CND-06/07/08 (new).**
- **Image requirement too NLI-only** — browse uses NLI, Oxford, Cambridge, Manchester, JTS proxies (`web/pages/browse.py:3624`); reuse existing provider resolution/proxies + breaker, don't invent direct URLs. → **ANC-02 rewritten.**
- **CND-04 triage keying** — desktop dedups by `(sys_id,page)` but triage is `sys_id`-keyed and resets on re-anchor (`desktop/join_workbench.py:4982`). → **CND-04 rewritten.**
- **VSM-01 stale-anchor rules** — desktop tracks `_vs_loaded_sid` + pending toggle to prevent old-anchor eye badges after re-anchor (`desktop/join_workbench.py:2207`); add disabled/no-data + empty-intersection UX. → **VSM-01 rewritten.**
- **FND-03/04/05 deep-link contracts** — need exact params (`sys_id`, shelfmark, page/img, `fl_id`, `volume_ie`, initial VS mode) and whether builder/candidate state is shareable vs device-local. → **FND-08 (new).**
