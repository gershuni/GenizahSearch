# Domain Click Behavior in Browse Metadata

**Created:** 2026-02-13
**Priority:** Low
**Source:** Phase 27 UAT

## Context

When a user clicks a domain link/badge in the browse page metadata section, what should happen?

## Options

### (a) Standalone Domain Browsing Page
- New page showing all manuscripts with that domain classification
- Browse-style interface filtered by domain
- Could include domain hierarchy navigation

### (b) Pre-fill Search with Domain Filter Active
- Navigate to search page
- Set the domain filter to show only that domain (exclude all others)
- User would need to run a search first, then the filter would be applied

### (c) Pre-fill Search Query
- Navigate to search page with a special "domain:" search prefix
- This would require adding domain-aware search to the search engine
