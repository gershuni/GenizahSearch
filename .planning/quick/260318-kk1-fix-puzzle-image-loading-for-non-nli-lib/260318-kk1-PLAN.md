<objective>
Fix puzzle image loading for non-NLI libraries (Manchester, Oxford, JTS, Cambridge).

Currently, adding a Manchester, Oxford, or JTS manuscript to the puzzle fails with "No images found" because the image resolution paths only understand NLI IIIF FL IDs. These libraries serve images via IIIF canvas URLs stored in `images_ext` (populated by `enrich_metadata`), not FL IDs.

**Key design constraint:** Non-NLI library images do NOT need the browser extension. They use existing server-side proxy endpoints (`/api/manchester_image/`, `/api/cambridge_image/`, `/api/jts_image/`, `/api/oxford_image/`) that fetch IIIF images server-side. These proxies already exist and work for the browse page — the puzzle just needs to use them too.

**Background removal** works for external library images via the same HSV pipeline as NLI images. On desktop, `_fetch_direct_url` returns raw bytes → `remove_background()` applies. On web, the `_loadImageWithFallbacks` JS fetches raw bytes from the proxy endpoint, then the server applies BG removal (same as the extension upload flow). External fragments use `processed=True` with default `threshold=30.0`.

Purpose: Researchers need to assemble fragments from any Genizah holding library, not just NLI-hosted ones.
</objective>

## Architecture Overview

### Image Source Architecture

There are TWO categories of manuscript images:

1. **NLI-hosted** (CUL, RNL, ENA, etc.): Images served via NLI IIIF.
   - Identified by FL IDs (e.g., FL7734473)
   - URL pattern: `https://iiif.nli.org.il/IIIFv21/FL{digits}/full/{size},/0/default.jpg`
   - On web: fetched via browser extension (NLI blocks datacenter IPs) or server cache
   - On desktop: fetched directly from NLI IIIF

2. **External library** (Manchester, Oxford, Cambridge, JTS): Images served via each library's own IIIF.
   - Identified by page index (0, 1, 2...) into `images_ext` array
   - Canvas URLs stored in `enrich_metadata` result: `data['images_ext']`
   - `data['external_provider']` = 'manchester' | 'cambridge' | 'oxford' | 'jts'
   - On web: fetched via server-side proxy endpoints (NO extension needed)
   - On desktop: fetched directly using IIIF URLs

### How enrich_metadata Returns External Images

`genizah_core.py` `MetadataManager.enrich_metadata(sys_id)` returns a dict with:
```python
data['images_nli'] = [{'fl_id': str, 'label': str, 'url': str}, ...]   # NLI IIIF FL IDs
data['images_ext'] = [{'label': str, 'url': str, 'folio_num': int|None}, ...]  # External canvas base URLs
data['external_provider'] = 'manchester' | 'cambridge' | 'oxford' | 'jts' | None
```

Format of `images_ext` entries by library:
- **Manchester**: `{'label': 'A', 'url': 'https://luna.manchester.ac.uk/luna/servlet/iiif/{luna_id}', 'folio_num': None}`
- **Cambridge**: `{'label': '1r', 'url': 'https://images.lib.cam.ac.uk/iiif/{canvas_id}'}`
- **Oxford**: `{'label': '21a', 'url': 'https://hebrew.bodleian.ox.ac.uk/.../full_url', 'thumb_url': '...', 'folio_num': 21}`
- **JTS**: `{'label': '1', 'url': 'https://iiif-cloud.princeton.edu/iiif/2/{id}'}`

Image fetch URL = `{canvas_url}/full/{size},/0/default.jpg`

### Existing Web Proxy Endpoints (already working for browse page)

```
GET /api/cambridge_image/{sys_id}?page=N   -> looks up images_ext[N] from nli_cache, fetches {url}/full/2000,/0/default.jpg
GET /api/manchester_image/{sys_id}?page=N  -> looks up images_ext[N] from nli_cache, fetches {url}/full/2000,/0/default.jpg
GET /api/jts_image/{sys_id}?page=N         -> looks up images_ext[N] from nli_cache, fetches {url}/full/2000,/0/default.jpg
GET /api/oxford_image/{sys_id}?page=N      -> uses CodicologicalManager, different lookup path
```

**Important**: These proxy endpoints require `enrich_metadata` to have been called first (populates `nli_cache`). So the puzzle's folio resolution must call `enrich_metadata` to populate the cache before the proxy endpoints will work.

### Browser Extension

The GenizahSearch Image Helper Chrome extension (`extension/`) is ONLY for NLI images. It exists because NLI blocks datacenter IPs (server can't fetch), so the browser extension fetches NLI images in the user's browser and sends them to the server for bg removal.

External library images (Manchester, Oxford, etc.) are fetched server-side through the proxy endpoints — **NO extension needed**.

def _fetch_direct_url(self, image_url: str, size: int) -> Optional[bytes]:
    """Fetch image from a direct IIIF canvas URL (non-NLI libraries)."""
    # Build IIIF Image API URL: {canvas_base}/full/{size},/0/default.jpg
    if '/full/' in image_url:
        url = image_url  # Already a complete image URL
    else:
        url = f"{image_url}/full/{size},/0/default.jpg"

    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
    }
    try:
        resp = requests.get(url, headers=headers, timeout=30)
        if resp.status_code == 200 and len(resp.content) > 100:
            logger.info(f"Direct IIIF fetch OK for {image_url[:80]}")
            return resp.content
        else:
            logger.warning(f"Direct IIIF fetch non-200 for {image_url[:80]}: status={resp.status_code}")
    except Exception as e:
        logger.warning(f"Direct IIIF fetch failed for {image_url[:80]}: {e}")
    return None

```python
@app.get('/api/puzzle_ext_image')
def puzzle_ext_image(sys_id: str, page: int = 0, provider: str = '',
                     threshold: float = 30.0, size: int = 800,
                     processed: bool = True):
    """Serve processed external library image for puzzle canvas.

    Delegates to the existing provider-specific proxy endpoints to fetch raw bytes,
    then applies BG removal and caches the processed result.

    IMPORTANT: Oxford images_ext entries have complete 'full_url' values (not canvas
    base URLs), so the existing oxford_image endpoint handles them differently from
    Cambridge/Manchester/JTS which use canvas_url + '/full/{size},/0/default.jpg'.
    This endpoint does NOT reimplement fetch logic — it calls the provider endpoints.
    """
    from shared.puzzle_image_service import get_puzzle_image_service
    from shared.background_removal import remove_background

    if not provider or not sys_id:
        return Response(content="Missing provider or sys_id", status_code=400)

    # Cache key: includes provider to avoid collisions between libraries sharing sys_ids
    cache_id = f"{provider}_{sys_id}_page{page}"
    service = get_puzzle_image_service()
    cache_path = service.get_cache_path(cache_id, size, threshold, processed, is_cul=False)

    # Return cached if exists
    if cache_path.exists():
        try:
            cached = cache_path.read_bytes()
            content_type = 'image/png' if cached[:4] == b'\x89PNG' else 'image/jpeg'
            return Response(content=cached, media_type=content_type,
                          headers={"Cache-Control": "public, max-age=3600"})
        except (FileNotFoundError, OSError):
            pass

    # Delegate to existing provider-specific endpoint to fetch raw image bytes.
    # Each endpoint handles its own URL construction:
    #   - cambridge_image: canvas_url + '/full/2000,/0/default.jpg'
    #   - manchester_image: canvas_url + '/full/2000,/0/default.jpg'
    #   - jts_image: canvas_url + '/full/2000,/0/default.jpg'
    #   - oxford_image: uses full_url directly (or generates from part_id + folio)
    proxy_map = {
        'cambridge': cambridge_image,
        'manchester': manchester_image,
        'jts': jts_image,
        'oxford': oxford_image,
    }
    proxy_fn = proxy_map.get(provider)
    if not proxy_fn:
        return Response(content=f"Unknown provider: {provider}", status_code=400)

    # Call the existing proxy — returns a Response with image bytes
    proxy_resp = proxy_fn(sys_id=sys_id, page=page)
    if proxy_resp.status_code != 200:
        return proxy_resp  # Pass through error

    raw_bytes = proxy_resp.body
    if not raw_bytes or len(raw_bytes) < 100:
        return Response(content="Empty image from proxy", status_code=502)

    # Apply BG removal if requested
    if processed:
        try:
            result_bytes = remove_background(raw_bytes, threshold=threshold)
        except Exception:
            result_bytes = raw_bytes  # fallback to original
    else:
        result_bytes = raw_bytes

    # Cache result
    try:
        cache_path.parent.mkdir(parents=True, exist_ok=True)
        cache_path.write_bytes(result_bytes)
    except OSError:
        pass

    content_type = 'image/png' if result_bytes[:4] == b'\x89PNG' else 'image/jpeg'
    return Response(content=result_bytes, media_type=content_type,
                  headers={"Cache-Control": "public, max-age=3600"})
```
