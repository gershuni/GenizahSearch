<objective>
Implement SEED-031: gently re-invite not-yet-opted-in desktop users to enable telemetry
on a new-version launch, WITHOUT nagging — via a throttled, NON-MODAL bar.

Today desktop telemetry is opt-in via a single first-run modal gated on `FIRST_RUN_SHOWN_KEY`,
so it shows at most once ever and a reflexive "Not now" becomes a permanent lifetime opt-out
(~9 opt-in users observed). This plan loosens the too-strict lock (it does NOT add pressure):
re-ask ONLY when all hold — not already opted in, ≥30 days since last ask, under a ~3 lifetime
cap, and the user has not chosen "Don't ask again."

Purpose: raise informed opt-in without dark patterns, preserving all Phase 112–116 anti-nag
hardening.
Output: re-askable config-model + a non-modal re-ask bar + faithful gate logic + tests.
</objective>
