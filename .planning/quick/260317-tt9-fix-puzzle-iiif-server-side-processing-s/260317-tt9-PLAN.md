  <name>Task 2: Update all three JS fallback paths to use /iiif-proxy/ instead of direct NLI</name>

  <action>
Update ALL THREE JavaScript fallback paths in the puzzle.py JS block. Each currently falls back to direct NLI URL `https://iiif.nli.org.il/IIIFv21/FL{digits}/full/{size},/0/default.jpg`. Change them to use the same-origin proxy path `/iiif-proxy/FL{digits}/full/{size},/0/default.jpg`.

Because `/iiif-proxy/` is same-origin, the fallback can keep `crossOrigin='anonymous'` and use fetch() + createObjectURL for a cleaner approach. However, for simplicity and consistency, just change the URL in each fallback — the img tag approach still works fine for display (even without bg removal).

**1. addFragment onerror (line ~365-394):**
Change line 380:
```javascript
// OLD: var iiifUrl = 'https://iiif.nli.org.il/IIIFv21/FL' + digits + '/full/' + iiifSize + ',/0/default.jpg';
// NEW: use same-origin proxy (Cloudflare Worker)
var iiifUrl = '/iiif-proxy/FL' + digits + '/full/' + iiifSize + ',/0/default.jpg';
```
KEEP the `htmlImg.removeAttribute('crossOrigin')` and the rest of the fallback logic unchanged. The proxy adds CORS headers, but removing crossOrigin is still safe for the img-tag-only display path.

Actually, since /iiif-proxy/ IS same-origin AND adds CORS headers, we can KEEP crossOrigin='anonymous'. This means if the proxy works, the image won't taint the canvas. Better approach: DON'T remove crossOrigin in the proxy fallback. Only remove it in the final "both failed" fallback (direct NLI):

```javascript
htmlImg.onerror = function(err) {
    console.warn('Server fetch failed for', key, '— trying proxy');
    var m = meta || {};
    var flId = m.fl_id || '';
    var digits = String(flId).replace(/[^0-9]/g, '');
    if (!digits) {
        console.error('No fl_id digits for fallback:', key);
        self._removePlaceholder(key);
        self._emitEvent('puzzle-add-result', { key: key, success: false, error: 'no-fl-id' });
        return;
    }
    var iiifSize = (m.size || 800);
    // Try same-origin Cloudflare proxy (keeps crossOrigin for canvas compatibility)
    var proxyUrl = '/iiif-proxy/FL' + digits + '/full/' + iiifSize + ',/0/default.jpg';
    htmlImg.onerror = function() {
        // Proxy also failed — last resort: direct NLI (no bg removal, no canvas access)
        console.warn('Proxy failed for', key, '— loading NLI directly');
        var directUrl = 'https://iiif.nli.org.il/IIIFv21/FL' + digits + '/full/' + iiifSize + ',/0/default.jpg';
        htmlImg.removeAttribute('crossOrigin');
        htmlImg.onerror = function() {
            console.error('All image sources failed for', key);
            self._removePlaceholder(key);
            self._emitEvent('puzzle-add-result', { key: key, success: false, error: 'iiif-failed' });
        };
        htmlImg.src = directUrl;
    };
    htmlImg.src = proxyUrl;
};
```
