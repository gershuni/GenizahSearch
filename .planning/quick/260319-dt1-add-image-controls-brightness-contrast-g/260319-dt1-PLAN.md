**2. Add adjustment state to ZoomableScrollArea** (L1394):
- New instance variables: `_brightness = 0` (range -100..+100), `_contrast = 0`, `_gamma = 1.0` (range 0.2..3.0), `_invert = False`.
- New method `set_adjustments(brightness, contrast, gamma, invert)` that stores values and calls `_apply_display_filters()`.
- New method `_apply_display_filters()` that:
  1. If no pixmap, return.
  2. Take `self._pixmap` (original), convert to QImage.
  3. Apply adjustments via LUT (lookup table) for performance:
     - Build 256-entry LUT: for each input value 0-255, apply brightness (add offset), contrast (multiply around midpoint), gamma (power function), invert (255 - val).
     - Formula per pixel channel: `val = clamp(((val - 128) * contrast_factor + 128) + brightness_offset, 0, 255)`, then `val = 255 * (val/255)^(1/gamma)`, then if invert: `val = 255 - val`.
     - `brightness_offset = brightness * 2.55` (maps -100..+100 to -255..+255 range, scaled)
     - `contrast_factor = 1 + contrast/100` (maps -100..+100 to 0..2 multiplier)
  4. Apply LUT to every pixel of the QImage (use `scanLine` for performance, or `bits()` with numpy if available). For simplicity without numpy: iterate using `QImage.pixel()`/`setPixel()` but convert to Format_RGB32 first for speed. Better: use Python `bytes`/`bytearray` manipulation on `QImage.bits()`.
  5. Convert adjusted QImage back to QPixmap, set on `_pixmap_item`.
- New method `reset_adjustments()`: sets all to defaults, calls `_apply_display_filters()`.

**3. Update `_get_rotated_pixmap()`** (L1460) to return the ADJUSTED + rotated pixmap:
- Rename to `_get_export_pixmap()` (or keep name but apply adjustments).
- Apply the same LUT-based adjustment to `self._pixmap` before rotation.
- This ensures Copy Image and Save Image As export the filtered version.

**4. Update `set_image()`** (L1470) to reset adjustments when a new image loads (call `reset_adjustments()` but skip the display update since `set_image` already handles display).

**5. Add controls toolbar row to ManuscriptViewerWidget** (after existing top_bar at L1665):
- New `QHBoxLayout` as second toolbar row.
- `QLabel("B")` + `QSlider(Horizontal, -100..+100, default 0, width 120)` connected to `self.scroll_area.set_adjustments(...)`.
- Same for Contrast ("C") and Gamma ("G", slider 20..300, default 100, map to 0.2..3.0).
- `QPushButton` for Invert toggle (text "Inv" or icon, checkable button).
- `QPushButton` for Reset ("Reset Adjustments").
- Connect all sliders via `valueChanged` → `_schedule_filter_update()` which uses a **QTimer debounce (100ms)** to batch rapid slider drags into a single filter pass. This is mandatory, not optional — 2000x3000 images at 6M pixels need throttling.
- Store slider/button references as instance variables so Reset can set them back to defaults.
- Add this row with `layout.addLayout(adj_bar)` right after `layout.addLayout(top_bar)` (before attribution label).

**6. Performance:** Use `QTimer.singleShot(100, self._apply_adjustments)` pattern — on slider `valueChanged`, restart a 100ms timer. Only the final value triggers the LUT pass. Use `QImage.Format_ARGB32` and `bits()` + `memoryview` for direct byte access. The LUT approach processes each pixel once with a pre-computed 256-entry table.

**Important:** Keep `self._pixmap` as the ORIGINAL unmodified image. Display filtering creates a temporary adjusted pixmap for the scene. Export also applies from `self._pixmap` to get full quality.
