# Quick Task 260714-9jc: FGP default demotion via coverage ratio

Implements SEED-030 (`.planning/seeds/SEED-030-fgp-default-coverage-ratio.md`). Design is
fully specified + Codex-reviewed there. Reading-view default now shows the V0.8/HTR (MiDRASH)
transcription instead of an FGP source when the FGP edition is a partial/selected excerpt of
the folio (Gregor Schwarb report; Firkovich median ~9% coverage).

## Task 1 — shared coverage policy (`shared/fgp_service.py`)

- **files:** `shared/fgp_service.py`
- **action:**
  - `_heb_letter_count(text)` — count base Hebrew letters, reusing the module's existing
    `_HEBWORD_RE` (`[א-ת]+`) + `_NIKUD_RE` (strips points/te'amim). Naturally strips
    whitespace/punctuation/`][` lacuna markers and KEEPS letters inside `[...]` brackets.
    (Deliberate deviation from the seed's "reuse strip_search_diacritics" — the module already
    has purpose-built Hebrew-letter regexes; cleaner + no cross-module import.)
  - `_DEFAULT_MIN_COVERAGE = 0.33`, `_COVERAGE_MIN_HTR_LETTERS = 40`, `_min_coverage()`
    (env override `FGP_DEFAULT_MIN_COVERAGE`, re-read per call, bounds [0,1]).
  - `choose_default_source(sources, htr_text, page_num) -> {source, reason, ratio, eligible}` —
    pure. FGP editions only (`group_transcription_sources`); per-folio FGP text via
    `get_fgp_section_for_page` (NOT `content`); demote when best edition coverage < threshold;
    KEEP FGP when HTR letters < floor (unknown baseline); `logger.debug` the ratio.
- **verify:** import + call in a REPL with hand-built dicts; unit tests (Task 5).
- **done:** helper importable, pure, no DB.
