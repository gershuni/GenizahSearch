<objective>
Fix Manchester image fetch so recto and verso are shown as separate pages instead of showing
recto for both sides.

Purpose: Manchester LUNA stores each page (recto/verso) as a SEPARATE luna_id with its own
IIIF manifest containing exactly 1 canvas. The current code takes only the first crossref
image's ImageSourceName to construct a single manifest URL, so all pages resolve to the same
(first) image. The fix builds canvas entries directly from ALL crossref images, bypassing the
single-manifest fetch for Manchester.

Output: Correct multi-page Manchester image display in both web and desktop apps.
</objective>
