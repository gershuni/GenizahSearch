<objective>
Migrate Supabase authentication code from deprecated gotrue imports to current supabase_auth API, switch OAuth flow from implicit to PKCE, and remove all implicit-flow artifacts.

Purpose: The current `except AuthApiError` handlers import from `gotrue.errors` but supabase v2.28.0 raises `supabase_auth.errors.AuthApiError` -- these are distinct classes, so error handling is silently broken. This plan fixes the import (a correctness fix), removes the implicit OAuth flow in favor of PKCE (a security improvement), preserves OAuth error feedback for cancelled/failed flows, and removes the dead `/api/auth/oauth-callback` POST endpoint that was the server-side counterpart of implicit flow. Per D-01 through D-06.

Output: Four source files updated with correct imports, PKCE-only flow, cleaned-up callback handler with error param handling, and dead API endpoint removed.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> /auth/callback | OAuth redirect with authorization code or error params in query string |
| /auth/callback -> Supabase | Code exchange (code + code_verifier -> tokens) |
| Desktop -> Supabase | Direct email/password auth (no browser redirect) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-64-01 | Information Disclosure | OAuth flow | mitigate | Migrate from implicit flow (tokens in URL fragment visible to browser history/extensions) to PKCE (tokens never in URL) per D-01 |
| T-64-02 | Spoofing | PKCE code exchange | mitigate | code_verifier + S256 challenge prevents authorization code replay (built into supabase_auth, no custom code needed) |
| T-64-03 | Denial of Service | Singleton client code_verifier | accept | Concurrent OAuth logins could overwrite code_verifier in singleton storage. Low risk: small user base, concurrent OAuth rare. Documented as known limitation per RESEARCH.md |
| T-64-04 | Tampering | AuthApiError class mismatch | mitigate | Fix import from gotrue.errors to supabase_auth.errors so except blocks actually catch auth errors (currently silently broken) per D-04 |
| T-64-05 | Spoofing | /api/auth/oauth-callback POST | mitigate | Remove dead POST endpoint that accepts raw access/refresh tokens in request body -- this is an implicit-flow artifact that bypasses PKCE security. With implicit flow removed from the callback page, no client sends to this endpoint, making it dead code with unnecessary attack surface. |
</threat_model>
