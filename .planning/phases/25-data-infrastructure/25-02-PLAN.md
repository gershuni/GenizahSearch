**Class: FjmsService**

```python
class FjmsService:
    """Service for accessing FJMS enrichment data from the SQLite sidecar."""

    def __init__(self, db_path: str = None, thread_safe: bool = False):
        """
        Initialize FjmsService.

        Args:
            db_path: Path to fjms_enrichment.db. If None, auto-detect from project root.
            thread_safe: If True, use check_same_thread=False for NiceGUI web app.
                        Desktop app should leave this False (single-threaded).
        """
```

**Auto-detection of db_path:** Try these paths in order:
1. Explicit `db_path` parameter
2. `fist_data/fjms_enrichment.db` relative to the project root (detect project root by looking for `libraries.csv` up from `__file__`)

**Connection management:**
- Open connection in `__init__`, store as `self._conn`
- For web (thread_safe=True): `sqlite3.connect(db_path, check_same_thread=False)`
- For desktop (thread_safe=False): `sqlite3.connect(db_path)`
- Always open read-only: Use `sqlite3.connect(f'file:{db_path}?mode=ro', uri=True, check_same_thread=...)` to enforce read-only at the SQLite level
- Set `self._conn.row_factory = sqlite3.Row` for dict-like access
- If db_path does not exist, set `self._conn = None` and log a warning (graceful degradation)

**Methods to implement:**

1. `get_domains(self, sys_id: str) -> list[dict]`
   - Returns list of `{'domain': str, 'domain_heb': str, 'parent_domain': str, 'parent_domain_heb': str}`
   - Query: `SELECT Domain, DomainHeb, ParentDomain, ParentDomainHeb FROM domains WHERE AlmaId = ?`
   - Returns `[]` if conn is None or sys_id not found

2. `get_manuscripts_by_domain(self, domain: str) -> set[str]`
   - Returns set of AlmaId strings for manuscripts in the given domain
   - Query: `SELECT DISTINCT AlmaId FROM domains WHERE Domain = ? OR ParentDomain = ?`
   - This enables domain filtering in search: intersection of search results with domain set
   - Returns `set()` if conn is None

3. `get_all_domains(self) -> list[dict]`
   - Returns all unique domain names with counts for populating filter dropdowns
   - Query: `SELECT Domain, DomainHeb, COUNT(DISTINCT AlmaId) as count FROM domains GROUP BY Domain ORDER BY count DESC`
   - Returns `[]` if conn is None

4. `get_join_group(self, sys_id: str) -> list[dict]`
   - Returns list of `{'alma_id': str, 'join_group_id': int, 'scholar_name': str, 'comment': str, 'join_type': str}`
   - First finds the JoinGroupId(s) for the sys_id, then fetches all members of those groups
   - Query (two-step):
     ```sql
     -- Step 1: Find join group IDs for this manuscript
     SELECT DISTINCT JoinGroupId FROM joins WHERE AlmaId = ?
     -- Step 2: Get all members of those groups (excluding the query sys_id)
     SELECT AlmaId, JoinGroupId, ScholarName, Comment, JoinType
     FROM joins WHERE JoinGroupId IN (?) AND AlmaId != ?
     ```
   - Use parameterized IN clause (build placeholder string dynamically)
   - Returns `[]` if conn is None or no joins found

5. `get_catalog(self, sys_id: str) -> dict | None`
   - Returns catalog metadata dict or None
   - Query: `SELECT * FROM catalog WHERE AlmaId = ?`
   - Returns first matching row as dict with keys: `title, title_heb, author_text, copy_date, copy_place, description_eng, description_heb, textual_frame_heb, textual_frame_eng`
   - Map column names to snake_case keys in the returned dict
   - Returns `None` if conn is None or not found

6. `get_version(self) -> str | None`
   - Query: `SELECT value FROM meta WHERE key = 'version'`
   - Returns version string or None

7. `is_available(self) -> bool`
   - Returns True if `self._conn is not None`

8. `close(self)`
   - Close the connection if open. Called at app shutdown.

**Error handling:** All methods wrap queries in try/except, log errors, and return empty/None (never raise). Follow the pattern from `shared/document_service.py`.

**Module-level convenience:** Add a module-level singleton pattern:
```python
_default_service: FjmsService | None = None

def get_fjms_service(thread_safe: bool = False) -> FjmsService:
    """Get or create the default FjmsService singleton."""
    global _default_service
    if _default_service is None:
        _default_service = FjmsService(thread_safe=thread_safe)
    return _default_service
```
