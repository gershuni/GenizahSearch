Create `scripts/export_fist_enrichment.py` that:

1. **Connects to source**: `sqlite3.connect('FIST_DB_BACKUP/FIST.db')` (read-only)
2. **Creates target**: `sqlite3.connect('fist_data/fjms_enrichment.db')` in `fist_data/` directory (create dir if needed)

3. **Creates and populates the `domains` table:**
```sql
CREATE TABLE domains (
    AlmaId TEXT NOT NULL,
    Domain TEXT NOT NULL,
    DomainHeb TEXT,
    ParentDomain TEXT,
    ParentDomainHeb TEXT
);
CREATE INDEX idx_domains_alma ON domains(AlmaId);
CREATE INDEX idx_domains_domain ON domains(Domain);
```
Export query (join path verified against FIST.db schema):
```sql
SELECT DISTINCT
    TRIM(CAST(alma.AlmaId AS TEXT)) as AlmaId,
    d.EngDesc as Domain,
    d.HebDesc as DomainHeb,
    pd.EngDesc as ParentDomain,
    pd.HebDesc as ParentDomainHeb
FROM dbo_InventoryAlma alma
JOIN dbo_Inventory inv ON alma.InventoryId = inv.InventoryId
JOIN dbo_InventorySignature isig ON inv.InventoryId = isig.InventoryId
JOIN dbo_Signature sig ON isig.SetSignatureId = sig.SetSignatureId
JOIN dbo_UnitCatalogRec cat ON sig.SignatureId = cat.SignatureId
JOIN dbo_CatalogMultiDomain cmd ON cat.UnitCatalogRecId = cmd.UnitCatalogRecId
JOIN CODE_Domain d ON cmd.DomainId = d.DomainId
LEFT JOIN CODE_Domain pd ON d.BelongToDomainId = pd.DomainId
```
Expected: ~390K rows, ~203K distinct AlmaIds.

4. **Creates and populates the `joins` table:**
```sql
CREATE TABLE joins (
    AlmaId TEXT NOT NULL,
    JoinGroupId INTEGER NOT NULL,
    ScholarName TEXT,
    Comment TEXT,
    JoinType TEXT
);
CREATE INDEX idx_joins_alma ON joins(AlmaId);
CREATE INDEX idx_joins_group ON joins(JoinGroupId);
```
Export query:
```sql
SELECT DISTINCT
    TRIM(CAST(alma.AlmaId AS TEXT)) as AlmaId,
    uj.UnitJoinId as JoinGroupId,
    uj.ScholarName,
    uj.Comment,
    fc.EngDesc as JoinType
FROM dbo_InventoryAlma alma
JOIN dbo_Inventory inv ON alma.InventoryId = inv.InventoryId
JOIN dbo_InventorySignature isig ON inv.InventoryId = isig.InventoryId
JOIN dbo_Signature sig ON isig.SetSignatureId = sig.SetSignatureId
JOIN dbo_UnitJoin uj ON sig.SignatureId = uj.SignatureId
LEFT JOIN CODE_FullCode fc ON uj.JoinTypeCode = fc.ComputedCode
```
Expected: ~48K rows, ~20K distinct AlmaIds.

5. **Creates and populates the `catalog` table:**
```sql
CREATE TABLE catalog (
    AlmaId TEXT NOT NULL,
    Title TEXT,
    TitleHeb TEXT,
    AuthorText TEXT,
    CopyDate TEXT,
    CopyPlace TEXT,
    DescriptionEng TEXT,
    DescriptionHeb TEXT,
    TextualFrameHeb TEXT,
    TextualFrameEng TEXT
);
CREATE INDEX idx_catalog_alma ON catalog(AlmaId);
```
Export query:
```sql
SELECT DISTINCT
    TRIM(CAST(alma.AlmaId AS TEXT)) as AlmaId,
    cat.Title,
    cat.GenizahTitleText as TitleHeb,
    cat.AuthorText,
    CAST(cat.CopyDate AS TEXT) as CopyDate,
    cat.CopyPlace,
    cat.IdentificationTextEng as DescriptionEng,
    cat.IdentificationTextHeb as DescriptionHeb,
    cat.BI_TextualFrameHeb as TextualFrameHeb,
    cat.BI_TextualFrameEng as TextualFrameEng
FROM dbo_InventoryAlma alma
JOIN dbo_Inventory inv ON alma.InventoryId = inv.InventoryId
JOIN dbo_InventorySignature isig ON inv.InventoryId = isig.InventoryId
JOIN dbo_Signature sig ON isig.SetSignatureId = sig.SetSignatureId
JOIN dbo_UnitCatalogRec cat ON sig.SignatureId = cat.SignatureId
```
Expected: ~243K rows, ~226K distinct AlmaIds.
Note: CopyDate is stored as REAL in FIST (e.g., 1744.0); cast to TEXT and strip trailing `.0` in Python before insert.

6. **Creates FTS5 virtual table:**
```sql
CREATE VIRTUAL TABLE catalog_fts USING fts5(
    AlmaId,
    Title,
    TitleHeb,
    DescriptionEng,
    DescriptionHeb,
    TextualFrameHeb,
    TextualFrameEng,
    content='catalog',
    content_rowid='rowid'
);
-- Populate from catalog table
INSERT INTO catalog_fts(rowid, AlmaId, Title, TitleHeb, DescriptionEng, DescriptionHeb, TextualFrameHeb, TextualFrameEng)
SELECT rowid, AlmaId, Title, TitleHeb, DescriptionEng, DescriptionHeb, TextualFrameHeb, TextualFrameEng FROM catalog;
```

7. **Creates meta table:**
```sql
CREATE TABLE meta (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL
);
INSERT INTO meta (key, value) VALUES ('version', '1.0.0');
INSERT INTO meta (key, value) VALUES ('created', '{ISO timestamp}');
INSERT INTO meta (key, value) VALUES ('source', 'FIST.db');
```

**Script conventions (follow existing patterns from `scripts/fist_shelfmarks_export.py`):**
- Use `pathlib.Path` for file paths (script_dir / project_dir pattern)
- Print progress with counts (e.g., "Exporting domains... 390,956 rows")
- Use `tqdm` for progress bars on large queries (domains, catalog)
- Use `executemany` with batches of 10,000 for efficient inserts
- Delete and recreate the target .db if it already exists (idempotent)
- Call `target.execute("PRAGMA journal_mode=WAL")` before inserts for performance
- Call `target.execute("VACUUM")` at the end to compact the database
- Add `if __name__ == '__main__':` entry point

**Important:** The AlmaId in dbo_InventoryAlma is INTEGER type. CAST to TEXT in the SELECT (or convert in Python) because libraries.csv system_number is stored as a string. Consistency matters for lookups.
