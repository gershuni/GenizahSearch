**Module structure:**

```python
"""
Document Service for PGP document-fragment relationships.

Provides:
- get_document_for_fragment(sys_id) -> dict | None
- get_fragments_for_document(pgpid) -> list[dict]
- get_transcription_for_document(pgpid) -> str | None
- get_document_metadata(pgpid) -> dict | None
"""
from typing import Optional, List, Dict
from web.supabase_client import get_client
```

**Function implementations:**

1. `get_document_for_fragment(sys_id: str) -> Optional[Dict]`
   - Query `document_fragments` where sys_id matches
   - If found, query `documents` by document_id (the pgpid)
   - Return document dict with all fields, or None if not found
   - Include pgp_url in response

2. `get_fragments_for_document(pgpid: int) -> List[Dict]`
   - Query `document_fragments` where document_id = pgpid
   - Order by sequence_order ASC
   - Return list of fragment dicts (sys_id, shelfmark, sequence_order, page_info)
   - Return empty list if no fragments found

3. `get_transcription_for_document(pgpid: int) -> Optional[str]`
   - Query `documents` where pgpid matches
   - Return transcription field, or None if not found/empty

4. `get_document_metadata(pgpid: int) -> Optional[Dict]`
   - Query `documents` where pgpid matches
   - Return dict with: document_type, tags, dates, description, pgp_url, shelfmark_combined
   - Return None if not found

**Error handling:**
- Wrap all queries in try/except
- Log errors with print() (matching supabase_client.py pattern)
- Return None or empty list on errors, never raise

**Type hints:** All functions must have complete type hints.
