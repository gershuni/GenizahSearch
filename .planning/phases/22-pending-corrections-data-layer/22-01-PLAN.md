  <action>
Create `shared/corrections_service.py` following the pattern established by `shared/document_service.py`:

1. **Module header**: UTF-8 encoding comment, docstring explaining the module provides correction-related service functions for both web and desktop apps.

2. **Function `get_pending_corrections_for_page(client, sys_id, page_number, user_id=None)`**:
   - Parameters:
     - `client`: A Supabase Client instance (authenticated as the user). Both apps pass their own authenticated client:
       - Web uses `get_user_client()` from `web/supabase_client.py`
       - Desktop uses `SupabaseCorrectionsClient._get_client()` (already authenticated after login)
     - `sys_id` (str): The manuscript system ID
     - `page_number` (int): The page number (1=recto, 2=verso, etc.)
     - `user_id` (str, optional): The user's UUID. If None, return empty list immediately.
   - Returns: `List[Dict[str, Any]]` -- list of correction dicts, each containing:
     - `id` (int): correction ID
     - `corrected_text` (str): the correction text content
     - `status` (str): one of 'draft', 'pending', 'under_review'
     - `created_at` (str): ISO timestamp
     - `notes` (str): any notes the user added
     - `original_text` (str): what was being corrected
   - Implementation:
     - If `client` is None or `user_id` is None, return `[]`
     - Query: `client.table('corrections').select('id, corrected_text, status, created_at, notes, original_text').eq('sys_id', sys_id).eq('page_number', page_number).eq('author_id', user_id).in_('status', ['draft', 'pending', 'under_review']).order('created_at', desc=True).execute()`
     - Return `response.data or []`
     - Wrap in try/except, print error, return `[]` on failure (matching document_service.py error handling pattern)
   - Note: RLS policy "Users can view own corrections" (`auth.uid() = author_id`) provides server-side security. The `user_id` parameter is a client-side convenience filter that matches the authenticated session. Even if user_id were wrong, RLS would prevent seeing other users' non-approved corrections.

3. **Type imports**: `from typing import Optional, List, Dict, Any`

4. **Create `web/corrections_service.py`** as a backward-compatibility shim (following the pattern of `web/document_service.py`):
   ```python
   from shared.corrections_service import get_pending_corrections_for_page
   ```
   Include a module docstring explaining the shim purpose.

Do NOT modify `shared/__init__.py` -- the shared package init only exports reading desk model classes, and corrections service will be imported directly via `from shared.corrections_service import ...` (same pattern as document_service).
