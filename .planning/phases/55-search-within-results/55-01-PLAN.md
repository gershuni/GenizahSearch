    Create `shared/refinement.py` with:

    1. `RefinementStep` dataclass with fields:
       - `query: str` -- the search query text
       - `mode: str` -- search mode ('exact', 'variants', 'responsa', 'Title', 'Shelfmark', etc.)
       - `gap: int = 0` -- gap/distance parameter
       - `exclude_words: list = field(default_factory=list)` -- negated words
       - `text_position: Optional[str] = None` -- None, 'start', 'end', 'line_start', 'line_end'
       - `responsa_options: Optional[dict] = None` -- full responsa options dict when mode=='responsa'
       - `result_count: int = 0` -- stored after execution for breadcrumb display (per D-06, NOT authoritative -- updated on replay)

    2. Methods on RefinementStep:
       - `to_dict(self) -> dict`: return `dataclasses.asdict(self)`
       - `@classmethod from_dict(cls, d: dict) -> RefinementStep`: construct from dict, ignoring unknown keys (use `{k: v for k, v in d.items() if k in cls.__dataclass_fields__}`)
       - `@property display_label(self) -> str`: return `self.query`

    3. Module-level helper functions:

       `def needs_mode_labels(chain: list[RefinementStep]) -> bool`:
       Return `len(set(s.mode for s in chain)) > 1` if chain has 2+ items, else False. (per D-10)

       `def compute_effective_restrict(filter_restrict: set | None, refinement_restrict: set | None) -> set | None`:
       EXPLICIT CONTRACT (addresses review concern):
       - Both None -> None (no restriction at all)
       - filter_restrict=None, refinement_restrict=set -> return refinement_restrict (could be empty set)
       - filter_restrict=set, refinement_restrict=None -> return filter_restrict (could be empty set)
       - Both sets -> return `filter_restrict & refinement_restrict` (intersection, could be empty set)
       Key: empty set means "restrict to nothing" (zero results). None means "no restriction". These are DIFFERENT.

       `def truncate_chain(chain: list[RefinementStep], index: int) -> list[RefinementStep]`:
       Return `chain[:index]` (per D-12, removing a chip at index removes it AND all subsequent)

       `def replay_chain(chain: list[RefinementStep], searcher, filter_restrict: set | None) -> set | None`:
       Replay refinement chain sequentially to rebuild restrict sets. For each step:
       - Compute effective = compute_effective_restrict(filter_restrict, accumulated_restrict)
       - Call searcher.execute_search(step.query, step.mode, step.gap, exclude_words=step.exclude_words or None, responsa_options=step.responsa_options, restrict_sys_ids=effective, text_position=step.text_position)
       - Extract result sys_ids: {r.get('display', {}).get('id') for r in results if r.get('display', {}).get('id')}
       - Update step.result_count = len(result_sys_ids)
       - Set accumulated_restrict = result_sys_ids if result_sys_ids else set()
       Returns final accumulated_restrict, or None if chain is empty.
       NOTE: This is a synchronous function -- the web app wraps in run.io_bound, desktop runs in main thread or QThread.

       `def scope_signature(restrict_set: set | None) -> str`:
       Compute a stable hash-like signature for the current filter restrict set. Used for D-16 stale detection.
       - If None: return 'none'
       - If set: return str(hash(frozenset(restrict_set)))
       Both UIs store the scope_signature at chain creation time and compare on filter change.
