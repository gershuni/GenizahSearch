  <action>
Wire PGP loading into ResultDialog by modifying these methods in the `ResultDialog` class:

**1. In `load_page()` (~line 3533):** After the text is rendered and `_rd_load_versions()` is called (line 3616), start the PGP source worker. Add after line 3616:

```python
# Start PGP source fetch for this page
parent = self.parent()
if parent:
    self._rd_pgp_worker = PGPSourceWorker(self.current_sys_id, self.current_p_num or 1)
    self._rd_pgp_worker.finished_signal.connect(self._on_rd_pgp_loaded)
    self._rd_pgp_worker.error_signal.connect(self._on_rd_pgp_error)
    self._rd_pgp_worker.start()
```

Make sure `PGPSourceWorker` is accessible -- it's already imported via gui_threads in genizah_app.py (added in Plan 01).

**2. Add `_on_rd_pgp_loaded(self, sys_id, sources, pgp_doc)` method on ResultDialog:**
- **Stale-request guard**: If `sys_id != self.current_sys_id`, return immediately
- Store `self._rd_pgp_sources = sources` and `self._rd_pgp_doc = pgp_doc`
- Call the parent's shared helper: `parent = self.parent()`, then `has_pgp = parent._populate_pgp_combo(self.rd_version_combo, sources, pgp_doc)`
- If `has_pgp`:
  - Call `edition_data = parent._auto_select_pgp_edition(self.rd_version_combo)`
  - If `edition_data` and `edition_data.get('content')`:
    - Display edition text: `self._rd_display_text(edition_data.get('content', ''))`
    - Store original text in `self._rd_original_text` if not already stored
  - Enable combo
- Then call `self._rd_refresh_versions_append()` to add corrections AFTER PGP items -- see step 3.

**3. Modify `_rd_refresh_versions()` to handle PGP coordination:**
Similar to Browse tab's `_check_document_community_status()` coordination:
- Check if PGP items already exist in the combo (look for `source == 'pgp_edition'` in item data)
- If PGP items exist: do NOT clear the combo. Instead, append corrections/versions after the existing V0.8 item. Find the V0.8 item index, then insert corrections after it (with separator).
- If no PGP items: existing behavior (clear, add V0.8, fetch all versions/corrections).
- The key: `_rd_refresh_versions()` is called by `_rd_load_versions()` which runs BEFORE the PGP worker completes. So on initial load, it runs with no PGP items (normal behavior). Then when PGP loads, `_on_rd_pgp_loaded` rebuilds the combo with PGP items and re-appends corrections.

**Alternative simpler approach** (recommended): Instead of modifying `_rd_refresh_versions`, have `_on_rd_pgp_loaded` do:
1. Populate PGP items in combo via `_populate_pgp_combo` (this clears and rebuilds with PGP + V0.8)
2. Then re-run the corrections-only portion: iterate through corrections already fetched in `_rd_refresh_versions` and append them. Store corrections data on `self._rd_corrections_cache` during `_rd_refresh_versions` so they can be re-appended.

**Simplest correct approach**: Modify `_rd_load_versions()` to also store the fetched corrections in `self._rd_cached_corrections`. Then in `_on_rd_pgp_loaded`, after calling `_populate_pgp_combo`, iterate `self._rd_cached_corrections` and append them to the combo using the same label/data logic from `_rd_refresh_versions`. This avoids re-fetching from the server.

**4. Modify `_rd_load_version_content()` (~line 3112):**
Add handling for PGP source types. Currently handles "original", "correction", and version_id. Add:
- `elif source == "pgp_edition"`: Get content from `version_data.get('content')`. Cache with key `f"pgp_{version_data.get('source_id')}"`. Display with `self._rd_display_text(content)`. Ensure RTL layout direction: `self.text_ms.setLayoutDirection(Qt.LayoutDirection.RightToLeft)`.
- `elif source == "pgp_translation"`: Get content from `version_data.get('content')`. Cache similarly. Check language: if `version_data.get('language') == 'English'`, set `self.text_ms.setLayoutDirection(Qt.LayoutDirection.LeftToRight)`. Otherwise RTL. Display with `self._rd_display_text(content)`.
- When selecting `source == "original"`, restore RTL: `self.text_ms.setLayoutDirection(Qt.LayoutDirection.RightToLeft)`.

**5. Add `_on_rd_pgp_error(self, sys_id, error_msg)` method:**
- Log with `logger.debug("PGP fetch error for %s: %s", sys_id, error_msg)`
- Do nothing else -- silently fall back to existing V0.8 + corrections behavior per discretion recommendation.
