Wire PGP loading into the Browse tab by modifying these methods:

**1. In `on_browse_enriched_loaded()` (~line 6714):** After the enrichment callback runs and before `_check_document_community_status()` is called (line 6805), start the PGP source worker:

```python
# Start PGP source fetch (runs in background)
self._browse_pgp_worker = PGPSourceWorker(self.current_browse_sid, self.current_browse_p or 1)
self._browse_pgp_worker.finished_signal.connect(self._on_browse_pgp_loaded)
self._browse_pgp_worker.error_signal.connect(self._on_browse_pgp_error)
self._browse_pgp_worker.start()
```

**2. Add `_on_browse_pgp_loaded(self, sys_id, sources, pgp_doc)` method:**
- **Stale-request guard**: If `sys_id != self.current_browse_sid`, return immediately (user navigated away)
- Store `self._browse_pgp_sources = sources` and `self._browse_pgp_doc = pgp_doc` for later use
- Call `has_pgp = self._populate_pgp_combo(self.browse_version_combo, sources, pgp_doc)`
- If `has_pgp`:
  - Call `edition_data = self._auto_select_pgp_edition(self.browse_version_combo)`
  - If `edition_data`, display the edition content: call `self._browse_display_version_text(edition_data.get('content', ''))`. Handle **text directionality**: if edition_data indicates it's Hebrew (or no language specified), keep RTL. Default to RTL for editions.
  - Store original V0.8 text in `self.browse_original_page_text` if not already stored (it should already be stored by `_check_document_community_status`)
  - Enable the combo
- Now call `self._check_document_community_status_append()` -- see step 3.

**3. Create `_check_document_community_status_append(self)` method** OR modify the existing `_check_document_community_status()`:
The key coordination challenge: PGP items are now in the combo. The existing `_check_document_community_status()` starts by clearing the combo and adding V0.8 (line 5167-5170). This would destroy PGP items.

**Solution**: Modify `_check_document_community_status()` to NOT clear the combo if PGP items are already populated. Specifically:
- At the start, check if the combo already has PGP items (check if `self.browse_version_combo.count() > 1` and first non-header item has `source == 'pgp_edition'`).
- If PGP items exist: skip the clear/rebuild of V0.8 (lines 5167-5170). Instead, just store the original text and proceed to append corrections/versions AFTER the existing PGP + V0.8 items.
- If no PGP items: proceed with existing behavior (clear, add V0.8, fetch versions).
- The corrections and versions (V0.7, user versions, user corrections) should be APPENDED after the V0.8 item, not replace the whole combo.
- Add a separator before corrections section if corrections exist.

**4. Modify `_browse_change_version()` (~line 5081) and `_browse_load_version()` (~line 5094):**
Add handling for PGP source types:
- In `_browse_load_version()`, add cases for `source == "pgp_edition"` and `source == "pgp_translation"`:
  - For `pgp_edition`: content is already in `version_data.get('content')`. Display it with RTL direction.
  - For `pgp_translation`: content is in `version_data.get('content')`. Check `version_data.get('language')`: if `'English'`, change `self.browse_text.setLayoutDirection(Qt.LayoutDirection.LeftToRight)` and display with LTR. For Hebrew/default, keep RTL.
  - Cache PGP content: use cache key `f"pgp_{version_data.get('source_id')}"`.
- When selecting `source == "original"` (V0.8), restore RTL layout direction.

**5. Handle page changes in Browse tab:**
When the user changes pages via `on_browse_page_combo_changed()` or `browse_navigate()`, the PGP data needs to refresh for the new page. In `browse_render_page()` or wherever the page changes and triggers community status check, also restart the PGP worker with the new page number. The simplest approach: in the existing flow where `_check_document_community_status()` is called after a page change, also start a new PGP worker. Check if PGP is needed by verifying `self._browse_pgp_sources` exists (was populated on initial load).

**Per user decision**: Auto-select PGP edition as default. HTR V0.8 remains in selector but not pre-selected. Existing behavior unchanged when no PGP. All Supabase in QThread.
