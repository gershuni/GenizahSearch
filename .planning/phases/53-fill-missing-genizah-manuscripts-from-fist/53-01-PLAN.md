  <action>
Create scripts/generate_fist_gap_csv.py that:

1. Opens FIST.db (project root) and reads existing libraries.csv to build a set of existing AlmaIds (system_number column 0, digits only).

2. Queries FIST.db for gap records:
   SELECT i.InventoryId, i.Shelfmark, ia.AlmaId, i.CollectionId, c.LibraryId
   FROM dbo_Inventory i
   JOIN dbo_InventoryAlma ia ON ia.InventoryId = i.InventoryId
   JOIN CODE_Collection c ON i.CollectionId = c.CollectionId
   WHERE i.RecordStatus = 0
   AND ia.AlmaId IS NOT NULL AND ia.AlmaId != ''
   Then filters out AlmaIds already in libraries.csv.

3. Maps LibraryId to library_code using a hardcoded dict built from CODE_Library.LibraryNameEng. The 53 direct mappings include: 233->CUL, 79->JTS, 229->RNL, 242->Manchester, 235->Oxford, 238->BL, 177->Mosseri, 169->AIU, 248->Westminster, 147->HAS, 90->Katz, 130->Senckenberg. 12 new codes for small FIST-only collections (Halpern, Solomon, Reinach, Harvard, Vatican, Copenhagen, Mehlman, CentralArch, Princeton, JCMainz, Chapira, Corwin). Harvard and Princeton already exist in LIBRARY_CODES -- use those existing codes.

4. For titles, joins fjms_enrichment.db (fist_data/fjms_enrichment.db):
   SELECT uc.AlmaId, gt.OrgTitle FROM UnitCatalogRec uc
   JOIN CODE_GenizahTitle gt ON uc.GenizahTitleId = gt.GenizahTitleId
   WHERE gt.OrgTitle IS NOT NULL AND gt.OrgTitle != ''
   Provides titles for ~8,632 gap records.

5. Generates CSV rows: AlmaId,,Shelfmark,library_code,,,,Title
   - Column 0: AlmaId as-is from FIST (18-digit ending 05171)
   - Column 1: empty
   - Column 2: Shelfmark from dbo_Inventory.Shelfmark (single variant, no pipes)
   - Column 3: library_code from mapping
   - Columns 4-6: empty
   - Column 7: title from FJMS catalog or empty

6. Skips: AlmaId already in libraries.csv, Shelfmark contains "Undefined Shelfmark", LibraryId has no mapping.

7. Supports --dry-run flag (prints stats without modifying CSV). Without --dry-run, appends to libraries.csv.

8. Prints summary: total gap records, records appended, skipped by reason, library distribution.

Important: To discover full LibraryId->name mapping, query: SELECT LibraryId, LibraryNameEng FROM CODE_Library. Then map names to existing LIBRARY_CODES values. For records with commas in shelfmarks, the CSV writer must quote the field.
