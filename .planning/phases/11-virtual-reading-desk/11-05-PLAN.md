  <how-to-verify>
**Web App Verification:**
1. Start web app: `python -m web.main`
2. Go to /browse, load "T-S 13J8.17" (has PGP joins with multiple fragments)
3. Click the green joins button -> "View All Fragments"
4. **Dual-pane check:** LEFT pane shows stacked images, RIGHT pane shows stacked texts
5. **Per-image controls:** Each image has zoom/rotate buttons. Zoom one image -- others should NOT be affected
6. **Version selector:** Each fragment's text has a PGP version dropdown. Select a different version -- text updates
7. **Synchronized scrolling:** Scroll down in the image pane -- text pane should auto-scroll to matching fragment
8. **Fragment links:** Click a fragment header (shelfmark) -- should exit reading desk and navigate to that fragment
9. **Add by shelfmark:** In the toolbar, type "T-S 12.1" and click Add -- new manuscript appears in both panes
10. **Add from list:** Click "Add from List" -- dialog shows lists. Select one -- items added
11. **Remove:** Click X on a fragment header -- removed from both panes
12. **Back to normal:** Click "Back to Page View" -- returns to single-page browse

**Standalone entry point test (web):**
1. Load any single manuscript (no joins needed)
2. Click "Add to View" button near the Go field
3. Reading desk starts with just this manuscript
4. Add more by shelfmark in the toolbar

**Desktop App Verification:**
1. Start desktop app: `python genizah_app.py`
2. Go to Browse tab, load "T-S 13J8.17" or any manuscript with joins
3. Click "Add to View" button near the Go/shelfmark field
4. **Dual-pane check:** Text pane shows stacked texts, Image viewer pane shows stacked images
5. **Per-image controls:** Each image has zoom/rotate buttons. Zoom one -- others unaffected
6. **Version selector:** Click "Switch version" link -- dialog shows PGP source options
7. **Synchronized scrolling:** Scroll text pane -- image pane scrolls proportionally
8. **Add by shelfmark:** Type a shelfmark in the toolbar, click Add -- new manuscript added
9. **Add from list:** Click "Add from List" -- lists panel opens. Click an item -- added to desk
10. **Remove:** Click X on a fragment header -- removed
11. **Joins entry:** Use joins dropdown -> "Open in Reading Desk" -- opens with all connected fragments
12. **Exit:** Click "Exit Reading Desk" -- returns to normal browse

**Both apps -- cross-cutting checks:**
- Hebrew text displays correctly (RTL direction)
- Images load for NLI and Oxford manuscripts (not black boxes)
- Empty text shows "No text available" (not blank)
- PGP edition/translation language direction (Hebrew=RTL, English=LTR)
- Multiple images per fragment (recto + verso) all visible
- Lazy loading works (images below fold load on scroll)
