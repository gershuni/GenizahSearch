Fix three bugs in genizah_app.py:

**D1 — Scroll sync broken (bidirectional sync between text and image panes):**

The current `_browse_rd_setup_sync_scroll()` method (around line 7883) connects `text_bar.valueChanged` and `image_bar.valueChanged` for proportional sync. The reported bug: "scrolling text pane only moves images pane, not text itself."

**Root cause analysis:** The `_browse_rd_render()` method is called multiple times — once initially with V0.8 text, and again when PGP data loads from the worker. Each call runs `_browse_rd_render_images()` which:
1. Deletes the old `_browse_rd_image_scroll` (via `deleteLater()`)
2. Creates a new QScrollArea
3. Calls `_browse_rd_setup_sync_scroll()` which connects new handlers

BUT: `_browse_rd_setup_sync_scroll()` does NOT disconnect old connections on `text_bar.valueChanged` before adding new ones. The old connection (from the first render) still points to the old (now-deleted) image scroll bar. This means `text_bar.valueChanged` has TWO connections — one to a dead handler and one to the new handler. The dead handler may cause issues.

**Fix `_browse_rd_setup_sync_scroll()`:**
1. At the start of the method, disconnect any existing `valueChanged` connections on the text scroll bar to prevent accumulation:
```python
def _browse_rd_setup_sync_scroll(self):
    if not self._browse_rd_image_scroll:
        return

    text_bar = self.browse_text.verticalScrollBar()
    image_bar = self._browse_rd_image_scroll.verticalScrollBar()

    # Disconnect previous sync connections to prevent accumulation
    try:
        text_bar.valueChanged.disconnect()
    except (TypeError, RuntimeError):
        pass
    try:
        image_bar.valueChanged.disconnect()
    except (TypeError, RuntimeError):
        pass

    def sync_text_to_image(value):
        if self._browse_rd_syncing:
            return
        self._browse_rd_syncing = True
        try:
            text_max = text_bar.maximum()
            image_max = image_bar.maximum()
            if text_max > 0 and image_max > 0:
                ratio = value / text_max
                image_bar.setValue(int(ratio * image_max))
        finally:
            self._browse_rd_syncing = False

    def sync_image_to_text(value):
        if self._browse_rd_syncing:
            return
        self._browse_rd_syncing = True
        try:
            text_max = text_bar.maximum()
            image_max = image_bar.maximum()
            if text_max > 0 and image_max > 0:
                ratio = value / image_max
                text_bar.setValue(int(ratio * text_max))
        finally:
            self._browse_rd_syncing = False

    text_bar.valueChanged.connect(sync_text_to_image)
    image_bar.valueChanged.connect(sync_image_to_text)
```

2. **Additional issue:** The `_browse_rd_render_images()` method calls `deleteLater()` on the old image scroll, then immediately creates a new one and calls sync setup. `deleteLater()` is deferred — the old widget still exists briefly. Fix by calling `setParent(None)` before `deleteLater()` to immediately remove it from the layout, preventing stale signal connections:

In `_browse_rd_render_images()`, around line 7755-7757, change:
```python
if self._browse_rd_image_scroll is not None:
    self._browse_rd_image_scroll.setVisible(False)
    self._browse_rd_image_scroll.deleteLater()
```
to:
```python
if self._browse_rd_image_scroll is not None:
    try:
        self._browse_rd_image_scroll.verticalScrollBar().valueChanged.disconnect()
    except (TypeError, RuntimeError):
        pass
    self._browse_rd_image_scroll.setVisible(False)
    self._browse_rd_image_scroll.setParent(None)
    self._browse_rd_image_scroll.deleteLater()
```

3. **Also fix the scroll timing:** The scroll sync needs to be set up AFTER the image widgets have been fully loaded and laid out. Currently, sync is set up immediately after adding the scroll area to the splitter, but before images have loaded (images load asynchronously via ImageLoaderThread). The scroll bar maximum is 0 until content is rendered. Add a deferred sync setup using QTimer:

After the `self._browse_rd_setup_sync_scroll()` call at the end of `_browse_rd_render_images()`, add a deferred re-sync:
```python
from PyQt6.QtCore import QTimer
QTimer.singleShot(500, self._browse_rd_setup_sync_scroll)
```
This ensures scroll sync works after images have loaded and scroll ranges are established.
