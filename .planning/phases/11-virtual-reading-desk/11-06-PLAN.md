
Fix the language switch state persistence bug in browse.py.

**W4 — Language switch loses reading desk state:**
The `_persist_reading_desk_state()` function saves to `app.storage.user['reading_desk_state']` and `_restore_reading_desk_state()` reads it on page load. The restore function calls `enter_joined_view()` which should rebuild the reading desk.

Debug this by checking the full restore flow:

1. **Check that `_restore_reading_desk_state` is called early enough:** It's currently called at the bottom of `create_browse_page()` (around line 3601). Verify it runs before `update_content()` is called. The issue may be that `update_content()` is called before restore, clearing the UI.

2. **Check the return value handling:** Currently `_restore_reading_desk_state()` calls `enter_joined_view()` which calls `update_content()`. If there's a timing issue where the initial `update_content()` runs after restore, it could overwrite the restored state.

3. **Most likely root cause:** The `_restore_reading_desk_state()` function calls `enter_joined_view()` which sets `state.view_joined = True` and calls `update_content()`. But NiceGUI recreates the entire page on language switch, so `state` is a new object. The `state` variable is created inside `create_browse_page()` as a local namespace. When the page recreates, a NEW state object is created. The reading desk data is only persisted as sys_id/shelfmark pairs in `app.storage.user`, but the full state (view_joined flag, entries with pages/sources) needs to be reconstructed.

**Fix approach:** In `_restore_reading_desk_state()`, verify:
- The function returns `True` when restore succeeds (it currently does)
- The calling code at line ~3601 properly skips normal position restore when reading desk is restored
- The `enter_joined_view()` call in restore properly loads full manuscript data (pages, sources) -- it currently passes `frag_info` to `enter_joined_view` which loads everything. This should work.

**The actual bug is likely:** `app.storage.user` may not be available yet when `_restore_reading_desk_state()` is called, or there may be an exception being silently swallowed. Add debug logging: after the `try:` block in `_restore_reading_desk_state()`, add `import logging; logging.getLogger('browse').info(f'Restore reading desk: {saved}')` temporarily to verify the saved state exists.

**Alternative fix if the state IS there but restore still fails:** The `enter_joined_view` call inside `_restore_reading_desk_state` may fail because `service.get_full_manuscript()` requires the service to be initialized, which may not have happened yet at page-load time. If this is the case, wrap the restore in a `ui.timer(0.5, ...)` to delay it slightly:

```python
def _restore_reading_desk_state():
    try:
        saved = app.storage.user.get('reading_desk_state')
        if saved and saved.get('entries'):
            frag_info = saved['entries']
            pgpid = saved.get('pgpid')
            # Use timer to delay restore until page is fully initialized
            def do_restore():
                enter_joined_view(
                    [{'shelfmark': e['shelfmark'], 'document_id': e['sys_id']} for e in frag_info],
                    pgpid=pgpid
                )
            ui.timer(0.3, do_restore, once=True)
            return True
    except Exception as ex:
        import logging
        logging.getLogger('browse').warning(f'Failed to restore reading desk: {ex}')
    return False
```

This ensures the page is fully rendered before the restore kicks in, which handles the case where `service` or other dependencies aren't ready yet.

Also ensure the `selected_sources` state is preserved. Currently only `entries` (sys_id + shelfmark) and `pgpid` are saved. The selected version source per fragment is lost. Add `selected_sources` to the persisted state:

In `_persist_reading_desk_state()`, add:

```python
app.storage.user['reading_desk_state'] = {

    'selected_sources': dict(state.reading_desk_selected_sources) if hasattr(state, 'reading_desk_selected_sources') else {}
}
```

In `_restore_reading_desk_state()`, after `enter_joined_view`, restore selected sources:
```python
if saved.get('selected_sources'):
    state.reading_desk_selected_sources = saved['selected_sources']
```
