  <name>Task 1: Fix RuntimeError from orphaned ui.timer elements (Test 3)</name>
  <files>
    web/components/version_selector.py
    web/components/notes_display.py
    web/components/joins_panel.py
  </files>
  <action>
    Three ui.timer(0.1, callback, once=True) calls create asyncio tasks that survive content_container.clear(). When their parent element is GC'd, _run_once() accesses a dead weakref parent_slot and raises RuntimeError. NiceGUI does NOT cancel timer tasks on element deletion (known issue #1500, #3187).

    Fix: Wrap each timer callback in a try/except RuntimeError guard. This is the safest approach because canceling asyncio tasks from NiceGUI's element tree is fragile and undocumented.

    **version_selector.py (~line 185):**
    The callback is `load_and_apply_latest`. Wrap in a safe wrapper:
    ```python
    def _safe_load():
        try:
            load_and_apply_latest()
        except RuntimeError:
            pass  # Parent element was deleted (NiceGUI timer lifecycle)
    ui.timer(0.1, _safe_load, once=True)
    ```

    **notes_display.py (~line 416):**
    The callback is `check_comments`. Wrap identically:
    ```python
    def _safe_check():
        try:
            check_comments()
        except RuntimeError:
            pass  # Parent element was deleted
    ui.timer(0.1, _safe_check, once=True)
    ```

    **joins_panel.py (~line 291):**
    The callback is `load_count`. Wrap identically:
    ```python
    def _safe_load_count():
        try:
            load_count()
        except RuntimeError:
            pass  # Parent element was deleted
    ui.timer(0.1, _safe_load_count, once=True)
    ```

    Do NOT modify any other timer behavior. The 0.1s delay and once=True remain unchanged.
  </action>

    Three independent fixes in browse.py, all non-overlapping:

    **Fix A: Light Mode white-on-white header (Test 8)**
    Root cause: Global CSS `.q-card { background: var(--bg-card) !important; }` in main.py:596 overrides the reading desk header card's inline green gradient. The 11-08 fix addressed text color but missed the background.

    At the reading desk header card (line 2421-2422), change the card's inline style to add !important to the background:
    ```python
    with ui.card().classes('w-full mb-2').style(
        'background: linear-gradient(135deg, #15803d 0%, #166534 100%) !important;'
    ):
    ```
    This is the minimal fix. Only the `!important` keyword is added to the existing background style. Do NOT restructure the element hierarchy. The debug session confirmed that the "Add from List" dialog and Document preview dialog use ui.row() inside their cards for gradient styling (a different pattern), so they are NOT affected by this issue. Only the reading desk header card at line 2421 needs the fix.

    **Fix B: Language switch state loss (Test 9)**
    Root cause: update_content() at ~line 1665 has `if not state.current_page:` which early-returns to show the welcome prompt. During language-switch restoration, enter_joined_view() sets state.view_joined=True but never sets state.current_page. This blocks the `elif state.view_joined:` branch at ~line 2198.

    Change the guard at line 1665 from:
    ```python
    if not state.current_page:
    ```
    to:
    ```python
    if not state.current_page and not state.view_joined:
    ```
    This allows the code to fall through to the reading desk rendering branch when restoring from language switch. Do NOT change any other guard logic.

    **Fix C: Inconsistent word wrap (Test 10)**
    Root cause: Right pane card (~line 2610) uses `flex: 1 1 auto` without `min-width: 0`. CSS flexbox default min-width:auto prevents flex items from shrinking below content intrinsic width.

    At the right pane card (~line 2610), add `min-width: 0;` to the style string:
    ```python
    with ui.card().style('flex: 1 1 auto; min-width: 0; min-height: 70vh; display: flex; flex-direction: column;'):
    ```

    At the text container column (~line 2774), add `min-width: 0;` to the style:
    ```python
    tc = ui.column().classes('w-full px-3 py-2').style('min-width: 0;')
    ```

    Also fix the single-page view text panel (~line 3235) for consistency. The current code is:
    ```python
    text_panel_flex = 'flex: 1 1 auto;' if has_image else 'flex: 1 1 100%;'
    ```
    Change BOTH branches to include min-width:0:
    ```python
    text_panel_flex = 'flex: 1 1 auto; min-width: 0;' if has_image else 'flex: 1 1 100%; min-width: 0;'
    ```
    This ensures min-width:0 is applied regardless of whether has_image is true or false.
