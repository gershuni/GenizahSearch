Fix three elements in the reading desk header bar (around lines 2380-2396) that are invisible in Light Mode:

1. **Icon (line 2380):** Change from `.classes('text-white text-xl')` to `.classes('text-xl').style('color: white !important;')`. Icons are simple elements (like badges) where inline style works.

2. **Label (line 2385):** Change from `.classes('text-lg font-bold text-white')` to `.classes('text-lg font-bold').style('color: white !important;')`. Labels don't have Quasar's `text-color` prop but inline style with `!important` works for non-button elements.

3. **Button (lines 2392-2396):** Change from `.props('flat dense').style('color: white !important;')` to `.props('flat dense text-color=white')`. The `text-color` prop is Quasar's official API for button text color and overrides internal Light Mode CSS. This is the established pattern used by 20+ other buttons in the codebase (see auth_state.py:387, joins_panel.py:323, etc.).

WHY the current approaches fail:
- `.classes('text-white')` is a Tailwind utility class overridden by Quasar's Light Mode theme at higher specificity
- `.style('color: white !important;')` on buttons is overridden by Quasar's internal `.q-btn` CSS rules that have even higher priority
- `.props('text-color=white')` is Quasar's dedicated API that sets color at the component level, above CSS cascade

Also fix the "Add from List" dialog header label (around line 2255) which uses `.classes('text-white')` -- change to `.style('color: white !important;')` for consistency. The close button on that dialog already uses `.props('text-color=white')` correctly.

**Word wrap fix (Test 11):**
Find the text content container around line 2728:
```python
tc = ui.column().classes('w-full px-3 py-2').style('overflow: hidden;')
```
Remove the `.style('overflow: hidden;')` entirely. The `w-full` class provides width constraint. The scroll area parent handles overflow. The `overflow: hidden` clips vertically-expanded wrapped text, making it appear as if wrapping doesn't work.

Result should be:
```python
tc = ui.column().classes('w-full px-3 py-2')
```

Also fix the secondary word-wrap issue in the single-page viewer `render_text_content` (around line 3264-3267). Add `overflow-wrap: break-word; word-break: break-word;` to the ui.label style string, after the existing `white-space: pre-wrap;`. This ensures word wrap works in the non-reading-desk single manuscript view too.

**RuntimeError fix (Test A2):**
In `toolbar_add_by_shelfmark` (around line 2222-2238), wrap the `_add_sys_id_to_reading_desk` call and surrounding code in a broader try/except that catches RuntimeError specifically. The error occurs when ui.notify is called from a stale slot context after the reading desk UI has been rebuilt.

Change the function body to catch RuntimeError alongside the existing Exception handler:
```python
def toolbar_add_by_shelfmark(shelfmark_text):
    if not shelfmark_text or not shelfmark_text.strip():
        return
    query = shelfmark_text.strip()
    try:
        results, exact_match = service.search_by_shelfmark(query, limit=5)
        if not results:
            ui.notify(f'{tr("No manuscript found")}: {query}', type='warning')
            return
        result = results[0]
        found_sid = result.sys_id
        found_sm = result.shelfmark or query
        _add_sys_id_to_reading_desk(found_sid, found_sm)
    except RuntimeError:
        # Stale slot reference after UI rebuild -- silently ignore
        pass
    except Exception as e:
        try:
            ui.notify(f'{tr("Error")}: {str(e)}', type='negative')
        except RuntimeError:
            pass
```
