(mode + set) model, closing the v8.3.0 deferred gap logged in `docs/OPEN_ISSUES.md` (2026-06-29).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> NiceGUI server (/parallels) | The dialog's checked-codes list returns from client JS (`parLibFilterGetChecked`) and the persisted `parallels_library_filter` value can be crafted/stale. Untrusted input crosses here. |
| per-user state -> safe_storage | The new `{'mode','codes'}` value is written/read through `web/safe_storage.py`; multitenant leakage is the boundary the Phase 87 chokepoint guards. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-131-05-01 | Tampering | crafted/stale `parallels_library_filter` value or JS-returned checked list | mitigate | Apply handler runs `sanitize_library_codes()` (drops non-str, unknown, `'LOCAL'`); restore runs `sanitize_library_codes()` on both list and dict branches (V5 input validation). |
| T-131-05-02 | Spoofing/Info disclosure | cross-user state leak | mitigate | All reads/writes route through `safe_user_get`/`safe_user_set` (the `web/safe_storage.py` chokepoint, Phase 87); `tests/test_no_raw_storage_access.py` allowlist stays `[]` (V3 session). |
| T-131-05-03 | Tampering | `'LOCAL'` injected as a web library option | mitigate | Dialog universe is `library_codes_with_manuscripts()` minus `'LOCAL'` with an inline literal guard; `tests/test_web_library_options_no_local.py` AST scan enforces the literal in the new function. |
| T-131-05-04 | Denial of service | post-fetch resolution over result rows | accept | Filtering iterates the already-bounded result list and reuses the per-row `meta_mgr.get_library_for_id` lookup the render path already performs; no new heavy corpus scan (Pitfall 4 avoided by NOT doing complement resolution). |
| T-131-05-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs (RESEARCH § Package Legitimacy Audit: none). |

**V3 session:** parallels persistence routes ONLY through `web/safe_storage.py`; no raw `app.storage.user`;
allowlist stays `[]`. No new network endpoint, auth path, or schema change.
