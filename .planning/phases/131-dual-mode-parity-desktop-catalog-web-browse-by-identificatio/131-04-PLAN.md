## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> NiceGUI server (catalog page) | The dialog's checked-codes list returns from client JS (`catLibFilterGetChecked`) and the persisted `catalog_library_filter` value + the `incoming_filters` handoff can be crafted/stale. Untrusted input crosses here. |
| per-user state -> safe_storage | The `{'mode','codes'}` value is written/read through `web/safe_storage.py`; multitenant leakage is the boundary the Phase 87 chokepoint guards. |
| catalog handoff -> /search consume | The `{mode,codes}` dict is passed via `incoming_filters` and re-sanitized in `consume_incoming_filters` (filter_panel) before it touches /search state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-131-04-01 | Tampering | crafted/stale `catalog_library_filter` value, JS-returned checked list, or `incoming_filters` library_filter dict | mitigate | Apply handler + the consume handoff both run `sanitize_library_codes()` (drops non-str, unknown, and `'LOCAL'`) and validate `mode` against `{'show_only','hide'}` (bogus -> 'hide'); restore runs `sanitize_library_codes()` on both list and dict branches; the dialog build keeps the inline `c != 'LOCAL'` guard (V5 input validation). |
| T-131-04-02 | Spoofing/Info disclosure | cross-user state leak | mitigate | All reads/writes route through `safe_user_get`/`safe_user_set` (the `web/safe_storage.py` chokepoint, Phase 87); `tests/test_no_raw_storage_access.py` allowlist stays `[]` (V3 session). |
| T-131-04-03 | Tampering | `'LOCAL'` injected as a web library option | mitigate | Dialog universe is `library_codes_with_manuscripts()` minus `'LOCAL'` with an inline literal guard; `tests/test_web_library_options_no_local.py` AST scan enforces the literal in every function touching `LIBRARY_CODES`. |
| T-131-04-04 | Information disclosure | get_browse_library_facets counts | accept | Facets count the SAME public catalog metadata over the user's active filters; discloses nothing beyond what the browse results already show. |
| T-131-04-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs (RESEARCH § Package Legitimacy Audit: none). |
