**D. Component card implementation:**

For each component (0-3), create a QFrame or QGroupBox with:
- Vertical layout
- Title label
- 4 QLineEdit inputs (2 visible initially, 2 hidden)
- Each QLineEdit: placeholder "מילה N", font SBL Hebrew or similar, RTL
- Each QLineEdit gets `focusInEvent` connected (use `installEventFilter` or subclass) to call `_on_word_focus(comp_idx, word_idx)`
- Each QLineEdit gets `textChanged` connected to call `_update_preview()`
- "+" QPushButton (small, icon="+") to show next hidden word slot
- "Remove" QPushButton (only visible on components 3 and 4)

**Important for focus tracking:** QLineEdit does not have a direct focus signal. Use `eventFilter` on the dialog to catch `QEvent.Type.FocusIn` events from word inputs, or subclass QLineEdit with a custom signal.

Simple approach — install event filter on each QLineEdit:
```python
word_input.installEventFilter(self)

def eventFilter(self, obj, event):
    if event.type() == QEvent.Type.FocusIn:
        # Find which (comp_idx, word_idx) this input belongs to
        for ci, comp in enumerate(self._component_widgets):
            for wi, inp in enumerate(comp['inputs']):
                if inp is obj:
                    self._on_word_focus(ci, wi)
                    break
    return super().eventFilter(obj, event)
```

**G. Select-and-Modify Pattern:**

`_on_word_focus(comp_idx, word_idx)`:
1. Set `self._active_word = (comp_idx, word_idx)`
2. Set `self._updating_modifiers = True`
3. Load mods from `self._component_data[comp_idx]['words'][word_idx]['mods']`
4. Update all 6 checkboxes `.setChecked(mods.get('key', False))`
5. Set `self._updating_modifiers = False`

`_on_modifier_changed()`:
1. If `self._updating_modifiers` or `self._active_word is None`: return
2. Read all 6 checkboxes into a mods dict
3. Save to `self._component_data[comp_idx]['words'][word_idx]['mods']`
4. Call `_update_preview()`

**H. Live Preview:**

`_update_preview()`:
1. Build the components list from `self._component_data` (matching the format `generate_tabular_syntax` expects)
2. Build distances list from `self._distance_spinners`
3. Get scope from radio buttons
4. Call `generate_tabular_syntax(components, distances, scope)`
5. Update preview label text (monospace, RTL)

**I. Buttons:**

- "Clear All": Reset all QLineEdit to empty, uncheck all modifiers, reset spinners to 0, hide extra words/components back to initial state, set scope to word_range, update preview.
- "Cancel": `self.reject()`
- "Apply": Call `_update_preview()` to ensure latest syntax, then `self.accept()`

```python
def _open_query_builder(self):
    """Open the tabular query builder dialog."""
    dlg = TabularQueryBuilderDialog(self)
    if dlg.exec() == QDialog.DialogCode.Accepted:
        syntax = dlg.get_syntax()
        negated = dlg.get_negated_words()
        if syntax.strip():
            # One-way sync: builder -> text field
            self.search_input.setText(syntax)
            # Add negated words to exclude input (append to existing)
            if negated:
                existing_exclude = self.exclude_input.text().strip()
                exclude_parts = existing_exclude.split() if existing_exclude else []
                for w in negated:
                    if w not in exclude_parts:
                        exclude_parts.append(w)
                self.exclude_input.setText(' '.join(exclude_parts))
            # Auto-trigger search
            self.start_search()
```
