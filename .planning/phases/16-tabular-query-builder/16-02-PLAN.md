**C. Implement the `open_query_builder()` function** (add as a local function inside `create_search_page`, near the other dialog functions):

The dialog must implement ALL of the following:

**1. Dialog Structure (RTL):**
```python
with ui.dialog() as builder_dialog, ui.card().classes('p-4 q-pa-md').style('min-width: 700px; max-width: 900px; direction: rtl;'):
```
On mobile, add `.props('maximized')` to the dialog or use responsive breakpoint.

**2. Scope Toggle** at the top:
- `ui.toggle({'word_range': tr('Word Range'), 'within_document': tr('Within Document')}, value='word_range')`
- When scope changes, hide/show distance spinners between components.

**3. Builder State Dict:**
```python
builder_state = {
    'components': [],   # List of component dicts, each with 'words' list
    'distances': [],    # List of distance values between adjacent components
    'scope': 'word_range',
    'active_word': None, # (comp_idx, word_idx) tuple
    'num_components': 2,
}
```

Initialize with 2 components, each having 2 visible word slots (with mods dict for each). Each word: `{'text': '', 'mods': {'prefix': False, 'suffix': False, 'wildcard_prefix': False, 'wildcard_suffix': False, 'plene': False, 'negation': False}}`.

**4. Components Row** (RTL, Component 1 on right):
- Use `ui.row().classes('w-full gap-3 flex-wrap justify-end')` for the components container.
- Each component is a `ui.card().classes('p-3').style('border: 1px solid #e0e0e0; border-radius: 8px; min-width: 150px;')` containing:
  - A label: `tr('Component') + f' {i+1}'`
  - 2 visible `ui.input` word slots (RTL, placeholder "מילה 1", "מילה 2")
  - Hidden word slots 3 and 4 (initially invisible, shown via "+" button)
  - Small "+" button to show next hidden word slot (up to 4)
  - Remove button (only visible on 3rd and 4th components, use `ui.button(icon='close')`)
  - Each word input has `.on('focus', lambda comp_idx=i, word_idx=j: on_word_focus(comp_idx, word_idx))` to track active word for modifier context-switching
  - On input change: update builder_state text and call `update_preview()`

- Between each pair of components, add a distance spinner:
  - `ui.number(label=tr('Distance'), value=0, min=0, max=50).classes('w-20')` styled between component cards
  - Bind to `builder_state['distances'][pair_idx]`
  - Hidden when scope is `'within_document'`

- "+ Component" button (up to 4 components):
  - `ui.button(tr('Add Component'), icon='add').props('outline dense')`
  - Adds a new component card, adds a distance value to distances list
  - Hidden when 4 components are visible

**5. Shared Modifier Checkboxes Row** (below components):
Use compact labels with operator symbols and tooltips (per research recommendation):
```python
with ui.row().classes('w-full gap-3 mt-3 items-center flex-wrap'):
    ui.label(tr('Modifiers') + ':').classes('text-sm font-medium')
    prefix_cb = ui.checkbox('# _').tooltip(tr('Prefixes') + ' — קידומות דקדוקיות (ו/ה/ב/כ/ל/מ/ש)')
    suffix_cb = ui.checkbox('_ #').tooltip(tr('Suffixes') + ' — סיומות דקדוקיות')
    wild_start_cb = ui.checkbox('* _').tooltip(tr('Wildcard Start') + ' — מילים שמסתיימות ב...')
    wild_end_cb = ui.checkbox('_ *').tooltip(tr('Wildcard End') + ' — מילים שמתחילות ב...')
    plene_cb = ui.checkbox('%').tooltip(tr('Plene/Defective') + ' — כתיב מלא/חסר (ו/י)')
    negation_cb = ui.checkbox('✕').tooltip(tr('Exclude') + ' — שלילה, הוצא מילה זו')
```

Each checkbox: on change, save to `builder_state['components'][comp_idx]['words'][word_idx]['mods'][modifier_name]` using the currently active word. Also call `update_preview()`.

**6. Select-and-Modify Pattern:**
- `on_word_focus(comp_idx, word_idx)`: set `builder_state['active_word'] = (comp_idx, word_idx)`, then update all 6 checkboxes to show that word's current modifier state. Use `.set_value()` without triggering on_change (use a guard flag like `_updating_modifiers = True`).
- `on_modifier_change(modifier_name, value)`: if `active_word` is set and `_updating_modifiers` is False, save `value` to the active word's mods dict. Call `update_preview()`.

**7. Live Preview** (below modifiers):
```python
with ui.row().classes('w-full mt-3 items-center'):
    ui.label(tr('Preview') + ':').classes('text-sm font-medium')
    preview_label = ui.label('').classes('text-sm font-mono').style('direction: rtl; color: var(--primary-600);')
```
`update_preview()` calls `generate_tabular_syntax()` from genizah_core with the current builder_state and updates preview_label.text.

**8. Bottom Buttons:**
```python
with ui.row().classes('w-full justify-between mt-4'):
    ui.button(tr('Clear All'), on_click=clear_all, icon='delete_sweep').props('flat')
    with ui.row().classes('gap-2'):
        ui.button(tr('Cancel'), on_click=builder_dialog.close).props('flat')
        ui.button(tr('Apply'), on_click=on_apply, icon='check').props('color=primary')
```

**9. Key Functions:**

`clear_all()`: Reset all word inputs to empty, uncheck all modifiers, reset distances to 0, reset scope to 'word_range', remove extra components back to 2, update preview.

`on_apply()`:
1. Call `generate_tabular_syntax()` with builder_state to get `(syntax_str, negated_words)`
2. Set `query_input.set_value(syntax_str)`
3. Close dialog: `builder_dialog.close()`
4. Store negated_words somewhere accessible to execute_search (set as a nonlocal or on the search state)
5. Trigger search: call the existing search function (the same one wired to the search button)

`update_preview()`: Call `generate_tabular_syntax()` and update `preview_label.text`. If result is empty, show placeholder text.

**10. Negation Integration:**
The `on_apply` function gets negated_words from `generate_tabular_syntax()`. These must be passed to `execute_search()` as the `exclude_words` parameter. The web search function currently calls `engine.execute_search(...)`. Find where this call happens and ensure `exclude_words=negated_words` is passed. Store negated_words in a variable accessible from the search execution code (e.g., a nonlocal variable or attribute on a shared state object).

**11. Builder Opens Empty:**
Every time the dialog opens, clear all state. Either create a new dialog each time, or call `clear_all()` when the dialog opens.

**12. Mobile Responsiveness:**
- On small screens, component cards should stack vertically (use `flex-wrap`)
- Distance spinners move between stacked components
- Consider adding `.props('maximized')` on mobile (check screen width via JavaScript or NiceGUI's responsive utilities)
