- **Author** if present
- **Running Title** from `detail["running_titles"]` for this team's UnitCatalogRecIds
- **TextualFrame** (eng/heb based on language mode)
- **Copy Date/Place** if present

**Section B: Physical Description**
Header: "Physical Description" (tr() for i18n). Key-value pairs layout.

Aggregate across all records' UnitCatalogRecIds:
- **Material:** from `detail["fields"]` where FieldCategory="FragmentMaterial" -- show distinct values comma-separated
- **Size:** from `detail["sizes"]` -- format as "{SizeX} x {SizeY} mm" (hide if both null)

- **Language:** from `detail["fields"]` where FieldCategory="GenizahLanguages"
- **Script Type:** from `detail["fields"]` where FieldCategory="TypeOfScript"
- **Script Style:** from `detail["fields"]` where FieldCategory="TypeOfScriptStyle"
- **Vocalization:** from `detail["fields"]` where FieldCategory="TypeOfVocalization"
- **Number of Folios/Columns/Lines:** from records' num_folio, num_column, num_row

Hide empty fields (per user decision). Each field rendered as `ui.row()` with label and value.

**Section C: Free Descriptions**
If any free descriptions exist in `detail["free_descriptions"]`, show them fully visible (no collapse/expand per user decision) under a "Free Description" header. Each as a separate paragraph.

**Close button:** Bottom-right, "Close" / tr("Close").

Import and use `tr()` from the web translations module for all labels. Follow app language via the existing translation system pattern used in bibliography_dialog.py.
