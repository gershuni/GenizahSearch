<decisions_made>

- QScrollArea (Quasar) doesn't work in flex containers without explicit height — use plain div
- Field categories in FIST export use CODE_FCDTable.TableName which produces TypeOfScript
  (not GenizahScriptType). The "Genizah" prefix was an incorrect assumption in plan 37-03/04.
- NumBifolio is a separate field from NumFolio in dbo_UnitCatalogRec — FIST uses bifolios
  (a sheet folded to make 2 folios), not the same as folio count.
- Free descriptions must NOT have version filter because they live on different SignatureIds
  than catalog records within the same SetSignatureId.
- FIST.db copied from FIST_DB_BACKUP/ to fist_data/ for export (was 0 bytes before).
</decisions_made>
