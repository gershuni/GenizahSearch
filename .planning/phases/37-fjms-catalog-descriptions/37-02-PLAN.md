- In `get_catalog_records()`: Same removals and additions. The record dict should include `"unit_catalog_rec_id"` for grouping child data in the dialog.

**2. Add `get_catalog_source_counts(self, sys_ids: list[str]) -> dict[str, int]`:**
Batch method for search card button labels. For each batch of sys_ids (up to 500 at a time), query:
```sql
SELECT AlmaId, COUNT(DISTINCT SourceName) as cnt FROM catalog
WHERE AlmaId IN (?,?,...)
AND SourceName IS NOT NULL AND SourceName != ''
AND SourceName NOT IN ('Catalogs','Institution','Collection','Other')
GROUP BY AlmaId
```
Returns dict mapping sys_id -> count. Uses the same batch pattern as `get_domains_for_sys_ids()`.

**3. Add `get_catalog_detail(self, sys_id: str) -> dict`:**
Returns a structured dict for the dialog with all child table data:
```python
{
    "records": [...],          # from get_catalog_records()
    "running_titles": {},      # UnitCatalogRecId -> [{"running_title": str, "comment": str}]
    "sizes": {},               # UnitCatalogRecId -> [{"size_x": float, "size_y": float, "inner_size_x": float, "inner_size_y": float}]
    "fields": {},              # UnitCatalogRecId -> {"FieldCategory": [{"value": str, "value_heb": str}]}
    "free_descriptions": [],   # [{"text": str, "signature_id": int}]
}
```

Implementation:
1. Call `self.get_catalog_records(sys_id)` for records
2. Query `catalog_running_titles WHERE AlmaId = ?` and group by UnitCatalogRecId
3. Query `catalog_sizes WHERE AlmaId = ?` and group by UnitCatalogRecId
4. Query `catalog_fields WHERE AlmaId = ?` and group by UnitCatalogRecId then FieldCategory
5. Query `catalog_free_desc WHERE AlmaId = ?` for free descriptions

Each sub-query should be wrapped in try/except returning empty defaults -- graceful fallback if individual tables don't exist (backward compat with old sidecars).

Handle the case where `self._conn is None` by returning a dict with empty values for all keys.
