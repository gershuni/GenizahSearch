<objective>
Modify the desktop app's image resolution pipeline in genizah_core.py to use pre-resolved FL IDs from the NLI crossref SQLite sidecar, eliminating the NLI IIIF manifest network fetch. Also add Cambridge IIIF local resolution to bypass both NLI MARC and CUDL network fetches.

Purpose: The desktop app's `enrich_metadata()` currently makes 2-3 network calls per manuscript: MARC XML fetch, IIIF manifest fetch, and optionally CUDL manifest fetch. With 815K pre-resolved image records and 141K Cambridge manifest URLs in the local sidecar, we can serve images without any of these network calls for covered manuscripts, dramatically reducing load time.

Output: Modified genizah_core.py with local-first image resolution, and unit tests verifying the new paths.
