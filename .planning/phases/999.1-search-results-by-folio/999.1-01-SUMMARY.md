desktop app's `COL_IMG` column shows at `genizah_app.py:16111`. Users no longer need to
open Quick View to learn which folio a hit came from.

Task 2 feedback, revising decision D-05 in place (descriptive tooltip allowed; click

## Decision revision (post-smoke-check, 2026-05-18)

**D-05 revised in place:** the original CONTEXT.md decision was "display only — no click
handler, no link, no tooltip." After Hillel ran the 8-step smoke check and approved the
visual result, he asked for a hover tooltip identifying the chip ("Image number" / "מספר תמונה").
The revised wording in the code comments at `web/pages/search_results.py:475-476` is:

> D-05 (revised 2026-05-18 after Task 2 smoke check): descriptive tooltip is
> allowed; still no click handler and no link.

`tr('Image number')` was wired through the existing `web.translations` chokepoint;
the new translation entry sits at `genizah_translations.py:3186-3187` next to the most
recent visual-similarity strings.

Translation verified end-to-end:
```python
>>> from web.translations import tr, set_language
>>> set_language('he'); tr('Image number')
'מספר תמונה'
>>> set_language('en'); tr('Image number')
'Image number'
```

## Out-of-scope (preserved from CONTEXT.md Deferred Ideas)

- Folio labels (`1r` / `2v`) — `display['img']` is the raw image index, not the
  recto/verso label. Adding labels needs a separate metadata join.
- Grouping/sorting by manuscript or folio number — separate UX question.
- Parallels-result-card extension — different render path at `web/pages/parallels.py`.
- Composition-search results — different render path; explicitly out of scope.
- Click-to-deep-link to a specific image — D-05 (revised) still prohibits click handlers
  on the chip itself; deep-link is already available via the Browse button on the card.

## What this enables

Power users who skim search results no longer round-trip through Quick View to find
out which folio of a multi-folio manuscript a hit landed on. This was item from the
2026-02-27 power-user feedback letter (folio surfacing) carried in MEMORY.md.
