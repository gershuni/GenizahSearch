**Fixture approach:**
Create a pytest fixture `pgp_service` that:
1. Creates an in-memory SQLite database (`:memory:`)
2. Creates the schema matching pgp.db (documents, document_sources, document_fragments tables with all columns)
3. Inserts sample test data
4. Creates a `PgpService` instance with `db_path=':memory:'` -- BUT since PgpService auto-detects path, instead pass the connection directly or use a temp file. The cleanest approach: create a temp db file with `tempfile.NamedTemporaryFile`, write schema+data, pass path to `PgpService(db_path=...)`.
5. Yields the service instance
6. Cleans up temp file
