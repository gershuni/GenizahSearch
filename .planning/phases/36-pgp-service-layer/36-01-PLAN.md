<task type="auto">
  <name>Task 1: Rewrite shared/document_service.py to PgpService class with SQLite backend</name>
  <files>shared/document_service.py</files>
  <action>
Rewrite `shared/document_service.py` following the class-based sidecar pattern from `shared/fjms_service.py`. The file structure should be:

1. **Imports**: Replace `from shared.supabase_provider import get_client` with `import sqlite3`, `import json`, `import logging`, `from pathlib import Path`. Keep existing imports (`re`, `html.parser`, `typing`).

2. **Module constants**: `_SIDECAR_FILENAME = "pgp.db"`, `_SIDECAR_DIR = "pgp_data"`, `logger = logging.getLogger(__name__)`.

3. **`_find_project_root()`**: Copy from FjmsService -- looks for `libraries.csv` up to 5 levels from `__file__`.

4. **`_row_to_dict(row, json_columns=())` helper**: Convert sqlite3.Row to dict, calling `json.loads()` on specified columns when value is not None. This is CRITICAL for JSON round-trip correctness (tags as list, sections as list of dicts).

5. **`class PgpService`**: Constructor takes `db_path=None, thread_safe=False`. Auto-detects `pgp_data/pgp.db` from project root. Opens read-only URI connection (`file:...?mode=ro`) with `check_same_thread=not thread_safe`, `row_factory=sqlite3.Row`, `timeout=10.0`. Has `is_available()` method.

6. **PgpService methods** (all 11 that currently use Supabase):
   - `get_document_for_fragment(sys_id, page_num=None)` -> 2 SQLite queries (fragment lookup + document fetch). Parse `tags` via `_row_to_dict`. Return None on error/not-found.
   - `get_fragments_for_document(pgpid)` -> `SELECT * FROM document_fragments WHERE document_id = ? ORDER BY sequence_order`. Return `[dict(row) for row in cursor]`.
   - `get_transcription_for_document(pgpid)` -> `SELECT transcription FROM documents WHERE pgpid = ?`. Return string or None.
   - `get_document_metadata(pgpid)` -> `SELECT document_type, tags, doc_date_original, doc_date_standard, inferred_date_display, description, pgp_url, shelfmark_combined FROM documents WHERE pgpid = ?`. Parse `tags` via `_row_to_dict`.
   - `get_sources_for_document(pgpid)` -> `SELECT * FROM document_sources WHERE pgpid = ? ORDER BY doc_relation, sequence_order`. Parse `sections` via `_row_to_dict`.
   - `get_all_sources_for_fragment(sys_id)` -> OPTIMIZED: 2 queries instead of N+1. Get fragment links, batch-query sources with `WHERE pgpid IN (?)`, attach `page_info`, sort Editions first.
   - `get_editions_for_document(pgpid)` -> `WHERE doc_relation LIKE '%Edition%' ORDER BY sequence_order`. Parse `sections`.
   - `get_translations_for_document(pgpid)` -> `WHERE doc_relation LIKE '%Translation%' ORDER BY sequence_order`. Parse `sections`.
   - `get_sys_ids_with_transcriptions(sys_ids)` -> Chunked `SELECT DISTINCT sys_id FROM document_fragments WHERE sys_id IN (?)` with batch_size=500.
   - `get_fragments_by_tag(tag)` -> `SELECT ... FROM documents d, json_each(d.tags) je WHERE je.value = ?` + batch fragment lookup. Return list of dicts with sys_id, shelfmark, document_type, description, pgpid, transcription.
   - `get_all_distinct_tags()` -> `SELECT DISTINCT je.value as tag FROM documents d, json_each(d.tags) je WHERE je.value != '' ORDER BY tag`. Return sorted list.

7. **Module-level singleton**: `_default_service: Optional[PgpService] = None` and `get_pgp_service(thread_safe=False) -> PgpService` factory (matches FjmsService pattern). Use `thread_safe=True` as default since both apps run in separate processes and read-only is always safe.

8. **Module-level wrapper functions**: All 11 existing function signatures PRESERVED as thin wrappers that call `get_pgp_service().method()`. Keep all docstrings. Example:
   ```python
   def get_document_for_fragment(sys_id: str, page_num: int = None) -> Optional[Dict[str, Any]]:
       svc = get_pgp_service()
       return svc.get_document_for_fragment(sys_id, page_num)
   ```

9. **Pure functions UNCHANGED**: `parse_transcription_sections()`, `get_section_for_page()`, `parse_html_sections()`, `PGPHTMLParser` class -- these have ZERO Supabase dependency and must remain exactly as they are.

Key constraints:
- Use `logger.error()` instead of `print()` for error logging (consistent with FjmsService)
- Every function returning documents MUST parse `tags` column via `_row_to_dict(row, json_columns=('tags',))`
- Every function returning sources MUST parse `sections` column via `_row_to_dict(row, json_columns=('sections',))`
- guard clauses at start of every method: `if not self._conn: return None/[]/set()`
- Error handling: try/except returning None/[]/set() (matching current behavior)
- The module-level `get_pgp_service()` should default to `thread_safe=True` since read-only SQLite connections are safe across threads and this eliminates the web vs desktop initialization concern
