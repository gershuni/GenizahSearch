## Spacing Scale

Declared values (multiples of 4 only). Matches the existing web app's Tailwind/Quasar utility classes in `web/main.py` and `web/pages/`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline chip padding (`px-1 py-0`) |
| sm | 8px | Chip/badge horizontal padding (`px-2`), compact row gaps (`gap-2`) |
| md | 16px | Default element spacing, section padding (`px-4`, `py-4`), card internal padding (`p-4`) |
| lg | 24px | Section-to-section spacing, header padding (`px-6`) |
| xl | 32px | Layout column gap between anchor pane and work column |
| 2xl | 48px | Major panel breaks |
| 3xl | 64px | App header height (already fixed at 64px in `web/main.py`) |

**Exceptions:**

- Anchor pane sticky top offset: 64px (exact header height) — not a spacing token, it's a positional offset.
- Zoom control touch targets: minimum 44px height (WCAG 2.5.5 Level AAA; use `min-h-[44px]` on zoom buttons).
- Cold-start input: minimum 48px height for comfortable mobile entry (matches existing search input height convention in `web/pages/search.py`).

**Source:** `web/main.py` (header 64px, `px-6`, `px-4`, `gap-2/3/4`), `web/pages/search_results.py` (`p-4`, `px-2 py-0.5`). Defaults used where not explicitly set.

## Layout Architecture

These layout rules are downstream of D-01 through D-04 from `117-CONTEXT.md`. They are binding for the executor.

### Wide-screen (≥ 768px)

```
┌──────────────────────────────────────────────────────┐
│  App header (64px, sticky, emerald gradient)          │
├─────────────────────────────────┬────────────────────┤
│  Sidebar/drawer (280px, left EN │                    │
│  / right HE)                    │                    │
│                                 │                    │
│  [via existing create_layout()] │  /joins-lab page   │
│                                 │  content area      │
└─────────────────────────────────┴────────────────────┘
```

Within the `/joins-lab` content area on wide screens:

```
┌──────────────────────────────────────────────────────┐
│  [Anchor Pane — sticky, position: sticky, top: 64px]  │
│  Width: 380px (EN: left column; HE: right column)     │
│  ┌──────────────────────────────────┐                │
│  │  Image viewer (manuscriptViewer) │                │
│  │  Zoom/Pan/Folio nav controls     │                │
│  │  RTL numbered transcription      │                │
│  └──────────────────────────────────┘                │
│                                                       │
│  [Work Column — scrolls, flex-1]                      │
│  ┌──────────────────────────────────┐                │
│  │  Builder (multi-line textarea)   │                │
│  │  Run Search CTA                  │                │
│  │  Candidate grid                  │                │
│  └──────────────────────────────────┘                │
└──────────────────────────────────────────────────────┘
```

- Anchor pane: `position: sticky; top: 64px; height: calc(100vh - 64px); overflow-y: auto;` — stays in view while work column scrolls.
- Anchor pane width: **380px** fixed on wide screens. Work column: `flex: 1; min-width: 0;` to take remaining space.
- **Direction-aware:** EN interface → anchor on LEFT (`flex-row`). HE interface → anchor on RIGHT (`flex-row-reverse`). This mirrors the existing RTL conventions (`rtl_mode` in `create_layout()`).
- The two-column flex container is the direct child of the `ui.page_sticky` / page content area registered via `@ui.page('/joins-lab')`.

### Narrow screens (< 768px)

- Anchor collapses to a **collapsible strip** at the top of the single scroll column.
- Default state on mobile: **collapsed** (shows shelfmark chip + a "Show anchor" expand button). User can tap to expand the full image viewer.
- Builder + candidate grid follow below in a single scroll column.
- Breakpoint: 768px — matches existing `breakpoint=768` on the sidebar drawer (`web/main.py:1040`).

### Room for 118/119 additions (D-04)

- The work column is a `ui.column()` with no hardcoded children structure — Phase 118 inserts the known-joins panel above the builder; Phase 119 inserts the table-view toggle and Compare panel below the grid. No re-layout required.
- The anchor pane is a standalone extracted component (`web/components/anchor_viewer.py`) — Phase 119 Compare reuses it in a second pane by instantiation.

**Source:** D-01..D-04 from `117-CONTEXT.md`. Widths set to match `web/main.py` drawer width (280px) and page conventions.

## Typography

Aligns with existing `web/static/common.css` and `web/pages/browse.py` transcription rendering.

Exactly **2 font weights** are used across the entire phase: **400 regular** and **600 semibold**. Visual hierarchy is driven by size, never by adding a third weight tier — the 20px Display heading is distinguished from labels by size alone, not by going bolder.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body (EN labels, metadata, helper text) | 14px (0.875rem / `text-sm`) | 400 regular | 1.5 | Inter / system-ui |
| Label (section headers, button text, form labels) | 14px (0.875rem / `text-sm`) | 600 semibold (`font-semibold` in Tailwind = 600; do NOT use `font-medium` = 500) | 1.3 | Inter / system-ui |
| Heading (anchor pane title, section headings) | 16px (1rem / `text-base`) | 600 semibold | 1.2 | Inter / system-ui |
| Display (cold-start empty state heading) | 20px (1.25rem / `text-xl`) | 600 semibold | 1.2 | Inter / system-ui |

**RTL Hebrew transcription (ANC-03):**

- Font size: 1.4rem (matches `_render_line_numbered_html` default in `browse.py:46`)
- Line height: 2.2 (matches `browse.py:46` default — generous to accommodate diacritics and line-number gutter alignment)
- Font: David, Frank Ruehl, Noto Sans Hebrew, SBL Hebrew, serif
- Direction: RTL (`direction: rtl; text-align: right`)
- Weight: 400 regular

**Builder textarea:**

- Font size: 16px (`text-base`) — matches existing search input in `web/pages/search.py` (`text-lg` class, ≈1.125rem; use `text-base` here as textarea content is user-typed lines, not a prominent search bar)
- Weight: 400 regular (user-typed content)
- Direction: RTL (`direction: rtl; text-align: right`) — transcription lines are Hebrew
- Font: David, Frank Ruehl, Noto Sans Hebrew, serif — same as transcription display

**Source:** `web/static/common.css` sidebar nav (font-size 0.7rem labels, font-weight 600 active), `web/pages/browse.py:46` transcription defaults, `web/pages/search.py` (text-sm, text-lg patterns). 4-size / **2-weight (400 + 600)** contract enforced.

## Color

Tokens from `web/static/common.css` `:root`. All three themes (light / parchment / dark) are supported via CSS variable inheritance — this contract names the **light-theme hex values** as canonical references; the CSS variables automatically adapt in parchment/dark.

| Role | CSS Variable | Light Value | Usage |
|------|-------------|-------------|-------|
| Dominant (60%) | `--bg-primary` | `#ffffff` | Page background, anchor pane background, work column background |
| Secondary (30%) | `--bg-secondary` / `--bg-card` | `#f8fafc` / `#ffffff` | Candidate grid cards (`bg-card`), builder textarea container, anchor pane inner content |
| Accent (10%) | `--primary-600` / `--primary-700` | `#059669` / `#047857` | Reserved list below |
| Destructive | `--error` | `#ef4444` | Error states only (search failure, image load failure) |

**Accent (`--primary-600` = `#059669`) is reserved for:**

1. The "Run Search" / primary CTA button background.
2. Focus ring on the builder textarea and shelfmark input.
3. Active/selected folio indicator in the folio navigation row.
4. The "pin" / anchor chip border (shelfmark chip in the anchor pane header).
5. The "open in /browse" link text on candidate cards (matches existing `a { color: var(--primary-700) }` from `common.css`).

**No other elements use accent.** Hover states use `--bg-hover` (`#f1f5f9`) not accent.

**Muted / secondary text:** `--text-secondary` (`#475569`) for metadata labels, folio counts, library codes. `--text-muted` (`#475569`) for helper text and placeholders.

**Border:** `--border-light` (`#e2e8f0`) for card borders, textarea border, section dividers. `--border-focus` (`#059669`) for focused inputs.

**Source:** `web/static/common.css` — directly extracted, not inferred.

## Page States

All states must be visually distinct. Each maps to a container shown/hidden in the page content area.

| State | Trigger | Visual |
|-------|---------|--------|
| Empty (cold start) | No anchor loaded | Centered "pin an anchor" panel: empty-state heading + body + smart box + "choose from list" button |
| Loading anchor | `sys_id` param present, fetching | Skeleton placeholder in anchor pane (image area: grey box, transcription: shimmer lines) |
| Anchor loaded, no search yet | Anchor pane populated | Builder textarea visible + "Run Search" button + helper text |
| Searching | Search in flight | "Run Search" button shows spinner + becomes disabled; builder read-only |
| Candidates loaded | Search completed | Candidate grid rendered below builder |
| No results | Search returned 0 candidates | Empty candidates message (see Copywriting) |
| Error (image) | Image fetch failed / NLI breaker tripped | Grey placeholder with broken-image icon + retry affordance (no toast; inline degradation) |
| Error (search) | Search adapter threw | Inline error below button (see Copywriting); button re-enabled |

**Source:** Inferred from REQUIREMENTS.md FND-01/ANC-01/CND-01/CND-02 success criteria + D-16 (stale-generation handling). No upstream artifact answered this explicitly.

## Interaction Contracts

### Cold-start smart box (D-05)

- Accepts: shelfmark string (e.g. `T-S 12.123`) or raw `sys_id` integer.
- On submit (Enter key or explicit button): resolve via existing shelfmark normalization path (`search_shelfmark()` pattern from `browse.py`) — no new resolver.
- On resolution failure: inline error "Fragment not found. Check the shelfmark and try again." — not a toast, not a redirect.
- The `sys_id` URL param (`/joins-lab?sys_id=...`) bypasses the smart box and loads directly. URL param wins over restored `safe_storage` anchor (D-13).

### Builder textarea (D-08/D-09)

- Multi-line `ui.textarea()` with RTL direction.
- Each non-empty line → one `BuilderRow(term=line)` when the user runs search.
- Empty lines are ignored (not submitted as empty rows).
- No per-line UI affordances in Phase 117 (those are Phase 118).
- Fixed search mode: exact (`SideQuery.variants=False`). No mode toggle rendered in Phase 117.

### Run Search button

- Disabled when: builder is empty (all lines blank), OR a search is already in flight (`is_running`).
- On click: increments `search_generation` (latest-wins guard), assembles `BuilderRow` list, calls `WebSearchExecutor` via `run.io_bound`, renders candidates on completion.
- Re-entrancy: a new click while in-flight cancels the prior generation (stale-generation check on result delivery, not mid-flight abort). No cancel button in Phase 117 — runs to completion.

### Anchor pane folio navigation

- Previous / Next folio buttons: same icon style as `/browse` (`chevron_left` / `chevron_right`, flat, round). Each has a visible tooltip (see icon-only control table) and an `aria-label`.
- Zoom controls: zoom_in (`add`), zoom_out (`remove`), zoom_reset (`fit_screen`) — matching `browse.py:1388`. Each has a visible tooltip and an `aria-label`.
- Touch target: minimum 44px on all zoom/nav controls.

### Anchor pane collapse (narrow screens)

- Expand/collapse toggle: `expand_more` / `expand_less` icon, flat button, right of the shelfmark chip. Visible tooltip "Show anchor" / "Hide anchor" + matching `aria-label`.
- Collapsed height: 48px (shelfmark chip + toggle button).
- Expanded: full image viewer at 100% viewport width.

### "Choose from list" (D-06)

- Anonymous user: clicking shows a `ui.dialog()` with the standard login prompt (same as other login-gated list reads in the web app). Does NOT navigate away.
- Logged-in user: shows a list-picker dialog (NiceGUI `ui.dialog()` + scrollable list of saved research lists). On selection, the picked fragment becomes the anchor.

### Candidate cards (D-14)

- Read-only in Phase 117. Each card: thumbnail image (48×48px or 96×96px on 2x screens), shelfmark, library chip, title (truncated, 2 lines max).
- "View in Browse" link (`/browse?sys_id={sys_id}`) opens in the same tab.
- Grid layout: `ui.grid(columns=2)` on wide, single column on narrow (< 640px breakpoint).
- No hover triage state in Phase 117 (Phase 119).

### Anchor sys_id persistence (D-13)

- On anchor load: `safe_user_set('joins_lab', {..., 'schema_version': 1, 'anchor_sys_id': sys_id})`
- On bare `/joins-lab` (no URL param): read `joins_lab.anchor_sys_id` from `safe_storage`, load it, show restored-anchor toast.
- URL param `sys_id` always wins; overwrite `safe_storage` anchor to match.

## Deep-link URL Contract (FND-08)

Phase 117 implements the minimum subset. Document explicitly.

| Parameter | Type | Required | Example | Notes |
|-----------|------|----------|---------|-------|
| `sys_id` | string/int | Yes (when entering via URL) | `/joins-lab?sys_id=990001234` | Primary anchor identifier. Resolved by the anchor-load path. |
| `shelfmark` | string | No | `/joins-lab?shelfmark=T-S+12.123` | If present AND `sys_id` absent, resolved via shelfmark normalization → converted to `sys_id` internally. If both present, `sys_id` wins. |
| `fl_id` | string | No | `/joins-lab?sys_id=990001234&fl_id=T-S+12.123.1r` | Hints at starting folio. Passed to anchor viewer for initial folio selection. |
| `page` | int | No | `/joins-lab?sys_id=990001234&page=2` | Starting page number (p_num). |
| `volume_ie` | string | No | `/joins-lab?sys_id=990001234&volume_ie=IE123` | Multi-IE volume discriminator. Passed to anchor viewer. |

**What is NOT in the URL:** builder lines, candidate list, triage verdicts, filter state. These are device-local (server-side `safe_storage`). Deep links carry only the anchor identity.

**Source:** CONTEXT.md "Claude's Discretion" — param set is researcher's discretion. FND-08 requirement. Minimum `sys_id`; optional params added where the anchor viewer already accepts them (matching `/browse` param conventions).

## safe_storage Schema (Phase 117 definition)

Key: `joins_lab` (string). Shape:

```python
{
    "schema_version": 1,          # int — bump on breaking shape change; triggers invalidation
    "anchor_sys_id": "990001234", # str | None — last loaded anchor
    "anchor_fl_id": None,         # str | None — last folio, for restore (optional)
    "anchor_volume_ie": None,     # str | None — last volume_ie (optional)
}
```

- All reads via `safe_user_get('joins_lab', default=None)`.
- All writes via `safe_user_set('joins_lab', {...})`.
- On read: check `schema_version`. If absent or != 1, discard the entire key and treat as cold start.
- Builder/triage/filter state NOT persisted in Phase 117 (Phase 120).

**Source:** D-12, D-13 from `117-CONTEXT.md`. Key name and dict shape are Claude's discretion (CONTEXT.md "Claude's Discretion").

## Accessibility Notes

- All interactive elements: `aria-label` via `.props(f'aria-label="{tr(...)}"')` — matches existing pattern in `web/main.py:938`.
- Builder textarea: `aria-label` = `tr("Search lines — one line per row")`.
- All icon-only controls (zoom, folio nav, anchor collapse) carry BOTH a visible `ui.tooltip()` AND an `aria-label` — see the "Icon-only control tooltips" table in the Copywriting Contract for exact copy.
- Candidate cards: each card is a `ui.card()` with an implicit semantic role; the "View in Browse" link is the primary keyboard-accessible action.
- Color contrast: all text uses `--text-primary` (#1e293b on #ffffff = 16.1:1) or `--text-secondary` (#475569 on #ffffff = 7.5:1) — both WCAG AA.
- RTL: the entire page toggles direction with `resolved_lang == 'he'` via the existing `rtl_mode` convention.
