<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NiceGUI request thread (event loop) → search engine | A synchronous, potentially multi-second `execute_search` must never run on the event loop |
| caller args → `state.searcher.execute_search` | `query_str`/`mode`/`corpus_scope` flow into the engine; the engine performs its own tokenization (no shell/SQL injection surface here) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-117-01 | Denial of Service | `WebSearchExecutor.execute_search` invoked on the event loop | mitigate | Adapter is synchronous and documented "io_bound only"; `tests/test_joins_lab_off_loop.py` (Task 3) statically asserts joins_lab.py never calls it on the loop (SC#3) |
| T-117-02 | Tampering | adapter routing search through HTTP `/api/search` (drops text_position/corpus_scope, caps modes) | mitigate | Adapter wraps `state.searcher` directly; Task 1 acceptance grep asserts no `api/search`/`requests`/`httpx` import (BLOCKER 1) |
