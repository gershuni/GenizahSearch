```python
@app.get('/api/puzzle_image')
def puzzle_image(fl_id: str, threshold: float = 30.0, size: int = 800, processed: bool = True):
    """Serve processed/original fragment image for puzzle canvas."""
    from shared.puzzle_image_service import get_puzzle_image_service
    service = get_puzzle_image_service()
    image_bytes = service.resolve_fragment_image(
        fl_id=fl_id, size=size, threshold=threshold, processed=processed
    )
    if image_bytes is None:
        return Response(content="Image not found", status_code=404)
    content_type = 'image/png' if processed else 'image/jpeg'
    return Response(
        content=image_bytes,
        media_type=content_type,
        headers={"Cache-Control": "public, max-age=3600"}
    )
```

**2. `/api/puzzle_folios/{sys_id}` endpoint:**
```python
@app.get('/api/puzzle_folios/{sys_id}')
def puzzle_folios(sys_id: str):
    """Get ordered folio list for a manuscript (for prev/next navigation)."""
    from shared.nli_crossref_service import get_nli_crossref_service
    service = get_nli_crossref_service()
    if not service.is_available():
        return Response(content="NLI crossref not available", status_code=503)
    folios = service.get_folio_images(sys_id)
    return [{'fl_id': f.get('fl_id', ''), 'label': f.get('folio_label', '')} for f in folios]
```

**A. Create `web/pages/puzzle.py`** -- the main puzzle page module.

The page has two parts: Python (NiceGUI UI construction) and JavaScript (Fabric.js canvas logic via `window.puzzleCanvas` global object).

**Python side (`create_puzzle_page(initial_add=None)`):**

1. **Fabric.js CDN**: Add `<script src="https://cdn.jsdelivr.net/npm/fabric@6.4.3/dist/index.min.js"></script>` via `ui.add_head_html()`

2. **Toolbar row 1**: Shelfmark autocomplete input + "Add" button + "Remove Selected" button + background mode cycle button (icon: `palette`) + "Fit All" button (icon: `fit_screen`)

3. **Toolbar row 2**: Scale slider (10%-400%, default 100%) + Rotation slider (-180 to 180) + Threshold slider (10-80, default 30) + bg toggle checkbox ("Show Original")

4. **Canvas area**: `ui.html('<canvas id="puzzleCanvas" width="1200" height="800"></canvas>')` inside a container div that fills remaining vertical space. Style the container: `flex: 1; position: relative; overflow: hidden;`

5. **Shelfmark autocomplete**: Use `ui.input` with `on_change` handler that calls `MetadataManager.get_shelfmark_suggestions()` and updates autocomplete options. On Enter or Add button click:
   - Look up sys_id via `MetadataManager.get_sys_id_for_shelfmark()`
   - Get folios via `nli_crossref_service.get_folio_images(sys_id)`
   - Take first folio's fl_id
   - Call `ui.run_javascript(f'window.puzzleCanvas.addFragment("{key}", "/api/puzzle_image?fl_id={fl_id}&threshold={threshold}&size=800", {x}, {y}, 0, 1.0, false, false)')`
   - Store fragment metadata in `app.storage.tab['puzzle_fragments']` dict (keyed by `sys_id,folio_label`)

6. **Initial add from query param**: If `initial_add` is provided (format: `sys_id,fl_id`), auto-add that fragment after canvas init using a `ui.timer(0.5, ..., once=True)`

7. **Canvas init**: Use `ui.timer(0.3, init_canvas, once=True)` to wait for DOM. In `init_canvas()`, call `ui.run_javascript('window.puzzleCanvas.init("puzzleCanvas")')`. Then restore state if any exists in `app.storage.tab`.

8. **Slider bindings**:
   - Scale slider `on_change`: `ui.run_javascript(f'window.puzzleCanvas.setSelectedScale({value/100})')`
   - Rotation slider `on_change`: `ui.run_javascript(f'window.puzzleCanvas.setSelectedRotation({value})')`
   - Threshold slider `on_change`: triggers re-fetch of selected fragment's image with new threshold
   - BG toggle checkbox: `ui.run_javascript('window.puzzleCanvas.toggleSelectedBg()')`

9. **Session state persistence**: Before page unload, save state. Use `app.on_disconnect` or periodic timer (every 30s) to call `ui.run_javascript('window.puzzleCanvas.getState()')` and store result in `app.storage.tab['puzzle_state']`. On page load, restore from `app.storage.tab` if present.
