CUDL label normalization: `construct_mosseri_cudl_label('Moss. III,27O')` returns `'MS-MOSSERI-III-00027-O'`.
The CUDL classmark form (URL slug) is `mosseriiii27o`. To bridge these:
- forward label (e.g. `MS-MOSSERI-III-00027-O`) → strip dashes → lowercase → `msmosseriiii00027o`
- BUT actual CUDL classmark form is `mosseriiii27o` (no `ms` prefix, no zero padding)
- So the alias index key should be `cudl_normalize(<some form>)` of a string that survives `cudl_normalize`'s rules (which strip `ms.`, dashes, leading zeros within numeric segments).

Verification needed during implementation: try indexing both
  (a) `cudl_normalize(construct_mosseri_cudl_label(variant))` — pass forward label through bridge normalizer, AND
  (b) `cudl_normalize(variant)` — pass the original libraries.csv variant
and confirm at least one matches CUDL's `mosseriiii27o` form. If `construct_mosseri_cudl_label` output `MS-MOSSERI-III-00027-O` after `cudl_normalize` becomes `mosseriiii27o`, that's the expected key. (cudl_normalize lower+strip-spaces, replaces `ms.` and `-`, then strips leading zeros within numeric segments via `(?<=\.)0+(\d)` and `^0+(\d)` — note these only strip zeros after a dot or at string start; the zfill(5) `00027` has no preceding dot so the `00027` zeros may NOT be stripped. Validate empirically.)

If `cudl_normalize` does not strip the zfill zeros, add a Mosseri-specific cleanup: after calling `construct_mosseri_cudl_label`, strip leading zeros from each `-`-separated numeric segment BEFORE passing to `cudl_normalize`. Document this in code comments.

1. **`build_alias_index(csv_bank)`** — module function, no class. Input is the dict-of-dicts from `MetadataManager.csv_bank`. Output: populate module-level `_CUDL_ALIAS_INDEX`.

   ```python
   def build_alias_index(csv_bank):
       from genizah_core import construct_mosseri_cudl_label  # late import — break cycle
       global _CUDL_ALIAS_INDEX
       index = {}

       def _index_key_for_label(label: str) -> str:
           # Strip the zfill leading zeros that construct_mosseri_cudl_label adds, since
           # CUDL's URL slug form drops them (MS-MOSSERI-III-00027-O -> mosseriiii27o).
           # Walk dash-separated segments; for any pure-numeric segment, lstrip('0') (keep '0' as '0').
           parts = []
           for seg in label.split('-'):
               if seg.isdigit():
                   parts.append(seg.lstrip('0') or '0')
               else:
                   parts.append(seg)
           return cudl_normalize('-'.join(parts))

       for sys_id, data in csv_bank.items():
           variants = data.get('call_numbers_raw') or []
           # Also include the primary 'shelfmark' if not already in the variant list.
           primary = data.get('shelfmark')
           if primary and primary not in variants:
               variants = list(variants) + [primary]

           # Pick a canonical shelfmark for return value: prefer the one in MOST_LIKELY_CUDL_FORM,
           # else fall back to data['shelfmark']. Simplest: use data['shelfmark'].
           canonical = data.get('shelfmark') or (variants[0] if variants else '')

           library_code = data.get('library_code') or ''

           for variant in variants:
               # --- Mosseri forward path (D-03) ---
               if library_code == 'Mosseri':
                   label = construct_mosseri_cudl_label(variant)
                   if label:
                       key = _index_key_for_label(label)
                       if key and key not in _COLLISION_KEYS:
                           index.setdefault(key, (sys_id, canonical))

               # --- Generic CUDL-form path (CUL Or./T-S/Add. — applies in Plan 03 too) ---
               # Index every variant under cudl_normalize(variant). Collision-key exclusion
               # is enforced for ALL paths since leading-zero collapse may produce dupes
               # in the generic case as well.
               if library_code in ('CUL', 'Mosseri'):  # Mosseri included for completeness
                   key = cudl_normalize(variant)
                   if key and key not in _COLLISION_KEYS:
                       index.setdefault(key, (sys_id, canonical))

       _CUDL_ALIAS_INDEX = index
       logger.info("Built CUDL alias index: %d entries (collisions excluded: %d)",
                   len(index), len(_COLLISION_KEYS))
   ```

   Notes:
   - Store `(sys_id, canonical)` tuples in the dict so `lookup_cudl` can return both per D-04.
   - Use `index.setdefault(...)` not `index[key] = ...` so the FIRST sys_id to claim a key wins (deterministic, depends on dict iteration order = insertion order). Subsequent same-key claims by OTHER sys_ids are silently dropped — those would be collisions Plan 01's audit should have caught for the leading-zero case, but for non-zero cases (e.g. truly duplicate shelfmarks across rows) we accept first-wins. If you want to be paranoid here, log a warning when a same-key collision is encountered with a different sys_id.

   ```python
   def lookup_cudl(classmark: str) -> Optional[Dict[str, str]]:
       """Map a CUDL classmark to a libraries.csv row. Returns None if no match."""
       if _CUDL_ALIAS_INDEX is None or not _CUDL_ALIAS_INDEX:
           return None
       key = cudl_normalize(classmark)
       if not key:
           return None
       hit = _CUDL_ALIAS_INDEX.get(key)
       if hit is None:
           return None
       sys_id, shelfmark = hit
       return {"sys_id": sys_id, "shelfmark": shelfmark}
   ```
