In web/auth_state.py, modify the `create_auth_buttons()` function (around line 379-425) to defer login dialog creation until the user actually clicks Login or Register.

Current code (anonymous user branch, around line 412-425):
```python
else:
    # Login/Register buttons
    dialog = create_login_dialog()

    def open_login():
        dialog.tabs.set_value(dialog.login_tab)
        dialog.open()

    def open_register():
        dialog.tabs.set_value(dialog.register_tab)
        dialog.open()

    ui.button(tr('Login'), on_click=open_login).props('flat text-color=white dense').classes('text-sm')
    ui.button(tr('Register'), on_click=open_register).props('outline text-color=white dense').classes('text-sm')
```

Replace with lazy creation using a nonlocal variable:
```python
else:
    # Login/Register buttons (dialog built lazily on first click)
    dialog = None

    def _ensure_dialog():
        nonlocal dialog
        if dialog is None:
            dialog = create_login_dialog()
        return dialog

    def open_login():
        d = _ensure_dialog()
        d.tabs.set_value(d.login_tab)
        d.open()

    def open_register():
        d = _ensure_dialog()
        d.tabs.set_value(d.register_tab)
        d.open()

    ui.button(tr('Login'), on_click=open_login).props('flat text-color=white dense').classes('text-sm')
    ui.button(tr('Register'), on_click=open_register).props('outline text-color=white dense').classes('text-sm')
```

This avoids building the login dialog (with tabs, inputs, Google OAuth button, form validation) on every page load for anonymous users. The dialog is only created when Login or Register is actually clicked.

**Do NOT modify** the logged-in branch (the `if GlobalAuthState.is_logged_in():` branch) -- it doesn't create a dialog.
