<objective>
Replace the 200-result WebSocket cap with client-side pagination, allowing users to browse all search results in pages of 50.

Purpose: Currently, search results are capped at 200 items rendered simultaneously via WebSocket, which both limits what users can see and causes UI sluggishness. With pagination, ALL results are held server-side in `search_state.results`, but only 50 are rendered at a time. This eliminates the 200-cap limitation while actually improving rendering performance (50 components vs 200).

Output: web/pages/search.py with pagination in render_results(), page navigation controls, and all call sites updated to remove the [:200] cap.
</objective>

**Step 2: Rewrite render_results() to support pagination.**

Replace the current `render_results(results)` function (around line 2213) with a paginated version:

```python
def render_results(results, page=None):
    results_container.clear()
    search_state.displayed_results = results  # Track full filtered set for Advanced View

    # Use stored page or provided page
    if page is not None:
        search_state.current_page = page
    # Clamp page to valid range
    total = len(results)
    total_pages = max(1, (total + PAGE_SIZE - 1) // PAGE_SIZE)
    if search_state.current_page >= total_pages:
        search_state.current_page = 0

    # Show loading spinner when search is running
    if search_state.is_running:
        with results_container:
            with ui.column().classes('w-full h-64 items-center justify-center'):
                ui.spinner('bars', size='xl', color='primary').classes('mb-4')
                ui.label(tr("Searching...")).classes('text-xl font-bold animate-pulse').style('color: var(--primary-600);')
        return

    if not results:
        with results_container:
            with ui.column().classes('w-full h-64 items-center justify-center'):
                ui.icon('search').classes('text-5xl').style('color: var(--text-muted);')
                ui.label(tr("Ready to search.")).classes('mt-4').style('color: var(--text-muted);')
        return

    # Calculate page slice
    page_idx = search_state.current_page
    start = page_idx * PAGE_SIZE
    end = min(start + PAGE_SIZE, total)
    page_results = results[start:end]

    with results_container:
        # Pagination controls at top (only if more than one page)
        if total_pages > 1:
            with ui.row().classes('w-full justify-between items-center px-4 pt-2'):
                ui.label(f"{start + 1}-{end} {tr('of')} {total}").classes('text-sm').style('color: var(--text-muted);')
                def on_page_change(e):
                    search_state.current_page = e.value - 1  # ui.pagination is 1-indexed
                    render_results(results, page=search_state.current_page)
                ui.pagination(1, total_pages, value=page_idx + 1,
                    on_change=on_page_change).props('max-pages=7 boundary-numbers')

        # Render only this page of results
        with ui.column().classes('w-full gap-2 p-4'):
            for i, res in enumerate(page_results):
                create_result_card(start + i, res)

        # Pagination controls at bottom (only if more than one page)
        if total_pages > 1:
            with ui.row().classes('w-full justify-center items-center px-4 pb-2'):
                def on_page_change_bottom(e):
                    search_state.current_page = e.value - 1
                    render_results(results, page=search_state.current_page)
                    # Scroll to top of results (NiceGUI containers may not have scroll_to)
                    ui.run_javascript('window.scrollTo(0, 0)')
                ui.pagination(1, total_pages, value=page_idx + 1,
                    on_change=on_page_change_bottom).props('max-pages=7 boundary-numbers')
```
