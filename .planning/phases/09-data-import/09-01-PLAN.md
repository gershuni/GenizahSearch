<task type="auto">
  <name>Task 2: Build comprehensive import script</name>
  <files>scripts/import_pgp_full.py</files>
  <action>
Create `scripts/import_pgp_full.py` -- a single comprehensive import script replacing the two v1 scripts. Reuse proven patterns from v1 (`import_pgp_documents.py`, `import_document_sources.py`) and the code examples from 09-RESEARCH.md.

**CLI interface:**
- `--dry-run` (default): Validate all data, report statistics, do not write to database
- `--execute`: Actually import to Supabase
- Uses argparse with mutually exclusive group (proven v1 pattern)

**Data loading functions (all use `encoding='utf-8-sig'` for BOM handling):**

1. `load_documents_full(path)` -> Dict[int, Dict]: Load ALL columns from documents.csv. Handle BOM in first column (`\ufeffpgpid` fallback). Parse tags with `parse_tags()`. Convert 'Y'/'N' to boolean for has_transcription/has_translation. Return dict keyed by pgpid.

2. `load_fragment_metadata(path)` -> Dict[str, Dict]: Load fragments.csv into shelfmark -> metadata lookup. Each row has pgpids (semicolon-separated), collection, library, library_abbrev, url, iiif_url. Handle BOM on first column.

3. `load_footnotes(path)` -> List[Dict]: Load footnotes.csv. Each row has pgpid, source, source_slug, doc_relation, location, url, notes, content. Handle BOM, compute content_length where content exists. Return list (not dict, since multiple footnotes per pgpid).

4. `load_transcriptions(path)` -> List[Dict]: Load transcriptions_linked.csv. Each row has pgpid, source_scholar, doc_relation, languages, content, content_length. Handle BOM on first column. Return list of all source records. **This is the data source for document_sources upsert (per user decision: full upsert of document_sources alongside documents).**

**Record preparation functions:**

5. `prepare_document_records(documents, transcription_lookup)` -> (List[Dict], List[Dict]): From loaded documents dict, prepare records for upsert. Map all columns to database column names. Include shelfmark_combined, document_type, tags (JSONB array), all date fields, languages, description, scholarship_records, shelfmarks_historic, language_note, has_transcription, has_translation, input_by. **IMPORTANT (per user decision "Fetch and import any available transcription/translation text for new documents"):** For documents that have content available in transcriptions_linked.csv, merge the transcription text and source into the document record's `transcription` and `transcription_source` fields. Build a `transcription_lookup` dict from the loaded transcriptions (keyed by pgpid, picking the first Digital Edition entry as the primary transcription). For documents WITHOUT transcription content available, omit `transcription` and `transcription_source` keys so the upsert does not null out any existing data. This ensures new documents get transcription text where available, and existing documents' transcription column is preserved or updated.

6. `prepare_source_records(transcription_records)` -> (List[Dict], Dict): From loaded transcriptions_linked.csv records, prepare document_sources records for upsert. **Reuse the exact pattern from `import_document_sources.py` `prepare_document_sources()` function**: detect translation language (Hebrew vs English based on content), compute sequence_order within (pgpid, doc_relation) groups, map fields to: pgpid, source_scholar, doc_relation, language, content, content_length, sequence_order. Return prepared records and stats dict. The on_conflict key for upsert is `pgpid,source_scholar,doc_relation` (matching the existing unique constraint on document_sources).

7. `prepare_footnote_records(footnotes)` -> (List[Dict], List[Dict]): From loaded footnotes, prepare records for document_footnotes upsert. Map columns. Compute content_length. Deduplicate by (pgpid, source_slug, doc_relation) composite key. Return valid records and issues.

8. `prepare_fragment_records_from_csv(fragment_metadata, gs_lookup)` -> (List[Dict], List[Dict]): From fragments.csv metadata, build document_fragments records. For each fragment row: normalize shelfmark, look up sys_id in gs_lookup. For each pgpid in the semicolon-separated pgpids field: create a record with document_id, sys_id, shelfmark, sequence_order, collection, library, library_abbrev, fragment_url, iiif_url. Deduplicate by (document_id, sys_id) using a seen_keys set. For sequence_order in multi-fragment documents: group fragments by pgpid and assign sequence based on order encountered (or parse from documents.csv shelfmark order if available). Return valid records and issues.

**Infrastructure (reuse from v1):**

9. `detect_translation_language(content)` -> str: Reuse from import_document_sources.py. Check for Hebrew characters in first 500 chars. Return "Hebrew" or "English".

10. `upsert_in_batches(client, table_name, records, on_conflict, dry_run)`: Batch upsert with tqdm progress. BATCH_SIZE = 500 (proven). Pass on_conflict as string for the constraint columns.

11. `capture_table_counts(client)` -> Dict[str, int]: Before/after snapshot of row counts for documents, document_fragments, document_sources, document_footnotes.

12. `write_verification_report(before, after, stats, issues, report_path)`: Write comprehensive report to `pgp_data/full_import_report.txt` with: before/after counts per table, deltas, records processed per pass, issues by type, success rate calculation.

**Main function -- multi-pass pipeline:**

```
main():
  1. Parse args (--dry-run / --execute)
  2. Verify input files exist (documents.csv, fragments.csv, footnotes.csv, transcriptions_linked.csv, libraries.csv)
  3. Check SUPABASE_SERVICE_KEY (fail fast if --execute and not set)
  4. Create Supabase client (only if --execute)
  5. Load all data sources:
     - documents.csv via load_documents_full()
     - fragments.csv via load_fragment_metadata()
     - footnotes.csv via load_footnotes()
     - transcriptions_linked.csv via load_transcriptions()
     - GenizahSearch shelfmarks via load_genizahsearch_shelfmarks() from pgp_transcriptions_export
  6. If --execute: capture before-counts
  7. Build transcription_lookup from loaded transcriptions (Dict[int, Dict] keyed by pgpid with first Digital Edition content)
  8. Prepare all record sets:
     - prepare_document_records(documents, transcription_lookup)
     - prepare_source_records(transcription_records)
     - prepare_footnote_records()
     - prepare_fragment_records_from_csv()
  9. Report statistics (record counts, issues by type)
  10. If --dry-run: print summary and exit
  11. If --execute:
     - Pass 1: Upsert documents (on_conflict='pgpid')
     - Pass 2: Upsert document_sources (on_conflict='pgpid,source_scholar,doc_relation')
     - Pass 3: Upsert footnotes (on_conflict='pgpid,source_slug,doc_relation')
     - Pass 4: Upsert fragment links (on_conflict='document_id,sys_id')
     - Capture after-counts
     - Write verification report
     - Print summary with success rate
```
