```sql
ALTER TABLE document_footnotes ENABLE ROW LEVEL SECURITY;

DO $$
BEGIN
    IF NOT EXISTS (
        SELECT 1 FROM pg_policies
        WHERE tablename = '...' AND policyname = '...'
```

```python
class _ConcurrencyRecorder:
    def __init__(self):
        self._lock = threading.Lock()
        self._active = 0
        self.max_concurrent = 0
        self.call_count = 0

    def enter(self):
        with self._lock:
            self._active += 1
            if self._active > self.max_concurrent:
                self.max_concurrent = self._active
            self.call_count += 1

    def exit(self):
        with self._lock:
            self._active -= 1
```

Use `max_concurrent == 1` to assert serialization (NOT `call_count == 2`, which passes even when calls overlap concurrently).

### 5. `web/supabase_client.py:233-319` — `get_user_client()` wrapped with `WeakKeyDictionary` memo

**NO EXISTING ANALOG.** Phase 90 D-12 deliberately removed all caching from this function. Phase 92.2 introduces a task-scoped memo as a NEW pattern. The planner MUST call out this deliberate drift.

Most-relevant existing context (lines 233-320):
```python
def get_user_client() -> Client:
    """Return a freshly-built, fully-authenticated supabase Client for the
    current user. Stable signature -- all 30+ call sites use this verbatim.
    """
    try:
        from web.safe_storage import safe_user_get
        auth_session = safe_user_get('auth_session') or {}
        access_token = auth_session.get('access_token')
        refresh_token = auth_session.get('refresh_token')

        if not access_token or not refresh_token:
            logger.info("[get_user_client] No auth_session tokens — returning anonymous singleton")
            return get_client()

        # Proactive refresh: if access_token is near expiry, rotate BEFORE building.
        if _access_token_near_expiry(access_token):
            refreshed = _refresh_user_session(stale_refresh_token=refresh_token)
            if not refreshed:
                return get_client()
            auth_session = safe_user_get('auth_session') or {}
            access_token = auth_session.get('access_token')
            if not access_token:
                return get_client()

        user_client = create_client(SUPABASE_URL, SUPABASE_ANON_KEY)
        _apply_user_auth_to_client(user_client, access_token)
        return user_client
    except Exception as e:
        logger.error(f"[get_user_client] Error building per-user client: {e}")
        return get_client()
```

**New pattern to introduce (no prior repo analog):**

```python
import asyncio
import weakref

# Module-level: WeakKeyDictionary keyed by asyncio.Task.
# When the task ends, the entry is GC'd automatically.
# Phase 90 D-12 "no cross-request caching" invariant preserved by construction:
# task lifetime = request lifetime in NiceGUI HTTP/event handlers.
_user_client_memo: 'weakref.WeakKeyDictionary[asyncio.Task, dict]' = weakref.WeakKeyDictionary()
```

Inside `get_user_client()`, after `_session_uuid` and `access_token` are known and BEFORE the `create_client(...)` call:
```python
session_uuid = safe_user_get('_session_uuid')  # or get_persisted_session_uuid()
if not session_uuid:
    # Phase 90 D-09/D-10: skip memo, build fresh (anonymous-like path).
    pass
else:
    try:
        task = asyncio.current_task()
    except RuntimeError:
        task = None
    if task is not None:
        task_memo = _user_client_memo.get(task)
        if task_memo is None:
            task_memo = {}
            _user_client_memo[task] = task_memo
        memo_key = (session_uuid, access_token)
        cached = task_memo.get(memo_key)
        if cached is not None:
            return cached
        # ... build user_client + _apply_user_auth_to_client(...) ...
        task_memo[memo_key] = user_client
        return user_client
# Fallback path (no session_uuid, or asyncio.current_task() returned None):
# build fresh, no memo. Existing line 315-317 logic preserved.
```

**Conventions to replicate from the existing function:**
- All `logger.info(...)` lines for control-flow branches use the `[get_user_client]` prefix (lines 284, 300, 312).
- Top-level `try/except` wraps the entire function, falling back to `get_client()` on any unexpected error (line 318).
- Imports of `safe_user_get` are LOCAL inside the function (line 278), not module-top — this avoids a circular import with `web.safe_storage`.
- `_session_uuid` reads MUST go through `safe_user_get('_session_uuid')` or `get_persisted_session_uuid()` (Phase 87 chokepoint).

**Phase 90 D-12 invariant preservation (cite in plan):** the memo lives in a `WeakKeyDictionary` keyed by `asyncio.Task`. When the task finishes, the entry is GC'd. The memo never spans tasks (= never spans requests in NiceGUI). This is the SAME logical guarantee as the deleted `_client_cache` had at request boundaries, achieved via Python GC rather than explicit eviction.

```python
    """Batched item-count lookup for all lists owned by user_id.

    Returns {list_id_int: count_int}. Lists with zero items are absent
    from the result; callers should default to 0 via counts.get(list_id, 0).

    Phase 92.2 D-FANOUT-02: replaces the per-list _get_list_item_count
    fanout in /lists rendering. Calls the security-invoker RPC
    get_list_item_counts_for_user(p_user_id) added in
    migrations/<date>-list-item-counts-rpc.sql. RLS-equivalent semantics
    via the inner `where exists (... ul.user_id = p_user_id)` clause.
    """
    try:
        client = get_user_client()
        response = client.rpc(
            'get_list_item_counts_for_user',
            {'p_user_id': user_id},
        ).execute()
        rows = response.data or []
        return {int(r['list_id']): int(r['item_count']) for r in rows if 'list_id' in r}
    except Exception as e:
        if _is_jwt_expired(e):
            logger.warning("JWT expired in get_list_item_counts, refreshing session and retrying")
            _refresh_user_session()
            try:
                return get_list_item_counts(user_id=user_id)
            except Exception as e2:
                logger.error(f"Error getting list item counts (retry): {e2}")
                return {}
        logger.error(f"Error getting list item counts: {e}")
        return {}
```

```python
    cache: dict[str, object],
    cache_time: dict[str, float],
    cache_path: str = NLI_PERSISTENT_CACHE_FILE,
    *,
    now: float | None = None,
) -> bool:

    Phase 92.2 D-NLI-01: serialized across concurrent callers via
    _nli_persist_lock; os.replace retried on PermissionError / WinError 5
    at 100/250/500ms backoffs.
    """
    import time as _time
    import errno

    now = _time.time() if now is None else now
    if NLI_DISK_CACHE_TTL <= 0:
        return False  # disabled

    # ... build entries + payload (existing lines 274-291) ...

    temp_path = f"{cache_path}.tmp.{os.getpid()}.{threading.get_ident()}"
    with _nli_persist_lock:
        try:
            cache_dir = os.path.dirname(cache_path)
            if cache_dir:
                os.makedirs(cache_dir, exist_ok=True)
            with open(temp_path, 'w', encoding='utf-8') as handle:
                json.dump(payload, handle, ensure_ascii=True, sort_keys=True)

            # Retry os.replace on EACCES / WinError 5 (Windows file-in-use).
            for attempt, delay_ms in enumerate((0, 100, 250, 500)):
                if delay_ms:
                    _time.sleep(delay_ms / 1000.0)
                try:
                    os.replace(temp_path, cache_path)
                    return True
                except (PermissionError, OSError) as e:
                    if getattr(e, 'errno', None) not in (errno.EACCES, errno.EPERM, 13):
                        # Not the WinError-5 retry case -- re-raise to outer handler
                        raise

                        "_save_nli_persistent_cache: os.replace attempt %d failed "
                        "(EACCES/WinError 5): %s", attempt + 1, e,
                    )
            # All retries exhausted
            logger.warning(
                "Failed to persist NLI FL-ID cache to %s after 4 attempts "
                "(WinError 5 / EACCES on os.replace)", cache_path,
            )
            return False
        except Exception as e:
            logger.warning(f"Failed to persist NLI FL-ID cache to {cache_path}: {e}")
            return False
        finally:
            # Best-effort tmp cleanup on any non-success path
            try:
                if os.path.exists(temp_path):
                    os.remove(temp_path)
```
