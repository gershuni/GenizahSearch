### Task 2a: ASGI middleware (web/main.py)

`_ListsPerfRouteTimingMiddleware` mounted via `app.add_middleware()` after `apply_all_patches()`. When `GS_LISTS_PERF_INSTRUMENTATION=1` and path is `/lists`:
1. Calls `_inst_reset()` and `_inst_set_request_id(request_id)` where `request_id = uuid4().hex[:12]` (Reviews Round-2 MEDIUM-3)
2. Starts `time.perf_counter()` at request entry
3. At `http.response.body` with `more_body=False`, emits `lists_perf_baseline=<json>` with `source='asgi_request_body_flush'`, top-level `request_id`, and `totals.total_wall_clock_ms`
4. Exception branch emits `source='asgi_request_exception'` with `body_flushed=False`

Zero overhead for non-/lists paths (path check before instrumentation check).

### Task 2b: sidebar decomposition log + data=None forward-port (web/pages/lists.py, web/components/project_tree.py, web/user_lists.py)

`render_lists_sidebar()` rewritten to:
- Capture `lists_mgr = state.lists_mgr` ONCE (Phase 89 D-03/D-04 factory-property discipline)
- Capture `data = lists_mgr.data` INSIDE the timed `try:` block (cost measured by sidebar_render_ms AND ASGI wall-clock)
- Pass `data=data` to `create_project_tree()` (Reviews Round-2 HIGH-2 Path A: eliminates double-fetch)
- `finally:` emits `lists_sidebar_decomposition=<json>` reusing captured `data` local (NO second `.data` access)
- Decomposition computes L/S/Cp/Cs from `data['lists']` and `delta_vs_codex_formula.ratio` vs `4 + L + 2*S`
- Includes `request_id: _inst_request_id.get()` for log pairing (Reviews Round-2 MEDIUM-3)

`data=None` kwarg forward-ported:
- `create_project_tree()` — `data=None` falls back to `lists_mgr.data`
- `get_lists_by_project(data=None)` — falls back to `_get_cached_data()`
- `get_list_display_color(list_id, data=None)` — falls back to `_get_cached_data()`

### Task 2c: _lists_task_probe() (web/pages/lists.py)
