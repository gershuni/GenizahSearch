## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LOCAL filesystem (filename / parent folder / filepath / matched text) → CSV field, TXT line, DOCX run | LOCAL field values flow into CSV cells, TXT text lines, and DOCX paragraph runs. CSV is the only format where a value can be interpreted as a spreadsheet formula when the .csv is later opened in Excel/Sheets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-07 | Tampering (CSV formula injection) | CSV branch — LOCAL filepath / filename / matched text written via `csv.writer` | mitigate | The CSV branch currently writes raw values (only `*` is stripped). A LOCAL filepath or filename beginning with `= + - @` would be a live formula when the CSV is opened in a spreadsheet app. Mitigation: in the CSV branch, route LOCAL-influenced cells (the Filepath column, the remapped Shelfmark=filename / Library=parent-folder cells, and the appended Page) through a leading-meta-character escape before `writer.writerow`.
