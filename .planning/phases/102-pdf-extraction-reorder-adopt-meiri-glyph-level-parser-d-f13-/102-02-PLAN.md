`def _detect_corrupt_encoding(text: str) -> bool` (D-07 — codepoint-garbage ratio, NOT cmap introspection, CONSERVATIVE):
  - Return False immediately if `len(text) < 100` (need strong evidence on enough text).
  - Count "garbage" codepoints: U+FFFD (replacement char), Private Use Area (0xE000-0xF8FF, 0xF0000-0xFFFFD, 0x100000-0x10FFFD), noncharacters (0xFDD0-0xFDEF, and any cp & 0xFFFE == 0xFFFE), and illegal C0/C1 controls (excluding \t \n \r).
  - Count "wordlike" codepoints: letters (`c.isalpha()`), digits, and whitespace.
  - ALLOWLIST (do NOT count as garbage): Arabic (0x0600-0x06FF, 0x0750-0x077F), Greek (0x0370-0x03FF), common math operators, Hebrew presentation forms (0xFB1D-0xFB4F), bidi marks (0x200E,0x200F,0x202A-0x202E,0x2066-0x2069), and broad Unicode punctuation categories (`unicodedata.category(c).startswith('P')`).
  - garbage_ratio = garbage / len(text); wordlike_ratio = wordlike / len(text).
  - Flag (return True) ONLY with strong evidence: `garbage_ratio > 0.05` (5-10% band; use 0.05 floor) OR (`wordlike_ratio < 0.40` AND garbage_ratio > 0.02). Conservative per Codex MED-7.

`def _detect_multicolumn_suspected(page_lines_x: list[tuple[float, float]]) -> bool` (D-09 — cheap, detect+log only, NO reconstruction):
  - Input: list of (line_min_x, line_max_x) bboxes for a page's text lines.
  - Heuristic: if the distribution of line start-x values is strongly bimodal (cluster the min_x values into two groups by the midpoint of the page width; if BOTH clusters have a substantial share of lines — each ≥ 25% — and a clear horizontal gutter gap between the right edge of the left cluster and left edge of the right cluster), return True.
  - Keep it cheap (single pass + simple split); it only drives a log/marker, never reflow.

Add tests in tests/test_local_pdf_rawdict_extraction.py: feed _detect_corrupt_encoding a clean Hebrew paragraph (→ False), an Arabic paragraph (→ False, allowlisted), a string of mostly U+FFFD/PUA (→ True), and a short (<100) garbage string (→ False, length guard). Feed _detect_multicolumn_suspected a single-column x-list (→ False) and a clearly two-column x-list (→ True).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local PDF file bytes → PyMuPDF rawdict parse | Untrusted/local PDFs (incl. malformed/malicious) are parsed by PyMuPDF inside extract_pdf_pages. This is the primary attack surface of the phase. |
| extracted text → corrupt-encoding / multi-column detectors | Garbage codepoints from broken cmaps flow into pure string scanners. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-102-04 | Denial of Service | malformed/malicious PDF causing PyMuPDF parse hang or huge rawdict on a 12K-PDF re-index | mitigate | D-11 clears the image-preserve flag so rawdict is ~1.68× baseline not ~4.5× (bounded memory). Per-page try/except + the existing worker-level try/except keep one bad page/file from killing the run. Bulk re-index is background-worker-only (D-10). |
| T-102-05 | Denial of Service | decompression / parse resource exhaustion (zip-bomb-style stream) | mitigate | Pre-existing oversized / zip_bomb_suspected guards in the indexer remain in force; this rewrite changes only text extraction, not the file-size/stream gates. No new unbounded buffering — text is built per-page and yielded. |
| T-102-06 | Tampering | corrupt cmap producing garbage codepoints indexed as real content | mitigate | _detect_corrupt_encoding flags the file (corrupt_encoding status, Plan 03) instead of indexing garbage; conservative thresholds avoid false-flagging legit Arabic/Greek/math. |
| T-102-07 | Elevation of Privilege | execution of embedded PDF content | accept | No eval/exec of PDF content anywhere; PyMuPDF text extraction only, no JavaScript/action execution. |
</threat_model>
