```python
Validate ie_volume_map.json against live NLI IIIF manifests.

- Separate strata: 2-volume, 3-volume, 4+ volume manuscripts
- Cases with large page-count gaps between volumes

Sample size: ~200-300 manuscripts (per D-08)

Output: Structured report with pass/fail per manuscript + summary (per D-09)

Usage:
  python scripts/validate_ie_volume_map.py                    # Full validation (~200-300 samples)
  python scripts/validate_ie_volume_map.py --sample 50        # Quick check
  python scripts/validate_ie_volume_map.py --output report.json  # Save JSON report
"""
```

**Validation logic for each sampled manuscript:**
1. Load `ie_volume_map.json`
2. For each volume entry `{"ie_id": "IE...", "suffix": N, "page_count": M}`:
   a. Fetch IIIF manifest at `https://iiif.nli.org.il/IIIFv21/{sys_id}-{suffix}/manifest`
   b. Count canvases in manifest
   c. Compare manifest canvas count with `page_count` in map
   d. Verify manifest exists (HTTP 200) for the claimed suffix
3. Check that suffix=1 is always the primary IE
4. Check no suffix gaps (e.g., suffix 1, 3 but no 2)

**Stratified sampling (per D-07):**
```python
def build_stratified_sample(volume_map, target_size=250):
    strata = {
        '2_volume': [],   # most common
        '3_volume': [],
        '4plus_volume': [],
        'large_gap': [],  # page_count ratio > 5:1 between volumes
    }
    for sys_id, entry in volume_map.items():
        vols = entry['volumes']
        n = len(vols)
        counts = [v['page_count'] for v in vols]
        if max(counts) / max(min(counts), 1) > 5:
            strata['large_gap'].append(sys_id)
        if n == 2: strata['2_volume'].append(sys_id)
        elif n == 3: strata['3_volume'].append(sys_id)
        else: strata['4plus_volume'].append(sys_id)

    sample = []
    # Take ALL 4+ volume and large_gap (they're rare)
    sample.extend(strata['4plus_volume'])
    sample.extend(strata['large_gap'])
    # Fill remaining from 2/3 volume proportionally
    remaining = target_size - len(sample)
    # ... random.sample from each stratum
    return sample
```
