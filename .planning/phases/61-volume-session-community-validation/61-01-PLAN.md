<objective>
Add ie_id (volume/IE context) to all correction and comment write paths so that community
contributions on multi-IE manuscripts reference the specific volume they were made on.

Purpose: Different volumes contain different text. A correction without IE context can be
semantically wrong — it might apply to IE X's text but be displayed against IE Y.

Output: All create_correction and create_comment calls pass ie_id from active browse state.
Supabase corrections and comments tables gain nullable ie_id TEXT column.
</objective>
