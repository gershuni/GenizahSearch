Create `scripts/import_pgp_documents.py` following the architecture from 02-RESEARCH.md.

**Requirements:**
1. **CLI interface** with argparse:
   - `--dry-run` (default): Validate and report without writing to database
   - `--execute`: Actually perform the import
   - `--batch-size N`: Optional batch size override (default 500)

2. **Two-pass import** (Pattern 1 from research):
   - Pass 1: Import documents (no FK dependencies)
   - Pass 2: Create document_fragments links (depends on documents.pgpid)

3. **Data sources** - Join on pgpid:
   - `pgp_data/transcriptions_linked.csv`: sys_id, pgpid, content (transcription), source_scholar
   - `pgp_data/documents.csv`: pgpid, shelfmark, type, tags, dates, description, side

4. **Column mappings** (from research):
   ```
   documents table:
   - pgpid -> pgpid (int)
   - shelfmark -> shelfmark_combined
   - type -> document_type
   - tags -> tags (split on ',' to list for JSONB)
   - doc_date_original -> doc_date_original
   - doc_date_standard -> doc_date_standard
   - inferred_date_display -> inferred_date_display
   - description -> description
   - content (from transcriptions) -> transcription
   - source_scholar (from transcriptions) -> transcription_source
   ```

5. **Multi-fragment parsing** (Pattern from research):
   - Split shelfmark on ` + ` delimiter (1,617 multi-fragment docs)
   - Split side column on ` ; ` for page_info
   - Enumerate for sequence_order (1-indexed)
   - Use sys_id from transcriptions_linked.csv for single-fragment
   - For multi-fragment, need shelfmark normalization to match each part

6. **Batch upsert** with tqdm progress:
   - Batch size 500 (Supabase optimal)
   - Use `on_conflict='pgpid'` for documents
   - Use `on_conflict='id'` for document_fragments (let Supabase handle)

7. **Error handling**:
   - Unmatched sys_ids: Log and skip, record in report
   - Parse failures: Import document, skip joins
   - Report format: CSV with columns (pgpid, shelfmark, issue_type, details)

8. **Environment**:
   - Use SUPABASE_URL and SUPABASE_SERVICE_KEY env vars
   - Use `encoding='utf-8-sig'` for CSV reading (BOM handling)

**Key insight from research:** Import only documents that have transcriptions. Join documents.csv with transcriptions_linked.csv on pgpid first.
