## Decisions Made

1. **Group menu into sections** - Clear separation between transcriptions (multiple scholars' editions) and translations (Hebrew/English).

2. **Filter by page content, not existence** - An edition might exist but have no content for recto or verso. Check actual markers.

3. **Translations on all pages** - Unlike editions that may be page-specific, translations are full-document content and should appear on all pages that have editions.

4. **Return None for empty pages** - When a source has no content for the current page, return None so UI can filter appropriately.
