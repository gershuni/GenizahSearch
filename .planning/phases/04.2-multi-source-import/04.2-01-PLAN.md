  <action>
Create SQL migration file with:

1. Create `document_sources` table with columns:
   - `id` BIGSERIAL PRIMARY KEY
   - `pgpid` INTEGER NOT NULL REFERENCES documents(pgpid) ON DELETE CASCADE
   - `source_scholar` TEXT NOT NULL (attribution)
   - `doc_relation` TEXT NOT NULL (Digital Edition, Digital Translation, Edition, etc.)
   - `language` TEXT (detected language: Hebrew, English, or original document language)
   - `content` TEXT NOT NULL (transcription or translation text)
   - `content_length` INTEGER (for display/sorting)
   - `source_url` TEXT (optional URL to original source)
   - `notes` TEXT (emendations/notes from PGP)
   - `sequence_order` INTEGER DEFAULT 1 (order within same doc_relation type)
   - `created_at` TIMESTAMPTZ DEFAULT now()

2. Create indexes:
   - `idx_document_sources_pgpid` on (pgpid) for document lookup
   - `idx_document_sources_relation` on (pgpid, doc_relation) for filtering by type

3. Create composite unique constraint:
   - `UNIQUE(pgpid, source_scholar, doc_relation)` to prevent duplicate imports

4. Add RLS policy:
   - Enable RLS on table
   - CREATE POLICY "Public read access" allowing SELECT for all (anon and authenticated)

Use DO block with IF NOT EXISTS pattern for safe re-runs (same pattern as add_doc_relation_column.sql).
