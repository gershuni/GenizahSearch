# Phase 4.2 Plan 01: Document Sources Table Summary

**One-liner:** Created document_sources table to store multiple transcriptions and translations per PGP document with scholar attribution.

## What Was Done

### Task 1: Create Migration SQL (auto)
Created `migrations/create_document_sources_table.sql` with:

**Table Schema:**
| Column | Type | Purpose |
|--------|------|---------|
| id | BIGSERIAL | Primary key |
| pgpid | INTEGER | FK to documents(pgpid) |
| source_scholar | TEXT NOT NULL | Attribution (e.g., "S.D. Goitein") |
| doc_relation | TEXT NOT NULL | Type: "Digital Edition", "Digital Translation", etc. |
| language | TEXT | Detected language |
| content | TEXT NOT NULL | Full transcription/translation text |
| content_length | INTEGER | Character count for sorting |
| source_url | TEXT | Optional external link |
| notes | TEXT | Emendations/scholarly notes |
| sequence_order | INTEGER | Order within same relation type |
| created_at | TIMESTAMPTZ | Import timestamp |

**Indexes:**
- `idx_document_sources_pgpid` - Primary lookup by document
- `idx_document_sources_relation` - Filtered lookup by (pgpid, doc_relation)

**Constraints:**
- `UNIQUE(pgpid, source_scholar, doc_relation)` - Prevents duplicate imports

**Security:**
- RLS enabled with public read access policy
