  <action>
Add new functions to document_service.py:

1. `get_sources_for_document(pgpid: int) -> List[Dict]`:
   - Query document_sources table for all sources with this pgpid
   - Order by: doc_relation (Edition first, then Translation), then sequence_order
   - Return list of source dicts with all fields
   - Handle errors gracefully (return empty list)

2. `get_editions_for_document(pgpid: int) -> List[Dict]`:
   - Filter to doc_relation containing 'Edition' (Digital Edition, Edition)
   - Returns list of scholar transcriptions
   - Useful for transcription selector

3. `get_translations_for_document(pgpid: int) -> List[Dict]`:
   - Filter to doc_relation containing 'Translation' (Digital Translation)
   - Returns list of translations with language field
   - Useful for translation section

Keep existing get_document_for_fragment() unchanged - it returns the primary transcription from documents table for backward compatibility.

The new functions provide additional sources when available.
  </action>
  <verify>Functions can be called and return data: `python -c "from web.document_service import get_sources_for_document; print(get_sources_for_document(8820))"`</verify>
