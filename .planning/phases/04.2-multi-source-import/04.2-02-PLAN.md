Create import script following the pattern of import_pgp_documents.py:

1. Load transcriptions_linked.csv (all 9,364 records, not deduplicated by pgpid)

2. For each record, prepare document_sources record:
   - `pgpid`: from row['pgpid']
   - `source_scholar`: from row['source_scholar']
   - `doc_relation`: from row['doc_relation']
   - `content`: from row['content']
   - `content_length`: from row['content_length'] or len(content)
   - `language`: DETECT from content for translations:
     * For Digital Translation: check if content contains Hebrew characters (U+0590-U+05FF)
       - Has Hebrew chars -> "Hebrew"
       - No Hebrew chars -> "English"
     * For Digital Edition: use row['languages'] field (original document language)
   - `notes`: empty for now (could parse emendations from footnotes.csv later)
   - `sequence_order`: track position within same (pgpid, doc_relation) group

3. Use batch upsert (BATCH_SIZE=500) to document_sources table:
   - on_conflict='pgpid,source_scholar,doc_relation' for idempotent re-runs

4. Track and report:
   - Total records processed
   - Digital Editions imported
   - Digital Translations imported (Hebrew vs English breakdown)
   - Unique pgpids with multiple sources

5. Support --dry-run (default) and --execute flags.

Language detection function:
```python
def detect_translation_language(content: str) -> str:
    """Detect if translation is Hebrew or English based on content."""
    import unicodedata
    hebrew_count = sum(1 for c in content[:500]
                       if ord(c) >= 0x0590 and ord(c) <= 0x05FF)
    return "Hebrew" if hebrew_count > 10 else "English"
```

IMPORTANT: Do NOT update the documents table - it keeps the primary transcription (last Digital Edition) for backward compatibility. The document_sources table is additive.
