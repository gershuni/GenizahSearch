<objective>
Migrate the reader functions in `web/supabase_client.py` that query RLS-`TO authenticated` tables (user_lists, projects, list_items, recent_items, plus the user-private branches of corrections/comments/discoveries) from the anonymous singleton `get_client()` to the per-request authenticated `get_user_client()`. Install an AST scanner CI guard that bans future regressions. Add behavioral regression tests that prove migrated readers build authenticated clients when an auth_session is present. Register the new READER-XX requirement IDs in REQUIREMENTS.md and finalize the Phase 92.1 row in ROADMAP.md.

Purpose: Close the P0 reader-client RLS-reachability regression introduced by Phase 90 D-09/D-10 (singleton-anonymous-only invariant). Phase 90 correctly closed the multitenant SIGNED_IN-event-listener leak by routing all five bootstrap helpers through throwaway clients — but the ~18 reader functions in `web/supabase_client.py` still call `get_client()`, which is now permanently anonymous, so RLS policies `TO authenticated USING (auth.uid()=user_id)` filter every row out. Before Phase 90, the SIGNED_IN listener auto-authenticated the singleton; after Phase 90 the channel is gone and the readers must be migrated.

Output:
- `web/supabase_client.py` with migrated readers (12 of 18 call sites change from `get_client()` to `get_user_client()`; 6 call sites intentionally KEEP `get_client()` with documented justification — auth-API helpers [490, 502], `TO public` profile/approved-corrections-count fast-paths [711, 721, per Revision Warning 5], fragment_joins Exception fallback [1326], and `get_feed_items` whose every branch is public-filtered [1579, per Reviews M2 — see disposition table]).
- `tests/test_no_anonymous_reads_on_authenticated_tables.py` AST scanner with parametrized seed traps mirroring `tests/test_no_set_session_outside_oauth.py` style.
- `tests/test_supabase_client_reader_rls.py` behavioral tests covering get_user_lists, get_list_items, get_recent_items, get_projects, get_deleted_lists (5 readers minimum) using `monkeypatch.setattr('web.safe_storage.app', SimpleNamespace(...))` pattern from `tests/test_auth_revocation_and_headers.py:149-203`.

def _refresh_user_session(stale_refresh_token: Optional[str] = None) -> bool:
    """Returns True if refresh succeeded (auth_session now has fresh tokens).
    Returns False on no-persisted-UUID or terminal failure."""
