  <name>Task 1: Create shared NliCrossrefService class</name>
  <files>shared/nli_crossref_service.py</files>
  <action>
Create `shared/nli_crossref_service.py` following the EXACT same patterns as `shared/fjms_service.py`:
- Same `_find_project_root()` helper (or import from fjms_service)
- Read-only URI mode connection (`file:path?mode=ro`)
- `thread_safe: bool` parameter for NiceGUI web app
- `sqlite3.Row` row factory
- All methods return empty results (not exceptions) when `_conn is None`
- Module-level singleton: `_default_service` + `get_nli_crossref_service(thread_safe=False)`

**Sidecar location:** `nli_data/nli_crossref.db` (auto-detect from project root, same pattern as FJMS)

**Service methods (designed for downstream phases 30-34):**

1. `is_available() -> bool` - Connection is active
2. `get_version() -> Optional[str]` - Sidecar version from meta table

**Image lookup (Phase 30: IMG-01):**
3. `get_images(sys_id: str) -> list[dict]` - All image rows for a manuscript by NLI_AlmaId.
   Returns list of dicts with keys: fgp_image_number_id, fgp_number, image_name, image_source_name, shelfmark.
   Ordered by ImageName (natural page sequence).

4. `get_images_batch(sys_ids: list[str]) -> dict[str, list[dict]]` - Batch lookup for search results.
   Uses batched IN queries (batch_size=500) like FjmsService.get_domains_for_sys_ids.

**Cambridge IIIF (Phase 30: IMG-02):**
5. `get_cambridge_manifest(normalized_shelfmark: str) -> Optional[str]` - Returns manifest URL for a normalized shelfmark, or None if not found. Query cambridge_manifests by normalized_shelfmark.

6. `get_cambridge_manifest_by_label(label: str) -> Optional[str]` - Returns manifest URL for a CUDL label (e.g., "MS-TS-00006-F-00001"). Query cambridge_manifests by label.

**Metadata (Phase 32: META-01, META-02):**
7. `get_physical_metadata(sys_id: str) -> Optional[dict]` - Material, folio counts, and size for a manuscript.
   Query: SELECT DISTINCT Material, NumFolio, NumBifolio, Size FROM nli_images WHERE NLI_AlmaId = ? AND (Material != '' OR NumFolio != '' OR NumBifolio != '' OR Size != '')
   Returns first non-empty row as dict with keys: material, num_folio, num_bifolio, size. Returns None if no metadata.

**Relationships (Phase 33: REL-01, REL-02):**
8. `get_part_of(sys_id: str) -> list[str]` - PartOf shelfmark references for this AlmaId.
   Query: SELECT DISTINCT PartOf FROM nli_images WHERE NLI_AlmaId = ? AND PartOf != ''
   Returns list of shelfmark strings.

9. `get_see_references(sys_id: str) -> list[str]` - See cross-references.
   (Note: data investigation showed 0 records, but keep the method for future data updates.)

10. `get_bifolio_partners(sys_id: str) -> list[dict]` - BifolioWith references (306K records in data).
    Query: SELECT DISTINCT BifolioWith, ImageName FROM nli_images WHERE NLI_AlmaId = ? AND BifolioWith != ''
    Returns list of dicts with keys: bifolio_with, image_name.

**Image availability indicator (Phase 31: IMG-03):**
11. `get_image_sources(sys_id: str, normalized_shelfmark: str = None) -> dict` - Quick check of which image sources exist.
    Returns dict: {"nli_fgp": bool, "cambridge": bool, "image_count": int}
    - nli_fgp: True if any FGPImageNumberId is non-empty for this AlmaId
    - cambridge: True if normalized_shelfmark has a match in cambridge_manifests
    - image_count: count of rows with non-empty FGPImageNumberId

12. `close()` - Close database connection.

**Column name mapping:** SQL PascalCase -> Python snake_case in returned dicts (same convention as FjmsService).
