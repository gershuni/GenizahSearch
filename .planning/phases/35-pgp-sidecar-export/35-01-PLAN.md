  <name>Task 1: Create PGP sidecar export script</name>
  <files>scripts/export_pgp_sidecar.py</files>
  <action>
Create `scripts/export_pgp_sidecar.py` following the exact pattern of `scripts/export_fist_enrichment.py` but sourcing data from Supabase instead of a local SQLite database.

**Script structure:**
- `VERSION = "1.0.0"`
- Load `.env` with `dotenv.load_dotenv()` for `SUPABASE_URL` and `SUPABASE_ANON_KEY`
- Create Supabase client using `supabase.create_client(url, key)`
- Output path: `pgp_data/pgp.db`
- Delete existing pgp.db before starting (idempotent)
- Use `PRAGMA journal_mode=WAL` and `PRAGMA synchronous=NORMAL` during writes
- Wrap entire export in try/except: on ANY failure, close connection and delete partial pgp.db

**Helper functions:**
- `serialize_json(value)`: If None, return None. Otherwise `json.dumps(value, sort_keys=True, ensure_ascii=False, separators=(',', ':'))`. Used for tags and sections columns.
- `fetch_all_rows(client, table_name, order_by='id')`: Paginate with `.range()` in 1000-row pages. Use `.select('*').order(order_by).range(offset, offset + page_size - 1)`. Break when `response.data` is empty or `len(response.data) < page_size`.

**Four export functions (each prints table name, row count, elapsed time):**

1. `export_documents(client, cursor)`:
   - Fetch from `documents` table, order by `pgpid`
   - CREATE TABLE with 24 columns per research schema (pgpid INTEGER PRIMARY KEY, shelfmark_combined TEXT, document_type TEXT, tags TEXT, doc_date_original TEXT, doc_date_standard TEXT, doc_date_calendar TEXT, inferred_date_display TEXT, inferred_date_standard TEXT, inferred_date_rationale TEXT, inferred_date_notes TEXT, description TEXT, transcription TEXT, transcription_source TEXT, languages_primary TEXT, languages_secondary TEXT, language_note TEXT, scholarship_records TEXT, shelfmarks_historic TEXT, has_transcription INTEGER, has_translation INTEGER, input_by TEXT, pgp_url TEXT, created_at TEXT)
   - Map: `tags` through `serialize_json()`. `has_transcription` and `has_translation` pass through (Python bool -> SQLite int automatic). Everything else verbatim.
   - Use `executemany` with batches of 1000 rows
   - Create index: `idx_doc_type ON documents(document_type)`

2. `export_sources(client, cursor)`:
   - Fetch from `document_sources` table, order by `id`
   - CREATE TABLE with 13 columns per research schema
   - Map: `sections` through `serialize_json()`
   - Create indexes: `idx_sources_pgpid ON document_sources(pgpid)`, `idx_sources_relation ON document_sources(pgpid, doc_relation)`

3. `export_footnotes(client, cursor)`:
   - Fetch from `document_footnotes` table, order by `id`
   - CREATE TABLE with 11 columns per research schema (note: 11 columns including created_at, per research)
   - Create indexes: `idx_footnotes_pgpid ON document_footnotes(pgpid)`, `idx_footnotes_relation ON document_footnotes(pgpid, doc_relation)`

4. `export_fragments(client, cursor)`:
   - Fetch from `document_fragments` table, order by `id`
   - CREATE TABLE with 12 columns per research schema
   - Create indexes: `idx_fragments_sys_id ON document_fragments(sys_id)`, `idx_fragments_document_id ON document_fragments(document_id)`, `CREATE UNIQUE INDEX idx_fragments_unique ON document_fragments(document_id, sys_id)`
   - NOTE: The unique index may fail if Supabase has duplicate (document_id, sys_id) pairs. If so, use a regular index instead. Wrap in try/except and fall back to non-unique.

**Meta table** (same pattern as export_fist_enrichment.py):
- key/value TEXT pairs
- Entries: version, created (UTC ISO), source ("supabase"), supabase_url (the URL used), documents_count, sources_count, footnotes_count, fragments_count

**Validation function** `validate_export(client, conn)`:
- For each of the 4 tables: fetch Supabase count via `.select('*', count='exact', head=True)` and compare to SQLite `SELECT COUNT(*)`
- Sample 10 documents with non-NULL tags: verify `json.loads()` returns a list
- Sample 10 sources with non-NULL sections: verify `json.loads()` returns a list
- Print pass/fail for each check
- Return list of errors (empty = success)

**main() function:**
- Print source (Supabase URL) and target path
- Delete existing pgp.db
- Connect, set PRAGMAs
- Export all 4 tables (print progress per locked decision)
- Create meta table
- Run validation
- If validation fails: print errors, delete pgp.db, exit with error
- If validation passes: compact (PRAGMA journal_mode=DELETE, VACUUM), print summary with file size
- Error handling: any exception -> delete pgp.db, re-raise

**Important details:**
- Do NOT use tqdm (research says it's not needed for 4 tables)
- Use `time.time()` for elapsed timing per table
- For each row dict from Supabase, extract values in column order using `.get(key)` to handle missing keys gracefully (returns None)
- Use `import os, sys, json, time, sqlite3` from stdlib, `from pathlib import Path`, `from datetime import datetime, timezone`, `from dotenv import load_dotenv`, `from supabase import create_client`
