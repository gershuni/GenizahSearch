<feature>
  <name>Responsa Core: Data Model, Parser, Expansion, and Guard</name>
  <files>genizah_core.py, tests/test_responsa_core.py</files>
  <behavior>
    Requirements: CORE-01, CORE-02, CORE-03, CORE-07

    1. ResponsaComponent dataclass:
       - words: List[str] -- base words (from OR groups or single word)
       - grammatical_prefixes: bool = False -- # prefix flag
       - wildcard: Optional[str] = None -- None, 'suffix', 'prefix', 'pattern'
       - wildcard_pattern: Optional[str] = None -- raw pattern for character patterns like *a*b*c*
       - inline_pattern: Optional[str] = None -- for inline alternations like word(a/b)word

    2. parse_responsa_query(query_str) -> List[ResponsaComponent]:
       Cases:
       - "שלום" -> [ResponsaComponent(words=["שלום"])]
       - "שלום*" -> [ResponsaComponent(words=["שלום"], wildcard="suffix")]
       - "*נדר" -> [ResponsaComponent(words=["נדר"], wildcard="prefix")]
       - "*פ*ט*ר*פ*" -> [ResponsaComponent(words=["*פ*ט*ר*פ*"], wildcard="pattern", wildcard_pattern="*פ*ט*ר*פ*")]
       - "#שלום" -> [ResponsaComponent(words=["שלום"], grammatical_prefixes=True)]
       - "(עץ/אילן)" -> [ResponsaComponent(words=["עץ", "אילן"])]
       - "#(שלום/שלומות)" -> [ResponsaComponent(words=["שלום", "שלומות"], grammatical_prefixes=True)]
       - "#(שלום/שלומות) עולם*" -> 2 components
       - "אירו(ס/ש)ין" -> [ResponsaComponent(words=["אירו(ס/ש)ין"], inline_pattern="אירו(ס/ש)ין")]
       - "" -> []
       - "שלום עולם" -> 2 plain components

    3. expand_grammatical_prefixes(word) -> List[str]:
       - Uses GRAMMATICAL_PREFIXES constant with ~25 entries:
         '', 'ו', 'ה', 'ב', 'כ', 'ל', 'מ', 'ש',
         'וה', 'וב', 'וכ', 'ול', 'ומ', 'וש',
         'שה', 'שב', 'שכ', 'של', 'שמ',
         'כש', 'כשה', 'מה', 'בש', 'לכ'
       Cases:
       - "שלום" -> ~25 forms including שלום, ושלום, השלום, בשלום, כשלום, לשלום, משלום, ששלום, והשלום, ...
       - Returns list with no duplicates

    4. expand_judeo_arabic(word) -> List[str]:
       - SUN_LETTERS = set('תדרזסשצטלנ')
       Cases:
       - Moon letter "כלמה" -> 8 forms: כלמה, אלכלמה, ואלכלמה, באלכלמה, פאלכלמה, כאלכלמה, לאלכלמה, ללכלמה
       - Sun letter "שוא" -> 14 forms: above 8 + אששוא, ואששוא, באששוא, פאששוא, כאששוא, לאששוא
       - Sun letter "לסאן" -> 8 forms (assimilated form = regular form for lamed)
       - Returns list with no duplicates

    5. _apply_explosion_guard(components, variants_on, ja_on, var_mgr, variant_mode) -> (expanded_components, warning_msg, actual_options):
       - MAX_EXPANDED_TERMS = 500 (add to Config class)
       Cases:
       - Under limit: all options preserved, warning is None
       - Over limit with variants: downgrade variants to 'variants' (30 pairs), warning returned
       - Still over: disable variants, warning returned
       - Still over: disable JA, warning returned
       - Still over: raise ValueError with descriptive message

    Place all new code in genizah_core.py. The ResponsaComponent dataclass and pure functions go ABOVE the SearchEngine class (around line 4130-4140, after the MetadataManager class and before SearchEngine). Add MAX_EXPANDED_TERMS = 500 to the Config class (after line 1709).
