       New method signature: build_regex_pattern(self, terms, mode, max_gap, responsa_components=None, responsa_options=None)
       When responsa_components is provided (list of dicts, each with key 'regex_terms' and optional 'flex_patterns'):
       - Each component's regex_terms is a list of expanded terms for alternation
       - Optionally, 'flex_patterns' contains flex-spaced patterns for original terms

       - Sort by length descending, escape, build alternation groups
       - Wildcard suffix: append \S* to stem -> "שלום\S*"
       - Wildcard prefix: prepend \S* -> "\S*נדר"
       - Character pattern *a*b*c*: convert to \S*a\S*b\S*c\S*
       - Inline alternation word(a/b)word: if single-char alternatives -> character class [ab]; multi-char -> alternation (a|b)
       - Flexible spacing (CORE-05): when responsa_options.get('flex_spacing') is True, apply \s* between each character of ORIGINAL terms only (not expanded variants). Add these as additional alternatives in the regex group.
       - Bidirectional gap (CORE-06): when responsa_options.get('bidirectional') is True and len(components) >= 2, produce (forward)|(backward) where forward = sep.join(parts) and backward = sep.join(reversed(parts))

       Cases:
       - Suffix wildcard "שלום" -> regex part includes "שלום\S*"
       - Flex spacing on "בית" -> adds "ב\s*י\s*ת" as an alternative in the group
       - Bidirectional with 2 parts -> (A[sep]B)|(B[sep]A)
       - Existing path UNCHANGED when responsa_components is None
