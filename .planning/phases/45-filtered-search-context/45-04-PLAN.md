<objective>
Add pre-search filter panel, per-manuscript exclusion, and auto-exclude source to the web parallels page, matching the search page filter UI pattern.

Purpose: Parallels/composition search is the most time-consuming search mode. Pre-search filtering dramatically speeds it up by restricting which chunks are searched. Per-manuscript exclusion gives web users parity with desktop. Auto-excluding the source manuscript prevents trivial self-matches.

Output: Web parallels page with filter panel + chip bar, per-manuscript exclude buttons, auto-exclude source manuscript, import exclusions, and restrict_sys_ids integration.
</objective>

    **1. Compute restrict_sys_ids before parallels search:**
    In the search execution flow (near line 1410 where search parameters are captured), compute the filter set:
    ```python
    # Compute restrict_sys_ids from active pre-search filters
    restrict_sys_ids = None
    if any([p_state.filter_domain, p_state.filter_author, p_state.filter_work,
            p_state.filter_date_from, p_state.filter_date_to,
            p_state.filter_material_exclude]):
        fjms = get_fjms_service(thread_safe=True)
        if fjms.is_available():
            restrict_sys_ids = await run.io_bound(lambda: fjms.get_filter_sys_ids(
                domain=p_state.filter_domain,
                author=p_state.filter_author,
                work=p_state.filter_work,
                date_from=p_state.filter_date_from,
                date_to=p_state.filter_date_to,
                material_exclude=p_state.filter_material_exclude or None,
            ))
            p_state.restrict_sys_ids = restrict_sys_ids
            if restrict_sys_ids is not None and len(restrict_sys_ids) == 0:
                ui.notify(tr("No manuscripts match the current filters."), type='warning')
                p_state.is_running = False
                return
    ```

    **2. Merge per-manuscript exclusions into restrict_sys_ids:**
    If `p_state.excluded_manuscript_ids` is non-empty, and restrict_sys_ids is not None, subtract excluded manuscripts from the restrict set:
    ```python
    if p_state.excluded_manuscript_ids and restrict_sys_ids is not None:
        restrict_sys_ids = restrict_sys_ids - p_state.excluded_manuscript_ids
    ```
    If restrict_sys_ids is None but excluded_manuscript_ids is set, do NOT create a restrict set from excluded IDs alone — per-manuscript exclusion is a post-search filter applied after results return (to match existing domain exclusion pattern).

    **3. Pass restrict_sys_ids to search_composition_logic:**
    In `run_search()` (~line 1425), pass the set:
    ```python
    result = state.searcher.search_composition_logic(

        max_freq=captured_freq_threshold,
        mode=captured_mode,
        filter_text=captured_filter_text or None,
        progress_callback=progress_cb,
        boundary_mode=..., boundary_delimiter=..., boundary_boost=...,
        min_boundary_matches=..., min_delimiter_distance=...,
        restrict_sys_ids=restrict_sys_ids  # NEW
    )
    ```
    Similarly for the lab mode path (`state.lab_engine.lab_composition_search()`), pass restrict_sys_ids if supported.

    **4. Apply per-manuscript exclusions to results:**
    After search results return, filter out any results whose sys_id is in `p_state.excluded_manuscript_ids`. Move them to an excluded section (separate from the high-frequency/source-text filtered section).

    **5. Update the parallels search summary:**
    If pre-search filters were active, include filter info in the summary line (e.g., "12 parallels in 45s (filtered: Halakha, 3,241 manuscripts)").

    **6. Printed filter coexistence:**
    The existing 3-state printed filter (hide/show/only) on the parallels page is a post-search filter. The new pre-search material_exclude filter is a separate layer. They coexist:
    - Pre-search: `material_exclude=["Printed"]` prevents printed manuscripts from even being searched
    - Post-search: `printed_filter='hide_printed'` hides any remaining printed results after search
    Both can be active simultaneously without conflict.
