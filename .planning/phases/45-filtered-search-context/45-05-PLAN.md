    - **"Parallel search in these results"** button (icon: 'compare_arrows', color: 'secondary'). Same enablement condition. For this button to be maximally useful, the user should first select/click a specific manuscript in the results table whose text will be loaded for parallels search.

    **2. "Search in these results" click handler:**
    Build URL query params from current browse filters and navigate to search page:
    ```python
    def _search_in_results():
        params = {}
        if current_domain['value']:
            params['filter_domain'] = current_domain['value']
        if current_author['value']:
            params['filter_author'] = current_author['value']
        if current_work['value']:
            params['filter_work'] = current_work['value']
        if current_date_from['value']:
            params['filter_date_from'] = str(current_date_from['value'])
        if current_date_to['value']:
            params['filter_date_to'] = str(current_date_to['value'])
        # Encode as URL query string
        query_string = '&'.join(f"{k}={quote(str(v))}" for k, v in params.items() if v)
        ui.navigate.to(f'/search?{query_string}')
    ```

    The search page (Plan 02) should accept these URL params and populate the filter panel on load. If the search page doesn't yet support these URL params, use `app.storage.user` as a transfer mechanism:
    ```python
    app.storage.user['incoming_filters'] = {
        'domain': current_domain['value'],
        'author': current_author['value'],
        'work': current_work['value'],
        'date_from': current_date_from['value'],
        'date_to': current_date_to['value'],
    }
    ui.navigate.to('/search?from_browse=1')
    ```

    **3. "Parallel search in these results" click handler:**
    Similar to above but navigates to parallels page. If a manuscript is selected in the results table, include its text:
    ```python
    def _parallels_in_results(selected_sys_id=None):
        # Transfer filters via storage
        app.storage.user['incoming_filters'] = {
            'domain': current_domain['value'],
            'author': current_author['value'],
            # ... same as above
        }
        if selected_sys_id:
            # Get manuscript text for parallels input
            # (load from PGP or FJMS transcription)
            text = _get_manuscript_text(selected_sys_id)
            if text:
                ui.navigate.to(f'/parallels?initial_text={quote(text)}&from_browse=1')
                return
        ui.navigate.to('/parallels?from_browse=1')
    ```

    **4. One-way sync only:** Per user decision, browse→search carries filters but editing filters on the search page does NOT sync back to browse. This is natural since we're navigating away from browse.
