<decisions_made>

- Used `asyncio.ensure_future()` for async calls from sync handlers (NiceGUI pattern, avoids RuntimeError from bare coroutine)
- Multi-select approach: `ui.select(..., multiple=True).props('use-chips')` in NiceGUI — shows selected items as chips inside the dropdown
- Include/Exclude toggle is a single `ui.toggle({True: 'Include', False: 'Exclude'})` that applies to domain+author+work collectively
- Text filter uses three separate lists (`text_all`, `text_any`, `text_not`) with a mode selector, matching the catalog browse FTS5 pattern
- Backward compatibility: legacy single `domain`/`author`/`work` params auto-convert to lists in `get_filter_sys_ids()`
- Session persistence migration: reads legacy `search_filter_domain` key, wraps in list if present, stores as `search_filter_domains`
- Chip bar shows one chip per selected item (removable individually) instead of one chip per filter type
</decisions_made>
