<task type="auto">
  <name>Task 1: PGP batch translation script with checkpointing</name>
  <files>scripts/translate_pgp_descriptions.py</files>
  <action>
    Create `scripts/translate_pgp_descriptions.py` following the pattern from `export_pgp_sidecar.py`:

    1. **CLI arguments** (argparse):
       - `--pgp-db` — path to pgp.db (default: pgp_data/pgp.db)
       - `--workers` — concurrent API workers (default: 5, max 10)
       - `--batch-size` — checkpoint every N translations (default: 100)
       - `--checkpoint-file` — checkpoint JSON path (default: translate_pgp_checkpoint.json)
       - `--min-length` — minimum description length to translate (default: 20 chars)
       - `--dry-run` — count candidates without translating
       - `--limit` — optional limit for testing (translate first N rows only)

    2. **Checkpoint logic**:
       - `load_checkpoint(path) -> set[int]` — loads set of completed pgpids from JSON file
       - `save_checkpoint(path, completed_ids: set)` — atomic write (write to .tmp, os.replace)
       - On start, load checkpoint, skip already-completed IDs

    3. **Main flow**:
       a. Open pgp.db read-only for source data
       b. Open pgp.db writable for pgp_translations table (or a separate connection)
       c. Call `ensure_pgp_translations_table(conn)` to create table if needed
       d. Query: `SELECT pgpid, description, document_type FROM documents WHERE description IS NOT NULL AND length(description) >= ?` with min_length
       e. Filter out already-completed pgpids (from checkpoint)
       f. Load EN->HE few-shot template from `data/few_shot_en2he_scholarly.json`
       g. Build few-shot prompt string
       h. For document_type: look up PGP_DOCUMENT_TYPE_HE directly (no API call needed)
       i. For descriptions: use ThreadPoolExecutor with `translate_text()` for parallel API translation
       j. Every batch_size completions: flush to SQLite (INSERT OR REPLACE INTO pgp_translations) + save checkpoint
       k. Show progress with tqdm

    4. **Error handling**:
       - Individual translation failures logged and skipped (don't stop batch)
       - Network errors trigger exponential backoff retry (3 attempts per item)
       - KeyboardInterrupt triggers checkpoint save before exit

    5. **Summary output**: Print stats at end (total, translated, skipped, failed, elapsed time)

    The script does NOT run automatically in CI — it's a manual user-executed batch job. Include a docstring explaining usage:
    ```
    Usage:
      python scripts/translate_pgp_descriptions.py                    # Full run
      python scripts/translate_pgp_descriptions.py --dry-run          # Count candidates
      python scripts/translate_pgp_descriptions.py --limit 50         # Test with 50 items
      python scripts/translate_pgp_descriptions.py --workers 10       # Faster (more concurrent)
    ```
