  <name>Task 1: Desktop translation toggle + translated text display + SearchThread wiring</name>
  <files>genizah_app.py, genizah_core.py, genizah_translations.py, gui_threads.py</files>
  <action>
    **1. Initialize TranslationService** (`genizah_app.py`):
    In the app initialization (where FjmsService, PgpService are created), create a TranslationService instance:
    ```python
    from shared.translation_service import TranslationService
    self.translation_service = TranslationService(thread_safe=False)  # Desktop is single-threaded
    ```
    Guard with try/except -- if translation tables don't exist, service degrades gracefully.

    **2. Settings toggle** (`genizah_app.py`):
    In the settings dialog (where notifications_enabled, restore_mode, history_limit checkboxes are), add:
    - QCheckBox for "Show translations" / "הצג תרגומים"
    - Default: OFF (load_app_config().get('show_translations', False))
    - On change: save_app_config({'show_translations': state == 2})
    - Place it in the "Preferences" section of the settings dialog

    **3. Wire SearchThread for translated match detection** (`gui_threads.py`):
    In SearchThread.run(), after the core search completes and results are collected:
    - Check if show_translations is enabled: `load_app_config().get('show_translations', False)`
    - If enabled, create a thread-local TranslationService (thread_safe=True, same pattern as CatalogBrowseThread which creates thread-local FjmsService)
    - Call `translation_service.search_pgp_by_translation(query, lang)` to get the set of pgpids that match on translated text
    - Tag each result dict with `result['translated_match'] = True` if its pgpid is in the translated matches set
    - Emit the enriched results list via results_signal
    This ensures the "translated match" badge data is available when genizah_app.py renders results.

    **4. Search result enrichment** (`genizah_app.py`):
    In the search result display functions (where PGP description is shown in expanded/detail views):
    - Check `load_app_config().get('show_translations', False)`
    - If True and translation_service.is_available():
      - Batch fetch translations for displayed results: `self.translation_service.get_pgp_translations_batch(pgpids)`
      - For each result with a translation: show translated text with "(translated)" suffix in lighter color
      - Add tooltip with original text (QToolTip or setToolTip on QLabel)
    - If result has `translated_match` flag (set by SearchThread in step 3), show "translated match" text indicator

    **5. Browse/detail view enrichment** (`genizah_app.py`):
    In the browse detail display (where catalog data, descriptions, identifications are shown):
    - Same pattern: if show_translations is on, show translated versions with indicator
    - For FJMS catalog fields: show gap-filled translations
    - For FJMS free descriptions: show English translations

    **6. Hebrew UI strings** (`genizah_translations.py`):
    Add to TRANSLATIONS dict:
    - "Show translations": "הצג תרגומים"
    - "Translated": "מתורגם"
    - "Translated match": "התאמה בתרגום"
    - "Original text": "טקסט מקורי"
    - "Machine translated via Dicta": "תורגם אוטומטית באמצעות דיקטה"
    - "Translation": "תרגום"

    **Important**: Cache the show_translations preference at search start time (don't re-read config for every row). Use the same batch lookup pattern as the web app.
  </action>
