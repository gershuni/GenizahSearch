<task type="auto">
  <name>Task 1: FJMS catalog gap-fill script</name>
  <files>scripts/translate_fjms_catalog.py</files>
  <action>
    Create `scripts/translate_fjms_catalog.py` for translating FJMS catalog field gaps:

    1. **CLI arguments** (argparse):
       - `--fjms-db` — path to fjms_enrichment.db (default: fist_data/fjms_enrichment.db)
       - `--workers` — concurrent API workers (default: 5)
       - `--batch-size` — checkpoint every N translations (default: 50)
       - `--checkpoint-file` — checkpoint JSON path (default: translate_fjms_catalog_checkpoint.json)
       - `--dry-run` — count candidates without translating
       - `--limit` — optional limit for testing
       - `--category` — translate specific category only: "titles", "authors", "persons", "genizah_titles", "all" (default: all)

    2. **Gap detection queries** (gap-fill only — NEVER overwrite existing data):
       a. **Title gaps (HE->EN)**: `SELECT AlmaId, TitleHeb FROM catalog WHERE TitleHeb IS NOT NULL AND TitleHeb != '' AND (Title IS NULL OR Title = '')`
       b. **TitleHeb gaps (EN->HE)**: `SELECT AlmaId, Title FROM catalog WHERE Title IS NOT NULL AND Title != '' AND (TitleHeb IS NULL OR TitleHeb = '')`
       c. **AuthorText (HE->EN)**: `SELECT DISTINCT AuthorText FROM catalog WHERE AuthorText IS NOT NULL AND AuthorText != ''` — detect language, translate Hebrew ones to English
       d. **genizah_titles (HE->EN)**: `SELECT GenizahTitleId, GenizahTitleOrgTitle FROM genizah_titles WHERE GenizahTitleOrgTitle IS NOT NULL AND GenizahTitleOrgTitle != '' AND (GenizahTitleEngTitle IS NULL OR GenizahTitleEngTitle = '')`
       e. **genizah_persons HE->EN**: `SELECT GenizahPersonId, HebDesc FROM genizah_persons WHERE HebDesc IS NOT NULL AND HebDesc != '' AND (EngDesc IS NULL OR EngDesc = '')`
       f. **genizah_persons EN->HE**: `SELECT GenizahPersonId, EngDesc FROM genizah_persons WHERE EngDesc IS NOT NULL AND EngDesc != '' AND (HebDesc IS NULL OR HebDesc = '')`

    3. **Translation flow**:
       - Load HE->EN few-shot template for HE->EN translations
       - Load EN->HE few-shot template for EN->HE translations
       - Process each category separately with progress bar
       - Store results in fjms_translations table: (alma_id, field_name, signature_id=NULL, original_text, translated_text, direction, translated_at, model_version)
       - field_name values: 'Title', 'TitleHeb', 'AuthorText', 'GenizahTitleEngTitle', 'PersonEngDesc', 'PersonHebDesc'

    4. **Checkpoint**: Same atomic checkpoint pattern as PGP script, keyed by (category, id)

    5. **Summary**: Print per-category stats (candidates, translated, skipped, failed)

    Include docstring:
    ```
    Usage:
      python scripts/translate_fjms_catalog.py --dry-run           # Count all gaps
      python scripts/translate_fjms_catalog.py --category titles    # Titles only
      python scripts/translate_fjms_catalog.py --limit 20           # Test with 20 items
    ```
  </action>

  </verify>
  <done>Script exists, --dry-run reports gap counts per category (~5,600 total), imports resolve, gap-fill queries use proper NULL/empty guards.</done>

       - `--fjms-db` — path to fjms_enrichment.db (default: fist_data/fjms_enrichment.db)
       - `--workers` — concurrent API workers (default: 5, recommend starting conservative)
       - `--batch-size` — checkpoint every N translations (default: 200)
       - `--checkpoint-file` — checkpoint JSON path (default: translate_fjms_freedesc_checkpoint.json)
       - `--min-length` — minimum description length (default: 20 chars)
       - `--dry-run` — count candidates without translating
       - `--limit` — optional limit for testing
       - `--mode` — "freedesc" (default) or "bibliography" (deferred, prints warning that it's ~40 hours)

    2. **Free description translation** (mode=freedesc):
       - Query: `SELECT SignatureId, AlmaId, FreeDesc FROM catalog_free_desc WHERE FreeDesc IS NOT NULL AND length(FreeDesc) >= ?` with min_length
       - Skip already-translated (check fjms_translations table for existing entry with field_name='FreeDesc' and matching signature_id)
       - Translate HE->EN using Dicta API
       - Store in fjms_translations: (alma_id, field_name='FreeDesc', signature_id, original_text, translated_text, direction='he2en', translated_at, model_version)

    3. **Bibliography scaffold** (mode=bibliography):
       - Print clear warning: "Bibliography translation is ~542K entries (~40 hours). This is deferred to a future pass."
