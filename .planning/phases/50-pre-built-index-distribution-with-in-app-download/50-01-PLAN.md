**1. `auto_suggest_title(fragments: List[PuzzleFragment]) -> str`**
Generate title from unique fragment shelfmarks joined by ' + '. If no shelfmarks, return 'Untitled Join'.
```python
def auto_suggest_title(fragments):
    seen = []
    for f in fragments:
        if f.shelfmark and f.shelfmark not in seen:
            seen.append(f.shelfmark)
    return ' + '.join(seen) if seen else 'Untitled Join'
```

**2. `compose_puzzle_export(fragments: List[PuzzleFragment], image_service: PuzzleImageService, export_size: int = 3000, margin: int = 20) -> Optional[Image.Image]`**
Compose full-resolution RGBA PNG using **top-left origin with centered rotation pivot** (matching both Fabric.js and PyQt behavior):

- For each fragment:
  a. Call `image_service.resolve_fragment_image(fl_id, size=export_size, threshold=bg_removal_threshold, processed=frag.processed)`
  b. Open as PIL RGBA image
  c. **Apply crop first** (if any crop offsets > 0): The crop values are in canvas-pixel space (800px loaded images). Scale them to export-pixel space:
     ```python
     crop_scale = export_img.width / 800.0  # canvas images are loaded at 800px width
     ct = int(frag.crop_top * crop_scale)
     cb = int(frag.crop_bottom * crop_scale)
     cl = int(frag.crop_left * crop_scale)
     cr = int(frag.crop_right * crop_scale)
     if ct + cb + cl + cr > 0:
         export_img = export_img.crop((cl, ct, export_img.width - cr, export_img.height - cb))
     ```
  d. Apply scale: `new_size = (int(export_img.width * frag.scale), int(export_img.height * frag.scale))`; resize with LANCZOS
  e. Apply flips: `FLIP_LEFT_RIGHT` if flip_h, `FLIP_TOP_BOTTOM` if flip_v
  f. Apply rotation: `Image.rotate(-frag.rotation, expand=True, resample=BICUBIC, fillcolor=(0,0,0,0))`
     Note the negative sign: Fabric.js and Qt both use clockwise-positive angles, but PIL.rotate is counter-clockwise.

- **Coordinate mapping (top-left origin with centered rotation pivot):**
  Both apps store x/y as the top-left corner of the unrotated image. The rotation pivot is the center of the image. For export:
  ```python
  coord_scale = export_img_width_before_scale / 800.0  # map canvas coords to export coords
  # Fragment top-left in export space (before rotation)
  tl_x = frag.x * coord_scale
  tl_y = frag.y * coord_scale
  # Center of the (scaled, flipped, but unrotated) image
  half_w = scaled_img.width / 2
  half_h = scaled_img.height / 2
  center_x = tl_x + half_w
  center_y = tl_y + half_h
  # After rotation with expand=True, the new image is larger.
  # Place the rotated image so its center aligns with the computed center:
  paste_x = center_x - rotated_img.width / 2
  paste_y = center_y - rotated_img.height / 2
  ```

- After computing all placed fragments, find bounding box (min_x, min_y, max_x, max_y) across all fragment paste rects
- Create RGBA canvas of appropriate size, filled transparent
- Paste each transformed fragment using alpha composite
- Auto-crop with `canvas.getbbox()` and add `margin` px on each side
- Return the PIL Image
