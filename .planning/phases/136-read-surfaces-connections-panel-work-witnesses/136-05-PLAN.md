<objective>
Build the rebuild-preservation gate and pin its expectations from the currently-live asset — before
the rebuild exists.

Purpose: ordering is load-bearing. An expectation derived after the fact proves nothing, and the
existing deploy verifier reads its expected frame from the *candidate's own* manifest, which cannot
detect a wrong rebuild. Population-hash equality is necessary but NOT sufficient either: the frame
hash omits novelty, routing, precision, snapshot hash and `matched_letters`, so `matched_letters`
could drift inside a stratum completely undetected. The gate has to be an exact allowlisted diff.
Output: a diff harness, an externally pinned expectation file, and a positive control.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate asset → production | A rebuilt artifact replacing the one the certificate was measured on |
| expectation source | Whether the expectation comes from the live asset or from the candidate decides whether the gate means anything |
| diff report → ticket/paste | A violation message is an artifact that leaves the machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-05-01 | Tampering | A silent within-stratum drift (e.g. `matched_letters`) that hashes cannot see | mitigate | Per-table allowlisted full-column diff; positive control 1 asserts the frame hash misses it and this gate does not |
| T-136-05-02 | Spoofing | The candidate certifying itself by supplying its own expected frame | mitigate | Expectation is an external pinned artifact generated pre-rebuild; positive control 7 asserts the candidate-sourced path still fails |
| T-136-05-03 | Information disclosure | A diff report echoing manuscript text or a restricted title | mitigate | Violations name table, primary key and column only; a test asserts no cell value is echoed; masking scan on the pinned artifact |
| T-136-05-04 | Repudiation | The expectation regenerated after the rebuild, erasing the evidence | mitigate | Generator refuses to overwrite without an explicit flag and prints why; a test asserts the refusal |
| T-136-05-05 | Elevation of privilege | Weakening `verify_cert01_grading.py` check 10 to make the rebuilt asset pass | mitigate | `git diff --stat` on that script asserted empty; the rebuilt asset gets a separate compatibility attestation instead |
| T-136-05-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan |
