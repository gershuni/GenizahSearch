<objective>
Build the panel's display model as a pure, fully testable function over service rows — every display
rule in one place, none of them in a NiceGUI render function.

Purpose: the display rules are where this surface is most likely to be quietly wrong. The same work
appears twice under two titles on 921 row-pairs. 1,558 span-groups carry two to eight claims on
byte-identical offsets, and letting each become a row inflates a manuscript's match count. And the
cautionary example is on the record: a hand-picked local rule that disagreed with the shared
predicate rendered the best-measured population in the system as the weakest.
Output: two pure shared modules and a test suite that fails on a local reimplementation.
</objective>
