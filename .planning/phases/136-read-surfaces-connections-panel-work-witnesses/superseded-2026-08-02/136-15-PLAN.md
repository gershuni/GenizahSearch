Obtain the owner's deploy authorization on the gate evidence, then perform the ONE authorized
production redeploy — asset first, flag OFF throughout — and record the prod-box actuals.

Purpose: exactly one rebuild and one production redeploy are authorized, not a series. The asset
must land and be confirmed live BEFORE any UI code that reads the new columns is deployed; bundling
a schema change with the code that depends on it turns a contained change into a live incident, and
the flag being OFF does not make an unreadable column safe.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dev box → production box | A 370 MB binary crosses; only its content hash proves it arrived intact |
| manifest pointer → live loader | An atomic swap is the only moment production behaviour changes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-15-01 | Tampering | A truncated or corrupted upload becoming live | mitigate | Temp-name upload, on-box hash verification, rename, then a staged-manifest verify before the atomic swap |
| T-136-15-02 | Elevation of privilege | The flag being set during the deploy, exposing unreleased claim surfaces | mitigate | Flag never set; log asserts it; benchmark uses the flag-independent readiness predicate |
| T-136-15-03 | Denial of service | A schema-dependent code deploy bundled with the schema change | mitigate | Asset-only deploy; log states no web code shipped; UI plans deploy later |
| T-136-15-04 | Information disclosure | The public projection deployed before its release gate | mitigate | Public asset deploys only if the runbook provides a location; otherwise deferred with a recorded reason |
| T-136-15-05 | Repudiation | An untested rollback claimed as available | mitigate | Rollback drilled in both directions with timestamps |
| T-136-15-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs; deploy uses existing tooling |

</threat_model>
