<objective>
Derive the two visibility axes at build time and emit the public projection as a closed graph, then
prove the masking scan would actually catch a leak.

Purpose: "origin of the displayed assertion" is not representable in the shipped schema as written —
the schema REQUIRES a claim's `source_corpus` to equal its work's identity source, and evidence rows
carry only a family code with no assertion origin and no licence provenance. So `works.source_corpus`
is exactly the proxy that is insufficient: the restricted-corpus id prefix maps to 656 restricted
works AND 235 open ones, so a corpus-keyed rule mislabels in both directions. Exclusion must be
structural — private rows ABSENT from the public artifact, never hidden by a UI filter.
Output: two derived axes, a projector, and a positive control distinct from the built-in self-test.
</objective>
