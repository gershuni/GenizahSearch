<objective>
Ingest the pinned verdict cache into the asset as a tri-state on both evidence families, with
masked provenance — and prove the fail-closed default is real rather than asserted.

Purpose: the legacy boolean is computed only for the propagated family, leaving all shipped direct
rows at `is_new = 0` — which reads as "already recorded" when it means "never checked". 665 of
29,054 multi-evidence claims currently disagree with themselves. A tri-state that quietly degrades
to "not found" under failure would be worse than the boolean, because the surface would then make
a confident claim built on an error.
Output: ingestion, two verifier checks, and one forced-failure test per named failure path.
</objective>
