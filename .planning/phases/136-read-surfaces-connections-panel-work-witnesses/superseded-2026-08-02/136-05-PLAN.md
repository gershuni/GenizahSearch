<objective>
Land the D-02a lockstep: the one authorized `band_precision.tier_a` change, applied in step across
all five sites plus tests, so tier A goes default-visible without any measured percentage entering
the asset.

Purpose: today `tier_a` carries `precision=NULL, ci_low=NULL, measurement_status=NULL`, so
`is_default_eligible()` fails closed and the main pool collapses from ~46,644 identifications to
~2,241. The builder and the release verifier BOTH independently require `tier_a.precision` to stay
NULL — so writing 0.9382 in is not merely undesirable, it is unbuildable. The authorization pair
(`measurement_status='measured_pass'`, `ci_low=0.9084`) is exactly what the predicate reads.
Output: a build that flips the gate, and a validator that rejects any other value in that slot.
</objective>
