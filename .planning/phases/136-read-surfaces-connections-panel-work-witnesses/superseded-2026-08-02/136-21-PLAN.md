<objective>
Prove the panel's honesty invariants over rendered output rather than over source, in both
languages, across every service state — and prove the proof can fail.

Purpose: headless unit tests do not see what NiceGUI actually renders, and a source grep does not
see a string assembled at render time. The technique that worked on the sketches is a render-smoke
suite asserting the prohibited-wording invariants across every combination, each proven live by a
positive control: seeding a precision figure or a stored vocabulary key makes the suite fail. A green
check that cannot fail is worthless. The second lesson is equally load-bearing: one sketch assertion
tested the whole rendered page and PASSED while the thing it checked was wrong, because unrelated
prose contained the phrase it grepped for.
Output: a scoped render-smoke suite with positive controls, plus the masking capture record.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rendered DOM → reader | The last point a prohibited claim can be caught before a human reads it |
| interaction-created strings → masking scan | Only a browser-DOM capture sees them |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-21-01 | Repudiation | A green suite that cannot fail, giving false assurance | mitigate | Seven positive controls, each asserting the check reports a violation on a seeded input; per-control failure recorded |
| T-136-21-02 | Spoofing | An assertion passing for the wrong reason because of unrelated page prose | mitigate | Marker-class scoping on every assertion plus a dedicated scope control |
| T-136-21-03 | Information disclosure | A restricted string appearing only in an interaction-created DOM node | mitigate | Browser-DOM capture attempted; a skip is recorded with its residual risk rather than dropped |
| T-136-21-04 | Spoofing | An outage rendering as a zero result | mitigate | Timeout test asserts a distinct visible state with a retry affordance |
| T-136-21-05 | Information disclosure | A prohibited word entering through hand-written caveat prose | mitigate | Negated-word positive control targets exactly that path |
| T-136-21-SC | Tampering | npm/pip/cargo installs | mitigate | Browser automation may be needed for the DOM capture; if installed, verify the package on its registry page first and record it — otherwise record the skip |

</threat_model>
