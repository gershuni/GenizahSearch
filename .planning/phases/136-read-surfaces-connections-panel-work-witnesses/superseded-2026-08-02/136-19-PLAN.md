<objective>
Attach the panel to the browse page: an entry control in the second toolbar row, a fifth enrichment
placeholder filled on the existing staleness-guarded path, and correct rendering of every service
state — including the one that must not look like a genuine zero.

Purpose: four sections already load this way, so this is reuse rather than new plumbing. But the
seam carries three non-negotiable obligations: re-check the generation token after EVERY await or
fast navigation paints a stale panel over the wrong folio; bind the page client at render time
because background execution silently degrades per-user storage to empty and makes UI context calls
raise; and implement the envelope, because hiding the control on a true zero is correct while hiding
it during an outage is not.
Output: the entry control, the placeholder, the fetch, the state rendering, and the CSS.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| background enrichment → page render | Background execution loses UI context and per-user storage silently |
| async gather → user-visible panel | A stale generation token paints one folio's data onto another |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-19-01 | Spoofing | A stale panel painted over a different folio after fast navigation | mitigate | Generation token re-checked after the gather and before the state commit; client-liveness guard before touching containers |
| T-136-19-02 | Information disclosure | Per-user state silently degrading to empty in the background path, mixing or blanking user context | mitigate | Page client bound at render time; `tests/test_no_raw_storage_access.py` re-run as an acceptance gate with an empty allowlist |
| T-136-19-03 | Spoofing | An outage rendering as "no identifications for this manuscript" | mitigate | Four distinct states; outage states visually distinct with a retry affordance |
| T-136-19-04 | Denial of service | The panel fetch pushing browse enrichment past its latency budget | mitigate | Fetch joins the existing gather with the browse timeout; benchmarked against the §1.1 cap |
| T-136-19-05 | Elevation of privilege | A flag-on / asset-missing window exposing a broken surface | mitigate | Availability predicate read live at render time, never the flag alone and never captured at import |
| T-136-19-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs |

</threat_model>
