Ship the corpus-wide findings page's shell: its route, its availability-gated nav entry, the permanent
caveat slot, the mode strip, the filter bar with its facet cascade, the result bar and the pager.

panel track and this track proceed in parallel, and it keeps the honesty-critical chrome (the caveat,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| feature flag + sidecar readiness → public route | A new publicly-reachable page and nav entry |
| user filter/sort/unit input → service query | Free-form selection reaching a query builder |
| async page handler → blocking read | A single uvicorn worker; one sync read stalls the site |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-16-01 | Elevation of privilege | The page reachable while the sidecar is absent or the flag is off | mitigate | Gated on `discovery_available()` (flag AND readiness); tests assert the unavailable card, the absent nav entry, and that the builder is never imported |
| T-136-16-02 | Information disclosure | The page indexed by search engines before the release gate | mitigate | `noindex=True` in page meta, asserted by test |
| T-136-16-03 | Spoofing | A silently narrowed default result count reading as the corpus total | mitigate | The result bar states the default view is the main pool; approximate counts are labelled |
| T-136-16-04 | Spoofing | An outage rendering as "no findings" | mitigate | Four distinct service states with retry on timeout and busy |
| T-136-16-05 | Denial of service | A blocking facet or result read on the single event loop | mitigate | All reads through the enveloped async wrappers; `tests/test_no_await_sync_function.py` as an acceptance gate; server-side page cap |
| T-136-16-06 | Information disclosure | Prohibited wording reaching the permanent caveat, which is hand-written prose | mitigate | Honesty gate scoped to the caveat element, including the negated-wording rule that caught the sketch's first draft |
| T-136-16-07 | Tampering | Per-user selections written through raw storage, leaking across users | mitigate | Storage chokepoint only; `tests/test_no_raw_storage_access.py` as an acceptance gate |
| T-136-16-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan |
