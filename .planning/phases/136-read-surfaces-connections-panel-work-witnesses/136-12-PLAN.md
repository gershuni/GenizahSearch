`novelty_columns_for`'s own `divergence_correctness` parameter are all UNCHANGED by ruling L -- only
the SOURCE of the value changes (model → human-only). Whoever executes this plan must re-verify this
note is still current (check `shared/discovery_novelty.py`'s own module docstring section "divergence_correctness
is HUMAN-ONLY (ruling L)") before wiring Task 1's ingestion.

runs. The two hardest constraints land here: novelty must be fail-closed (a boolean cannot tell

Output: a build that writes every authorized new field, and a verifier that independently checks each.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verdict cache → shipped asset | An external, expensive build input whose identity must be proven before it is trusted |
| raw provenance → derived enum | The single point where restricted origin is consumed and must be discarded |
| curated artifact → shipped asset | Hand-produced data crossing into a release-contract-covered build |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-12-01 | Spoofing | A failed novelty check ingesting as a positive verdict | mitigate | `DEFAULT_STATUS` fail-closed with five explicit failure-mode tests |
| T-136-12-02 | Information disclosure | A raw provenance value or raw origin id reaching a column, log or error message | mitigate | Writes go only through `masked_provenance_label`; a build assertion restricts written labels to the masked set; a seeded-id log grep test |
| T-136-12-03 | Tampering | A substituted or edited verdict cache changing the flagship filter | mitigate | Content hash re-checked against the run record before any row is read; refusal tested |
| T-136-12-04 | Tampering | A curated artifact edited after pinning | mitigate | Hash-pinned fail-closed load, matching the existing curated-input mechanism |
| T-136-12-05 | Elevation of privilege | A row becoming public because the axes were derived after the raw origin was dropped | mitigate | Derivation placed while origin is in scope; fixtures cover both mislabelling directions where the corpus field alone gives the wrong answer |
| T-136-12-06 | Repudiation | A golden fixture refreshed to bless a regression | mitigate | The summary must name every changed assertion and why |
| T-136-12-07 | Spoofing | `container_predicts` rows silently rendered/read as if `diverges_work`/`diverges_part`'s default-hidden posture applied to them (or vice versa) | mitigate | The two are distinguishable by `novelty_status` alone; no shared "hidden" flag is written; a test asserts a `container_predicts` fixture row is never routed through the divergence-only `divergence_correctness` path |
| T-136-12-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan |
