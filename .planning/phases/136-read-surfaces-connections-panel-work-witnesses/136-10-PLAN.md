## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored vocabulary → rendered markup | Internal relation keys must never appear in HTML |
| display strings → both public surfaces | One module supplies every claim-level word a reader sees |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-10-01 | Information disclosure | A stored vocabulary key rendered into markup, exposing internal classification | mitigate | Filter uses short codes; the sweep test asserts no returned string contains a stored key |
| T-136-10-02 | Spoofing | A prohibited relation word reaching a surface through a hand-written string, including negated | mitigate | Sweep test over every public function in both languages, word-boundary and case-insensitive |
| T-136-10-03 | Spoofing | A per-kind coloured chip reintroducing confidence styling the requirement prohibits | mitigate | Neutral chip enforced by a CSS check asserting no colour keyed on relation kind |
| T-136-10-04 | Information disclosure | A missing Hebrew value rendering an English string in a Hebrew UI | mitigate | Test asserts every new `tr()` key has both languages |
| T-136-10-05 | Tampering | A human-review badge string reappearing on a surface | mitigate | The string is not defined anywhere; `grep` asserts its absence |
| T-136-10-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan |
