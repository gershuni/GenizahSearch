<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sidecar → both surfaces' data contract | Everything either surface renders comes through this one service |
| user filter/sort/unit selection → SQL | A large combination space reaching a query builder |
| async page handler → blocking query | A single uvicorn worker means one sync call stalls the whole site |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-14-01 | Spoofing | An outage rendering as "this manuscript has no identifications" | mitigate | Four distinct envelope statuses with pairwise-distinctness tests |
| T-136-14-02 | Denial of service | A blocking sidecar query on the single event loop stalling every request | mitigate | All new work through `_run_off_loop`; `tests/test_no_await_sync_function.py` re-run as an acceptance gate |
| T-136-14-03 | Denial of service | A per-row follow-up query multiplying browse-enrichment latency, or an unindexed findings combination scanning the corpus | mitigate | One query with joins plus a spy test; findings query reads the materialized grain with its composite index |
| T-136-14-04 | Tampering | Injection through the unit, sort or facet parameters | mitigate | Closed enums mapped to fixed SQL fragments; facet values bound as parameters |
| T-136-14-05 | Spoofing | Filtering on the manuscript's catalogue domain, hiding the findings that disagree with the catalogue | mitigate | Source-level wrong-axis guard naming the forbidden accessor, observed failing |

| T-136-14-07 | Repudiation | A human-confirmed row silently dropped by a routing predicate | mitigate | Regression test at the exact observed shape; the fix is in SQL |
