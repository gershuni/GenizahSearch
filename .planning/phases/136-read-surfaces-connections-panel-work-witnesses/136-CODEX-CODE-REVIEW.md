## Verbatim findings

1. **BLOCKER — masking/error paths.** The public loader echoes untrusted artifact values in exceptions and then logs the complete exception. Invalid `schema_version`, `claim_type`, and band values can therefore place a restricted name into a log, violating the standing exception/log rule. See [web/discovery_assets.py](C:/Genizahsearch/web/discovery_assets.py:368), [web/discovery_assets.py](C:/Genizahsearch/web/discovery_assets.py:431), and [web/discovery_assets.py](C:/Genizahsearch/web/discovery_assets.py:454). `test_refusal_is_logged_with_reason_and_no_row_content` cannot detect this: it seeds a harmless title cell, then forces an earlier audience failure, so the raw-enum branches are unreachable ([tests/test_discovery_assets_audience.py](C:/Genizahsearch/tests/test_discovery_assets_audience.py:76), [tests/test_discovery_assets_audience.py](C:/Genizahsearch/tests/test_discovery_assets_audience.py:151)). Replace raw-value interpolation with field names/counts or fixed error codes, and add controls using a public-audience fixture with sentinels in each rejected metadata/enum field. The current public artifact itself passed the strict repository, byte, and SQLite-cell masking scan.

2. **HIGH — projection dependency closure.** `later_shared_text` closure is keyed only by `page_id`, not by the work actually demoted. An unrelated publishable demotion on the same page makes the page “replayable” and can preserve evidence whose own backing demotion was removed for naming a private work ([scripts/project_discovery_public.py](C:/Genizahsearch/scripts/project_discovery_public.py:217), [scripts/project_discovery_public.py](C:/Genizahsearch/scripts/project_discovery_public.py:228)). The verifier repeats the same page-only test ([scripts/verify_discovery_sidecar.py](C:/Genizahsearch/scripts/verify_discovery_sidecar.py:833)). `test_later_shared_text_evidence_is_pruned_when_its_demotion_cannot_be_published` supplies only one demotion on its page, so it cannot express this false-green case ([tests/test_vis01_projection.py](C:/Genizahsearch/tests/test_vis01_projection.py:764)). Key closure and verification by page plus the evidence work’s canonical identity, and add the two-demotions-on-one-page adversarial fixture. Read-only live query: the deployed public artifact currently has 1,337 such evidence rows and zero unmatched exact demotion pairs, so the existing bytes are sound on this invariant.

3. **HIGH — deployed genre completeness/release gate.** The contract describes `Unassigned` as a real value rather than missing data, but the verifier inspects only nonempty genre values and never rejects NULL/empty rows ([scripts/verify_discovery_sidecar.py](C:/Genizahsearch/scripts/verify_discovery_sidecar.py:1559)). The builder likewise updates only artifact-matched works and leaves unmatched rows unchanged ([scripts/build_discovery_sidecar.py](C:/Genizahsearch/scripts/build_discovery_sidecar.py:5090)). Read-only live queries found 58 NULL/empty genres in the deployed public artifact and 181 in the private source; all are works with evidence but no shipped evidence. Nevertheless, the full public verifier returned clean. `test_unassigned_survives_into_the_asset_as_a_real_queryable_value` only requires at least one `Unassigned` row, so NULL rows alongside it cannot fail the test ([tests/test_discovery_schema.py](C:/Genizahsearch/tests/test_discovery_schema.py:650)). Expand the curated domain population to every work eligible to enter an artifact and make any NULL/empty genre a release violation.

4. **HIGH — verifier missing-table false green.** Four routing-audit checks silently return success when `discovery_routing_audit` is absent ([scripts/verify_discovery_sidecar.py](C:/Genizahsearch/scripts/verify_discovery_sidecar.py:829), [scripts/verify_discovery_sidecar.py](C:/Genizahsearch/scripts/verify_discovery_sidecar.py:864), [scripts/verify_discovery_sidecar.py](C:/Genizahsearch/scripts/verify_discovery_sidecar.py:934), [scripts/verify_discovery_sidecar.py](C:/Genizahsearch/scripts/verify_discovery_sidecar.py:1530)). No release-contract table-inventory check compensates for this. A current-schema artifact with the audit table removed therefore turns all associated gates into no-ops. Make absence a violation for current/public artifacts and retain compatibility only behind an explicit legacy profile. Add a whole-verifier positive control with the table removed. On the live public artifact the check is nonvacuous: 1,348 demotion rows were examined and zero had an unshipped kept reference.

5. **HIGH — duplicated main-pool rule.** `scripts/discovery_gate1_evidence.py::classify_identifications` independently implements bucket membership and omits the shared rule’s short-evidence gate ([scripts/discovery_gate1_evidence.py](C:/Genizahsearch/scripts/discovery_gate1_evidence.py:689), compared with [shared/discovery_main_pool.py](C:/Genizahsearch/shared/discovery_main_pool.py:247)). Read-only queries found 671 private and 608 public identifications stored as `insufficient_length` whose coverage otherwise clears the duplicate classifier’s final gate; that classifier would call them main. `test_second_implementation_guard_finds_none_on_the_real_tree` scans only `shared/` and `web/`, excluding `scripts/`, so it passes with this duplicate present ([tests/test_discovery_main_pool.py](C:/Genizahsearch/tests/test_discovery_main_pool.py:475)). Its seeded control tests only a hand-picked band-set shape, not alternate implementations like the live one ([tests/test_discovery_main_pool.py](C:/Genizahsearch/tests/test_discovery_main_pool.py:493)). Delete the duplicate and feed the evidence report through `main_pool_decision`; expand the guard to `scripts/` and compare executed decisions.

6. **MEDIUM — author-artifact coverage blind spot.** `assert_author_key_coverage` deliberately checks only works with shipped evidence ([scripts/build_discovery_sidecar.py](C:/Genizahsearch/scripts/build_discovery_sidecar.py:5125)).
