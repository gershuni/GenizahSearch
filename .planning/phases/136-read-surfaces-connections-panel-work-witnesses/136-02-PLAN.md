<objective>
Define — in the frozen schema contract, before any code writes them — every field and table the
one authorized rebuild adds, and correct the deploy runbook's rebuild command so the rebuild is
reproducible against the LIVE v2 inputs rather than against whatever the candidate happens to say.

Purpose: the schema doc is the contract the builder, the verifier and the loader all validate
against. Adding columns first and documenting them later is exactly how a coordinate-space
mismatch or an unauthorized precision field gets shipped.
Output: a dated schema amendment, a corrected runbook, and a lockstep test.
</objective>
