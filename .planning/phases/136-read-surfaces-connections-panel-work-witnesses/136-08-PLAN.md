<objective>
Persist the work-side match position the matcher already computes and currently discards at
ingest — `w_start` / `w_end` on `discovery_evidence`, for every source corpus.

Purpose: this is the highest-value item on the rebuild list. It is the only structural fix for
containment misattribution (a halakhic code that embeds the whole liturgy currently absorbs
liturgical fragments — one such work carries 2,070 identifications, seventh corpus-wide, above
Isaiah), and far more importantly it makes a citation locatable, which is what makes it worth
anything to a scholar. The matcher slices each work into overlapping 3,800-character windows and
tracks each window's offset, with an explicit in-code note that gram positions stay original so
span coordinates are unaffected — the coordinate exists at match time and is dropped at ingest.
Output: two new populated columns, a containment signal, and tests pinning the coordinate space.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reference-corpus text → asset | Work-side offsets are derived from restricted and public reference bodies; only integers may cross |
| stored offset → future display | An offset with an unnamed coordinate space becomes a wrong highlight on a surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-08-01 | Information disclosure | Reference text or a restricted locus crossing into the asset via the offset path | mitigate | Only integers are stored; Test 5 asserts the column types and runs the masking scan over the built fixture |
| T-136-08-02 | Tampering | Overloading `b_start`/`b_end` and corrupting the propagated B side | mitigate | Separate columns; Test 2 asserts the B side is untouched |
| T-136-08-03 | Spoofing | An offset presented as indexing the readable body when it indexes the normalized stream | mitigate | Coordinate space named at definition; Test 1 asserts the raw slice is wrong |
| T-136-08-04 | Elevation of privilege | The containment signal quietly changing routing before it is validated | mitigate | Acceptance criterion asserts no routing or bucket code reads it in this phase |
| T-136-08-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs |
