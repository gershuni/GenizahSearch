<objective>
Give PANEL-02's "Other manuscripts matching ⟨work⟩" expansion the things it actually needs and does not
have: the anchor side's relation and band, the weaker-band rule applied across the pair, rows a renderer
can actually draw, a real total from a count query, and an envelope that cannot report a failed query as
a genuine zero.

Purpose: this plan exists because a revision-1 instruction — including my own reading of it — was
wrong. `get_work_witnesses()` returns only the OTHER carrier's `claim_type` and band, with neither the
anchor's relation nor a total, so "wiring an existing field through" was never possible. PANEL-02
requires each side's own relation type when they differ, DATA-01 requires the weaker band of the pair,
a visible real total requires a count query — a bounded page cannot supply one — and the panel section
promises a library and a shelfmark per carrier that the return shape does not contain. All of it needs
service work, and pretending otherwise would have produced a panel section that silently showed the
anchor's band, a page size where a total belongs, and rows with nothing to name them by.
Output: an anchor-aware projection over renderable rows, a count query, an allowlist, and two enveloped
wrappers.
</objective>
