<objective>
Define the novelty identity key and the reproducible LLM contract, then run the funnel and stage
its verdict cache as a hash-pinned build input.

Purpose: today all 144,294 shipped direct evidence rows carry `is_new = 0` meaning UNCHECKED, not
"known" — a two-state filter over that data would tell a reader that 144,294 findings are already
recorded in the finding aids, which is false. The check also cannot key on raw source work ids
(they split aliases) or on the existing canonical id (documented as over-collapsing — one collapsed
id covers 39 Bible books). And false novelty is the reputationally costly error, so the model and
prompt must be pinned rather than trusted.
Output: a shared identity/contract module, an owner-authorized funnel run, and a pinned artifact.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external model API → build input | A third-party response becomes a claim on a public surface |
| gitignored research tree → committed artifact | Only a hash-pinned, masked output may cross |
| finding-aid provenance → display | Naming which restricted source already had a finding would leak the corpus |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-11-01 | Spoofing | A silent model downgrade producing weaker verdicts under the same label | mitigate | Model and version pinned as literal constants; a later test asserts they appear in the request payload |
| T-136-11-02 | Information disclosure | A restricted provenance value or a prompt reaching a committed artifact | mitigate | Artifact carries a masked provenance code only; `--scan-asset --strict` gates the commit; `masked_provenance_label` covers unknown and malformed input |
| T-136-11-03 | Tampering | A failure silently reading as "not found in the finding aids" | mitigate | `DEFAULT_STATUS` is `not_checked`; forced-failure tests land in plan 136-12 |
| T-136-11-04 | Repudiation | A verdict set with no recorded source versions or dates, unreproducible later | mitigate | `136-NOVELTY-CONTRACT.md` records per-source version and as-of date, plus the cache-key specification |
| T-136-11-05 | Elevation of privilege | An unauthorized spend or an unmeasured evaluation | mitigate | Blocking owner decision task before any run; real measured cost recorded afterwards |
| T-136-11-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages; the funnel runs from the existing gitignored tree with existing dependencies |

</threat_model>
