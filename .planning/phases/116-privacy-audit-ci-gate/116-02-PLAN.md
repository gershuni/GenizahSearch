<objective>
Add a headless `--telemetry-selftest` (and `--telemetry-selftest-offline`) CLI flag to
`genizah_app.py __main__`, modeled exactly on the existing `--self-test-pymupdf` block (parsed BEFORE
`QApplication`). It reuses `desktop/telemetry.run_selftest()` to emit one `desktop_selftest` event,
waits for the daemon drain thread to attempt one POST, and prints a machine-readable token
(`SSL_OK` / `SSL_FAIL`, or `OFFLINE_OK` for the offline arm) with a non-zero exit on failure.

This is the on-device tool that verifies ROADMAP SC#3 (frozen-binary SSL + offline degradation). The
gold-standard proof - a clean no-Python Windows VM run - is captured as a HUMAN-UAT verification item
(D-06), which ALSO closes Phase 114's still-open "live PostHog event delivery" UAT.

Purpose: Give release engineers a one-command probe that proves certifi/SSL works inside the frozen
binary and that telemetry degrades silently offline - without writing consent to disk (D-04/D-05).
Output: ~30 lines in `genizah_app.py __main__`; documented in the runbook (plan 116-03, D-08d).

| frozen exe -> eu.i.posthog.com (TLS) | The self-test crosses the TLS boundary; certifi CA bundle must be present and trusted inside the frozen binary |
| dev/release operator -> headless CLI flag | A developer running the flag must not have their consent state persisted to config.pkl |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-116-04 | Spoofing | SSL/TLS to PostHog in the frozen exe | mitigate | certifi `cacert.pem` is auto-bundled by PyInstaller's `hook-certifi.py` (no spec change); the `--telemetry-selftest` SSL_OK token + the clean-VM HUMAN-UAT (Task 2) PROVE the bundle ships and verifies the cert chain. No user-supplied CA path is accepted. |
| T-116-05 | Tampering | dev-machine consent state (config.pkl write from a headless probe) | mitigate | The selftest toggles `_enabled` IN-MEMORY under `_enabled_lock` and restores it in `finally`; it NEVER calls `set_consent()` (Pitfall 2). config.pkl is unmodified by the probe. |
| T-116-06 | Denial of Service | offline self-test hang (blocked event loop / indefinite wait) | mitigate | Offline arm returns immediately (no sleep); online arm bounded by `requests.post(timeout=2.0)` + a single `sleep(1.5)`. Verified fast-return in the offline HUMAN-UAT (<=5s). |
