```python
class PuzzleImageLoaderThread(QThread):
    """Load and process a fragment image in the background via PuzzleImageService."""
    image_ready = pyqtSignal(str, bytes)   # (fl_id, rgba_png_bytes or jpeg_bytes)
    load_failed = pyqtSignal(str, str)     # (fl_id, error_message)

    def __init__(self, fl_id: str, threshold: float = 30.0, size: int = 800, processed: bool = True):
        super().__init__()
        self.fl_id = fl_id
        self.threshold = threshold
        self.size = size
        self.processed = processed

    def run(self):
        try:
            from shared.puzzle_image_service import resolve_fragment_image
            result = resolve_fragment_image(
                self.fl_id, size=self.size,
                threshold=self.threshold, processed=self.processed
            )
            if result:
                self.image_ready.emit(self.fl_id, result)
            else:
                self.load_failed.emit(self.fl_id, "Image not available")
        except Exception as e:
            self.load_failed.emit(self.fl_id, str(e))
```

Import `pyqtSignal` is already imported at the top of gui_threads.py. No new imports needed.

**Class 1: PuzzleFragmentItem(QGraphicsPixmapItem)**

A custom QGraphicsPixmapItem that holds a PuzzleFragment dataclass and handles per-item mouse interactions:

1. **Constructor** accepts `(puzzle_frag: PuzzleFragment, pixmap: QPixmap, parent=None)`:
   - Store `self.puzzle_frag = puzzle_frag`
   - Enable flags: `ItemIsMovable`, `ItemIsSelectable`, `ItemSendsGeometryChanges`
   - Set `SmoothTransformation` mode
   - Set transform origin to pixmap center: `self.setTransformOriginPoint(self.boundingRect().center())`
   - Apply initial position from puzzle_frag.x, puzzle_frag.y via `self.setPos()`
   - Apply initial rotation via `self.setRotation(puzzle_frag.rotation)`
   - Apply initial scale via `self.setScale(puzzle_frag.scale)`
   - Call `self._apply_flip()` for initial flip state
   - `self._rotating = False` and `self._rotation_start_angle = 0.0` for rotation state
   - `HANDLE_SIZE = 14` class constant for corner handle hit radius

2. **`_apply_flip(self)`**: Apply flip via QTransform:
   ```python
   t = QTransform()
   if self.puzzle_frag.flip_h:
       t.scale(-1, 1)
       t.translate(-self.boundingRect().width(), 0)
   if self.puzzle_frag.flip_v:
       t.scale(1, -1)
       t.translate(0, -self.boundingRect().height())
   self.setTransform(t)
   ```

3. **`flip_horizontal(self)`**: Toggle `self.puzzle_frag.flip_h`, call `_apply_flip()`
4. **`flip_vertical(self)`**: Toggle `self.puzzle_frag.flip_v`, call `_apply_flip()`

5. **`_is_near_corner(self, pos: QPointF) -> bool`**: Check if pos is within HANDLE_SIZE of any corner of `self.boundingRect()`. Return True if distance to any corner < HANDLE_SIZE.

6. **`mousePressEvent(self, event)`**:
   - If `self.isSelected()` and `self._is_near_corner(event.pos())`: enter rotation mode. Set `self._rotating = True`. Calculate `self._rotation_start_angle` as `math.degrees(atan2(pos.y - center.y, pos.x - center.x)) - self.rotation()`. Accept event and return.
   - Otherwise: call `super().mousePressEvent(event)`.

7. **`mouseMoveEvent(self, event)`**:
   - If `self._rotating`: calculate new angle from mouse position relative to bounding rect center, subtract `_rotation_start_angle`, set rotation via `self.setRotation(angle % 360)`, update `self.puzzle_frag.rotation`. Accept event and return.
   - Otherwise: call `super().mouseMoveEvent(event)`. Then if Shift modifier is held, snap position to 20px grid: `self.setPos(round(x/20)*20, round(y/20)*20)`.
   - After move, sync position back to puzzle_frag: `self.puzzle_frag.x = self.pos().x()`, `self.puzzle_frag.y = self.pos().y()`.

8. **`mouseReleaseEvent(self, event)`**: Set `self._rotating = False`. Call `super().mouseReleaseEvent(event)`.

9. **`wheelEvent(self, event)`**: Resize fragment. Calculate scale delta from `event.angleDelta().y()` (factor 1.05 per notch up, 0.95 down). Clamp scale to 0.1-4.0 range. Set via `self.setScale(new_scale)`. Update `self.puzzle_frag.scale`. Accept event.

10. **`paint(self, painter, option, widget)`**: Call `super().paint(painter, option, widget)`. If `self.isSelected()`, draw 4 small circles (radius=HANDLE_SIZE/2) at each corner of boundingRect in white with 50% opacity fill + solid white 1px border. Use `QPen(QColor(255,255,255), 1)` and `QBrush(QColor(255,255,255,128))`. Also draw dashed selection border: `QPen(QColor(255,255,255,180), 1, Qt.PenStyle.DashLine)` around `self.boundingRect()`.

11. **`update_pixmap(self, pixmap: QPixmap)`**: Replace the displayed image (for folio nav / threshold change). Call `self.setPixmap(pixmap)`, recalculate transform origin to new center.

12. **`shape(self) -> QPainterPath`**: Override to return the bounding rect as a path (needed for accurate hit testing with transparent pixels). Return `QPainterPath` with `addRect(self.boundingRect())`.

**Class 2: PuzzleCanvasView(QGraphicsView)**

A QGraphicsView that hosts PuzzleFragmentItem instances with view-level zoom/pan and background toggle:

1. **Constructor**:
   - Create `self.scene = QGraphicsScene(self)` and `self.setScene(self.scene)`
   - Set very large scene rect: `self.scene.setSceneRect(QRectF(-10000, -10000, 20000, 20000))`
   - Render hints: `Antialiasing`, `SmoothPixmapTransform`
   - Set `DragMode.NoDrag` (we handle pan manually)
   - Set `self.setTransformationAnchor(QGraphicsView.ViewportAnchor.AnchorUnderMouse)`
   - Hide scrollbars (same as ZoomableScrollArea pattern)
   - `self._checkerboard = False` (dark gray default)
   - `self._panning = False` and `self._pan_start = QPointF()` for hand-drag pan state
   - Style: `self.setStyleSheet("border: none;")`

2. **`set_checkerboard(self, enabled: bool)`**: Set `self._checkerboard = enabled`, call `self.scene.invalidate()` to trigger repaint.

3. **`drawBackground(self, painter, rect)`**: Override. If `self._checkerboard`: draw 20px checkerboard (light gray #c8c8c8 / medium gray #969696). Else: fill with dark gray `QColor(0x33, 0x33, 0x33)`.

4. **`mousePressEvent(self, event)`**:
   - If middle button or (left button + no item under cursor): start panning. Set `self._panning = True`, `self._pan_start = event.position()`, set cursor to ClosedHandCursor. Accept event.
   - Otherwise: `super().mousePressEvent(event)` (let items handle it).

5. **`mouseMoveEvent(self, event)`**:
   - If `self._panning`: calculate delta from `self._pan_start`, translate view using `self.horizontalScrollBar().setValue()` and `self.verticalScrollBar().setValue()`. Update `self._pan_start`. Accept event.
   - Otherwise: `super().mouseMoveEvent(event)`.

6. **`mouseReleaseEvent(self, event)`**: If `self._panning`: set `self._panning = False`, restore cursor to ArrowCursor. Else: `super().mouseReleaseEvent(event)`.

7. **`wheelEvent(self, event)`**:
   - If Ctrl modifier: zoom view. Factor = 1.15 if delta > 0, else 1/1.15. Clamp view scale 0.05-10.0. Call `self.scale(factor, factor)`. Accept event.
   - Else if item under mouse (`self.itemAt(event.position().toPoint())`): forward to item's wheelEvent. Accept event.
   - Else: ignore (allow scroll propagation).

8. **`get_fragment_items(self) -> list`**: Return all PuzzleFragmentItem instances from `self.scene.items()`.

9. **`get_selected_fragments(self) -> list`**: Return selected PuzzleFragmentItem instances from `self.scene.selectedItems()`.
