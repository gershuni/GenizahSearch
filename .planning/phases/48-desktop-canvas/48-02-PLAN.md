Get fl_ids for the sys_id by calling `self.app.meta_mgr.get_meta_for_id(sys_id)` to get metadata with fl_ids (or use a simpler lookup -- the MetadataManager has images_nli in the result of `resolve_images_and_meta()`). The folio_label defaults to "1r" for the first image.
   - IMPORTANT: `get_meta_for_id` may not have fl_ids readily available. Check what it returns. If it only returns basic metadata, the fl_ids come from the IIIF manifest which is async. In that case, a fallback approach: directly use the NLI crossref to get image count, or just try loading with the sys_id as a starting point. The executor should check `meta_mgr.get_meta_for_id()` return format and adapt.

3. **`_on_image_loaded(self, fl_id, image_bytes)`**:
   - Guard: `if sip.isdeleted(self): return`
   - Convert bytes to QPixmap: `img = QImage(); img.loadFromData(image_bytes); pixmap = QPixmap.fromImage(img)`
   - Find the PuzzleFragment that was created for this fl_id.
   - Create `PuzzleFragmentItem(puzzle_frag, pixmap)`.
   - Add to scene: `self.canvas_view.scene.addItem(item)`.
   - Store in `self._fragment_items[fl_id] = item`.
   - Remove any placeholder/loading indicator.

4. **`_on_image_failed(self, fl_id, error)`**: Show error in status bar. Remove placeholder.

Update slider_threshold value to match selected fragment's `bg_removal_threshold`. Update slider_scale to match `int(frag.puzzle_frag.scale * 100)`. If none or multiple, show count or "No selection".

6. **`_flip_selected_h(self)`**: For each selected PuzzleFragmentItem, call `item.flip_horizontal()`.

7. **`_flip_selected_v(self)`**: For each selected PuzzleFragmentItem, call `item.flip_vertical()`.

8. **`_on_threshold_changed(self, value)`**: Update `self.lbl_threshold_val.setText(str(value))`. For each selected fragment, set `item.puzzle_frag.bg_removal_threshold = float(value)`. Re-fetch image with new threshold: start PuzzleImageLoaderThread with updated threshold, connect image_ready to lambda that calls `item.update_pixmap()`.

9. **`_on_scale_changed(self, value)`**: Update `self.lbl_scale_val.setText(f"{value}%")`. For each selected fragment, set scale: `item.setScale(value / 100.0)`, update `item.puzzle_frag.scale = value / 100.0`.

Navigate to the next/prev entry, update puzzle_frag.fl_id and folio_label, re-fetch image.

11. **`_delete_selected(self)`**: For each selected item, remove from scene (`self.canvas_view.scene.removeItem(item)`), remove from `self._fragment_items`.

```python
def add_to_puzzle(self, sys_id, shelfmark, folio_label=None, fl_id=None):
    """Add a fragment to the puzzle canvas. Opens puzzle window if needed."""
    if self._puzzle_window is None or not self._puzzle_window.isVisible():
        self._puzzle_window = PuzzleCanvasWindow(self)
    self._puzzle_window.add_fragment(sys_id, shelfmark, folio_label or '1r', fl_id or '')
    self._puzzle_window.show()
    self._puzzle_window.raise_()
    self._puzzle_window.activateWindow()
```
