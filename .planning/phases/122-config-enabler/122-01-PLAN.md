`shared/config.py`, leave `genizah_core.Config` as a permanent re-export of the SAME class
object, retarget the one in-scope module-level back-edge (`shared/session_persistence.py:32`),
and install the permanent GUARD-01 AST back-edge guard (`tests/test_no_back_edges_core.py`)
co-located with the CONFIG-01 identity test.

This is the "Phase 0" cycle-pivot enabler of the v8.3.0 God-File Decomposition milestone.
`Config` must move first because the leaf modules extracted in Phase 123+ bind `Config.*` at
class-definition time; once `Config` lives in `shared/config.py` and `genizah_core.py` imports
it at the top via the shim, those later modules can `from shared.config import Config` at their
own module level without an import cycle.

Purpose: Break the import-cycle pivot that blocks ALL subsequent core moves (Phases 123-125),
and lock the back-edge invariant (GUARD-01) for the entire milestone via a parametrized
registry test that grows one entry per future extraction phase.
Output: `shared/config.py` (new), modified `genizah_core.py` (class deleted + shim added),
retargeted `shared/session_persistence.py`, new `tests/test_no_back_edges_core.py`.

no user-facing CHANGELOG entry beyond the internal milestone note.
