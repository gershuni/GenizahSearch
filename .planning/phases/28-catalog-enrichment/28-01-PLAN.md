  <action>
Add three new functions/methods to shared/fjms_service.py:

1. **Add `import re`** at the top of the file (needed for parse_textual_frame).

2. **Add `get_catalog_records()` method** to the FjmsService class (after the existing `get_catalog()` method). This replaces the single-record approach:

   ```python
   def get_catalog_records(self, sys_id: str) -> list[dict]:
       """Get all non-empty catalog records for a manuscript.

       Returns list of dicts. Filters out completely empty records and
       deduplicates by (textual_frame_eng, copy_date, title) tuple.
       Sentinel CopyDate values (0, -99, -1) are normalized to None.
       """
   ```

   Implementation details:
   - Query: `SELECT * FROM catalog WHERE AlmaId = ?`
   - For each row, build a dict with snake_case keys: title, title_heb, author_text, copy_date, copy_place, textual_frame_heb, textual_frame_eng, source_name, source_name_heb
   - **Handle missing SourceName columns gracefully**: Use `row.keys()` to check if "SourceName" exists before accessing (the old sidecar won't have these columns). If missing, set source_name and source_name_heb to None.
   - **Filter sentinel CopyDate values**: If copy_date is in ('0', '-99', '-1', '0.0', '-99.0', '-1.0') or is empty string, set to None.
   - **Filter empty records**: Skip any record where ALL content fields (title, title_heb, author_text, copy_date, copy_place, textual_frame_heb, textual_frame_eng) are None or empty string. Source name fields don't count toward "has content".
   - **Deduplicate**: Use a set of (textual_frame_eng or '', copy_date or '', title or '') tuples to detect duplicates. Skip if key already seen.
   - Return the filtered, deduped list.
   - Wrap in try/except, return [] on error.

3. **Add module-level `merge_catalog_records()` function** (outside the class, after the class definition, before the singleton section):

   ```python
   def merge_catalog_records(records: list[dict]) -> dict:
       """Merge multiple catalog records into a display-ready structure.

       Metadata fields (title, author, date, place) are merged by taking
       the first non-empty value. TextualFrame entries are collected as
       a list of distinct values with their source attribution.
       """
   ```

   Implementation:
   - Initialize result dict with None for title, title_heb, author_text, copy_date, copy_place
   - Iterate records: for each metadata field, take the FIRST non-empty value encountered
   - Collect distinct textual_frames as a list of dicts: `{'eng': str, 'heb': str, 'source_name': str, 'source_name_heb': str}`
   - Deduplicate frames by (eng, heb) tuple
   - Add 'record_count': len(records) to result
   - Add 'textual_frames': list to result
   - Return the merged dict

4. **Add module-level `parse_textual_frame()` function** (next to merge_catalog_records):

   ```python
   def parse_textual_frame(text: str) -> tuple[str, str]:
       """Parse '[$Category$]: Content' notation into (category, content).

       Strips optional @ prefix. Returns ('', full_text) if no pattern match.
       """
   ```

   Implementation:
   - Strip whitespace, strip leading '@' character
   - Match regex: `r'\[\$(.+?)\$\]\s*:\s*(.*)'` with re.DOTALL
   - If match: return (group(1).strip(), group(2).strip())
   - If no match: return ('', text)

5. **Keep the existing `get_catalog()` method** for backward compatibility but do NOT modify it.

Do NOT add any translation keys in this task -- that's handled in Plan 02.
