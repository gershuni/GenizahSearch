    Create `scripts/nli_only_subset.py` per D-05/D-06 from CONTEXT.md.

    **Core function `get_nli_only_subset(crossref_db_path, oxford_json_path=None)`:**
    1. Open nli_crossref.db at `crossref_db_path` with sqlite3
    2. Get all distinct NLI_AlmaId from `nli_images` table -> `nli_sysids` set
    3. Exclude Cambridge-covered (join key: `nli_images.Shelfmark = cambridge_manifests.normalized_shelfmark`):
       ```sql
       SELECT DISTINCT i.NLI_AlmaId
       FROM nli_images i
       JOIN cambridge_manifests c ON c.normalized_shelfmark = i.Shelfmark
       ```
    4. Exclude Manchester-covered (join key: `LOWER(nli_images.ImageSourceName) = manchester_luna.image_source_name`):
       ```sql
       SELECT DISTINCT i.NLI_AlmaId
       FROM nli_images i
       JOIN manchester_luna m ON LOWER(i.ImageSourceName) = m.image_source_name
       ```
    5. Exclude JTS-covered (join key: `nli_images.Shelfmark = jts_dpul.shelfmark`):
       ```sql
       SELECT DISTINCT i.NLI_AlmaId
       FROM nli_images i
       JOIN jts_dpul j ON j.shelfmark = i.Shelfmark
       ```
    6. Exclude Oxford-covered -- PRIMARY path is LibraryAbbrev:
       ```sql
       SELECT DISTINCT NLI_AlmaId FROM nli_images WHERE LibraryAbbrev = 'Oxford'
       ```
       SECONDARY path (if oxford_json_path provided): load oxford_full_db.json, extract 225 volume shelfmark keys, match against nli_images.Shelfmark using prefix match (`Shelfmark LIKE ? || '%'` for each key). This catches any non-Oxford-library manuscripts that Oxford happens to have digitized.
    7. Return a dict with:
       - `nli_only`: set of NLI_AlmaId values (nli_sysids minus all excluded)
       - `exclusion_counts`: `{"cambridge": len, "manchester": len, "jts": len, "oxford": len, "total_excluded_sysids": len(union of all excluded)}`
       Note: A single sys_id may be excluded by multiple providers. `total_excluded_sysids` is the union count.

    **Function `get_library_breakdown(crossref_db_path, nli_only_sysids)`:**
    1. Create a temp table and INSERT all NLI-only sys_ids (avoids 44K-item IN clause):
       ```sql
       CREATE TEMP TABLE nli_only_ids (sys_id TEXT);
       INSERT INTO nli_only_ids VALUES (?);  -- executemany
       ```
    2. Query:
       ```sql
       SELECT i.LibraryAbbrev,
              COUNT(DISTINCT i.NLI_AlmaId) as manuscripts,
              COUNT(*) as image_rows,
              SUM(CASE WHEN i.FGPImageNumberId IS NULL OR i.FGPImageNumberId = '' THEN 1 ELSE 0 END) as no_fgp_rows
       FROM nli_images i
       JOIN nli_only_ids n ON n.sys_id = i.NLI_AlmaId
       GROUP BY i.LibraryAbbrev
       ORDER BY image_rows DESC
       ```
    3. Return list of dicts: `[{"library_code": "RNL", "manuscripts": N, "image_rows": N, "no_fgp_rows": N, "avg_per_manuscript": float}]`

    **Function `get_sample_fl_ids(crossref_db_path, nli_only_sysids, n=500, seed=None)`:**
    (Addresses review concern #7 -- fixed seed for reproducibility)
    1. If seed is provided, set `random.seed(seed)`. Default seed=42 for reproducible default.
    2. Convert nli_only_sysids to sorted list for deterministic ordering
    3. Sample n sys_ids using `random.sample()` (stratified proportionally by library if possible -- at minimum ensure top-5 libraries are represented)
    4. For each sampled sys_id, query nli_images for all rows:
       ```sql
       SELECT NLI_AlmaId, Shelfmark, LibraryAbbrev, FGPImageNumberId, ImageSourceName
       FROM nli_images WHERE NLI_AlmaId = ?
       ```
    5. Flag which need manifest fetch: `needs_manifest = all FGPImageNumberId are NULL/empty for that sys_id`
    6. Return list of dicts: `{"sys_id": str, "library_code": str, "shelfmark": str, "image_count": int, "fgp_ids": [str], "needs_manifest": bool}`
    7. Save sample list to JSON file at `{output_path}_sample.json` for downstream reuse

    **CLI (argparse):**
    - `--crossref-db` (default: auto-detect from `nli_data/nli_crossref.db` or `nli_crossref.db`)
    - `--oxford-json` (default: `oxford_full_db.json`)
    - `--output` (default: stdout; or JSON file path)
    - `--sample N` (optional: output N sample manuscripts for rate testing)
    - `--seed INT` (default: 42; random seed for reproducible sampling)

    ```json
    }
    ```
