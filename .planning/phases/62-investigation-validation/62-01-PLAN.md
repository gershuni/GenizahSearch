    Create `scripts/nli_only_subset.py` per D-05/D-06 from CONTEXT.md:

    **Core function `get_nli_only_subset(crossref_db_path, oxford_json_path)`:**
    1. Open nli_crossref.db with sqlite3 (row_factory = sqlite3.Row)
    2. Get all distinct NLI_AlmaId from `nli_images` table -> `nli_sysids` set
    3. Exclude Cambridge-covered: JOIN nli_images with cambridge_manifests ON normalized_shelfmark. Query: `SELECT DISTINCT i.NLI_AlmaId FROM nli_images i JOIN cambridge_manifests c ON c.normalized_shelfmark = i.Shelfmark`
    4. Exclude Manchester-covered: JOIN nli_images with manchester_luna ON ImageSourceName (case-insensitive). Query: `SELECT DISTINCT i.NLI_AlmaId FROM nli_images i JOIN manchester_luna m ON LOWER(i.ImageSourceName) = m.image_source_name`
    5. Exclude JTS-covered: JOIN nli_images with jts_dpul ON Shelfmark. Query: `SELECT DISTINCT i.NLI_AlmaId FROM nli_images i JOIN jts_dpul j ON j.shelfmark = i.Shelfmark`
    6. Load oxford_full_db.json with json.load(). Extract keys as Oxford sys_ids. NOTE: Inspect key format first -- may be sys_id or shelfmark. If keys are shelfmarks, need to cross-reference via nli_images.Shelfmark instead of direct sys_id match.
    7. Return `nli_sysids - cambridge_covered - manchester_covered - jts_covered - oxford_covered`

    **Function `get_library_breakdown(crossref_db_path, nli_only_sysids)`:**
    1. For each NLI-only sys_id, query: `SELECT library_code, COUNT(DISTINCT NLI_AlmaId) as manuscripts, COUNT(*) as image_rows FROM nli_images WHERE NLI_AlmaId IN (...) GROUP BY library_code`
    2. NOTE: For large sets, use temp table approach: INSERT nli_only sys_ids into temp table, then JOIN. SQLite handles this better than 44K-item IN clause.
    3. Also compute: total image rows, average images per manuscript, count of sys_ids with zero FGPImageNumberId

    **Function `get_sample_fl_ids(crossref_db_path, nli_only_sysids, n=500)`:**
    1. Select n random NLI-only sys_ids (stratified by library if possible -- ensure RNL, BL, Mosseri, AIU all represented)
    2. For each, get all nli_images rows including FGPImageNumberId
    3. Flag which ones need manifest fetch (FGPImageNumberId is empty)
    4. Return list of dicts: {sys_id, library_code, shelfmark, fgp_ids: [...], needs_manifest: bool}

    **CLI (argparse):**
    - `--crossref-db` (default: `nli_crossref_data/nli_crossref.db`)
    - `--oxford-json` (default: `oxford_full_db.json`)
    - `--output` (default: stdout, or JSON file path)
    - `--sample N` (optional: output N random FL IDs for rate testing)

    **Output format (JSON to stdout or file):**
    ```json
    {
      "total_nli_sysids": 253103,
      "nli_only_count": 44705,
      "excluded": {"cambridge": N, "manchester": N, "jts": N, "oxford": N},
      "library_breakdown": [
        {"library_code": "RNL", "manuscripts": 16332, "image_rows": 271476, "avg_per_ms": 16.6, "no_fgp_count": 16332}
      ],
      "total_image_rows": 347435,
      "no_fgp_manuscripts": 14436,
      "no_fgp_percentage": 32.3
    }
    ```

    Follow existing script conventions from build_ie_volume_map.py: pathlib for paths, argparse for CLI, tqdm for progress bars, print statements for key results.
