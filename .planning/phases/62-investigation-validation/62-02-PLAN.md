    **Script 1: `scripts/nli_rate_test.py`** (per D-01 through D-04)

    Purpose: Two-phase rate tester that (a) resolves FL IDs from manifests, (b) measures pure image-fetch rate separately. Addresses review concern #2 -- manifest resolution and image fetch are measured independently.

    **PHASE 1: FL ID Resolution `resolve_fl_ids(session, sample_manuscripts, output_dir, rate_limit=1.0)`**
    - Input: list of sample manuscript dicts from get_sample_fl_ids (each has sys_id, needs_manifest, fgp_ids)
    - For each manuscript, fetch IIIF manifest at `https://iiif.nli.org.il/IIIFv21/DOCID/PNX_MANUSCRIPTS{sys_id}-1/manifest`
    - Extract FL IDs from `sequences[0].canvases[*].images[0].resource.service.@id` using regex `r'FL(\d+)'`
    - If manifest returns error, try suffix `-2` (some manuscripts have multiple IEs)
    - Rate limit at `rate_limit` req/sec (default 1.0 -- conservative for manifests)
    - Save resolved FL IDs to `{output_dir}/_resolved_fl_ids.json`:
      ```json
      {"sys_id_1": ["12345", "12346"], "sys_id_2": ["67890"], ...}
      ```
    - Log manifest resolution stats: total manifests fetched, success/fail count, avg response time
    - This phase is NOT timed as part of the image rate test -- it is infrastructure

    **PHASE 2: Image Rate Test `test_rate(session, fl_ids, rate, width, output_dir, csv_writer)`**
    (Addresses review concern #2 -- measures PURE image-fetch rate using pre-resolved FL IDs)
    - `fl_ids`: flat list of pre-resolved FL ID strings (from Phase 1 output)
    - `rate`: requests per second (float)
    - `width`: image width in pixels (800 or 1200)
    - `interval = 1.0 / rate`
    - Loop through fl_ids for PLATEAU_DURATION = 300 seconds (5 minutes per D-02a)
    - For each: GET `https://iiif.nli.org.il/IIIFv21/FL{fl_id}/full/{width},/0/default.jpg` with timeout=30s
    - Abort on HTTP 429 or 403 (per D-03)
    - Abort on 3+ consecutive timeouts >30s (per D-03)
    - Save successful images to `output_dir/{width}px/FL{fl_id}.jpg` (reused by storage sampling)
    - Track per request: timestamp, fl_id, http_status, response_time_ms, file_size_bytes, error_type
    - **Per-request CSV logging** (addresses review concern #4):
      Write each request to CSV via `csv_writer` with columns:
      `timestamp,fl_id,width,http_status,response_time_ms,file_size_bytes,error_type`
      CSV file: `{output_dir}/_rate_test_log_{width}px.csv`
    - Return dict: `{rate, width, successes, errors, error_rate, avg_response_ms, median_response_ms, p95_response_ms, avg_size_bytes, status, duration_sec}`
    - Status: "OK" (completed plateau), "ABORT_429", "ABORT_403", "ABORT_TIMEOUT"

    **Main ramp-up function `run_ramp_test(fl_ids, width, output_dir)`:**
    - Rates per D-02: [1, 2, 4, 8] req/sec
    - For each rate: run test_rate for 5 minutes
    - If test_rate returns abort status, record last successful rate as plateau
    - Between rates: 60-second cooldown
    - After all rates or abort: write `_rate_test_results_{width}px.json` with all rate results
    - Print summary table with rate / successes / errors / error_rate / avg_ms / median_ms / p95_ms / status

    **Sample unit definition** (addresses review concern #5):
    Document clearly in script docstring and help text:
    - "Image" = one FL-ID page download (a single JPEG file)
    - "Manuscript" = one sys_id which may have 1-20+ images/pages
    - "1000+ images" target = download ~500 manuscripts x avg ~2 pages x 2 resolutions = ~2000 individual image downloads
    - The rate test measures individual image downloads per second, not manuscripts per second

    **CLI (argparse):**
    - `--crossref-db` (default: auto-detect `nli_data/nli_crossref.db`)
    - `--oxford-json` (default: `oxford_full_db.json`)
    - `--output-dir` (default: `_nli_cache_test/`)
    - `--width` (default: 800, choices: [800, 1200])
    - `--fl-ids-file` (optional: pre-resolved FL IDs JSON -- skips Phase 1)
    - `--dry-run` (validate script logic without network -- use mock responses: 200 status, random 50-200KB, 100-500ms simulated delay)
    - `--max-manifests N` (default: 50 -- limit manifest resolution)
    - `--sample-count N` (default: 200 -- how many FL IDs to use in rate test)
    - `--seed INT` (default: 42 -- passed to get_sample_fl_ids for reproducibility)

    **Dry-run mode:** Replace HTTP calls with simulated responses. Print "[DRY RUN]" prefix on all output. Generate realistic CSV log entries with simulated data.

    **Script 2: `scripts/nli_storage_sample.py`** (per D-07/D-07a)

    Purpose: Download the same 500+ NLI-only manuscripts at both 800px and 1200px for paired comparison. Compute statistics and cost projection.

    **Function `sample_images(crossref_db_path, oxford_json_path, output_dir, n_manuscripts=500, rate=2.0, seed=42)`:**
    1. Import `get_nli_only_subset` and `get_sample_fl_ids` from `nli_only_subset` (add scripts/ to sys.path if needed)
    2. Get NLI-only subset and sample n manuscripts with fixed seed
    3. Check for pre-resolved FL IDs from rate test (`{output_dir}/_resolved_fl_ids.json`); reuse if available
    4. For remaining, resolve FL IDs from manifests (same logic as rate test)
    5. For each FL ID: download at both 800px and 1200px widths
    6. Rate limit at `rate` req/sec (default 2.0 -- conservative, below expected plateau)
    7. Save to `output_dir/800px/FL{fl_id}.jpg` and `output_dir/1200px/FL{fl_id}.jpg`
    8. Reuse any images already downloaded by rate test (check file existence before fetching)
    9. Per-request CSV logging to `{output_dir}/_storage_sample_log.csv` (same format as rate test)

    **Function `compute_statistics(output_dir)`:**
    - For each resolution (800px, 1200px):
      - Total images downloaded (count .jpg files)
      - Total size (bytes, MB, GB)
      - Average file size, Median, Std deviation, Min, Max
      - Per-library breakdown (parse library from manifest metadata or companion JSON)
    - **Projection** (addresses review concern #5 -- explicit units):
      - Total NLI-only image rows (from subset script output, NOT manuscripts) x average file size = estimated total cache size in GB
      - Document: "~347K individual image pages, not ~44K manuscripts"
    - **Cost projection** (per D-16): `total_size_gb * $0.08` = monthly gp3 cost
    - Also compute: estimated fetch duration = total_images / plateau_rate_per_sec / 3600 = hours

    **CLI (argparse):**
    - `--crossref-db`, `--oxford-json` (same defaults as subset script)
    - `--output-dir` (default: `_nli_cache_test/`)
    - `--manuscripts N` (default: 500)
    - `--rate` (default: 2.0 req/sec)
    - `--stats-only` (skip downloading, just compute stats from existing files in output-dir)
    - `--fl-ids-file` (optional: pre-resolved FL IDs JSON from rate test)
    - `--seed INT` (default: 42)

    **Output:** JSON stats file `{output_dir}/_nli_storage_stats.json`:
