    **Script 1: `scripts/nli_rate_test.py`** (per D-01 through D-04)

    Purpose: Conservative ramp-up rate tester that discovers the sustainable NLI IIIF fetch rate.

    **FL ID resolution (CRITICAL -- per Pitfall 1 from RESEARCH.md):**
    Before rate testing images, must resolve FL IDs from IIIF manifests. FGPImageNumberId is NOT a FL ID.
    - Function `resolve_fl_ids(session, sys_ids)`: For each sys_id, fetch manifest at `https://iiif.nli.org.il/IIIFv21/DOCID/PNX_MANUSCRIPTS{sys_id}-1/manifest`. Extract FL IDs from `sequences[0].canvases[*].images[0].resource.service.@id` using regex `FL(\d+)` on the service @id URL.
    - If manifest returns error, try suffix `-2` (some manuscripts have multiple IEs).
    - Save resolved FL IDs to `_rate_test_fl_ids.json` in output directory for reuse.
    - If `--fl-ids-file` is provided, load pre-resolved FL IDs instead of fetching manifests.

    **Rate test function `test_rate(session, fl_ids, rate, width, output_dir)`:**
    - `rate`: requests per second (float)
    - `width`: image width in pixels (800 or 1200)
    - `interval = 1.0 / rate`
    - Loop through fl_ids for PLATEAU_DURATION = 300 seconds (5 minutes per D-02a)
    - For each: GET `https://iiif.nli.org.il/IIIFv21/FL{fl_id}/full/{width},/0/default.jpg` with timeout=30s
    - Abort on HTTP 429 or 403 (per D-03)
    - Abort on 3+ consecutive timeouts >30s (per D-03)
    - Save successful images to `output_dir/{width}px/FL{fl_id}.jpg` (reused by storage sampling)
    - Track: successes, errors, consecutive_timeouts, response times, file sizes
    - Return dict: `{rate, width, successes, errors, error_rate, avg_response_ms, median_response_ms, avg_size_bytes, status}`
    - Status: "OK" (completed plateau), "ABORT_429" (rate limit), "ABORT_403" (forbidden), "ABORT_TIMEOUT" (consecutive timeouts)

    **Main ramp-up function `run_ramp_test(fl_ids, width, output_dir)`:**
    - Rates per D-02: [1, 2, 4, 8] req/sec
    - For each rate: run test_rate for 5 minutes
    - If test_rate returns abort status, record last successful rate as plateau
    - Between rates: 60-second cooldown
    - After all rates or abort: write `_rate_test_results_{width}px.json` with all rate results

    **CLI (argparse):**
    - `--crossref-db` (default: `nli_crossref_data/nli_crossref.db`)
    - `--oxford-json` (default: `oxford_full_db.json`)
    - `--output-dir` (default: `_nli_cache_test/`)
    - `--width` (default: 800, choices: [800, 1200])
    - `--fl-ids-file` (optional: pre-resolved FL IDs JSON)
    - `--dry-run` (validate script logic without network requests -- use mock responses)
    - `--max-manifests N` (default: 50 -- limit manifest resolution for testing)
    - `--sample-count N` (default: 200 -- how many FL IDs to use in rate test)

    **Dry-run mode:** When `--dry-run` is set, replace HTTP calls with simulated responses (200 status, random 50-200KB content, 100-500ms delay). This allows validating script logic without network access.

    **Output:** JSON results file per resolution + saved images in output directory.

    **Script 2: `scripts/nli_storage_sample.py`** (per D-07/D-07a)

    Purpose: Download the same 500+ NLI-only manuscripts at both 800px and 1200px for paired comparison.

    **Function `sample_images(crossref_db_path, oxford_json_path, output_dir, n_manuscripts=500)`:**
    1. Import `get_nli_only_subset` and `get_sample_fl_ids` from `nli_only_subset`
    2. Get NLI-only subset and sample n manuscripts (stratified by library per D-07)
    3. For each manuscript: resolve FL IDs from manifest (same logic as rate test, or reuse `_rate_test_fl_ids.json` if available)
    4. For each FL ID: download at both 800px and 1200px widths
    5. Rate limit: 2 req/sec (conservative, below expected plateau from rate test)
    6. Save to `output_dir/800px/FL{fl_id}.jpg` and `output_dir/1200px/FL{fl_id}.jpg`
    7. Reuse any images already downloaded by rate test (check file existence before fetching)

    **Function `compute_statistics(output_dir)`:**
    - For each resolution (800px, 1200px):
      - Total images downloaded
      - Total size (bytes, MB, GB)
      - Average file size
      - Median file size
      - Std deviation
      - Min/max
      - Per-library breakdown (group by library_code from manifest metadata)
    - Projection: (NLI-only image count from subset) * (average file size) = estimated total cache size
    - Cost projection: total_size_gb * $0.08/month (gp3 per D-16)

    **CLI (argparse):**
    - `--crossref-db`, `--oxford-json` (same defaults as subset script)
    - `--output-dir` (default: `_nli_cache_test/`)
    - `--manuscripts N` (default: 500)
    - `--rate` (default: 2.0 req/sec)
    - `--stats-only` (skip downloading, just compute stats from existing files in output-dir)
    - `--fl-ids-file` (optional: pre-resolved FL IDs JSON from rate test)

    **Output:** JSON stats file `_nli_storage_stats.json` with:
