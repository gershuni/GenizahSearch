<objective>
Move domain enrichment off the desktop main thread and make catalog detail lazy (fetched on button click, not page load).

Purpose: `on_search_finished` currently blocks the main thread with `_collect_result_domains()` (a batch SQLite query) before displaying any results. Moving this to a background worker lets results appear instantly while domain badges fill in asynchronously. Similarly, catalog detail is currently fetched eagerly during browse page load even though users rarely click the catalog button.

Output: New DomainEnrichmentWorker in gui_threads.py, updated on_search_finished and catalog button handlers in genizah_app.py.
</objective>
