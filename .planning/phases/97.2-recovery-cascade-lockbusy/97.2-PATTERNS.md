#### D. `_close_internal_writer_index` / `_reopen_internal_writer_index` — `:2622–2638` (REUSE AS-IS)

**Reusable asset.** Three sites in 97.2 reuse these:
1. D-01 — `genizah_core.py:6878–6896` temp-indexer close (call `_close_internal_writer_index()` on the temp indexer before discarding it).
2. R97.2-E `reset_my_library()` step 1 (close all handles before rmtree).

```python
def _close_internal_writer_index(self) -> None:
    """Close LocalIndexer's own _writer + _index handles before os.rename (LD-5)."""
    try:
        if self._writer is not None:
            try:
                self._writer.rollback()
            except Exception:
                pass
            self._writer = None
    except Exception:
        self._writer = None
    self._index = None

def _reopen_internal_writer_index(self) -> None:
    """Reopen _writer + _index after atomic swap so LocalIndexer can continue."""
    self._index = tantivy.Index(build_local_schema(), path=self._index_dir)
    self._writer = self._index.writer(heap_size=256 * 1024 * 1024)
```

Note: heap size differs between init (`15_000_000`) and reopen (`256 * 1024 * 1024`). The planner should keep the existing values — they are load-bearing for different call paths.

#### I. New `LocalIndexer.reset_my_library()` method (R97.2-E) — append near `discard_run`

**Analog 1:** `discard_run` at `:2905–3019` (multi-step protocol with rollback).
**Analog 2:** `rebuild_main_index_atomic` at `:2660–2813` (7-step protocol with rename + reload).

D-05 spec for the method body (6 steps):

```python
def reset_my_library(
    self,
    close_searcher_cb: Callable[[], None],
    reload_searcher_cb: Callable[[], None],
) -> dict:
    """Phase 97.2 R97.2-E — atomic LOCAL teardown + recreate + migrate.

    Steps (per CONTEXT D-05):
      1. Close all live handles (engine searcher + writer/index + SQLite conn).
      2. Atomic rename LOCAL_INDEX_DIR + LOCAL_LAB_INDEX_DIR -> .reset-quarantine-<ts>.
      3. Recreate empty directories.
      4. Schedule quarantine cleanup via pending_dir_cleanup (or shutil.rmtree
         ignore_errors fallback if SQLite is gone).
      5. Reinitialize self via __init__ — triggers migration ladder on fresh DB.
      6. Reload searcher.

    Returns dict of counts (quarantined_paths, reinit_ok).
    """
    import time as _time
    import shutil
    ts = int(_time.time())
    counts = {"quarantined": [], "reinit_ok": False}

    # Step 1: close all 7+1 handles
    close_searcher_cb()
    self._close_internal_writer_index()
    try:
        if hasattr(self._thread_local, "_conn") and self._thread_local._conn is not None:
            self._thread_local._conn.close()
            self._thread_local._conn = None
    except Exception:
        logger.exception("reset_my_library: SQLite close failed (continuing)")

    # Step 2: atomic rename aside
    quarantine_main = f"{self._index_dir}.reset-quarantine-{ts}"
    quarantine_lab = f"{self._lab_index_dir}.reset-quarantine-{ts}"
    try:
        self._retry_windows_rename(self._index_dir, quarantine_main)
        counts["quarantined"].append(quarantine_main)
    except OSError:
        logger.exception("reset_my_library: main rename failed")
        raise
    try:
        self._retry_windows_rename(self._lab_index_dir, quarantine_lab)
        counts["quarantined"].append(quarantine_lab)
    except OSError:
        logger.exception("reset_my_library: LAB rename failed (continuing)")

    # Step 3: recreate empty dirs
    os.makedirs(self._index_dir, exist_ok=True)
    os.makedirs(self._lab_index_dir, exist_ok=True)

    # Step 4: best-effort cleanup (SQLite file was inside quarantine_main, so we
    # can't INSERT into pending_dir_cleanup yet — fall back to direct rmtree)
    for qdir in counts["quarantined"]:
        try:
            shutil.rmtree(qdir, ignore_errors=True)
        except Exception:
            logger.exception("reset_my_library: rmtree %s failed", qdir)

    # Step 5: reinit via __init__ (triggers _run_migrations ladder)
    self.__init__(self._index_dir, self._lab_index_dir, self._db_path)
    counts["reinit_ok"] = True

    # Step 6: reload searcher
    reload_searcher_cb()
    return counts
```

The `_retry_windows_rename` at `:2603–2620` is already in place and handles the Windows access-denied retry shape — reuse as-is.
