- **One atomic git commit per cluster (7 commits total).** Forced leaf-first ordering:
  `browse_map_utils` → `text_normalize` → `variants` → `responsa` → `codicological` →
  `joins_manager` → `lists_manager`. Wave 0 (test scaffolding) for each cluster is folded into
  that cluster's commit — there is no separate Wave 0 commit.

  the full suite before each of the 7 commits. Full-suite command: `pytest tests/ -q`; locally
  set `GITHUB_ACTIONS=true QT_QPA_PLATFORM=offscreen` to avoid the PyQt6 headless segfault, and do
  NOT use `-n auto` (it OOMs loading Tantivy per worker). The quick gate
  `pytest tests/test_no_back_edges_core.py tests/test_responsa_core.py tests/test_shelfmark_bridge.py
  -x -q` (<30s) is the per-task fast loop.

  breaks every `from genizah_core import …` caller (Pitfall 4). Use ONLY per-file
  `python -m ruff check <file>` on each new module + `genizah_core.py` before committing.

  `genizah_core.py` is ~12.5K lines and shifts constantly; line numbers were verified 2026-06-25
  but drift. Use `grep -n "def <name>"` / `grep -n "class <name>"` to find the exact range, then
  Read that range before copying.
- **The same-object shim recipe (proven Phase 122):** (1) copy the implementation VERBATIM into the
  new `shared/X.py` (GUARD-01-clean: NO module-level `import genizah_core` / `from genizah_core
  import …`); (2) in `genizah_core.py` REPLACE the original def(s) with `from shared.X import …
