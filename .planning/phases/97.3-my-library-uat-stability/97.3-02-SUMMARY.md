## Decisions Made

- **`getattr` defensive read in `_auto_rescan_on_startup`:** the plan's literal text said `if self._skip_startup_rescan_once:`. I used `if getattr(self, "_skip_startup_rescan_once", False):` instead. Rationale: behavioural equivalent when the attribute is initialised in `__init__` (which it always is post-Edit 1), but defensive against any future `__init__` ordering change that might delete Edit 1 by accident. Test 1 ensures the attribute exists, so this defensive form does NOT mask bugs.
- **D-08 message wrapped in `try/except`:** the parent window in unit-test scenarios is often `None` (the `_make_tab` fixture passes `parent=None`), so a future test that monkeypatches `_show_recovery_modal` Skip path must not crash on `statusBar()` access. The `try/except` with `logger.debug` fallback handles this gracefully; the user-visible code path always has a real parent.
