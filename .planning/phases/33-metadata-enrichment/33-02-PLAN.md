**A. FjmsService methods** (add to `shared/fjms_service.py`):

1. `get_bibliography(self, sys_id: str) -> list[dict]`:
   - Query: `SELECT * FROM bibliography WHERE AlmaId = ? ORDER BY CASE MentionType WHEN 'Discussion' THEN 0 WHEN 'Mentioned' THEN 1 ELSE 2 END, RunningTitle`
   - Return list of dicts with keys: running_title, title_year, title_acronym, mention_page, from_page, to_page, volume, mention_type, transcription_type, translation_type, article_name, article_author_eng, article_author_heb, catalog_acronym
   - Follow existing error-handling pattern (if conn is None return [], try/except -> log + return [])
   - Wrap in try/except to handle missing table (old sidecar without bibliography table)

2. `get_catalog_refs(self, sys_id: str) -> list[dict]`:
   - Query: `SELECT * FROM catalog_refs WHERE AlmaId = ? ORDER BY CatAcronym, CatalogEntry`
   - Return list of dicts with keys: cat_acronym, catalog_author, catalog_title, catalog_entry, is_source
   - Same error-handling pattern with missing-table graceful degradation

3. `get_source_names(self, sys_id: str) -> list[str]`:
   - Query: `SELECT DISTINCT SourceName FROM catalog WHERE AlmaId = ? AND SourceName IS NOT NULL AND SourceName != ''`
   - Filter out generic labels: `GENERIC_SOURCE_NAMES = {'Catalogs', 'Institution', 'Collection', 'Other'}`
   - Return list of non-generic SourceName strings
   - Used for displaying scholarly source classification beyond domain

**B. NliCrossrefService methods** (add to `shared/nli_crossref_service.py`):

1. `get_is_not_genizah(self, sys_id: str) -> bool`:
   - Query: `SELECT 1 FROM nli_images WHERE NLI_AlmaId = ? AND IsNotGenizah = 'True' LIMIT 1`
   - Return True if any row found, False otherwise
   - Use try/except, return False on error

2. `get_catalog_entry(self, sys_id: str) -> Optional[str]`:
   - Query: `SELECT DISTINCT CatalogEntry FROM nli_images WHERE NLI_AlmaId = ? AND CatalogEntry != '' LIMIT 1`
   - Return the CatalogEntry string (e.g., "Neubauer - Cowley 2603.1") or None
   - All values are Oxford Neubauer-Cowley references

3. `get_collection_storage(self, sys_id: str) -> Optional[dict]`:
   - Query: `SELECT DISTINCT CollectionName, OBBox, OBVolume, OBFolio FROM nli_images WHERE NLI_AlmaId = ? AND (CollectionName != '' OR OBBox != '' OR OBVolume != '' OR OBFolio != '') LIMIT 1`
   - Return dict with keys: collection_name, ob_box, ob_volume, ob_folio
   - Return None if no non-empty data found
