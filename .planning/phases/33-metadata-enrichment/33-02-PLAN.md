**FjmsService (shared/fjms_service.py) -- add 2 new methods:**

1. `get_bibliography(self, sys_id: str) -> list[dict]`:
   - Query: JOIN bibliography b with code_title t ON b.TitleId=t.TitleId, LEFT JOIN bib_authors ba ON b.UnitBibliographyReferenceId=ba.UnitBibliographyReferenceId, LEFT JOIN code_author a ON ba.AuthorId=a.AuthorId WHERE b.AlmaId=?
   - Group results: first query bibliography rows, then batch-fetch article authors per UnitBibliographyReferenceId
   - Actually, simpler approach: two queries:
     a. Main bibliography query: `SELECT b.*, t.RunningTitleEng, t.FullTitleEng, t.FullTitleHeb, t.AcronymEng, t.TitleYearEng, t.CityEng FROM bibliography b LEFT JOIN code_title t ON b.TitleId = t.TitleId WHERE b.AlmaId = ?`
     b. For each distinct UnitBibliographyReferenceId, batch query: `SELECT ba.UnitBibliographyReferenceId, a.EngDesc, a.HebDesc, ba.AuthorOrder FROM bib_authors ba JOIN code_author a ON ba.AuthorId = a.AuthorId WHERE ba.UnitBibliographyReferenceId IN (...) ORDER BY ba.AuthorOrder`
   - Return list of dicts with keys: title_eng (RunningTitleEng or FullTitleEng), title_heb (FullTitleHeb), acronym (AcronymEng), year (TitleYearEng), city (CityEng), mention_page, mention_type (map 1035->"Discussion", 2035->"Mentioned", 3035->"Index"), transcription (map 1036->"Full", 2036->None, 3036->"Partial", 4036->"Exists"), translation (same mapping), article_name, volume, authors (list of {eng, heb} sorted by AuthorOrder)
   - Graceful error handling: return [] on error, handle missing code_title/code_author tables (may not exist in old sidecars)

2. `get_catalog_refs(self, sys_id: str) -> list[dict]`:
   - Query: `SELECT cr.CatalogEntry, cc.CatAcronym, cc.Author as CatalogAuthor, cc.Title as CatalogTitle FROM catalog_refs cr LEFT JOIN code_catalog cc ON cr.CatalogCode = cc.CatalogId WHERE cr.AlmaId = ?`
   - Return list of dicts with keys: catalog_entry, catalog_acronym, catalog_author, catalog_title
   - Group by catalog_acronym for display (e.g., "Baker/Polliack #1234")
   - Graceful error handling: return [] on error or missing tables

**NliCrossrefService (shared/nli_crossref_service.py) -- add 1 new method:**

3. `get_nli_metadata(self, sys_id: str) -> Optional[dict]`:

   - Return None if not found
   - Graceful error handling same pattern as get_physical_metadata
