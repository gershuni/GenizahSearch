<feature>
  <name>Search Diacritics Stripping (strip_search_diacritics)</name>
  <files>genizah_core.py, tests/test_search_normalization.py</files>
  <behavior>
    Function: strip_search_diacritics(text: str) -> str

    Strips the following from input text:
    1. All Unicode combining diacritical marks in range U+0300 to U+036F
    2. Hebrew geresh (U+05F3 / ׳)
    3. Hebrew gershayim (U+05F4 / ״)

    Does NOT strip:
    - Hebrew nikud/vowel points (U+05B0-U+05BD, U+05BF, U+05C1-U+05C2, U+05C4-U+05C5, U+05C7)
      (nikud stripping already exists via NIKUD_PATTERN and is handled separately)
    - Hebrew base letters (U+05D0-U+05EA)
    - Hebrew final letters
    - Latin characters, digits, spaces, or standard punctuation

    Test cases (input -> expected output):
    - "te\u0301st" -> "test"  (combining acute accent removed)
    - "cafe\u0300" -> "cafe"  (combining grave accent removed)
    - "שלום" -> "שלום"  (Hebrew unchanged)
    - "word" -> "word"  (ASCII unchanged)
    - "ר׳ יהודה" -> "ר יהודה"  (geresh removed)
    - "חז״ל" -> "חזל"  (gershayim removed)
    - "ר׳ שמואל בר חז״ל" -> "ר שמואל בר חזל"  (both removed)
    - "" -> ""  (empty string)
    - "a\u0300\u0301b\u0302c" -> "abc"  (multiple stacked marks)
    - "שלו\u0308ם" -> "שלום"  (combining mark on Hebrew letter)
  </behavior>
  <implementation>
    Place the function in genizah_core.py near the existing utility functions (after expand_judeo_arabic ~line 4433, before _SOFIT_TO_NORMAL). Use a compiled regex pattern stored as a module-level constant:

    COMBINING_DIACRITICALS_PATTERN = re.compile(r'[\u0300-\u036F\u05F3\u05F4]')

    def strip_search_diacritics(text: str) -> str:
        """Strip combining diacritical marks and geresh/gershayim from search text."""
        if not text:
            return text
        return COMBINING_DIACRITICALS_PATTERN.sub('', text)
  </implementation>
</feature>

<feature>
  <name>Mark-Tolerant Regex Pattern (make_mark_tolerant_pattern)</name>
  <files>genizah_core.py, tests/test_search_normalization.py</files>
  <behavior>
    Function: make_mark_tolerant_pattern(escaped_term: str) -> str

    Takes an already re.escape()-d term and inserts optional combining mark
    matchers between each character, so that the regex will match even when
    the source text contains combining diacritical marks between base letters.

    Inserts the pattern [\u0300-\u036F]* between each character of the escaped term.

    Test cases (input -> expected output pattern -> matches):
    - re.escape("שלום") -> pattern matches "שלום" (no marks)
    - re.escape("שלום") -> pattern matches "ש\u0300ל\u0301ו\u0302ם" (marks between each letter)
    - re.escape("test") -> pattern matches "te\u0308st" (mark in Latin text)
    - re.escape("abc") -> pattern matches "abc" and "a\u0300b\u0301c"
    - "" -> "" (empty string)

    The function should NOT insert matchers inside escaped sequences (e.g., re.escape("a.b")
    produces "a\\.b" -- the matcher should go between "a", "\\.", and "b" not between "\\" and ".").

    Implementation approach: Since re.escape() produces individual escaped chars where special
    chars become \\X (2-char sequences), we need to handle this properly. Use a regex to split
    the escaped string into logical tokens (either \\X escape sequences or single chars), then
    join with the optional mark pattern.
  </behavior>
  <implementation>
    Place immediately after strip_search_diacritics in genizah_core.py.

    MARK_TOLERANT_INSERTER = '[\u0300-\u036F]*'

    def make_mark_tolerant_pattern(escaped_term: str) -> str:
        """Insert optional combining mark matchers between characters of an escaped regex term.

        Takes an re.escape()-d string and returns a pattern that matches the same
        text even when combining diacritical marks (U+0300-U+036F) appear between
        base characters in the source text.

        Args:
            escaped_term: A regex-escaped string (output of re.escape())

        Returns:
            Modified pattern string with optional mark matchers between each logical char
        """
        if not escaped_term:
            return escaped_term
        # Split escaped string into tokens: \\X (escape sequences) or single chars
        tokens = re.findall(r'\\.|.', escaped_term)
        return MARK_TOLERANT_INSERTER.join(tokens)
  </implementation>
</feature>
