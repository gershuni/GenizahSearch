```python
def strip_search_diacritics(text: str) -> str:
    """Strip combining diacritical marks, apostrophe variants, and geresh/gershayim from search text.

    Removes:
    - Combining diacritical marks (U+0300-U+036F)
    - ASCII apostrophe (U+0027)
    - Hebrew geresh (U+05F3)
    - Hebrew gershayim (U+05F4)
    - Curly single quotes (U+2018, U+2019)

    Preserves:
    - Hebrew base letters, nikud/vowel points, Latin chars, digits, punctuation
    """
```

**Why these specific characters:**
- U+0027: ASCII apostrophe ' (most common keyboard input)
- U+2018: Left single quotation mark ' (curly)
- U+2019: Right single quotation mark ' (curly)
- U+05F3: Hebrew geresh ׳ (already present)
- U+05F4: Hebrew gershayim ״ (already present)

**Reasoning:** The whitespace tokenizer keeps punctuation attached to words, so הקב'ה and הקבה become different tokens. Users predominantly type ASCII apostrophes, but documents contain mixed mark types. Normalizing all variants maximizes recall.
