✓ What changed (your notes → how it's addressed)
  • Minimalist: options/modifiers/filters hidden behind buttons; only the query + results show by default.
  • Anchor pane ~30%, resizable (QSplitter — drag the ⋮ grip).
  • 4 icons → anchor side, no text: 📖 / 🧩 / ☰ / 🔗 (tooltips only) act on the anchor.
  • Per-line ⚙: modifiers + ⊢/⊣ start/end in the ⚙ dialog; the gap ↓N is a compact inline control on each line (no extra row).
  • Bulk Browse single-only: 📖 is disabled unless exactly one item is checked.
  • Filter shows the current fragment (library/material/size/lines) + "from anchor" shortcuts.
  • Global "Search options" button: variants / Judeo-Arabic / flex / bidirectional.
  • Typed signs + tooltip ⓘ: boxes accept #/%/*/−; ⓘ shows the legend.
  • "This side" / self-match line / "include anchor" — removed.
  • "search also on the other side" (keeps AND-narrow / OR-widen).
  • Filter → button (popover), not an always-on row.
  • "Browse results ▶" prominent by Grid/Table → stepping compare window.
  • Grid actions = icons (tooltips), not text. Right-click context menu on grid/table.
  • Grid & table both have checkboxes → one shared bulk-action bar above the results.
  • Add to Puzzle adds the anchor too (in cards, table, and Compare).
