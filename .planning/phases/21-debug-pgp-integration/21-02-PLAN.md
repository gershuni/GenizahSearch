**Create the SQL migration file** at `migrations/add_sections_column.sql`:

```sql
-- Add structured sections column to document_sources
-- Stores per-canvas section data parsed from pgp-text HTML files
-- Format: [{"canvas_url": "...", "canvas_num": 1, "label": null, "text": "..."}]
ALTER TABLE document_sources ADD COLUMN IF NOT EXISTS sections JSONB;

-- Also add language and direction metadata from HTML section element
ALTER TABLE document_sources ADD COLUMN IF NOT EXISTS source_language TEXT;
ALTER TABLE document_sources ADD COLUMN IF NOT EXISTS source_direction TEXT;

COMMENT ON COLUMN document_sources.sections IS
    'Structured section data from pgp-text HTML: [{canvas_url, canvas_num, label, text, subsections}]';
```

**Create the import script** at `scripts/import_pgp_sections.py`:

Follow the patterns from `scripts/import_pgp_full.py` (argparse CLI, dry-run default, tqdm progress, dotenv loading, verification report).

The script must:

1. **Clone or update pgp-text repo** to `pgp_data/pgp-text/`. Use `subprocess.run(['git', 'clone', '--depth', '1', 'https://github.com/princetongenizalab/pgp-text.git', target_dir])` for first clone. If directory exists, do `git -C target_dir pull`.

2. **Scan for HTML files** using `glob.glob('pgp_data/pgp-text/*/*/PGPID*.html')`. Parse filenames with regex `r'PGPID(\d+)_s(\d+)_(.+)_(transcription|translation)\.html'` to extract pgpid, source_id (for logging only), author_slug, and type.

3. **Group by PGPID.** Build dict `{pgpid: [file_paths]}`. For each pgpid, prefer edition (`_transcription.html`) over translation. If multiple editions exist, parse each and use the one with the most sections (most canvases). Also import translations separately.

4. **Parse each HTML file** using `parse_html_sections()` from `shared.document_service` (implemented in Plan 01). This returns `{'sections': [...], 'language': str, 'direction': str}`.

5. **Load existing document_sources** from Supabase. Fetch all records: `client.table('document_sources').select('pgpid, source_scholar, doc_relation').execute()`. Build lookup: `{pgpid: [source_records]}`.

6. **Match strategy** (apply for each pgpid):
   - Get all HTML files for this pgpid
   - For each `_transcription.html` file: parse sections, apply to ALL "Digital Edition" sources for that pgpid (same physical manuscript structure)
   - For each `_translation.html` file: parse sections, apply to ALL "Digital Translation" sources for that pgpid
   - This is correct because section structure is a property of the physical manuscript, not the scholarly edition
   - Log unmatched pgpids (in pgp-text but not in our DB)

7. **Build update batches.** For each matched source record, create update dict:
   ```python
   {
       'pgpid': pgpid,
       'source_scholar': source_record['source_scholar'],
       'doc_relation': source_record['doc_relation'],
       'sections': parsed_result['sections'],
       'source_language': parsed_result['language'],
       'source_direction': parsed_result['direction'],
   }
   ```

8. **Execute updates in batches** (batch size 500). Use Supabase `.upsert()` with `on_conflict='pgpid,source_scholar,doc_relation'` to update only the new columns. This matches the existing unique constraint on document_sources.

9. **Dry-run mode** (default, `--dry-run`): Parse all files and report statistics but do NOT write to database. `--execute` flag triggers actual writes.

10. **Verification report**: Write to `pgp_data/sections_import_report.txt`:
    - Total HTML files found (by type: transcription vs translation)
    - Successfully parsed
    - Matched to document_sources records
    - Unmatched pgpids (in pgp-text but not in DB)
    - Unmatched sources (in DB but no pgp-text HTML)
    - Sections column update count
    - Sample of parsed sections (first 3 pgpids)

Script entry point:
```python
if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='Import PGP sections from pgp-text HTML')
    group = parser.add_mutually_exclusive_group()
    group.add_argument('--dry-run', action='store_true', default=True, help='Validate without writing (default)')
    group.add_argument('--execute', action='store_true', help='Actually import data')
    parser.add_argument('--skip-clone', action='store_true', help='Skip git clone/pull (use existing repo)')
    args = parser.parse_args()
    main(dry_run=not args.execute, skip_clone=args.skip_clone)
```

Run: `python scripts/import_pgp_sections.py --dry-run` to verify it works (clones repo, parses files, reports statistics).
