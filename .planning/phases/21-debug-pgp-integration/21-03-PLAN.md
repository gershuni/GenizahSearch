**Update get_section_for_page in shared/document_service.py:**

Add an optional `sections` parameter to `get_section_for_page()`:

```python
def get_section_for_page(transcription: str, page_num: int, sections: list = None) -> Optional[str]:
    """
    Get the appropriate transcription section for a page number.

    Args:
        transcription: Full transcription text
        page_num: Page number (1 = recto, 2 = verso for single-fragment docs)
        sections: Optional structured sections from document_sources.sections JSONB.
                  List of dicts with canvas_url, canvas_num, label, text.
                  When provided, uses canvas_num matching instead of regex parsing.

    Returns:
        Section text for the page, None if no content exists for this page,
        or full transcription if no recto/verso markers found at all.
    """
```

Implementation:
1. If `sections` is provided and non-empty:
   - Look up section where `canvas_num == page_num`
   - If found, return that section's `text`
   - If not found (page_num > len(sections)), return full transcription
2. If `sections` is None or empty:
   - Fall through to existing regex-based `parse_transcription_sections()` logic (which now uses the fixed regex from Plan 01)

This is backward-compatible -- existing callers that don't pass `sections` get the regex fallback.
