from html.parser import HTMLParser

def parse_html_sections(html_content: str) -> dict:
    """
    Parse PGP HTML transcription into structured per-canvas sections.

    Args:
        html_content: HTML string from pgp-text repository

    Returns:
        Dict with:
        - 'sections': List of dicts, each with:
            - canvas_url (str): Full IIIF canvas URL
            - canvas_num (int): Canvas number extracted from URL
            - label (str|None): Section label from h3 (e.g., "Verso.", "Right margin")
            - text (str): Plain text content (lines joined with newlines)
        - 'language' (str|None): Language code from section element (e.g., "jrb", "he", "ar")
        - 'direction' (str|None): Text direction from section element ("rtl" or "ltr")
    """
```

Implementation approach:
- Use Python's built-in `html.parser.HTMLParser` (no new dependencies needed)
- Track state: current tag, current div's data-canvas, current h3 text, accumulating li texts
- When entering a `<section>` tag, capture `dir` and `lang` attributes
- When entering a `<div>` with `data-canvas` attribute, start a new section
- When entering `<h3>`, start capturing label text
- When entering `<li>`, start capturing line text
- When closing `</div>` that had data-canvas, finalize the section
- Extract canvas_num from canvas URL by finding the last numeric path segment using regex: `r'/(\d+)/?$'`
- Associate h3 labels with the next data-canvas div (h3 appears before div in HTML structure)

# CURRENT (broken):
section_pattern = re.compile(
    r'^(Recto|Verso)(?:\s*[-,]\s*[^\n]+)?[:\s]*\n',
    re.MULTILINE | re.IGNORECASE
)

# FIXED:
section_pattern = re.compile(
    r'^(Recto|Verso)\b[^\n]{0,60}\n',
    re.MULTILINE | re.IGNORECASE
)
```

The fix uses a simpler, more robust pattern:
- `\b` word boundary prevents matching "Rectory" or similar words
- `[^\n]{0,60}` matches up to 60 characters of any modifier (periods, parens, spaces, etc.)
- `\n` requires the marker to end at a newline (header line, not content)
- 60-char limit prevents matching content lines starting with "Recto"/"Verso"
