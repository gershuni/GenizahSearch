**GREEN phase -- Fix the regex:**

In `shared/document_service.py`, line 199-201, replace the current `section_pattern` regex:

```python
# CURRENT (broken):
section_pattern = re.compile(
    r'^(Recto|Verso)(?:\s*[-,]\s*[^\n]+)?[:\s]*\n',
    re.MULTILINE | re.IGNORECASE
)

# FIXED:
section_pattern = re.compile(
    r'^(Recto|Verso)\b[^\n]{0,60}\n',
    re.MULTILINE | re.IGNORECASE
)
```

The fix uses a simpler, more robust pattern:
- `\b` word boundary prevents matching "Rectory" or similar words
- `[^\n]{0,60}` matches up to 60 characters of any modifier (periods, parens, spaces, etc.)
- `\n` requires the marker to end at a newline (so it's a header line, not content)
- 60-char limit prevents matching content lines that happen to start with "Recto" or "Verso"
