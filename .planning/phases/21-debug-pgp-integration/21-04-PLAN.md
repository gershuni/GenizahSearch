**Root Cause from UAT:**
Desktop app's `_populate_pgp_combo` method (genizah_app.py:6070-6115) iterates translations in database sequence_order without language-based grouping. Web app (web/components/version_selector.py:256-264) explicitly groups Hebrew first, English second. When DB has English (seq 1) and Hebrew (seq 2), desktop shows English first under Hebrew label.

**Fix Direction:**
Add language-based grouping to desktop app matching web app behavior. Before iterating translations, split into language groups (Hebrew, English, other) and iterate in that order.

**Reference Implementation:**
Web app (version_selector.py:256-264) shows the correct pattern:
```python
hebrew_trans = [t for t in translations if t.get('language') == 'Hebrew']
english_trans = [t for t in translations if t.get('language') == 'English']
other_trans = [t for t in translations if t.get('language') not in ('Hebrew', 'English')]
```

           language = trans.get('language', '')
           label = f"  {language} - {scholar}" if language else f"  {scholar}"
