<objective>
Implement the LOCK-FREE crash emission foundation in `desktop/telemetry.py` (D-05) and the
top-frame-only, frame-walked crash payload builder (D-07), and reconcile `_ALLOWED_PROPS`.

Purpose: This is the D-05 BLOCKER core. The crash hook must read consent and distinct_id without
any lock (a crash while `set_consent()` holds `_state_lock`/`_enabled_lock` would otherwise
deadlock — violating SC#4 "no lock acquisition"). The payload must be built by walking traceback
frames (`co_filename` basename + `tb_lineno`) — never `traceback.format_exception`, never
`str(exc)` — so no message string, path, or query text can ever materialize (D-07 / CRASH-04).
These primitives MUST land before Plan 03's hook body that consumes them.

Output: `_is_enabled_nolock()`, `_crash_distinct_id`/`_in_crash_hook` snapshot/guard globals,
`_make_crash_props()`, `_emit_crash_direct()`, a reconciled `_ALLOWED_PROPS`, the snapshot write
wired into `set_consent`/`_set_current_distinct_id`, and `_reset_for_tests` extended.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| exception object → crash payload | Untrusted exception message / file paths / Hebrew content must NOT cross into the payload |
| failing thread holding a lock → crash hook | The hook must not acquire any lock the failing thread might already hold |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-113-04-MSG | Information Disclosure | exception message string (`FileNotFoundError: 'C:\\Users\\...'`, query text, Hebrew content) leaking into payload | mitigate | `_make_crash_props` receives only `exc_type`+`exc_tb`, never the value; NEVER calls `traceback.format_exception` or `str(exc)`; test_no_str_exc_in_emit_crash + test_no_forbidden_keys_in_payload |
| T-113-04-PATH | Information Disclosure | full `co_filename` path (instead of basename) in payload | mitigate | `os.path.basename()` only; `error_module='external'` for non-in-app frames; test_no_path_in_crash_props + test_external_module_fallback |
| T-113-04-ALLOW | Information Disclosure | a future free-ish prop (`traceback_scrubbed`/`thread_name`) leaking | mitigate | `_ALLOWED_PROPS` REMOVES both keys (D-07); `_validate_props` drops anything off-list; test_payload_keys_allowlisted asserts allowlist-only |
| T-113-05-DEADLOCK | Denial of Service | crash while `set_consent()` holds `_state_lock`/`_enabled_lock` deadlocks the hook | mitigate | `_is_enabled_nolock()` + `_crash_distinct_id` snapshot read lock-free; test_hook_acquires_no_locks |
| T-113-05-LOOP | Denial of Service | crash inside the crash handler loops forever | mitigate | module-level `_in_crash_hook` recursion guard; test_recursion_guard |
| T-113-SC | Tampering | npm/pip/cargo installs | accept | zero new packages (RESEARCH audit: none); stdlib only |
</threat_model>
