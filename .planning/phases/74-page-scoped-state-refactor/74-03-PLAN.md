<!-- Cat-1 conversion rule (from RESEARCH §4, verified from nicegui/events.py). -->

```python
# NiceGUI 3.8.0 handle_event:
result = handler(arguments) if expects_arguments else handler()
if isinstance(result, Awaitable) and not isinstance(result, AwaitableResponse):
    async def wait_for_result():
        with parent_slot:          # preserves slot context
            try: await result
            except Exception as e: core.app.handle_exception(e)
    background_tasks.create(wait_for_result(), name=str(handler))
# => return coro()  flows through this. asyncio.ensure_future(coro()) returns Task, bypasses parent_slot.
```

<!-- Single-coroutine Cat-1 conversion template: -->
```python
# BEFORE:
def on_foo_change(e=None):
    ...
    asyncio.ensure_future(recompute_fn())
    update_chip_fn()

# AFTER (Option B - async def, per PATTERNS §filter_panel):
async def on_foo_change(e=None):
    ...
    await recompute_fn()
    update_chip_fn()
```

<!-- Multi-coroutine Cat-1 conversion template (Pitfall 1): -->
```python
# BEFORE:
def on_domain_change(e=None):
    ...
    asyncio.ensure_future(refresh_author_fn())
    asyncio.ensure_future(refresh_work_fn())
    asyncio.ensure_future(recompute_fn())
    update_chip_fn()

# AFTER (aggregate async def):
async def on_domain_change(e=None):
    ...
    await refresh_author_fn()
    await refresh_work_fn()
    await recompute_fn()
    update_chip_fn()
```

<!-- Bare on_click lambda conversion: -->
```python
# BEFORE: on_click=lambda: asyncio.ensure_future(load_page(direction=-1))
# AFTER:  on_click=lambda: load_page(direction=-1)
```

<!-- Cat-2 comment template (stays as asyncio.ensure_future with justification): -->
```python
# Cat-2: deferred to next event loop tick to allow [container/select/DOM/client-context]
#        to mount. Cannot convert to bare return - NiceGUI's awaitable path does not
#        re-enter slot/client context.
asyncio.ensure_future(...)
```

<!-- Cat-3 comment template: -->
```python
# Cat-3: long-running owned task handle - intentionally detached.
search_state.update_timer = asyncio.ensure_future(_progress_update_loop())
```

<!-- Deterministic per-site classification rule (applied by executor in Task 1 Step 1 and Task 2 Step 1): -->
```
If the call is on a bare `lambda` event handler inside a UI element constructor
(on_click=lambda: asyncio.ensure_future(X()), etc.), it is Cat-1 -> convert to
bare awaitable return (on_click=lambda: X()).

If it is a detached dialog reopen / deferred slot-mount / client-context re-entry
(inside `with refs.page_client:` blocks, `_deferred_*` helpers, or before a
container has finished mounting), it is Cat-2 -> keep + add comment.

If it is a long-running owned task handle stored on state for later cancellation
(e.g., state.update_timer = asyncio.ensure_future(loop)), it is Cat-3 -> keep
+ add Cat-3 comment.
```
