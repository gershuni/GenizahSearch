  <action>
Create `scripts/preview_background_removal.py` -- a PyQt6 application window that exercises the shared puzzle_image_service pipeline:

1. **Layout**: Split view showing original image (left) and background-removed image (right), with controls at top.

2. **Image loading**:
   - Text field for FL ID input (e.g., "PNX_MANUSCRIPTS990001521050205171-1")
   - "Load" button that fetches image via `service.resolve_fragment_image(fl_id, size=1200, processed=False)` for original and `service.resolve_fragment_image(fl_id, size=1200, threshold=current_threshold)` for processed
   - Hardcoded dropdown of ~8 sample FL IDs from different libraries for quick testing:
     - 2 NLI images (gray backgrounds) -- e.g., FL IDs from known T-S fragments
     - 2 Cambridge images -- direct IIIF URLs (Cambridge doesn't use NLI FL IDs, so for these, fetch directly with requests.get and pass bytes to remove_background)
     - 2 Manchester images
     - 2 Oxford images (if available, cream backgrounds)
   - Dropdown selection triggers load

3. **Threshold control**:
   - QSlider from 5 to 150, default 30
   - Label showing current value
   - On slider change: re-run `remove_background(original_bytes, threshold=slider_value)` and update right panel (uses cached original bytes, re-processes on the fly without re-fetching)

4. **Toggle**: QPushButton to swap right panel between "stripped" (RGBA with transparent shown as checkerboard) and "original" views. This validates BGRM-02.

5. **Info panel**: Show detected background color (H, S, V values in 0-255 scale), whether low-saturation fallback was used (S < 30), foreground ratio, processing time in ms.

Implementation notes:
- Import `from shared.puzzle_image_service import PuzzleImageService` -- NOT from web/services.py (Finding 8)
- Import `from shared.background_removal import remove_background, detect_background_color, DEFAULT_THRESHOLD, LOW_SATURATION_THRESHOLD`
- Convert Pillow RGBA image to QPixmap for display: `Image.open(io.BytesIO(bytes))` -> `ImageQt.toqpixmap(img)` or manual conversion via `QImage(data, w, h, QImage.Format.Format_RGBA8888)`
- For transparent pixels, render a checkerboard pattern behind the RGBA image so user can see where background was removed. Create a 16x16 checkerboard tile (light gray + white) and tile it behind the RGBA image.
- Run background removal in main thread (acceptable for a dev tool -- images are ~1200px, processing takes 1-3 seconds)
- Add `sys.path.insert(0, project_root)` at top for shared imports
- Window title: "Background Removal Preview - Fragment Puzzle"
- Initial window size: 1400x800
