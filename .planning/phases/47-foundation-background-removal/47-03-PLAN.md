   - Text field for FL ID input (e.g., "PNX_MANUSCRIPTS990001521050205171-1")
   - "Load" button that fetches image via `requests.get(build_iiif_image_url(fl_id, width=1200))`

     - 2 Manchester images (via Manchester URLs)
     - 2 Oxford images (if available)
   - Dropdown or buttons to load each sample quickly

3. **Threshold control**:
   - QSlider from 5 to 150, default 30
   - Label showing current value
   - On slider change: re-run `remove_background(image_bytes, threshold=slider_value)` and update right panel

4. **Toggle**: Button to swap right panel between "stripped" (RGBA with transparent shown as checkerboard) and "original" views

5. **Info panel**: Show detected background color (RGB), foreground ratio, processing time

- Convert Pillow RGBA image to QPixmap for display: `Image -> QImage -> QPixmap`
- For transparent pixels, render a checkerboard pattern behind the RGBA image so user can see where background was removed
- Run background removal in main thread (acceptable for a dev tool -- images are ~1200px, processing takes 1-3 seconds)
- Import `from shared.background_removal import remove_background, detect_background_color, DEFAULT_THRESHOLD`
- Import `from web.services import build_iiif_image_url` for NLI URLs
