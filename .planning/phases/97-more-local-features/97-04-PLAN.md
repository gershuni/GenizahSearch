Reviewer fold-ins:
- **Codex MEDIUM #3 + ADVICE LD-9:** Folder counter aggregation uses `local_files.folder_id` (relational key) + `local_files.extraction_status` (UI source of truth per LD-9). The earlier `processed_files.status` + `WHERE filepath LIKE folder_path || '%'` approach has TWO bugs: (1) `processed_files.status='committed'` for files with extraction errors (the `_commit_batch` mass-UPDATE sets all pending rows to committed regardless of per-file extraction outcome); (2) `LIKE 'C:\foo%'` matches `C:\foobar` too. The replacement query JOINs local_files on folder_id and aggregates extraction_status.
- **Codex MEDIUM #4:** Counter query includes status codes `oversized` / `zip_bomb_suspected` / `encoding_error` / `changed_during_index` / `unreachable` / `timeout`. Wave B introduced oversized/zip_bomb; Wave F adds the rest. The query lists all codes explicitly so it survives partial parallel landings.

```sql
-- For each folder touched by this batch, recompute counters from local_files.
UPDATE folders SET
    indexed_count = (
        SELECT COUNT(*) FROM local_files
        WHERE folder_id = folders.folder_id
          AND extraction_status IN ('ok', 'committed')
    ),
    error_count = (
        SELECT COUNT(*) FROM local_files
        WHERE folder_id = folders.folder_id
          AND extraction_status IN ('error', 'encoding_error', 'changed_during_index', 'no_text_layer')
    ),
    pending_count = (
        SELECT COUNT(*) FROM local_files
        WHERE folder_id = folders.folder_id
          AND extraction_status = 'pending'
    ),
    oversized_count = (
        SELECT COUNT(*) FROM local_files
        WHERE folder_id = folders.folder_id
          AND extraction_status IN ('oversized', 'zip_bomb_suspected')
    ),
    last_aggregate_at = strftime('%s', 'now')
WHERE folder_id IN (
    SELECT DISTINCT folder_id FROM local_files
    WHERE filepath IN (?, ?, ..., ?)
);
```
Note: SQLite query uses correlated subqueries; the IN-clause is parameterized with the touched filepaths from this commit batch.

       class PrescanWorker(QThread):
           """Phase 97 C-03 — folder walk off the UI thread."""
           finished_signal = pyqtSignal(int, int)  # file_count, total_bytes
           error_signal = pyqtSignal(str)

           def __init__(self, indexer, folder_path: str) -> None:

           def run(self) -> None:

                       self._folder_path,
                       cancel_check=lambda: self._cancel,

               except Exception as exc:
                   logger.exception("PrescanWorker")
                   self.error_signal.emit(str(exc))
