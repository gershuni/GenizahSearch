       ```python
       class PrescanWorker(QThread):
           """Phase 97 C-03 — folder walk off the UI thread.
           Emits filesystem-metadata-only results so existing _check_ceiling_*
           branches still work but no longer freeze the UI on large trees.
           """
           finished_signal = pyqtSignal(int, int)  # file_count, total_bytes
           error_signal = pyqtSignal(str)

           def __init__(self, indexer, folder_path: str) -> None:
               super().__init__()
               self._indexer = indexer
               self._folder_path = folder_path
               self._cancel = False

           def cancel(self) -> None:
               self._cancel = True

           def run(self) -> None:
               try:
                   file_count, total_bytes = self._indexer.prescan_count(
                       self._folder_path,
                       cancel_check=lambda: self._cancel,
                   )
                   self.finished_signal.emit(file_count, total_bytes)
               except Exception as exc:
                   logger.exception("PrescanWorker")
                   self.error_signal.emit(str(exc))
       ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI thread -> filesystem walk | Long os.walk on 50K-file trees freezes the UI; must move off-thread |
| commit-batch atomicity | counter UPDATE must be inside the existing synchronous=FULL transaction or counters can drift on crash |
| user disk -> Tantivy merge scratch | Mid-indexing Tantivy segment merges can spike disk use 2-3×; without headroom warning, user runs out of disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-97D-01 | Denial of Service | UI thread doing os.walk on 50K files | mitigate | PrescanWorker QThread + QProgressDialog with Cancel; cancel_check threaded into LocalIndexer.prescan_count |
| T-97D-02 | Tampering | folder counters out of sync with processed_files | mitigate | counter UPDATE inside same BEGIN IMMEDIATE transaction as the status='committed' UPDATE (Wave A R-04 bracket); guarantees atomicity |
| T-97D-03 | Denial of Service | Disk exhaustion mid-indexing | mitigate | Live indicator with 2× merge-headroom reservation + 1 GB safety margin; warning fires preemptively |
