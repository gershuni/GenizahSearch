<objective>
Add a 3-state post-search PGP filter toggle to the web `/search` results toolbar — modeled DIRECTLY on the existing `printed_filter` pattern at `web/pages/search.py:1402-1434`. Plus an active-filter chip co-located with `exclusion_chips_row` for at-a-glance visibility, plus session persistence via `web/safe_storage.py`. The PGP filter must be applied in EVERY post-search render branch (no bypass paths).

Purpose: Power users frequently want to either restrict their search results to manuscripts with PGP transcriptions (so they can dig into the text) or specifically hide those (so they can look for manuscripts that LACK transcriptions and may benefit from one). The existing `transcription_sys_ids` set on `SearchUIState` already encodes "this result has PGP" — this phase surfaces that signal as a user-facing post-search filter. Strict parity with `printed_filter`: same cycle, same toolbar, same persistence helper, same cascade discipline — with the additional discipline that PGP-only filtering (no printed/domain/exclusion active) must also work, which requires wiring into render branches that `printed_filter` currently bypasses-by-design.

```python
def _apply_printed_filter(results_list):
    """Apply printed material filter to a results list and return filtered list."""
    if search_state.printed_filter == 'all' or not search_state.printed_ids:
        return results_list
    filtered = []
    for r in results_list:
        sys_id = r.get('display', {}).get('id')
        is_printed = sys_id and sys_id in search_state.printed_ids
        if search_state.printed_filter == 'hide_printed' and is_printed:
            continue
        elif search_state.printed_filter == 'only_printed' and not is_printed:
            continue
        filtered.append(r)
    return filtered
```
