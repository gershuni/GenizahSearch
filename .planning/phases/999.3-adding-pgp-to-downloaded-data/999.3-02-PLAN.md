<objective>
Xlsx restructure + 4 lookup helpers + 3 sheets — the big plan.

Three distinct deliverables:

1. **NEW module `shared/export_dossier.py`** — 4 module-level lookup helpers (PGP, NLI, FJMS catalog summary, FJMS bibliography), each wrapping the existing services. Each helper takes a sys_id and returns a small dict (or None / empty list). Each is exception-resilient. Each is independently unit-tested.

2. **Restructure `export_search_results_excel`** into a multi-sheet builder:
   - Main 'Genizah Results' sheet: keep 7 existing columns, append 3 new ones (Has PGP / Is Printed / Domains). NO PGP columns on the main sheet (D-01a removed the 6 PGP columns from the SUPERSEDED plan).
   - 'Manuscripts' sub-sheet: one row per unique sys_id, full dossier columns (D-01c).
   - 'Bibliography' sub-sheet: one row per bib entry, joinable via System ID (D-01d).

3. **Wire the endpoint:** `web/api.py:export_excel` passes the session_payload's enrichment fields through to the export service.

**Scope decisions (Claude's Discretion, per CONTEXT.md):**
- **IIIF Manifest column is DEFERRED.** Per D-13 soft scope, the planner may defer to the Manuscripts sub-sheet. Rationale: per-row IIIF resolution would require fetching manifests for each unique sys_id+p_num combination, multiplying the lookup cost per result-row (not per unique sys_id). The Manuscripts sub-sheet already carries a `Library Viewer URL` via `nli_crossref_service.get_library_viewer_url(sys_id)` which is sys_id-scoped and cheap. Future phase can add per-page IIIF.
- **Catalog Summary fields:** Title, Author, Copy Date, Copy Place (from `fjms_service.get_catalog(sys_id)`). Rendered as `'Title: X | Author: Y | Date: Z | Place: W'` with empty fields omitted entirely. Fields chosen for citation utility — these 4 cover the core scholarly metadata most likely to be cited.
- **Bibliography fields:** System ID, Shelfmark, Author (article_author_eng), Title (running_title), Year (title_year), Page Reference (computed from from_page/to_page/mention_page), Mention Type (mention_type), Catalog Acronym (catalog_acronym), Comment (comment). 9 columns total. Skip Hebrew variants (D-04 English-only) and the noisy fields (transcription_type, translation_type, e_volume, journal_date).
- **URLs as plain text** (not Excel hyperlinks) — D-13's Discretion note; copy-safe for citations.
- **All-LTR alignment for new columns** — these are all English text + URLs.

Purpose: Researchers get a self-contained spreadsheet with citation-grade metadata. The 3 sheets form a normalized join: main sheet has per-folio hits, Manuscripts has the dossier (deduped), Bibliography has the references (one per entry).

Output:
- `shared/export_dossier.py` (NEW, ~250 lines).
- `web/export_service.py:export_search_results_excel` (heavily MODIFIED — multi-sheet rewrite).
- `web/api.py:export_excel` (MODIFIED — passes session enrichment through).

Closes METADATA-EXPORT-05 (helpers + Manuscripts sub-sheet + Bibliography sub-sheet) and METADATA-EXPORT-06 (main-sheet new columns + multi-sheet structure).

"""Phase 999.3 dossier-lookup helpers for the xlsx search-results export.

Wraps the existing read-only sidecar services (PGP via shared.document_service,
NLI via shared.nli_crossref_service, FJMS catalog + bibliography via
shared.fjms_service) and projects each lookup into a small fixed-shape dict
suitable for direct Excel-row construction.

Each helper is:
  - Module-level (no class wrapper).
  - Lazy on imports (services imported inside the function body).
  - Exception-resilient (lookup failures return None / []; no propagation).
  - Side-effect-free (no caching, no module-state mutation).

This module is the SINGLE SOURCE OF TRUTH for the "Manuscripts" and
"Bibliography" sub-sheets in web.export_service.export_search_results_excel.

Architecture decisions (locked in 999.3-CONTEXT.md and 999.3-02-PLAN.md):
  - SEPARATE from shared.search_serializer (which is the JSON-envelope SSOT
    consumed by /api/search, /api/browse, /api/parallels — different lifecycle,
    different audience, must stay stable per Phase 83's schema_version=1
    additivity-only commitment).
  - The PGP helper mirrors the 10-key shape of _build_pgp_subset (at
    shared/search_serializer.py:473) but fixes the latent comma-string-iteration
    bug for languages_primary / languages_secondary via _split_pgp_languages.
    _build_pgp_subset is NOT modified — browse continues to consume it as-is.
  - D-02 invariant: NO transcription text in any helper's output.
  - D-04 invariant: English only. No translation lookups, no get_language().

from __future__ import annotations

import logging
from typing import Any, Optional

logger = logging.getLogger(__name__)


# -----------------------------------------------------------------------------
# Internal: languages-format fix (replaces the latent list(value or []) bug)
# -----------------------------------------------------------------------------

def _split_pgp_languages(value: Any) -> list[str]:
    """Split a pgp.db languages_primary/secondary TEXT value into a real list.

    pgp.db stores these as comma-(optionally-)space-separated TEXT, not JSON.
    Sample values:
      None, '', 'Judaeo-Arabic', 'Aramaic, Hebrew', 'Hebrew,Aramaic'

    Defensive: accepts None / str / list and returns a list[str] of trimmed
    non-empty entries. Replaces `list(value or [])` which iterates characters
    for non-empty strings.
    """
    if value is None:
        return []
    if isinstance(value, list):
        return [str(v).strip() for v in value if v and str(v).strip()]
    if isinstance(value, str):
        if not value.strip():
            return []
        return [part.strip() for part in value.split(',') if part.strip()]
    # Unknown type — coerce to single-element list of its str form.
    s = str(value).strip()
    return [s] if s else []

def _pgp_subset_for_sys_id(
    sys_id: str,
    *,
    available_sys_ids: Optional[set] = None,
) -> Optional[dict]:
    """PGP-lookup-and-project helper for the Manuscripts sub-sheet.

    Wraps ``shared.document_service.get_document_for_fragment(sys_id, None)``
    and returns a 10-key projection mirroring ``_build_pgp_subset``'s shape.

    Per D-02 (999.3-CONTEXT.md): does NOT carry transcription text.
    Per D-09: optional ``available_sys_ids`` short-circuit — skip the SQLite
    hit when sys_id is known not to have PGP (caller's hint).

    Args:
        sys_id: GenizahSearch system identifier.
        available_sys_ids: Optional set of sys_ids known to have PGP (e.g.
            ``search_state.transcription_sys_ids``). When provided and
            ``sys_id not in available_sys_ids``, returns None without a DB hit.

    Returns:
        Dict with these 10 keys (mirrors ``_build_pgp_subset`` shape, fixes
        the languages-format bug):
            description, tags, document_type, languages_primary,
            languages_secondary, doc_date_original, doc_date_standard,
            inferred_date_display, pgpid, pgp_url
        Or None when sys_id is empty, short-circuited, has no PGP record, or
        the lookup raises.
    """
    if not sys_id:
        return None
    if available_sys_ids is not None and sys_id not in available_sys_ids:
        return None
    try:
        from shared.document_service import get_document_for_fragment
        doc = get_document_for_fragment(sys_id, None)
    except Exception as e:
        logger.debug(f"export_dossier._pgp_subset_for_sys_id error for {sys_id}: {e}")
        return None
    if not doc:
        return None
    return {
        'description':           doc.get('description'),
        'tags':                  list(doc.get('tags') or []),
        'document_type':         doc.get('document_type'),
        'languages_primary':     _split_pgp_languages(doc.get('languages_primary')),
        'languages_secondary':   _split_pgp_languages(doc.get('languages_secondary')),
        'doc_date_original':     doc.get('doc_date_original'),
        'doc_date_standard':     doc.get('doc_date_standard'),
        'inferred_date_display': doc.get('inferred_date_display'),
        'pgpid':                 doc.get('pgpid'),
        'pgp_url':               doc.get('pgp_url'),
    }

def _nli_subset_for_sys_id(sys_id: str) -> Optional[dict]:
    """NLI-lookup-and-project helper for the Manuscripts sub-sheet.

    Wraps ``shared.nli_crossref_service.get_catalog_entry(sys_id)`` and
    ``get_library_viewer_url(sys_id)``.

    Returns:
        Dict with 2 keys: ``description`` (str|None), ``library_viewer_url``
        (str|None). Or None when sys_id is empty, NLI service unavailable, or
        both fields are None.
    """
    if not sys_id:
        return None
    try:
        from shared.nli_crossref_service import get_nli_crossref_service
        svc = get_nli_crossref_service(thread_safe=True)
        if not svc.is_available():
            return None
        description = svc.get_catalog_entry(sys_id)
        viewer_dict = svc.get_library_viewer_url(sys_id)
        library_viewer_url = viewer_dict.get('url') if isinstance(viewer_dict, dict) else None
    except Exception as e:
        logger.debug(f"export_dossier._nli_subset_for_sys_id error for {sys_id}: {e}")
        return None
    if not description and not library_viewer_url:
        return None
    return {
        'description': description,
        'library_viewer_url': library_viewer_url,
    }

def _catalog_summary_for_sys_id(sys_id: str) -> Optional[dict]:
    """FJMS catalog-summary helper for the Manuscripts sub-sheet.

    Wraps ``shared.fjms_service.get_catalog(sys_id)`` and projects the 4
    citation-relevant English fields per D-04.

    Returns:
        Dict with 4 keys: ``title``, ``author_text``, ``copy_date``,
        ``copy_place`` (all str|None). Or None when sys_id is empty, FJMS
        service unavailable, or no catalog record found.
    """
    if not sys_id:
        return None
    try:
        from shared.fjms_service import get_fjms_service
        fjms = get_fjms_service(thread_safe=True)
        if not fjms.is_available():
            return None
        cat = fjms.get_catalog(sys_id)
    except Exception as e:
        logger.debug(f"export_dossier._catalog_summary_for_sys_id error for {sys_id}: {e}")
        return None
    if not cat:
        return None
    return {
        'title':       cat.get('title'),
        'author_text': cat.get('author_text'),
        'copy_date':   cat.get('copy_date'),
        'copy_place':  cat.get('copy_place'),
    }

def _bibliography_for_sys_id(sys_id: str) -> list[dict]:
    """FJMS bibliography helper for the Bibliography sub-sheet.

    Wraps ``shared.fjms_service.get_bibliography(sys_id)`` and projects each
    entry to a 9-key dict suitable for direct Excel-row construction.

    Returns:
        List of dicts with 9 keys per entry:
            article_author_eng, running_title, title_year, from_page, to_page,
            mention_page, mention_type, catalog_acronym, comment
        Returns [] when sys_id is empty, FJMS service unavailable, or no
        bibliography entries exist.
    """
    if not sys_id:
        return []
    try:
        from shared.fjms_service import get_fjms_service
        fjms = get_fjms_service(thread_safe=True)
        if not fjms.is_available():
            return []
        raw = fjms.get_bibliography(sys_id) or []
    except Exception as e:
        logger.debug(f"export_dossier._bibliography_for_sys_id error for {sys_id}: {e}")
        return []
    out: list[dict] = []
    for entry in raw:
        if not isinstance(entry, dict):
            continue
        out.append({
            'article_author_eng': entry.get('article_author_eng'),
            'running_title':      entry.get('running_title'),
            'title_year':         entry.get('title_year'),
            'from_page':          entry.get('from_page'),
            'to_page':            entry.get('to_page'),
            'mention_page':       entry.get('mention_page'),
            'mention_type':       entry.get('mention_type'),
            'catalog_acronym':    entry.get('catalog_acronym'),
            'comment':            entry.get('comment'),
        })
    return out

                elif from_p:
                    page_ref = f"{from_p}"
                elif mention_p:
                    page_ref = f"{mention_p}"
                else:
                    page_ref = ''

                row = [

                ]

                current_row = ws.max_row
                for col_idx in range(1, 10):
