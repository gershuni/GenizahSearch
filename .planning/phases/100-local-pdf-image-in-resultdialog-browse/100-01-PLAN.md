Public entry point:
```python
def request(self, sys_id, page_num, filepath, on_image, on_placeholder):
    """Debounced render request. Returns the token for this request, or None if gated out (non-PDF).
    on_image(QImage) is called on success with the latest token; on_placeholder(str) shows a localized placeholder.
    """
    if not self.is_pdf(filepath):
        return None
    token = self._next_token()
    self._awaiting_token = token
    self._pending = (token, sys_id, int(page_num), str(filepath), on_image, on_placeholder)
    # D-01: show Loading immediately, before debounce/enqueue
    on_placeholder(self._loading_text())
    self._debounce_timer.start(self._debounce_ms)   # restart persistent timer
    return token
```

`_fire_pending`: read `self._pending`; if None return. Unpack; if its token != `self._awaiting_token` return (superseded during debounce). Call `self._worker.enqueue(token, sys_id, page_num, filepath)`. Start `self._watchdog_timer.start(self._watchdog_ms)`.

`_on_render_succeeded(self, token, sys_id, page_num, image)`: if `token != self._awaiting_token: return` (latest-wins discard, D-03 — silent, no placeholder). Stop the watchdog (`self._watchdog_timer.stop()`). Retrieve the pending `on_image` callback (store callbacks keyed by token, or keep `self._pending` callbacks while token matches) and call `on_image(image)`.

`_on_render_failed(self, token, sys_id, page_num, reason, detail)`: if `token != self._awaiting_token: return`. Stop the watchdog. Map `reason` (a `PdfRenderFailure`) through `self._placeholder_for(reason)`; if the mapped text is not None, call the pending `on_placeholder(text)`. Log the failure: `logger.warning("PDF render failed token=%s sys_id=%s page=%s reason=%s detail=%s", token, sys_id, page_num, getattr(reason, 'value', reason), detail)`.

`_on_watchdog(self)`: if `self._awaiting_token is None: return`. Log `logger.warning("PDF render watchdog TIMEOUT token=%s", self._awaiting_token)`. Call the pending `on_placeholder(self._placeholder_for(PdfRenderFailure.TIMEOUT))`. Then invalidate so the late real result is discarded: bump `self._awaiting_token` by setting `self._awaiting_token = self._next_token()` is WRONG (would consume a token a caller might re-use) — instead set `self._awaiting_token = None` so any later echoed token compares unequal and is discarded silently.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user filesystem → render worker | LOCAL PDF path comes from the indexed `local_files`/`get_filepath` (already validated at index time); the controller only forwards an already-resolved path string |
| async worker thread → UI thread | render results cross the QThread→main-thread boundary via Qt queued signals; stale/late results must not corrupt UI state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-100-01 | Tampering | stale render result lands in viewer after navigation | mitigate | latest-wins token compare in `_on_render_succeeded`/`_on_render_failed` discards any token != `_awaiting_token`; covered by `test_stale_success_discarded` |
| T-100-02 | Denial of Service | wedged/slow render hangs the pane indefinitely | mitigate | ~8s `QTimer` watchdog synthesizes TIMEOUT placeholder + invalidates token; worker C-call is dropped, never force-killed (Phase 99 D-05); covered by `test_watchdog_fires_timeout_placeholder` |
| T-100-03 | Denial of Service | key-repeat navigation enqueues hundreds of 200 DPI renders | mitigate | 150ms debounce coalesces to a single enqueue (D-04); covered by `test_debounce_coalesces` |
| T-100-04 | Denial of Service | rendering a huge/malicious non-PDF or unsupported file | mitigate | extension gate (`.pdf` only) blocks enqueue for non-PDF (D-08/PDFIMG-05); huge-PDF memory bounded by Phase 99 DocLRU(4) + single render thread |
| T-100-05 | Information Disclosure | failure `detail` string leaking a full local path into logs | accept | desktop-only app, single-user local machine; log path detail is acceptable and aids debugging (worker already logs detail in Phase 99) |
