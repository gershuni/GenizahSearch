  Three targeted fixes in genizah_app.py:

  **Fix 1 - Tag click navigation (Test 3):**
  There are TWO definitions of `_search_by_pgp_tag` in GenizahGUI. The second (line ~12859) silently overrides the first (line ~7472). The second is missing the tab switch.

  - DELETE the first definition at line ~7472 (the one with `self.tabs.setCurrentWidget`, `query_input.setText`, `toggle_search`). It is dead code.
  - MODIFY the second definition at line ~12859 to add tab switch BEFORE the tag search:
    ```python
    def _search_by_pgp_tag(self, tag):
        """Entry point for searching by PGP tag (from browse/result dialog links)."""
        self.tabs.setCurrentWidget(self.search_tab)
        if hasattr(self, 'tag_search_combo'):
            self.tag_search_combo.setCurrentText(tag)
        self._execute_tag_search()
    ```

  **Fix 2 - Browse tab stuck (Test 12):**
  In `open_result_in_browse` (line ~13407), the `else` branch at line ~13443 (when `derived_fl_id` is None) does NOT clear `browse_shelf_input` or set `last_browse_field`. Tag search results always hit this branch because they have empty `raw_header`.

  - In the `else` branch (after `self.browse_fl_input.setText("")` at line ~13444), ADD:
    ```python
    else:
        self.browse_fl_input.setText("")
        self.browse_shelf_input.clear()        # Clear stale shelfmark
        self._set_last_browse_field("sys")     # Force sys_id priority
    ```

  **Fix 3 - ResultDialog crash (Test 13):**
  In `ResultDialog.load_result_by_index` (line ~3552), `data['uid']` raises KeyError for tag results which lack a `uid` key. Also `raw_header` is empty so `parse_full_id_components` returns None for sys_id.

  - Change line ~3554-3555 from:
    ```python
    if not data.get('full_text'):
        data['full_text'] = self.searcher.get_full_text_by_id(data['uid']) or data.get('text', '')
    ```
    To:
    ```python
    if not data.get('full_text'):
        uid = data.get('uid')
        if uid:
            data['full_text'] = self.searcher.get_full_text_by_id(uid) or data.get('text', '')
        else:
            # Tag search results: get full text by sys_id from display dict
            sid = data.get('display', {}).get('id', '')
            if sid and self.searcher:
                data['full_text'] = self.searcher.get_full_manuscript(sid) or data.get('text', '')
            else:
                data['full_text'] = data.get('text', '')
    ```

  - Change line ~3564-3567 from:
    ```python
    ids = self.meta_mgr.parse_full_id_components(data['raw_header'])
    self.current_sys_id = ids['sys_id']
    try: p = int(ids['p_num'])
    except: p = 1
    ```
    To:
    ```python
    ids = self.meta_mgr.parse_full_id_components(data.get('raw_header', ''))
    self.current_sys_id = ids['sys_id']
    if not self.current_sys_id:
        # Fallback for tag search results: get sys_id from display dict
        self.current_sys_id = data.get('display', {}).get('id', '')
    try: p = int(ids['p_num'])
    except: p = 1
    ```

  **Fix in shared/document_service.py:**
  In `get_fragments_by_tag()` (line ~474), add `transcription` to the select query. Note: transcription can be large, but we only need a snippet. Supabase PostgREST does not support server-side substring, so fetch the full field but limit usage client-side.

  Change the select at line ~474 from:
  ```python
  doc_response = client.table('documents').select(
      'pgpid, shelfmark_combined, document_type, description'
  ).filter('tags', 'cs', json.dumps([tag])).execute()
  ```
  To:
  ```python
  doc_response = client.table('documents').select(
      'pgpid, shelfmark_combined, document_type, description, transcription'
  ).filter('tags', 'cs', json.dumps([tag])).execute()
  ```

  Also update the result dict assembly (line ~495-501) to include transcription:
  ```python
  results.append({
      'sys_id': frag['sys_id'],
      'shelfmark': frag['shelfmark'],
      'document_type': doc.get('document_type', ''),
      'description': doc.get('description', ''),
      'pgpid': frag['document_id'],
      'transcription': doc.get('transcription', ''),
  })
  ```

  **Fix in genizah_app.py:**
  In `_on_tag_search_results` (line ~12824), change the snippet building from:
  ```python
  snippet = f"{doc_type}: {desc[:120]}..." if desc else doc_type
  ```
  To:
  ```python
  transcription = r.get('transcription', '') or ''
  if transcription:
      # Use first ~150 chars of transcription as snippet (Hebrew text)
      clean_text = transcription.replace('\n', ' ').replace('\r', ' ').strip()
      snippet = clean_text[:150] + ('...' if len(clean_text) > 150 else '')
  elif desc:
      snippet = f"{doc_type}: {desc[:120]}..."
  else:
      snippet = doc_type
  ```
