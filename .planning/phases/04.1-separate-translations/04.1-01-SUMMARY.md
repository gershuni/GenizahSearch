# Phase 4.1 Plan 01: Separate Translations from Transcriptions

**One-liner:** Service layer filters Digital Translations, showing only Digital Editions as PGP Transcription

## What Was Built

### Database Migration
- Added `doc_relation` column to `documents` table
- Created index `idx_documents_doc_relation` for filter performance
- Column distinguishes "Digital Edition" (transcriptions) from "Digital Translation"

### Data Population Script
- `scripts/update_doc_relation.py` - Populates doc_relation from CSV data
- Supports `--dry-run` and `--execute` flags
- Batch updates (500 per batch) matching import script pattern
- Reports statistics: 86.4% Digital Edition, 13.6% Digital Translation

### Service Layer Filtering
- Modified `get_document_for_fragment()` to only return Digital Editions
- Digital Translations return `None` (no PGP option in version selector)
- Simple, transparent fix - no UI changes required

## Data Statistics

| doc_relation | Count | Percentage |
|--------------|-------|------------|
| Digital Edition | 6,127 | 86.4% |
| Digital Translation | 961 | 13.6% |
| Edition | 2 | 0.0% |
| **Total** | **7,090** | **100%** |

## Verification Results

**Data Layer:**
- All 7,090 documents have doc_relation populated (0 NULL)
- Distribution matches CSV source data exactly

**Service Layer:**
- Translation (pgpid=7657): Returns `None` - correctly filtered
- Edition (pgpid=36408): Returns document - correctly returned

**UI Impact:**
- PGP Transcription option only appears for Digital Editions
- No English translations shown as "PGP Transcription"
- Users see original Hebrew/Aramaic transcriptions as expected

3. **Multi-version documents:** Some PGP documents may have both Digital Edition and Digital Translation - could show both as separate versions
