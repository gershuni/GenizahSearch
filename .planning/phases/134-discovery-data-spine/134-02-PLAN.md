<objective>
Extend the permanent DATA-05 masking CI guard to scan the shipped SQLite sidecar cell-by-cell (schema identifiers + every table/row/cell value, str AND bytes/BLOB), make `--scan-sqlite` a first-class `--strict` surface so the real ship command is a VALID invocation, pre-register R-source tokens, gitignore the sidecar payload dir, and commit the PERF-01 acceptance-budget artifact.

Purpose: The sidecar is a NEW leak surface; a raw-blob scan misses values split across pages/overflow and gives no cell provenance, and a str-only cell scan skips BLOB/bytes residue. A cell-level `--scan-sqlite` mode (str + BLOB) closes the gap while REUSING the already-Codex-hardened matcher. The current `--strict` requires BOTH `--scan-repo` and `--scan-asset`, so the documented ship command was invalid — `--scan-sqlite` must become a first-class strict surface. The budgets doc must exist from line one so 134-06/134-08 measure against it, and must not over-claim caps whose surfaces don't exist until Phase 136/139.
Output: extended `scripts/check_atlas_masking.py`, `tests/test_masking_sqlite.py`, `.gitignore` entry, `docs/specs/discovery-budgets.md`.
</objective>
