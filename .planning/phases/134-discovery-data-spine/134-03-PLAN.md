<objective>
Build a tiny deterministic, masking-safe fixture `discovery.db` (+ its `manifest.json`), author a single parameterized verifier `scripts/verify_discovery_sidecar.py` that runs ALL build-output invariants over any DB path (with the frame-hash check taking the EXPECTED hash as an input), and drive it from the invariant test files against the fixture — so every downstream test (schema, drift fields, source_corpus consistency, bands, units, frame, release contract, loader, service) proves correctness in CI WITHOUT the 3.1 GB research DB, and 134-07 can run the SAME verifier over the real shipped DB.

Purpose: These invariants are the executable form of the frozen schema's guarantees. Consolidating them into one path-parameterized verifier (DC7) means the real build (134-07) cannot silently skip band/unit/frame/FK/source_corpus/release checks — it runs the identical verifier. The frame-hash check is two-mode (DC7): it takes the expected hash as input, so the fixture test passes its own pinned golden while 134-07 passes the value recorded in discovery-frames.md (and the verifier cross-checks meta.frame_content_hash both ways). F4 — the verifier ALSO enforces a cross-table consistency invariant: every `work_witness_claims.source_corpus` must equal its parent `works.source_corpus` (a valid vocabulary code alone is not enough — a claim mislabeled with a different but still-valid corpus is caught). The distillation (134-04) verifies its real output against these same invariants; the loader (134-05) and service (134-06) use this fixture + manifest as their test assets.
Output: `tests/fixtures/discovery/build_fixture_db.py`, `scripts/verify_discovery_sidecar.py`, and five test files.
</objective>
