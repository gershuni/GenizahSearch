  <name>Task 1: Add folio label parsing and folio-ready image query to NliCrossrefService</name>
  <files>shared/nli_crossref_service.py, tests/test_nli_crossref_service.py</files>
  <action>
Add a module-level helper function `parse_folio_label(image_name: str) -> str` that extracts folio notation from NLI ImageName values. The ImageName pattern is:
`{shelfmark_prefix}__L{leaf}F{folio}B{bifolio}S{side}`
where S1=recto (r), S2=verso (v).

Examples:
- `T_S_12_1__L1F0B0S1` -> `1r` (Leaf 1, Side 1 = recto)
- `T_S_12_1__L1F0B0S2` -> `1v` (Leaf 1, Side 2 = verso)
- `I_C_71__L3F0B0S1` -> `3r` (Leaf 3, Side 1 = recto)
- `577_7_6__L1F0B1S2` -> `1v` (Leaf 1, Side 2 = verso)
- `Missing1` -> `1` (fallback: no match, use sequential index)
- `Yevr_III_B_1093__L7F0B0S1` -> `7r` (Leaf 7, Side 1)

Parsing logic:
1. Search for pattern `L(\d+)F\d+B\d+S(\d+)` in the ImageName string
2. Extract leaf number and side number
3. Map side: 1 -> 'r' (recto), 2 -> 'v' (verso)
4. Return `{leaf}{side_letter}` (e.g., "1r", "3v")
5. If pattern not found, return empty string (caller handles fallback)

Also add a method `get_folio_images(self, sys_id: str) -> list[dict]` to NliCrossrefService that returns the same data as `get_images()` but with an additional `folio_label` key in each dict, generated by calling `parse_folio_label()` on the image_name. For images where parse_folio_label returns empty string, assign a sequential fallback label (e.g., "1", "2", "3").

Add unit tests in tests/test_nli_crossref_service.py:
- `test_parse_folio_label_standard` - tests standard L/S patterns
- `test_parse_folio_label_verso` - tests S2 mapping to 'v'
- `test_parse_folio_label_missing` - tests fallback on unrecognized patterns
- `test_parse_folio_label_high_leaf` - tests L10+ leaf numbers
- `test_get_folio_images` - tests that folio_label key is added to results
  </action>
