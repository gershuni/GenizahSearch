<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous → authenticated | Add-to-List is a login-gated cloud write |
| client → Supabase list_items | list membership crosses to the cloud DB |
| candidate set → local download | export assembles a file on the server and downloads to the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-120-auth | Spoofing | Add-to-List write | mitigate | `is_logged_in()` gate + `create_login_dialog()`; `add_list_item` uses `get_user_client()` (RLS, V2) |
| T-120-loop | Denial of Service | export text fetch | mitigate | Off-loop batched `run.io_bound`; cancel between batches; count cap 500; per-cell text cap 4000 (V5) |
| T-120-blob | Denial of Service | export payload | mitigate | Export is a transient download (never persisted to safe_storage); no result blob written to storage |
| T-120-fnf | Denial of Service | list-write / export fire-and-forget | mitigate | `except RuntimeError: return` SEED-008 guard |
| T-120-SC | Tampering | npm/pip/cargo installs | accept | No new packages — openpyxl already present (RESEARCH.md § Package Legitimacy Audit — none added) |
</threat_model>
