<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser session → safe_storage | full working-state crosses into per-session server storage |
| persisted inputs → re-run search | restored builder inputs feed the off-loop search engine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-120-blob | Denial of Service | `_persist_state` payload | mitigate | Persist inputs only via write_full_state (Plan-01 caps); NEVER candidate lists/full_text/images (778 MB class) |
| T-120-loop | Denial of Service | restore re-run | mitigate | Search runs off-loop (`run.io_bound`); `tests/test_joins_lab_off_loop.py` stays green; storage writes only on the event loop (Pitfall 4) |
| T-120-leak | Information Disclosure | joins_lab storage | mitigate | `safe_user_*` per-session chokepoint; `tests/test_no_raw_storage_access.py` allowlist `[]` |
| T-120-fnf | Denial of Service | restore coroutine | mitigate | SEED-008 `except RuntimeError: return` guard on the restore task (client-deleted mid-restore) |
| T-120-SC | Tampering | npm/pip/cargo installs | accept | No new packages (RESEARCH.md § Package Legitimacy Audit — none) |
</threat_model>
