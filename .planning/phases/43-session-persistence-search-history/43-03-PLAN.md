Extend shared/session_persistence.py with history management functions. The history is stored in a separate JSON file (not in session.json) to keep concerns separate:

1. **Add Config import and HISTORY_FILE path:**
   ```python
   HISTORY_FILE = os.path.join(Config.INDEX_DIR, "search_history.json")
   ```

2. **`add_history_entry(search_type: str, entry: dict, limit: int = 20) -> bool`:**
   - `search_type` is either `'regular'` or `'composition'`
   - `entry` dict contains:
     - `query: str` (search query text or composition title)
     - `result_count: int`
     - `timestamp: str` (ISO format)
     - `search_params: dict` (mode, gap, variant_preset, chunk_size, etc.)
     - `state: dict` (full search state snapshot — results, exclusions, filters)
   - Dedup logic: if an entry with matching `query` AND `search_params` already exists for this search_type, UPDATE it (replace state, result_count, timestamp) rather than adding a new one
   - Enforce `limit`: if entries exceed limit after adding, remove oldest entries
   - Atomic write (write to .tmp, then os.replace)

3. **`get_history(search_type: str = None) -> dict`:**
   - Returns `{'regular': [...], 'composition': [...]}` if search_type is None
   - Returns list for the specified search_type if provided
   - Each entry in the list has: query, result_count, timestamp, search_params, state
   - Sorted by timestamp descending (newest first)

4. **`delete_history_entry(search_type: str, index: int) -> bool`:**
   - Deletes the entry at the given index for the search_type
   - Returns True on success

5. **`clear_history(search_type: str = None) -> bool`:**
   - Clears all history for the given search_type, or all history if None

6. **`get_interrupted_search() -> Optional[dict]`:**
   - Checks session.json for a `was_interrupted` flag
   - Returns the composition state if it was interrupted (search was running when app closed)
   - The `was_interrupted` flag should be set in _save_session when `self.is_comp_running` is True

7. **`clear_interrupted_flag() -> bool`:**
   - Removes the `was_interrupted` flag from session.json

All functions: log errors but never raise. Use the same atomic write pattern as save_session_state.

def _refresh_search_history(self):
    """Refresh the search history dropdown."""
    from shared.session_persistence import get_history
    self.search_history_combo.clear()
    entries = get_history('regular')
    for entry in entries:
        query = entry.get('query', '')[:40]  # Truncate long queries
        count = entry.get('result_count', 0)
        display = f"{query}  ({count})"
        self.search_history_combo.addItem(display, entry)  # Store full entry as userData
    self.search_history_combo.setCurrentIndex(-1)  # No selection by default

def _refresh_comp_history(self):
    """Refresh the composition history dropdown."""

**4. Handle history selection:**

```python
def _on_search_history_selected(self, index):
    """Restore state from a search history entry."""
    entry = self.search_history_combo.itemData(index)
    if not entry:
        return

    # Ask user: restore saved state or re-run?
    reply = QMessageBox.question(
        self, tr("Restore Search"),
        tr("Restore saved results or re-run the search?"),
        QMessageBox.StandardButton.Yes | QMessageBox.StandardButton.No,
        QMessageBox.StandardButton.Yes
    )

    state = entry.get('state', {})
    if reply == QMessageBox.StandardButton.Yes:
        # Restore full saved state
        self._restore_regular_search_from_state(state)
    else:
        # Re-run: just set the query and params, then trigger search
        self.query_input.setText(entry.get('query', ''))
        params = entry.get('search_params', {})
        if 'mode_index' in params:
            self.mode_combo.setCurrentIndex(params['mode_index'])
        if 'gap' in params:
            self.gap_input.setText(str(params['gap']))
        self.toggle_search()  # Re-execute

    self.search_history_combo.setCurrentIndex(-1)  # Reset selection
```

Create `_restore_regular_search_from_state(state)` that applies a history entry's state dict — similar to the regular_search restore logic from `_restore_session()` in Plan 01 but extracted into a reusable method.
