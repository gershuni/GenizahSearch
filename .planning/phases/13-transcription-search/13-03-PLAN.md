Add a helper function (near the top of the search page setup or in the web utilities) to detect if V0.7 content exists in the loaded index. Per user decision, the V0.7 checkbox must only be shown if V0.7 content exists:

```python
def _check_index_has_source(state, source_label):
    """Check if the search index contains any documents with the given source label.
    Used to conditionally show the V0.7 checkbox (per user decision)."""
    try:
        if state.searcher and state.searcher.index:
            from tantivy import Query, Occur
            schema = state.searcher.index.schema
            q = Query.term_query(schema, "source", source_label.lower())
            searcher = state.searcher.index.searcher()
            hits = searcher.search(q, 1).hits
            return len(hits) > 0
    except Exception:
        pass
    return False
```
