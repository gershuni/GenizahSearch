<remaining_work>

5 UAT issues remain (tracked as tasks #3-#7):

1. **Task #3: Table dark mode** — `ui.add_css()` with CSS variables not overriding Quasar's inline styles. The table cells are still white background with black text in dark mode. Need stronger selectors or use Quasar's `dark` prop on the table, or apply inline styles directly via `.style()` on the table element. Check how other pages (search.py, browse.py) handle Quasar tables in dark mode — they may use a different pattern entirely (e.g., Quasar `dark` prop, or not using ui.table at all).

2. **Task #4: Catalog button** — `$emit('catalogClick', {sys_id, shelfmark})` from Vue slot not reaching the Python `table.on('catalogClick', handler)`. May need to use `$parent.$emit` or a different event mechanism. Alternative: use `window.location.href` to navigate to `/browse?sys_id=X&show_catalog=1` and handle on browse page.

3. **Task #5: Table width** — Table extends full window width, not constrained to the content area between left sidebar and right domain panel. The table is inside `ui.column().classes('flex-grow min-w-0')` but the Quasar table ignores flex constraints. May need `overflow: hidden` on parent or explicit `max-width` calculation.

4. **Task #6: Thumbnails** — FL ID from full_header approach produces URLs that don't load. The `get_thumbnail_url(fl_id)` builds NLI IIIF URLs but images show broken. Possible issues: (a) not all manuscripts have FL IDs, (b) FL ID might not be the right format. Need to try Cambridge IIIF approach for CUL manuscripts, or use a different image source. Check how browse.py gets its first image for a manuscript.

5. **Task #7: Animation** — Detail rows open/close instantly via `display: none/''`. Add CSS transition with max-height or use Quasar's `<q-slide-transition>` component wrapping the detail content.
</remaining_work>
