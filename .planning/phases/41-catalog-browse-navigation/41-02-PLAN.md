```python
class FjmsService:
    def get_domain_hierarchy(self) -> dict:
        """Returns: Dict mapping parent_domain -> {parent_domain_heb, count, children: [{domain, domain_heb, count}]}"""

    def get_browse_authors(self, domain: str = None) -> list[dict]:
        """Returns: [{"author": str, "count": int}, ...] sorted by count desc"""

    def get_browse_works(self, domain: str = None, author: str = None) -> list[dict]:
        """Returns: [{"title": str, "title_heb": str, "count": int}, ...] sorted by count desc"""

    def get_browse_results(self, domain: str = None, author: str = None, work: str = None, offset: int = 0, limit: int = 50) -> dict:
        """Returns: {"results": [{"sys_id", "title", "title_heb", "author", "copy_date", "textual_frame_heb", "textual_frame_eng", "domains", "domains_heb"}], "total": int}"""

    def get_unclassified_count(self) -> int:
        """Returns: count of catalog AlmaIds with no domain entry"""
```

  <action>
Create `web/pages/catalog_browse.py` implementing the full catalog browse page. Follow existing page patterns from browse.py and search.py.

**Page Structure (top to bottom):**

1. **Page Header**: "Browse by Identification" / "עיון לפי זיהוי" with brief description

2. **Filter Controls Row** (above results):
   - **Active Filters Chip Bar**: Show removable chips for each active filter (e.g., "Domain: Bible x", "Author: Maimonides x"). "Clear All" button when any filter is active. Hidden when no filters.

3. **Two-Column Layout** (sidebar + results):

   **Left Sidebar (or right in RTL) - ~300px width:**

   a) **Domain Tree** (collapsible tree view):
      - Load hierarchy from `fjms.get_domain_hierarchy()`
      - Show as expandable tree: parent domains at top level, children indented below
      - Each node shows: domain name + manuscript count in parentheses, e.g., "Documentary (45,230)"
      - Use NiceGUI `ui.tree` component or build with nested `ui.expansion` elements
      - Clicking a domain node: sets domain filter, updates results, narrows author/work lists
      - Language: use `get_language()` to decide between domain (English) vs domain_heb (Hebrew)
      - Show "Unclassified" node at bottom with count from `get_unclassified_count()`
      - Highlight currently selected domain
      - Click behavior: clicking ANY level (parent or child) triggers manuscript display. Clicking a parent shows all manuscripts under it and its children.

   b) **Author Search** (below domain tree):
      - Label: "Author" / "מחבר"
      - `ui.input` with search-as-you-type
      - On input change (debounced ~300ms): fetch authors from `fjms.get_browse_authors(domain=current_domain)` filtered by typed text (client-side prefix match on the fetched list)
      - Show dropdown/autocomplete with matching authors and counts
      - Selecting an author: sets author filter, updates results and available works
      - Support Hebrew input

   c) **Work/Title Search** (below author search):
      - Label: "Work / Title" / "חיבור / כותרת"
      - `ui.input` with search-as-you-type
      - On input change (debounced ~300ms): fetch works from `fjms.get_browse_works(domain=current_domain, author=current_author)` filtered by typed text
      - Show dropdown/autocomplete with matching works and counts
      - Selecting a work: sets work filter, updates results

   **Main Content Area:**

   d) **Results Table**:
      - Use `ui.table` (NiceGUI's Quasar-based table)
      - Columns: Shelfmark, Library, Domain, Identification (author + title), Date
      - Fetch results from `fjms.get_browse_results(domain, author, work, offset, limit)`
      - For each result sys_id, resolve shelfmark and library_code using `service.mm.get_meta_for_id()` and `service.mm.get_library_for_id()`
      - Identification column: combine author + title (e.g., "Maimonides - Sefer HaMitzvot")
      - Domain column: show domain(s) from result data
      - Row click: navigate to `/browse?sys_id={sys_id}` (opens manuscript browse page)
      - Pagination: show "Page X of Y" with prev/next buttons. PAGE_SIZE = 50.
      - Empty state: "No manuscripts match the current filters" when results empty
      - Loading state: show spinner while fetching
      - Total count shown: "Showing 1-50 of 1,245 manuscripts"

4. **Cross-filtering Logic:**
   - When domain changes: re-fetch authors list scoped to domain, re-fetch works list scoped to domain + current author, re-fetch results
   - When author changes: re-fetch works list scoped to current domain + author, re-fetch results
   - When work changes: re-fetch results only
   - When a filter is removed (chip X clicked): clear that filter, re-expand the narrowed lists, re-fetch results

5. **State Management:**
   - Store current filters in local variables: `current_domain`, `current_author`, `current_work`, `current_page`
   - All filter changes trigger `refresh_results()` which updates the table and pagination
   - Use `async` functions for data fetching (wrap sync SQLite calls in `await run.io_bound(...)`)

6. **Deep Linking:**
   - URL query params: `?domain=Piyyut&author=Maimonides&work=Sefer+HaMitzvot&page=2`
   - On page load, read query params and set initial filters
   - On filter change, update URL via `ui.navigate.to(new_url, new_tab=False)` -- but ONLY update the URL, don't trigger full page reload. Use JavaScript `history.replaceState` instead via `ui.run_javascript()`.

**Implementation Notes:**
- Use `await run.io_bound(fjms.get_browse_results, ...)` pattern for SQLite calls (they block)
- RTL: wrap main container in `dir=rtl` when `is_rtl()`. Sidebar goes to the right.
- Mobile: on small screens, collapse sidebar to a top section or use Quasar drawer
- Follow the existing page styling patterns from browse.py (use same CSS classes)
- The page function should be: `def create_catalog_browse_page(initial_domain=None, initial_author=None, initial_work=None, initial_page=None)`
