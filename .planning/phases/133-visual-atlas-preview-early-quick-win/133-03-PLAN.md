## RESOLVED planner decision (Open Question #1)
Architecture = SHARED-SHELL EMBEDDED (Pattern 1). The `/atlas` route follows puzzle_page_route; the renderer runs as injected JS inside the NiceGUI page body; badge + honesty banner are reusable NiceGUI components.

## Authoritative asset-state model (HIGH-1 / HIGH-2 / MEDIUM-6 / MEDIUM-3)
- `web/atlas_assets.py` owns ALL asset state. `ATLAS_DATA_DIR` = repo-root `atlas_data/` (computed from `os.path.dirname(os.path.dirname(os.path.abspath(__file__)))`), OUTSIDE `web/static/`.
- `load_atlas_state()` (called ONCE at startup from web/main.py): read `atlas_data/manifest.json`; from it take `asset_basename`; load `<basename>.bin` (REQUIRED) into a module global; load `<basename>.bin.br` (OPTIONAL) if present; set `ready=True` only if the manifest parsed AND the plain `.bin` bytes loaded consistently. `.bin.br` being absent does NOT block readiness — it only means the brotli branch is unavailable (making the missing-representation negotiation path reachable, MEDIUM-3). ANY failure of the required parts (missing manifest, missing plain bytes, basename mismatch, parse error) => `ready=False`, no traceback (fail-closed).
- `atlas_preview_available()` = `ATLAS_PREVIEW_ENABLED and _state.ready`. This ONE predicate gates the page route, the data routes, the nav link, and (plan 133-05) the homepage teaser.
- Deploy posture (HIGH-2): the asset is scp'd asset-first then the process is restarted (plan 133-06), so the startup load is authoritative; no per-request `os.path.exists` and no mixing of startup-load with per-request stat.

## Encoding negotiation contract (MEDIUM-3)
- Provide a helper `_negotiate_encoding(accept_encoding_header, have_br, have_plain) -> 'br' | 'identity' | None`: parse the header into a `{coding: q}` map (splitting on commas, parsing `token;q=value`, defaulting q=1 when omitted), and note the wildcard `*`. Compute: `br` acceptable = `have_br` AND (`br` present with q>0, OR `br` absent but `*` present with q>0); `identity` acceptable = `have_plain` AND (identity is default-acceptable — if `identity` explicit then q>0; elif `*` present then its q>0; else True). Prefer br: return `'br'` if br acceptable; elif `'identity'` if identity acceptable; else `None`. `None` => the route returns 406.
- This honors `br;q=0` (falls back to plain), `identity;q=0` and `*;q=0` (no acceptable representation => 406, reachable), and a bare `*` (br served via wildcard). A request with no Accept-Encoding header gets plain (identity default-acceptable), never br.
