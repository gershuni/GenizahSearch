<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| accumulator (in-memory) → PostHog queue | The only place perf data crosses from the process to the network is `_flush_perf_summary` → `track_performance` → `_emit` → `_scrub_props`/`_validate_props` → `enqueue_event`. This is the chokepoint. |
| worker-thread perf data → accumulator | Enters via `accumulate_performance`; the dominant PII risk is a raw result count or query text reaching the summary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-115-PRIV-1 | Information Disclosure | result counts in summary | mitigate | Result counts are converted to coarse buckets (0/1-9/10-99/100+) INSIDE `_flush_perf_summary` (D-03); raw `result_counts` list is NEVER placed on the event — only `bucket_*` integer counts. Asserted by `test_perf_summary_buckets_only`. |
| T-115-PRIV-2 | Information Disclosure | nested perf_summary dict | mitigate | The summary contains ONLY low-cardinality numbers + low-cardinality mode-enum string keys (`keyword`, `comp`, etc. — producer-side literals). No query text, no shelfmark, no path. The scrubber recurses (`_scrub_value`) and the allowlist gates `perf_summary` as the single top-level container key. Asserted by `test_perf_summary_survives_scrubber`. |
| T-115-PRIV-3 | Information Disclosure | accumulate before consent | mitigate | `accumulate_performance` consent-gates `is_enabled()` first; `_flush_perf_summary` re-checks `is_enabled()` so data accumulated while gated never leaves the process. Asserted by `test_accumulate_disabled_when_no_consent`. |
| T-115-SD | Spoofing/Tampering | event name | mitigate | Event name is `DesktopEvent.SESSION_PERF` / `INDEXING_COMPLETE` enum members (PRIV-06), never dynamically constructed; `track_performance` re-validates against `_VALID_EVENT_VALUES`. |
| T-115-SC | Tampering | npm/pip/cargo installs | accept | No package installs (RESEARCH §Package Legitimacy Audit: N/A — zero new deps). |
</threat_model>
