    Create shared/exclusion_service.py with:

    1. **ResolvedEntry dataclass** (for D-04 resolution report table):
       ```python
       @dataclass
       class ResolvedEntry:
           original: str      # Raw input from file (e.g., "T-S 12.123")
           normalized: str    # After normalize_shelfmark (e.g., "ts12.123")
           sys_id: str | None # Matched sys_id or None
           status: str        # 'found', 'not_found', 'duplicate'
       ```

    2. **ExclusionSource dataclass** (per D-06 multi-source tracking):
       ```python
       @dataclass
       class ExclusionSource:
           label: str                          # "My reviewed list" or "imported.txt"
           source_type: str                    # 'list' or 'file'
           source_id: str                      # list_id or filename
           sys_ids: set                        # resolved sys_ids
           unresolved: list                    # shelfmarks that couldn't resolve (file imports only)
           resolved_entries: list = field(default_factory=list)  # ResolvedEntry list (transient, for report)
       ```

    3. **parse_shelfmark_file(content: str) -> list[str]**: Split on newlines, strip whitespace, filter empty lines and lines starting with '#'. Plain text, one shelfmark per line.

    4. **parse_csv_shelfmarks(content: str) -> list[str]**: Use csv.reader with io.StringIO. Strip \ufeff BOM from first header cell if present. Auto-detect shelfmark column by checking headers against keywords: {'shelfmark', 'shelf_mark', 'call_number', 'signature', 'classmark', 'shelf mark', 'call_numbers'}. Case-insensitive comparison. Fallback to column 0. Return list of stripped non-empty values from detected column. Skip rows where the detected column is empty.

    5. **resolve_shelfmarks(raw_lines: list[str], shelf_map: dict[str, str]) -> tuple[set[str], list[str], list[ResolvedEntry]]**: For each line, call normalize_shelfmark(line) and look up in shelf_map. Track seen sys_ids to mark duplicates. Return (resolved_sys_ids_set, unresolved_lines_list, resolved_entries_list). Import normalize_shelfmark from genizah_core.

    6. **build_shelf_map(csv_bank: dict) -> dict[str, str]**: Build {normalized_shelfmark: sys_id} from csv_bank. For each sys_id in csv_bank:
       - Normalize the 'shelfmark' field and add to map (first-write-wins)
       - Normalize each entry in 'call_numbers_raw' list if present and add to map (first-write-wins)
       This ensures variant shelfmarks like "MS. Heb. a.1" and "Ms. Heb. a 1" both resolve.

    7. **compute_excluded_ids(sources: list[ExclusionSource]) -> set[str]**: Return `set().union(*(s.sys_ids for s in sources))` if sources else `set()`.

    8. **serialize_sources(sources: list[ExclusionSource]) -> list[dict]**: Convert to JSON-serializable dicts. sys_ids as sorted list (not set). Do NOT serialize resolved_entries (transient data, too large for session storage). Include: label, source_type, source_id, sys_ids (as list), unresolved.

    9. **deserialize_sources(data: list[dict]) -> list[ExclusionSource]**: Reconstruct from serialized dicts (sys_ids back to set, resolved_entries defaults to empty list). Handle missing/malformed data gracefully (skip bad entries, log warning, return partial list).
