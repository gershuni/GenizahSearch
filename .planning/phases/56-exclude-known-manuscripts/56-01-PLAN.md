    Create shared/exclusion_service.py with:

    1. **ExclusionSource dataclass** (per D-06 multi-source tracking):
       ```python
       @dataclass
       class ExclusionSource:
           label: str           # "My reviewed list" or "imported.txt"
           source_type: str     # 'list' or 'file'
           source_id: str       # list_id or filename
           sys_ids: set         # resolved sys_ids
           unresolved: list     # shelfmarks that couldn't resolve (file imports only)
       ```

    2. **parse_shelfmark_file(content: str) -> list[str]**: Split on newlines, strip whitespace, filter empty lines. Plain text, one shelfmark per line.

    3. **parse_csv_shelfmarks(content: str) -> list[str]**: Use csv.reader with io.StringIO. Auto-detect shelfmark column by checking headers against keywords: {'shelfmark', 'shelf_mark', 'call_number', 'signature', 'classmark', 'shelf mark'}. Fallback to column 0. Handle utf-8-sig BOM by stripping \ufeff from first header. Return list of stripped non-empty values from detected column.

    4. **resolve_shelfmarks(raw_lines: list[str], shelf_map: dict[str, str]) -> tuple[set[str], list[str]]**: For each line, normalize_shelfmark(line) and look up in shelf_map (norm -> sys_id). Return (resolved_sys_ids_set, unresolved_lines_list). Import normalize_shelfmark from genizah_core.

    5. **build_shelf_map(csv_bank: dict) -> dict[str, str]**: Build {normalized_shelfmark: sys_id} from csv_bank. For each sys_id, normalize the 'shelfmark' field. Also normalize each entry in 'call_numbers_raw' list if present (for variant coverage). First-write-wins (don't overwrite existing mappings).

    6. **compute_excluded_ids(sources: list[ExclusionSource]) -> set[str]**: Return union of all source.sys_ids.

    7. **serialize_sources(sources: list[ExclusionSource]) -> list[dict]**: Convert to JSON-serializable dicts (sys_ids as list, not set). For session persistence.

    8. **deserialize_sources(data: list[dict]) -> list[ExclusionSource]**: Reconstruct from serialized dicts (sys_ids back to set). Handle missing/malformed data gracefully (return empty list on error).
