Add the following methods to NliCrossrefService (in shared/nli_crossref_service.py):

**1. get_manchester_manifest_url(image_source_name: str) -> Optional[str]**
- Query: `SELECT luna_id FROM manchester_luna WHERE image_source_name = ?`
- If found, return IIIF manifest URL: `https://luna.manchester.ac.uk/luna/servlet/iiif/m/{luna_id}/manifest`
- If not found, return None
- Graceful degradation: return None if conn is None or table doesn't exist

**2. get_manchester_luna_id(image_source_name: str) -> Optional[str]**
- Query: `SELECT luna_id FROM manchester_luna WHERE image_source_name = ?`
- Return luna_id or None
- Used for constructing detail page URLs

**3. get_jts_manifest_url(shelfmark: str) -> Optional[str]**
- Strip leaf suffix from shelfmark: re.sub(r'\.\d+$', '', shelfmark) to get base shelfmark
- Query: `SELECT manifest_url FROM jts_dpul WHERE shelfmark = ?`
- Try base shelfmark first, then full shelfmark if base fails
- Return manifest_url or None

**4. get_jts_dpul_url(shelfmark: str) -> Optional[str]**
- Same base/full shelfmark logic as above
- Query: `SELECT dpul_url FROM jts_dpul WHERE shelfmark = ?`
- Return dpul_url or None
- Used for constructing catalog page links

- For `abbrev == "JTS"`:
  - Look up dpul_url via get_jts_dpul_url(shelfmark)

# 2a-manchester: if no external link yet, try Manchester LUNA manifest via crossref sidecar
if not ext_link and crossref_svc and crossref_svc.is_available():

    images_for_lib = crossref_svc.get_images(system_id)
    if images_for_lib:
        first_img = images_for_lib[0]
        img_source = (first_img.get('image_source_name', '') or '').lower()

                ext_link = manchester_manifest
                current_meta['external_url'] = ext_link
                current_meta['external_provider'] = 'manchester'

# 2a-jts: if no external link yet, try JTS Figgy manifest via crossref sidecar
if not ext_link and crossref_svc and crossref_svc.is_available():
