<task type="auto">
  <name>Task 1: Create Manchester LUNA bulk import script</name>
  <files>scripts/import_manchester_luna.py</files>
  <action>
Create scripts/import_manchester_luna.py following the pattern of import_nli_crossref.py:

1. **Table schema** -- Create `manchester_luna` table in nli_crossref.db:
   ```sql
   CREATE TABLE manchester_luna (
       image_source_name TEXT PRIMARY KEY,
       luna_id TEXT NOT NULL,
       url_size0 TEXT
   )
   ```
   With index: `CREATE INDEX idx_ml_luna_id ON manchester_luna(luna_id)`

2. **Bulk pagination** -- Paginate through ALL Manchester items using empty query:
   ```
   GET https://luna.manchester.ac.uk/luna/servlet/as/fetchMediaSearch?fullData=false&q=&bs=100&os={offset}&lc=ManchesterDev~95~2
   ```
   Start at os=0, increment by 100 each batch. Stop when response JSON array is empty.
   Expected ~290 pages (29K items / 100 per page). Use tqdm for progress.

3. **JRL filename extraction** -- For each item in the response array:
   - Get `urlSize0` field (e.g., `https://luna.manchester.ac.uk/MediaManager/srvr?mediafile=/Size0/ManchesterDev-2-NA/{folder}/{jrl_filename}.jpg`)
   - Extract the JRL filename from the URL path: split by `/`, take last segment, strip `.jpg` extension
   - Lowercase both the extracted filename and store as `image_source_name`
   - Get `id` or `identity` field as the `luna_id`

4. **Rate limiting** -- Add 0.5 second delay between API calls to be respectful.
   Use requests with timeout=30 and retry on 5xx errors (max 3 retries with exponential backoff).

5. **Idempotent** -- Drop and recreate table on each run. Update meta table version to "1.1.0" and add `source_manchester` key.

6. **Match stats** -- After import, query crossref to report match statistics:
   ```sql
   SELECT COUNT(DISTINCT i.NLI_AlmaId)
   FROM nli_images i
   JOIN manchester_luna m ON LOWER(i.ImageSourceName) = m.image_source_name
   WHERE i.LibraryAbbrev = 'Manchester'
   ```
   Print: total LUNA items fetched, matched to crossref, unmatched.

7. **Error handling** -- If nli_crossref.db doesn't exist, print error and exit.
   If LUNA API returns non-200, log warning and continue to next page.
   Save progress checkpoint every 1000 items (so script can be restarted).

8. **CLI interface** -- Use argparse with:
   - `--db-path` (default: nli_data/nli_crossref.db)
   - `--batch-size` (default: 100)
   - `--delay` (default: 0.5)
   - `--dry-run` (fetch but don't write to DB)
