    **1. Add `get_library_viewer_url()` to NliCrossrefService** (shared/nli_crossref_service.py):

    Add a new method that constructs a URL to the holding library's digital collection page for a given manuscript. This method queries the nli_images table for LibraryAbbrev and Shelfmark, then builds the URL based on the library abbreviation:

    ```python
    def get_library_viewer_url(self, sys_id: str) -> Optional[dict]:
        """Get holding library digital collection URL for a manuscript.

        Returns dict with keys: url, label, library_abbrev, library_name_eng.
        Returns None if no URL can be constructed.
        """
    ```

    URL construction rules (based on known digital collections):
    - `CUL` -> `https://cudl.lib.cam.ac.uk/view/{shelfmark_dashed}` where shelfmark is reformatted with dashes (e.g., "T-S 12.1" -> "MS-TS-00012-00001"). Use the existing cambridge_manifests table label if available (query by sys_id cross-join with nli_images shelfmark), or fall back to constructing from shelfmark.
    - `JTS` (via "Princeton" shelfmark patterns like "ENA...") -> `https://dpul.princeton.edu/catalog/{identifier}` -- this is complex and may not have a reliable URL pattern. For JTS, construct: `https://dpul.princeton.edu/geniza/catalog?search_field=all_fields&q={shelfmark_urlencoded}` (search-based fallback).
    - `Manchester` -> `https://luna.manchester.ac.uk/luna/servlet/detail/{collection_id}` -- Use search URL: `https://luna.manchester.ac.uk/luna/servlet/s/{shelfmark_urlencoded}`.
    - `BL` -> `https://www.bl.uk/manuscripts/FullDisplay.aspx?ref={shelfmark_urlencoded}`
    - `Oxford` -> Already handled by existing external_url from MARC. Skip (return None for Oxford since it uses a different path).
    - For all others, return None (no known digital collection URL).

    The method should:
    1. Query `SELECT DISTINCT LibraryAbbrev, LibraryNameEng, Shelfmark FROM nli_images WHERE NLI_AlmaId = ? LIMIT 1`
    2. Map LibraryAbbrev to URL pattern (CUL, JTS, Manchester, BL)
    3. Return `{url, label, library_abbrev, library_name_eng}` or None

    Place the method in the `# ── Metadata (Phase 32: META-01, META-02)` section, after `get_physical_metadata`.
