### New Risks (NOT raised in prior rounds)

- **HIGH** — **R97.3-A Cancel is not implemented.** Plan 03 tests folder-switch cancellation, not clicking `_btn_cancel`; `_on_cancel_clicked` at `desktop/my_library_tab.py:1669` still only handles the indexing worker `_worker`. The new `_tree_worker` has no cancel route. **Orchestrator verified:** `_btn_cancel.clicked.connect(self._on_cancel_clicked)` at line 880; `_on_cancel_clicked` body only touches indexing worker state. Remediation: add a tree-population cancel route from `_btn_cancel` and a Qt test that clicks Cancel while `_tree_worker` is running.
- **HIGH** — **`_tree_worker` lifetime can drop the last Python reference while a canceled QThread is still running.** `_cancel_existing_tree_worker` sets `self._tree_worker = None` immediately after `prev.cancel()`, but the worker thread may still be inside `os.walk` for a few hundred ms before noticing `_cancel_requested`. The `finished.connect(deleteLater)` wire keeps Qt alive, but losing the last Python reference is undefined behavior with PyQt6. Remediation: keep retired workers in a list (e.g. `self._retired_tree_workers: list`) until `finished_signal` fires, then remove and `deleteLater`.
- **MEDIUM** — **`_on_cancel_finished_drain()` calls `_refresh_folder_list_ui()` at `desktop/my_library_tab.py:1772`, but Plan 03 Task 5 does not invalidate `_prior_status_cache` before that refresh. Orchestrator verified line 1772.** Remediation: add `_on_cancel_finished_drain` as a sixth lifecycle site (alongside `_on_worker_finished`, `_on_worker_error`, reset, folder add, folder remove), or prove that path cannot affect displayed status.
- **MEDIUM** — D-16 says inaccessible subdirs are logged, but Plan 03 Task 2 uses `os.walk(..., followlinks=False)` without an `onerror=` callback, so scandir errors are silently swallowed. Remediation: pass `onerror=lambda e: logger.warning(...)`.
- **MEDIUM** — Junction test may skip on Windows CI if `mklink /J` is unavailable (developer mode / admin required). Remediation: add a static fallback assertion that `_os.walk(...)` is called with `followlinks=False` (AST-level grep) so the invariant holds even when the runtime test skips.
