<objective>
Extend the versioned `joins_lab` safe_storage schema (Phase-117 stub) to persist the full Joins Lab
working state — builder inputs, global toggles, other-side builder, `sys_id`-keyed triage, active
filter, and view mode — under the SAME `schema_version: 1`. Add `write_full_state()` /
`read_full_state()` with size-cap discipline and extend `clear_joins_lab_state()` to wipe the new
`puzzle_staging` key too. This is the de-risk substrate Wave 2's actions and restore ride on.

zero result blobs (avoids the 778 MB search_history bloat class of bug) and zero raw `app.storage.user`.
Output: extended `web/joins_lab_storage.py` + new unit cases in `tests/test_joins_lab_storage.py`.
</objective>
