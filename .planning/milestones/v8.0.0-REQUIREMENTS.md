## Future Requirements (carried beyond v8.0.0)
- **JOINS-F1** — relative-offset cross-line positional search (spike-gated).
- **JOINS-F2** — Dicta/Sefaria citation-ID completion source for canonical texts.
- **JOINS-F3** — batch export of suggestions + persisted personal candidate list with re-import.
- **JOINS-F4** — automated ranked join-finder (research-only; explicitly OUT of the human-in-the-loop product).
- **PERF-F1 / D-F12** — regular Search ~constant ~8s wall-clock (profile-first effort).

## Out of Scope (v8.0.0)
- Automated / auto-ranked join finder (human-in-the-loop by design → JOINS-F4).
- New search-engine modes (the Workbench rides the existing module).
- New index or sidecar (`line_starts` / `line_ends` already present).
- One-click scholarly citations (parked in `docs/FEATURE_IDEAS.md`).
- Relative-offset positional search (spike-gated → JOINS-F1).
