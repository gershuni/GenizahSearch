dialog now render an RTL-aware line-number gutter alongside the transcription
text. Numbers correspond 1:1 with `text.split('\n')` per D-10 (aligning with

button (`format_list_numbered` icon, tooltip `tr('Toggle line numbers')`)

`ui.show_line_numbers`. Default ON per D-07.

CSS-grid column with `user-select: none` and `-webkit-user-select: none`.
A user dragging text inside the body cell selects only body content; pasted
text contains zero line-number digits.

## Task 3 — human verification

Hillel ran the 8-step smoke-check protocol from PLAN.md against commit
`ba666564` (post Quick View wiring). Reported one issue: numbers were
misaligned with body text — visibly drifting downward as you went down
the manuscript.

Diagnosis: the original implementation used a SINGLE gutter span
(numbers separated by `\n`) and a SINGLE body div inside a 2-column
CSS grid. Two structural bugs caused the drift:

1. **Line-height mismatch.** Gutter had `font-size: 0.75em` with the
   same unitless `line-height: 2.2`. Unitless line-height multiplies
   the local font-size, so gutter row height = `0.75 × 2.2 × 1.4rem
   ≈ 2.31rem` while body row height = `2.2 × 1.4rem = 3.08rem`. Each
   gutter row was shorter than each body row → drift accumulated.

2. **Body-wrap drift.** `white-space: pre-wrap` on the single body
   div meant any long source line wrapped to two visual rows. The
   gutter still showed one number for that source line, but the body
   used two rows → offset by one visual row from that point on.

Fix (commit `9bde739e`): replaced the structure with a **per-line grid
row** layout — one `(<span>n</span>, <div>line</div>)` pair per logical
source line, all inside one CSS grid. If a body cell wraps, the row
grows; the gutter number stays anchored at the top via `align-self:
start`. Gutter `line-height` is now an absolute `calc({line_height} *
{font_size})` (matching body row height regardless of the gutter's
smaller font-size). Blank source lines reserve their row via
`min-height: calc({line_height} * 1em)`. All 12 tests still pass —
the test helpers iterate over multiple gutter spans via `findall` so
they handle either the single-gutter or per-row layout.

Smoke check re-approved by Hillel after `9bde739e`.
