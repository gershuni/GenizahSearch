## Intent disambiguation

Phase title was ambiguous between several plausible readings — asked the user to pin it down first.

| Option | Description | Selected |
|--------|-------------|----------|
| Display folio label on each result | Surface scholarly citation form ('1r', '2v') instead of raw page index |  |
| Group results by manuscript, list folios inside | Collapse multiple hits from the same shelfmark into one card |  |
| Sort matching folios within a manuscript in folio order | Sub-sort within a shelfmark group |  |
| Filter / pagination by folio | "Next matching folio" navigation |  |

**User's choice:** "Very simple: show the folio number in search results (it is in desktop but not in web)."
**Notes:** Strict desktop-parity scope. The other three interpretations went into Deferred Ideas as candidate future phases.

## Label format

| Option | Description | Selected |
|--------|-------------|----------|
| "Folio N" (translatable via tr()) | Matches user's phrasing; Hebrew users see 'דף N'. (Recommended) |  |
| "Page N" / "p. N" | Matches Quick View's existing "Page X/Y" label |  |
| "Img N" (verbatim with desktop column header) | Strict desktop column-header parity |  |
| Just the number, no prefix | Compact: small badge / inline number | ✓ |

**User's choice:** Just the number, no prefix.
**Notes:** Keeps the title line uncluttered — the shelfmark stays primary; the number sits beside it as a small inline secondary indicator.

## Claude's Discretion

- Separator character between shelfmark and number (`·` middle dot, em dash, parentheses, thin space).
- Font weight / color of the number — must not visually compete with the bold shelfmark in `var(--primary-700)`.
- Whether to render anything when `display.get('img')` is empty (decision in CONTEXT.md D-02: render nothing).

## Deferred Ideas

- True folio labels ('1r' / '2v') instead of raw image numbers — requires per-library folio resolution.
- Group results by manuscript with folios listed inside the card.
- Sort matching folios within a manuscript in folio order.
- Folio-based pagination / "next matching folio" navigation.
- Add the same indicator to parallels / composition result lists.
