## v8.4.1 Requirements

### Public API

- [x] **DMF-11**: The public API `POST /api/search` and `POST /api/parallels` accept an optional library-filter **mode** (`include` / `exclude`) alongside `filters.library`, so programmatic callers can express "hide these libraries" as well as "only these". Backward-compatible: an omitted mode defaults to **include** (the current allowlist behavior, byte-for-byte); **exclude** resolves to the complement (sys_ids whose `library_code` is not in the given set) intersected into `restrict_sys_ids`. Invalid mode → 400 `invalid_request`. Documented in `docs/SEARCH_API.md` + the skill `api_contract.md`; skill clients gained first-class `--library` / `--library-mode`. — Complete (Phase 132; live-verified)
