# Milestone v5.7.0: Responsa Search

**Status:** SHIPPED 2026-02-10

## Overview

Added Responsa Project-style advanced search to both web and desktop apps -- syntax parsing with wildcards, grammatical prefix/suffix expansion, Judeo-Arabic article forms, flexible spacing, bidirectional gap search, tabular query builder, and combinatorial explosion guards.

## Milestone Summary

**Key Decisions:**
- Option II (Hybrid Integration) for core engine: Tantivy OR groups + Regex patterns
- Responsa as first-class dropdown mode (not separate checkbox row)
- `#` conflict: Responsa ON = all prefix shortcuts OFF
- Simplified Judeo-Arabic: always 'al' (no sun letter assimilation) -- 8 forms per word
- 6-step explosion guard cascade (MAX_EXPANDED_TERMS=500)
- Flex spacing: basic + advanced on original terms only
- One-way sync: tabular builder -> text field only
- Desktop: QDialog for tabular, web: dialog (evolved from expansion panel)

**Issues Resolved:**
- Flex Spacing + Tantivy integration (split alternatives added)
- Sofit letter conversion before suffix expansion
- Combined operators (#% and %#) in any order
- R+Space shortcut sub-options visibility
- WebSocket crash on large Responsa results (200 cap)
- Explosion guard cascade expanded from 3 to 6 steps
- ValueError surfaced to user via ui.notify

**Issues Deferred:**
- Phase 13 (Transcription Search) -- needs server-side index architecture
- Desktop QSettings persistence for Responsa checkboxes
- Per-component search modes (Option III)
- Bidirectional tabular<->text sync
- `\s*` per char on variant/JA expansions

**Technical Debt Incurred:**
- Phase 14 missing formal VERIFICATION.md (verified downstream by phases 15-17)
- Performance benchmarks skip without Genizah_Index (manual verification recommended)
- 13 pre-existing test failures (not regressions)
