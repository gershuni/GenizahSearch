## Milestone Summary

**Key Decisions:**
- Regex mode exempted from diacritics stripping (users control their regex patterns directly)
- Flex-spacing patterns not wrapped with mark tolerance (custom regex where marks would confuse semantics)
- Used stdlib HTMLParser for PGP canvas parsing (no external dependency)
- Sections stored as JSONB per-source (not per-document) for multi-scholar support
- Author_slug matching for per-source section import (prevents cross-source contamination)

**Issues Resolved:**
- 17 pre-existing test failures across export, boundary search, responsa, and shelfmark tests
- 3 obsolete backend test files from pre-Supabase era removed
- PGP section regex missing 712 marker variants (fixed with structured alternation)
- Import script broadcasting one HTML file's sections to ALL sources per PGPID (fixed with author_slug matching + validation guard)
- Desktop translation ordering inconsistent with web app (fixed with language-based grouping)

**Issues Deferred:**
- Recto/verso section headers stripped during parsing (v1 tech debt, not blocking)
- NORM-05: Intentional diacritical mark search (needs UX design)
- Transcription search (Phase 13, needs server-side index architecture)

**Technical Debt Incurred:**
- None significant
