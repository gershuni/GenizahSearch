## What the gates and reviews caught

**Six adversarial Codex rounds** (four pre-merge, two on the PRs). The ones that mattered
were invisible from inside the change: the workbook build running on the event loop of a
single-worker server; `request.base_url` — a client-controlled header — baked into every
link of a file that outlives its request; a capped total still bounding the export walk,
where the code contradicted its own comment; and `$` in the token regex accepting a
trailing newline, which turned a finished workbook into a 500.

**CI caught a regression no local run could.** The export added `slot` to `_run_off_loop`;
three hand-written test doubles kept the old signature and raised `TypeError` for reads
unrelated to the export. They live in files this work never touched, and the full local
suite segfaults partway. A tripwire now pins the keyword set and names all three doubles.

**38 mutations watched red by name**, with a residue scan the run cannot skip. Three of
them found gates that could not fail:

- **M13** — the credit test compared a constant against cells built from that constant.
- **M24** — green over a FALSE SENTENCE, not merely an unwatched line. The About sheet
  asserted "some rows… appear at the end" for all three causes of a degraded grouping,
  two of which place every row; and a capped group count was printed as a count.
- **M36** — green because the fix's own safety net masked it. `fullmatch` and the
  defensive `try/except` produce identical headers, so the gate now records whether the
  cookie layer is TOUCHED, with a positive control.

**The harness itself was hardened.** An interrupted run had left a mutation applied in the
working tree — the very defect the owner had reported. The restore state now lives outside
the process, proven by driving the harness's own repair through an `os._exit(9)`.

## Knowingly open

1. **The retro-plan** — built inline, no PLAN/SUMMARY pair. Phase 140 SC1.
2. **A pre-existing cross-file test failure.** Measured, not assumed: 6 failed / 609
   passed on the base versus 5 failed / 613 passed with this work. It reproduces in 2.2 s
   from merely IMPORTING the render-smoke findings module with its tests deselected, and
   the failing set varies between runs.
3. **The concurrency-slot leak** — harness-only (production has one long-lived loop, so
   the release callback always fires), pre-existing, worked around in the sweep and left
   unfixed by owner decision on 2026-08-21. Fixing it properly means replacing the
   budget's `asyncio.Semaphore` with a loop-independent primitive.
4. **`sanitize_text_for_excel` drops characters above U+FFFD** — pre-existing behaviour of
   the shared sanitizer that every export in this repository has; the live artifact
   contains none.
5. **Capping the matched passage itself** was offered and declined-by-silence: the context
   is already 90 characters a side from the bake and a quarter of the spans arrive
   `⋯`-abbreviated upstream, so cutting further means cutting matched text.
