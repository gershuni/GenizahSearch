<objective>
Ship PANEL-03: an on-demand evidence view showing the supporting span from our own manuscript text
with its match statistics, and — where the per-work licence permits — the matched passage of the
reference work beside it.

Purpose: today the reader sees a claim and must trust it. The evidence view is what lets a scholar
judge one. The two rendering defects are already solved as pure functions; this plan wires them into
the browse text render slot, which is the one place they can collide with search-term highlighting,
and adds the licence-gated reference side.
Output: the evidence component, the render-slot integration, and its render-smoke suite.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored offsets → rendered manuscript text | The evidence view is the surface that most directly asserts "this is the matching passage" |
| licence flag → rendered third-party text | A gate failure republishes someone else's edition without permission |
| one render slot → two highlight kinds | The collision point where a silent overwrite is possible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-23-01 | Tampering | Cross-site scripting through unescaped page text in the highlight | mitigate | Slice-then-escape in the shared renderer; render-smoke asserts special characters before the span are escaped and the span is still correct |
| T-136-23-02 | Spoofing | A stale span shown after the snapshot changed | mitigate | Per-side fail-closed drift check; highlight dropped on source switch; both asserted through the surface |
| T-136-23-03 | Elevation of privilege | Reference text rendered for a work without permission | mitigate | Licence gate asserted through rendered output with a positive control that fails when seeded permissive |
| T-136-23-04 | Information disclosure | A restricted locus or corpus name in the evidence view | mitigate | Masking assertion over rendered output in both languages with a seeded positive control |
| T-136-23-05 | Tampering | Search-term highlighting silently lost when a discovery span is active | mitigate | One co-render call; regression test for the search-only path and a co-existence test |
| T-136-23-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs |
