<objective>
Build the pure rendering primitives PANEL-03 needs, correctly: normalized→raw offset mapping,
per-line clipping, slice-then-escape, term co-rendering, and the per-work licence gate over
reference text.

Purpose: two defects were verified against the real asset. Stored offsets index the normalized
Hebrew-letter stream, so slicing raw text at them ends a highlight 652 characters early on a sampled
manuscript. And the line-number gutter splits highlight HTML on newlines, so a single span crossing
one leaves an unclosed tag in one row and no highlight in the middle rows — done correctly 72 of 148
grid rows highlight, done naively exactly 1, silently. The existing search-term helper escapes the
whole string first and then substitutes terms, so it cannot consume offsets at all.
Output: two pure, dependency-light shared modules with tests that assert the wrong answers are wrong.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored offsets → rendered HTML | An offset applied to the wrong stream highlights the wrong text and asserts something false |
| third-party licence flag → rendered copyrighted text | The gate decides whether someone else's edition is republished |
| raw page text → HTML | Slicing before escaping is correct but makes escaping order load-bearing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-136-17-01 | Tampering | Cross-site scripting via unescaped page text in the highlight output | mitigate | Every one of the three parts is escaped after slicing; a test asserts `&` and `<` before the span are escaped and the span is still correct |
| T-136-17-02 | Spoofing | A highlight over the wrong characters presenting as evidence | mitigate | Mapping test asserts both the right answer and that the naive answer is wrong; drift check withholds rather than showing a stale span |
| T-136-17-03 | Elevation of privilege | Reference text rendered for a work with no clear permission | mitigate | Exact-match licence gate, fail closed on absence, attribution required where the licence requires it |
| T-136-17-04 | Information disclosure | A restricted locus or corpus name reaching a rendered string | mitigate | Reference module never returns them on any path; fuzz test over malformed input; masking scan on the module |
| T-136-17-05 | Spoofing | A stated matched-letter count larger than what is highlighted | mitigate | Multi-span marker so the surface can qualify the label |
| T-136-17-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs; stdlib `html` and `unicodedata` only |
