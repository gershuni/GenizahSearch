<objective>
Extend the read spine so the panel can be built: a status envelope that tells an outage apart from
a genuine zero, the display fields the rows need, the manuscript-scope query that names works, and
a correctly-defined related-page count.

Purpose: today's wrappers collapse timeout, overload, absent sidecar and genuine zero all to an
empty list. Only about 17% of manuscripts carry claims, so hiding the entry control on a TRUE zero
is right — but hiding it during an outage, as though the manuscript had nothing, is not. Separately,
the routing filter drops 19 of 121 human-confirmed rows before the predicate meant to protect them
ever runs: two rows a human confirmed, treated differently, on the same manuscript.
Output: envelope wrappers, a fixed query, and the panel's data contract.
</objective>
