<objective>
Turn the stored work-side offsets into something a scholar can act on: a human reference for
Sefaria works (75% of claims), an approximate position for JA, and nothing at all for M-source —
plus the per-work licence metadata that decides whether the matched passage may ever be rendered.

Purpose: an unlocatable citation is close to worthless. The Sefaria mapping already exists as 322
`*.versemap.json` sidecars with verse-level character offsets. But the versemaps index the readable
BODY while the matcher indexes the normalized stream — two coordinate systems that do not agree.
This is the same trap already found and solved on the manuscript side; it must be budgeted on the
work side too.
Output: a new resolution module, ingested reference strings and licence flags, and round-trip tests.
</objective>

  <action>
    Create `scripts/discovery_workref.py` with three pure, dependency-light functions.

    `build_body_to_norm_map(body_text)` — returns a mapping from body character index to
    normalized-stream index, and its inverse, both deterministic functions of the same source text.
    Both normalizations are deterministic, so this is mechanical; state in the docstring which
    normalization each side applies and that neither may be changed without regenerating every
    stored reference.

    `resolve_reference(versemap, norm_offset, inverse_map)` — maps a `norm_stream` offset back to a
    body offset, then binary-searches the versemap's `start`/`end` ranges to return the covering
    record's `ref` string. Handle all three structures — `verse` (295 files), `hierarchical` (25),
    `flat` (2) — and return None rather than guessing when the offset falls outside every range.

    `approximate_position(w_start, work_norm_length)` — returns a coarse position descriptor for a
    work with no divisions to map, expressed as a fraction of the work, for the JA display tier.
    This function must not produce anything resembling a canonical citation: a synthetic address
    that looks canonical but is not would be worse than none.

    Write the tests alongside: a round-trip per structure type (a known passage's offsets resolve
    back to its known reference), and a mapping test on a work containing maqaf and nikud — the two
    cases the two normalizations treat differently, and therefore the two cases most likely to
    silently drift.
  </action>
