## Goal

Productize Yehuda Seewald's external prototype (`seewald_addition/`) as a first-class in-app desktop feature: users can point GenizahSearch at a folder of `.docx` / `.pdf` files and have those documents indexed into the desktop app's existing Tantivy + libraries.csv search machinery, so personal corpora surface inline in normal search / Composition Search / Parallels results with a clear `LOCAL` badge and a per-search opt-in toggle.

Explicit non-goals: no second installation, no `Program Files` UAC patching of the shared `libraries.csv`, no shared sys_id namespace with NLI / PGP / CUDL data, no web / API / Supabase exposure of indexed local documents.
