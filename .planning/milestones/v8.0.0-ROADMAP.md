# Milestone v8.0.0: Dicta Rebrand & Joins Lab

**Status:** ✅ SHIPPED 2026-06-09
**Phases:** 103, 105 (folded from the v7.17 cycle) + 106-110 (Joins Lab Component A). Phase 104 deferred → EXP-F3 (delivered in Phase 110).
**Total Plans:** 31 formal plans (35 completed plan-equivalents incl. 108 redesign/polish + 109 gap rounds)

## Overview

The flagship **v8.0.0 "Dicta Genizah Search Pro"** release. Bundles the delivered v7.17 cycle — the
desktop **rebrand** (display-only; binary identifiers unchanged so installs upgrade in place) and
LOCAL ("My Library") **export** support — with the new **Joins Lab**: an interactive,
**human-in-the-loop** join-hunting workbench (desktop) where a scholar keeps one anchor fragment in
view (image + numbered transcription) and drives the app's **existing** search tools to find the
fragments that physically join it. There is NO automated join-finder — the scholar is the ranker and
confirmer. Also adds **Composition Search over the Local corpus** (Genizah/Local/ALL selector
orthogonal to Lab mode) + LOCAL-aware composition export (EXP-F3).

Web Joins Lab UI is deferred to a later phase on the same shared Phase-106 API (desktop-first per the
Codex productionize critique). All of **Component B** (search-support algorithms JSA-01/02/03 + the
JWB-05 tear-side assist) was deferred to a post-v8.0.0 milestone (2026-06-08, /gsd-discuss-phase 110)
so the milestone could ship.

**Git range:** `v7.16.0` → `v8.0.0` (328 commits) · **Scope:** 266 files changed, +55,320 / −785 ·
**Timeline:** 2026-06-01 → 2026-06-09 (9 days).

## Milestone Summary

**Decimal Phases:** none in v8.0.0.

**Folded cycle:** the v7.17 cycle (Phases 103 + 105 + the BRAND rebrand, delivered) was folded into
v8.0.0 per the 2026-06-02 user decision rather than tagged as its own milestone. No `v7.17` tag exists.

**Key Decisions:**
- Ship the rebrand + Joins Lab + LOCAL composition together as the flagship **v8.0.0** (resolved 2026-06-01; folds v7.17).
- Desktop rebrand is **DISPLAY-only** — binary identifier `GenizahSearchPro` (exe/.spec/.iss/dist/auto-update) UNCHANGED so installs upgrade in place; web brand "Dicta Genizah Search" unchanged.
- Joins Lab is **human-in-the-loop** — the auto-ranked v7/v8 finder is explicitly OUT (JOINS-F4).
- **Extract pure logic first** (Phase 106 shared core, web-reusable, `SearchExecutor` adapter, no PyQt / no direct `fist_data`), desktop UI on top, web UI deferred — per the Codex productionize critique.
- Join model reuses the existing **pairwise→group BFS** (`JoinsManager.get_connected_fragments_by_id`); no new schema.
- VS merged INTO the candidate surface; standalone VS dialog soft-retired (one-cycle deprecation; physical deletion deferred to a cleanup phase).
- **Component B deferred in full** (JSA-01/02/03 + JWB-05) to a post-v8.0.0 milestone (2026-06-08); Phase 110 repurposed to the LOCAL-composition wiring + EXP-F3 the user wanted before release.
- Standard LOCAL composition uses the REGULAR My-Library index, NOT the LAB side-index (LAB = opt-in only).

**Issues Resolved:**
