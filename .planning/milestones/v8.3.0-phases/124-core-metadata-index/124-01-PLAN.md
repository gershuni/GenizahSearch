- **TWO atomic git commits.** Forced order: `metadata_manager` FIRST (Task 1, includes the GUARD-03

  class's commit — there is no separate Wave 0 commit.

  command: `GITHUB_ACTIONS=true QT_QPA_PLATFORM=offscreen pytest tests/ -q` — set the two env vars to
  avoid the PyQt6 headless segfault, and do NOT use `-n auto` (it OOMs loading Tantivy per worker).
  The per-commit fast gate (<60s) is:
  `GITHUB_ACTIONS=true QT_QPA_PLATFORM=offscreen pytest tests/test_no_back_edges_core.py

  breaks every `from genizah_core import …` caller (Pitfall 8). Use ONLY per-file
  `python -m ruff check <file>` on each new module + `genizah_core.py` before committing.

  per-file `ruff F401` (catches EXCESS imports) + full-suite-green-at-every-commit (catches MISSING
  imports, including method-runtime NameErrors that a bare `import shared.X` smoke test will NOT
  surface because the NameError only fires when the method RUNS). A bare standalone-import smoke test
  is necessary but NOT sufficient — the full suite is the real catch for missing `time`/`json`/`re`.

  `grep -n "class MetadataManager"` / `grep -n "class Indexer"` / `grep -n "_CUDL_LABEL_RE"`, etc.,
  then Read that range.
- **The same-object shim recipe (proven Phase 122/123):** (1) copy the implementation VERBATIM into
  the new `shared/X.py` (GUARD-01-clean: NO module-level `import genizah_core` / `from genizah_core
  import …`); (2) in `genizah_core.py` REPLACE the original code with `from shared.X import …
