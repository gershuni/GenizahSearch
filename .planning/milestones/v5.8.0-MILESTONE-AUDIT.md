## Tech Debt

### Phase 27: Domain Classifications
- **UX improvement:** Browse-to-search domain navigation (`/search?domain=X`) clears exclusions but doesn't auto-trigger a domain-filtered search. User must manually search. This is a UX polish item — the navigation works, the domain parameter is received, but the search isn't auto-started.
- **Unused method:** `get_all_domains()` exists in FjmsService but `get_domain_hierarchy()` is preferred everywhere (provides richer parent/child structure + counts).
